# 表格录入与 Excel 导入

原有“新建商品 / 新建资料”和每行“编辑”保留，适合针对性修改。新增表格入口适合集中建档和批量修改；两种方式使用同一套业务数据、权限和审计记录。

## 使用方法

1. 主数据页面点击“表格编辑 / Excel 导入”，表格载入当前列表页的记录。可以直接修改单元格，或“添加行”建档。
2. 点击“下载模板”，按模板整理 Excel；也可以直接导入自己的文件，在预览窗口匹配各列。
3. 支持 `.xlsx` 和 UTF-8 `.csv`，每个文件最多 5 MB，每批最多 500 行。旧 `.xls` 请先另存为 `.xlsx`。多工作表文件可选择工作表。
4. 从 Excel、WPS 或飞书复制多行多列，在目标单元格粘贴。Tab 连续横向输入，Enter 纵向移动；支持复制行、撤销和重做。
5. 点击“检查数据”，修正红色单元格，再“保存表格”。逐行显示成功和失败数量，失败行保留供修正重试。

表格修改需点击保存才写入系统，并非每个按键自动保存。主数据导入追加为新记录，不自动按编码覆盖已有资料；修改已有记录请编辑载入的行。重复编码会被业务校验拒绝。“移出选中行”只移出本次编辑内容，不删除数据库记录。

编码按文本保留前导零；关联资料可使用编码或完整下拉选项，重名不能唯一匹配时需使用编码。请先建立供应商、仓库、品类等关联资料，再导入商品和 SKU。公式单元格需先在 Excel 中粘贴为值。

## 页面范围

| 页面 | 表格方式 | 原有单条方式 |
|---|---|---|
| 商品、SKU、供应商、仓库、品牌、品类、颜色与尺码映射 | 批量新建、编辑、Excel 导入 | 全部保留 |
| 采购订单 | 单张采购草稿的多行明细录入、导入与修改 | 供应商/仓库表单及逐条明细保留，可切换 |
| 入库 | 按采购明细匹配批量填写到货数量、修订未过账单据 | 原有数量填写保留，可切换 |
| 库存 | 批量提交库存变化数量、原因和说明 | 单笔库存调整保留 |
| 采购建议 | 当前页待确认建议的采购量编辑与确认 | 单条确认、忽略保留 |
| 用户、角色 | 已有用户的姓名/状态、角色名称批量编辑 | 新建、角色分配、权限和密码操作保留原入口 |
| 各数据列表、库存流水、审计 | 导出当前页 Excel | 流水、审计和已过账单据仍只读 |

库存“变化数量”是增减量，不是盘点后的绝对库存。采购明细导入属于当前单据，不会自动把多个供应商拆成多张订单。采购建议表格保存会确认表内待处理行；调整建议量仍须填写原因，未接入真实销量时不会凭空生成建议。

## 保存与边界

- 批量主数据/库存调整逐行提交，每行独立事务；不是整份文件原子回滚。成功行不再重复提交，失败行可修正重试。
- 网络异常导致结果不确定时，该行锁定为原提交内容，直接重试确认结果，避免已保存但响应丢失时重复调整库存。
- 未保存编辑关闭时会提醒。主数据批量修改带更新时间检查，冲突时须刷新重新编辑，避免覆盖其他操作的新值。
- 采购、入库继续使用原有单据版本、确认、过账、幂等、权限与审计规则；不能直接编辑库存余额或历史流水。
- 用户资料表格只提交改变的资料字段，不重写角色与权限分配。
- 提供业务录入所需的表格交互，不包括公式计算、合并单元格、多人实时协作光标或完整办公表格功能。
- 本次无需数据库结构迁移，不改变已有记录或管理员密码。
