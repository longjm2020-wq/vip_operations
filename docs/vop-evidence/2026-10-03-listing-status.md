# 商品上下架状态接入与竞品浮动卡片 · 2026-10-03

## 核验范围

用户授权「接入后上线」。官方 `SalesVopService-1.0.0.queryConsignmentBarcodeListingInfo` 文档及测试工具的原始 HTTP/Java 示例已在浏览器读取。请求字段是 `req_context.vendor_code` 与 `barcode_listing_req.barcode_list`；方法不要求OAuth。响应按小写条码键关联，200的0/1表示下线/上线，404表示不存在，500表示未发布。原始 HTTP 示例将最后变更时间标为毫秒时间戳；保留长数值，对非零但不能验证单位的值提示待核对。

官方来源：[商品状态查询](https://vop.vip.com/home#/api/method/detail/com.vip.somp.sales.backend.service.SalesVopService-1.0.0/queryConsignmentBarcodeListingInfo)、[官方测试工具](https://vop.vip.com/apicenter/test?serviceName=com.vip.somp.sales.backend.service.SalesVopService-1.0.0&methodName=queryConsignmentBarcodeListingInfo)。未在测试工具输入应用密钥。

## 实现

新增042迁移、独立状态表与后台任务。使用现有签名连接，只读核对本库已采集档期条码。每批50条、每次最多10批；每小时重新核对，失败、过期或缺失的状态不冒充下线。款号状态仅汇总本库的条码，不能声称覆盖VC完整商品目录。新增分页状态筛选和单独更新商品状态按钮；未操作平台上下架，也未改动ERP库存、报表或邮件开关。

竞品四张分布图的前10款卡片：图片独立按钮，悬停120像素预览，点击放大；下方文字链接显示款号、特卖价和完整详细材质，缺失材质明确标注未公开。长文本换行并支持内部滚动，手机端三列显示。点击文字在新标签页打开商品详情。

本次扩展已有唯品会接入与竞品模块，更新手册19、33，无新增顶层模块，因此共享 `coreFeatureSummary` 保持现有内容。
