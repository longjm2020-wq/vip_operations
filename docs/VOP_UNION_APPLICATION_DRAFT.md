## 已核实的接口能力

官方服务：`com.vip.adp.api.open.service.UnionGoodsV2Service`，版本 `2.0.0`。

| 需求 | 官方接口与合同 | 尚需确认 |
| --- | --- | --- |
| 品牌销量排序 | `queryByBrandSn`；`fieldName=SALES`、`order=1`、`page=1`，`pageSize` 最大50 | 全品牌查询需要额外权限；排序范围和周期是否与目前网站品牌销量榜一致 |
| 商品资料 | `GoodsInfo` 包含商品 ID、货号 `sn`、价格、图片和落地页 | 七个目标品牌的可访问范围，以及后台任务和 `openId` 使用规范 |
| 材质、季节、规格 | `getGoodsBasicInfo`；一次最多50个商品 ID，返回 `propsList` 属性名称/值 | 实际商品是否返回完整成分、部位与百分比；缺失不能从标题补造 |
| 非个性化价格 | `goodsPriceScene=2` 表示全人群可用价，不计算可用券 | 与当前页面“特卖价”的口径核对，不直接混合来源 |

依据：[品牌查询官方文档](https://vop.vip.com/home#/api/method/detail/com.vip.adp.api.open.service.UnionGoodsV2Service-2.0.0/queryByBrandSn)、[商品资料官方文档](https://vop.vip.com/home#/api/method/detail/com.vip.adp.api.open.service.UnionGoodsV2Service-2.0.0/getGoodsBasicInfo)、[官方 SDK 下载](https://vop.vip.com/doccenter/viewdoc/20)。仅阅读官方 Java SDK `20260828092330` 源码，未执行下载的 SDK；原始 ZIP 的 SHA256 为 `5E24BBCB7CB92FCB3D1291FA8720B7153F2B34101976DC0C1F0F58D80AF3A32C`。

`GoodsBasicInfoResponse.goodsId` 为 Long，应保留其原始十进制标识，不能先转换为不安全的 JavaScript Number；品牌查询的 `goodsId` 和请求 `goodsIds` 为字符串。`propsList` 的元素包含 `name`、`value`、`optsList`、`propCode`，不保证所有商品属性齐全。`SALES` 的排序合同不能单独证明它等同于现有页面榜单或实际成交件数。
