# 项目管理

## 入口与流程

侧边栏「项目管理」包含「操作流程 SOP」「新建项目」。内置运营岗位的商品周上新七环节模板。模板中尚待补充的环节以可编辑交付要求呈现，不自动连接库存写回或商品发布。

1. 创建或选择岗位 SOP。管理员可维护所有模板，其他人员只能创建自己岗位的模板、编辑本人建立的模板。运营/商品、买手、客服、仓储、财务按系统角色对应。已发布项目保存独立流程快照，不随模板编辑改变。
2. 新建项目，选择标签、协作人、项目起止日期和一个或多个 SOP。支持描述加粗、斜体、列表、预览与200字摘要展开。
3. 按 SOP 生成任务后，打开「任务设置」逐格编辑、粘贴 Excel 内容或导入工作簿。填写接收人、岗位、接收日期、交付日期和下一流程接收人；甘特图由表格日期生成。可以额外填写产品需求，添加多个相似热销款参考卡片，图片必填，可上传600KB以内的 JPG/PNG/WebP 或输入 HTTPS 地址。
4. 草稿可不完整，仅发起人与管理员可见。发布时要求项目名称、协作人、日期、SOP和任务完整，每个流程环节至少一项任务。协作人收到站内项目卡片通知。
5. 当前任务接收人提交交付结果，下一流程接收人通过或驳回。驳回必须填写原因，可修改后重提。前序环节未全部验收时不能执行后序任务。所有任务验收通过后项目自动完成。发起人/管理员可代办验收并留下审计记录。
6. 勾选单个或多个任务，点击「沟通选中任务」打开右侧群聊，自动 @ 任务接收人和下一流程接收人；也可手选其他项目成员。协作人可以添加其他协作人员。消息仅在本系统内发送，不接入企业微信/飞书/微信。
7. 作废需要原因，保留项目、任务与沟通记录。已完成/作废项目不再编辑。消息分页加载历史，通知支持已读。

## 权限、存储与运行

SOP 编辑默认采用宽屏画布。右上角「编辑设置」展开右侧面板，合并名称、归属岗位、说明和环节内容编辑；面板默认收起，关闭面板保留当前草稿，点击「保存模板」持久保存。

SOP 支持分支无限画布：拖动空白平移、滚轮缩放、拖动卡片调整位置；编辑模板时从右侧输出圆点拖到目标左侧输入圆点，也可依次点击两端连接。点击连线后可删除。位置与连线随“保存模板”一起保存。多个出边表示并行，汇合节点等待全部入边环节验收完成。禁止自连接、重复连接与循环；驳回仍通过任务状态处理。断开全部入边的节点可独立启动。

旧模板及旧项目未记录连线时仍按原有顺序解释。新建项目快照保存节点位置和前置依赖，已发布项目不会因后续修改模板而变更执行规则。此更新无需数据库迁移。启用分支后不可回退到只识别顺序的旧版任务执行代码，否则会丢失并行语义。

迁移 `005_projects.sql` 新增 SOP、项目、成员、群聊、通知表，并建立 `project.read`、`project.create`、`sop.manage` 权限。现有岗位获得项目协作权限，同时增加商品、客服、财务岗位供管理员分配；不会创建人员账号或修改密码。项目内容由成员关系进一步隔离，草稿仅发起人与管理员可见。

数据库事务包含数据修改、站内通知、审计和幂等结果。任务/项目修改使用版本号，旧版本写入返回冲突。富文本以安全文本标记存储并由 React 渲染，不执行 HTML。图片随项目数据保存于 Postgres，备份项目时一并保存；单次请求上限8MB。项目详情只在版本变化时重新读取，避免包含图片的详情反复传输。群聊开启时5秒检查消息，站内通知15秒检查，关闭浏览器仍保留未读通知。

业务边界：流程验收是项目协作状态，不会自动进行商品建档、采购确认或库存变更；这些业务操作继续使用已有模块及权限。

## 验证与回退

`pnpm typecheck`、`pnpm lint`、`pnpm build`、`pnpm exec tsx tests/integration/projects.ts`（独立临时数据库），以及原有业务集成测试。验证草稿隔离、岗位权限、发布、通知、交付/驳回/重提、流程顺序、并发冲突、关联任务自动@、幂等、邀请、终态、迁移幂等及审计。

Railway API 部署前运行既有数据库迁移命令。无需增加环境变量或新服务。回退应用代码时保留新增表，后续重新上线即可继续访问记录；不要删除生产项目表。
