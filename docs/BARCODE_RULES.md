# 公司商品条码规则

来源：用户提供的《条码编码规则.xlsx》，2026-09-13 读取。工作表“条码生成规则”与“sheet1”。原文件未修改，商品记录未导入业务数据库。本文件补充既有规格；以下区分文件明确规则、样本观察与待确认设计。

## 已明确的编码规则

条码 = 款号 + 三位颜色代码 + 三位尺码代码，直接拼接，无分隔符。说明中的 X 表示组合关系，不是另加的字符；款号本身含有的 X 必须保留。

原表例：`H361X28886` + `009`（咖色）+ `004`（L）= `H361X28886009004`。

颜色代码和尺码代码必须作为字符串保存，保留前导零。款号保持原值，不按固定长度截断；不能按 X 分割。编码规则没有提供款号内部各段含义，也没有指定条码打印制式、校验位或 VOP 字段。

尺码字典：XS=001，S=002，M=003，L=004，XL=005，2XL=006，3XL=007，4XL=008，5XL=009，F=010。F 的业务含义未另行解释，不自动替换名称。

颜色字典共 65 项，代码为 001–065；完整原值见 [分析数据](barcode/workbook-analysis.json)。不得把近似名称自动合并，例如粉红色/粉色、兰色/蓝色、桔色/橘色。

## 全表核验结果

“sheet1”第 2–1516 行共 1,515 条记录，373 个款号，413 个货号，1,515 个不同条码。

- 全部货号符合“款号 + 三位色码”。这是样本中一致体现的关系。
- 全部条码符合“货号 + 三位尺码代码”。
- 全部色码存在于规则字典，全部尺码代码与记录中的尺码名称对应。
- 本表条码无重复；不能据此推断全公司的历史数据一定无重复。
- 有 99 个不同的“实际颜色名称 + 色码”组合，其名称不等于字典名称。这是名称差异，不直接认定为错误。

## 颜色名称与代码的区别

原表“花色”同时对应 025（K27/L27）与 044（K46/L46），不能按名称得到唯一代码。

历史商品存在实际颜色名称：例如 sheet1 第 2 行“烟雨灰”使用 003（字典为灰色），第 8 行“泼墨”使用 004（字典为米色）。还有花型名称。不得依据字典名称覆盖实际颜色名称，也不得从名称推测并重编历史条码。

建议在界面分开呈现“编码色码及参考名称”和“商品实际颜色名称”。新建时明确选代码，历史导入时按原条码及货号核验，并保留原名称。

## 对现有项目的影响及开工顺序

1. Product.styleNo 对应款号；SKU.colorCode、sizeCode 保留三位编码；SKU.colorName 保留实际名称；SKU.barcode 对应完整条码。
2. 货号表示款色维度，多个尺码共用，不能映射到现有要求唯一的 SKU.skuCode。建议增加明确的款色货号字段或派生展示；是否让 SKU.skuCode 与 barcode 相同仍需业务确认。
3. 先实现独立的字典、编码生成与校验函数，再连接 SKU 表单的条码预览；后端必须重复校验。不得只依赖前端。
4. 引入强制校验或唯一约束前，扫描现有数据库，列出冲突与旧编码。数据库迁移新增文件，不修改已应用的 001 migration；不得静默重编现有 SKU。
5. 导入此表前先做预览与错误报告。该表没有完整商品名称、品类、供应商等建档资料，不能擅自补造，也不能生成库存或采购单。
6. VOP Adapter 仍独立；公司的条码规则不证明任何 VOP 字段名、权限或平台校验规则。

## 待确认事项

- 新建商品的花色代码 025 与 044 如何选择；是否均有效。
- SKU 编码是否直接使用完整条码，还是与条码分别维护。
- 同款、同色码、同尺码能否存在多个 SKU；重复条码如何处理。当前样本不能替代全量历史政策，原 B02 不能仅凭此表完全关闭。
- 历史例外是否允许，以及有业务引用后变更款号/色码/尺码时的处理方式。

## 验收与禁止事项

验收覆盖：原表样例精确生成、前导零、变长款号和款号内 X、全部 1,515 条原记录核验、未知代码拒绝、实际名称保留、同名不同代码不被合并、条码冲突报告、前后端一致性。落地代码后运行相关单元和 API 测试；涉及唯一约束时补充真实 PostgreSQL 并发测试。

禁止自动新增分隔符、假定纯数字或 EAN-13、猜测校验位、将货号当成尺码级唯一 SKU 编码、自动替换历史颜色名称、直接改写库存或已存在的条码。当前交付为规则分析与项目规格补充，尚未启用条码自动生成或导入。


## 2026-09-13 用户确认与实现（优先于上文待确认记录）

用户确认重复花色为人为失误：花色对应 025，044 无效。原始分析 JSON 保留原文件取证值，不作为运行时字典。

已实现颜色映射与尺码映射管理页，分别支持新增、编辑、停用、删除；初始有效颜色 64 项、尺码 10 项。代码为三位数字且不能为 000；颜色 044 永久拒绝，025 的名称为花色。未引用代码可编辑，已被任何 SKU 引用的代码禁止改码或删除，可改名和停用；字典改名不覆盖商品实际名称或条码。
