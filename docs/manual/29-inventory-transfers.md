# 调拨订单与配送

更新日期：2026-10-01。入口：ERP系统 → 库存管理 → 调拨订单。查看需要库存查看权限；新建、发货和取消草稿需要库存调整权限。

## 前提与操作

1. 先建立两个不同的有效仓库及内部 SKU，源仓须有足够可售库存。
2. 新建调拨单，填写源仓、目标仓、调拨说明，添加不重复的 SKU 与正整数数量。保存草稿不扣库存。
3. 打开草稿点击「调拨发货」，选择无需物流配送或快递。无需物流配送生成四位交接核销码；快递需要公司与单号。
4. 发货事务从源仓扣减数量并写调拨出库流水，目标仓显示调拨在途；任一 SKU 库存不足时整个发货回滚。
5. 有到货编辑权限的接收方核验码或确认实际快递签收，再逐 SKU 盘点质检。送达不增加目标仓库存。
6. 合格数量进入进货仓待入库。有到货过账权限者选择调拨单的目标仓入库，生成调拨入库流水；所有调拨数量正式入库后单据完成。

## 差异及限制

漏发、错发、破损、瑕疵、污渍、品质问题分别记录数量与说明，问题件不计合格暂存或目标仓在仓。源仓已发出的问题数量不会自动返还；双方核对实际实物处置后另建调拨或有原因的库存调整，原质检记录保留。问题未处理的调拨单保持已发货。

只有草稿可填写原因取消；发货后不能撤销或改变仓库。目标仓不能改为其他仓；需要再搬仓时先完成本次入库，再另建调拨。快递未签收可更正公司和单号，接入物流服务后按小时查询，未配置时由接收方凭实际签收填写交接说明。

网络中断先查看原单，重复提交沿用原请求；同一包裹待入库数量不能被多次记库存。库存流水与审计记录只读。
