# 采购订单

更新日期：2026-10-01。入口：ERP系统 → 采购订单；配送与 SKU 验收也可在库存管理 → 采购配送处理。

## 建单到确认

1. 新建采购单，选择供应商和目标仓库。一张单对应一个供应商、一个仓库。
2. 逐条或用表格/Excel 填写 SKU、采购数量和单价，核对备注后保存草稿。
3. 打开草稿，检查明细，点击「提交采购」。有确认权限的人员再点击「确认采购」。
4. 确认不计入在途。在详情的 SKU 配送明细安排实际发货，选择无需物流配送或快递，实际发货量才计入采购在途。可关联已审核供应商账号，由对应供应商处理发货与补发。
5. 接收方验证四位核销码或确认实际快递签收后逐 SKU 盘点质检；合格数量暂存进货仓，正式选择仓库入库后更新已入库数量。问题件保留反馈，供应商再次发货时可重新选择配送方式。

旧采购单尚未开始包裹配送流程时可继续从「创建入库单」完成正常合格到货。开始新流程前必须处理或取消旧活动到货单；使用新流程后不再允许旧到货单重复过账。详情中的剩余可发量扣除已入库、在途和质检合格暂存数量。

## 编辑与取消

可编辑的草稿显示「编辑单据」。与采购建议关联的单据有额外限制，以页面按钮为准。取消必须填写原因；已入库、存在活动旧到货单或已开始配送质检的采购单不能取消。供应链订单关联产生的采购单由原订单中心处理未发货取消，同时关闭对应内部采购单。

## 常见问题

保存草稿不等于确认采购，确认采购不等于增加库存。Excel 明细只属于当前采购单，不会自动按多个供应商拆单。保存前核对数量与价格，避免将总金额填入单价。
