# 采购订单

更新日期：2026-09-16。入口：采购订单。

## 建单到确认

1. 新建采购单，选择供应商和目标仓库。一张单对应一个供应商、一个仓库。
2. 逐条或用表格/Excel 填写 SKU、采购数量和单价，核对备注后保存草稿。
3. 打开草稿，检查明细，点击「提交采购」。有确认权限的人员再点击「确认采购」。
4. 确认后计入有效在途。到货时从该采购单点击「创建入库单」，可分次收货。

## 编辑与取消

可编辑的草稿显示「编辑单据」。与采购建议关联的单据有额外限制，以页面按钮为准。允许取消的状态显示「取消单据」，取消必须填写原因；已产生后续业务的单据可能无法取消。

## 常见问题

保存草稿不等于确认采购，确认采购不等于增加库存。Excel 明细只属于当前采购单，不会自动按多个供应商拆单。保存前核对数量与价格，避免将总金额填入单价。
