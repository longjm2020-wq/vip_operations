# 商品经营决策

更新日期：2026-11-17。入口：运营中心 → 唯品会工作区 → 商品档案 → 字段分组栏「经营决策」。规则版本：2026-11-16.1。

## 用途与前提

按款汇总生产采购端、退供清仓端、销售数据端意见，分别给出补货资格和销售状态。允许补货表示具备补货条件，不等于现在需要下单；补多少仍需到库存明细按颜色、尺码核对。经营决策没有自动采购、库存调整或唯品会上下架动作，也不调用 AI 模型、不产生模型用量。

需要已保存、非空且有权查看的商品档案款号。查看沿用商品查看及款号单元格的保护权限；修改还需商品编辑、款号区域编辑及认领规则允许，传送锁定行不能修改。决策反馈为该款的共享业务资料，有权查看该款的人员可见。销售依据额外需要经营分析查看权限，无此权限不会返回销售指标及历史销售判断快照，仍可按权限查看或维护人工反馈。

## 查看与操作

1. 完成商品档案自动保存，再选择「经营决策」。在页面右上角的商品搜索框输入款号、供应商等关键词，或点相机图标查找同款。搜索期间商品档案的列筛选暂停，清除搜索后恢复。点击「清除图片查找」会恢复图片定位前的关键词或列筛选结果。只显示已保存且有权查看的款号。
2. 款号右侧显示商品档案「图片」字段第一张可查看的图片。缺少图片或没有图片查看权限时显示「—」。可按测试阶段、补货资格、销售状态及经营标签筛选，默认每页50款。表内还显示判断依据、数据截止和人工反馈人/时间。
3. 点击款号打开侧栏。生产采购端选择「待确认／允许补货／不允许补货」；非待确认必须选择对应原因，可填写补充说明。
4. 退供清仓端可标记「压仓库存」及填写补充说明；选择品质退供、大货退供、清仓完结表示明确的停售反馈。另可选择采用规则建议、确认继续销售或确认停售，人工确认必须填写原因。
5. 点击「保存三端反馈」才写入。新提交停售决定会再次确认，保存后显示「已确认停售」和「不允许补货」，不直接下架平台商品。保存成功立即重新判断，并记录操作者、时间、反馈、当时规则结果及报表口径；侧栏展示最近20次人工保存记录。
6. 修改反馈后未保存，关闭会询问是否放弃。恢复为「待确认」、取消压仓标记、撤销停售反馈或改回「采用规则建议」后，也须保存才生效。继续销售前须先撤销退供清仓端的停售反馈。
7. 「更新判断」重新读取最新已经完整导入的报表，不启动平台下载；页面打开后每分钟刷新判断。详情提供经营分析、库存明细入口，按权限显示；进入后可用该款号查询原始指标与 SKU 补货量。

自动判断按当前完整报表实时计算，不每分钟新增历史记录。历史中的结果是当时保存快照，可能与今天的判断不同。原表款号变更后不沿用原款人工反馈，显示重新确认提示，旧记录仍保留在历史中。

## 三端规则与优先级

生产采购端人工反馈：供应商有现货、生产周期不超过20天属于允许原因；不满足起订量、停产、生产周期超过20天、换季倒计时不超过30天属于不允许原因。生产周期正好20天归允许原因。这里只保存人工已核对的原因，不根据未接入的供应商系统自动推定。

综合补货资格：生产采购端不允许，或销售端首测/回测失败，显示「不允许补货」；生产采购端允许且有效销售窗口已有销量、没有需复核的高退货风险时，显示「允许补货」；缺少任一端确认时显示「待确认」。供应商现货不单独触发补货，销售量大于零也不覆盖生产端的不允许。人工确认继续销售不会自动改变补货资格。

销售状态优先级：明确的退供清仓停售反馈或人工确认停售最高；人工确认继续销售其次；已标记的压仓库存持续上线销售；其余采用自动建议。压仓库存不是停售的同义词，是长期积压、仍需要销售消化的库存，可与「高退货率」同时存在，不因高退货率自动停售。它也不自动授予补货资格。

## 销售数据判断

仅使用当前完整导入的罗盘「款号」维度报表，款号去除首尾空格、忽略字母大小写后完整匹配，不模糊关联、不将款号/货号/条码三份报表相加。售龄取报表截止日记录，缺失时才按首次上架日期计算；不用档案创建日期代替。观察窗口按截止日售龄回推，规则中的第1天包含在统计中。

- **首测，售龄1—10天**：统计首次在售日至报表截止日。有效销量大于零形成销售端允许依据。商详UV≥100且加购率≥8%时标「潜力款」「营销促转化」「待回测」，售龄进入第11天后进入回测。曝光UV、CTR一并展示供判断。
- **首测失败边界**：满10天、记录完整、曝光UV≥2000、商详UV<100且加购率<8%、销量明确为零，才标「非潜力款」「首测失败」「不允许补货」并建议停售。已有销量则继续观察，不同时给出相反结论。期未满、曝光不足、仅一个指标达标、商详/加购缺失或分母为零，都不自动判失败。CTR参考阈值5%，不是独立的停售条件。
- **回测，售龄11—20天**：只统计第11天起的回测销售，不把首测销量算作回测成果。有销量形成允许依据；满第20天、整个回测窗口完整且销量为零，标「回测失败」「不允许补货」并建议停售。未满观察期继续观察。
- **观察期，售龄21—30天**：统计第21天起的数据，继续观察销售，不自动判失败或停售。
- **常测，售龄超过30天**：统计截至报表截止日的近30天。期间退货率>80%标高退货率并建议人工复核停售，补货资格暂待确认；正好80%不命中。已标记压仓库存时继续销售，不因该指标产生停售建议。

CTR=期间累计商详UV÷累计曝光UV；加购率=累计加购UV÷累计商详UV；期间退货率=累计退货件数÷累计销售量。跨日UV未去重，退货率可能超过100%，不表示同一批订单的真实退货概率。缺失单元格不补零，也不拿每日比例的平均值冒充期间比例。

## 数据不足与常见问题

没有完整款号报表、截止日未匹配该款、同款出现多个平台记录、售龄无效、观察期覆盖不足、销量缺失，均不自动给出销售端允许或失败结论。报表截止日距今天超过3天视为过期；当天及未来日期的报表不能用于判断。人工有效的不允许或停售反馈仍保留，压仓库存继续销售的人工分类仍有效。

「经营分析 → 更新数据」完成后再回本页更新判断。短报表缺少完整观察窗口时需补齐原始来源，不能依靠缺失数据推导零销量。没有经营分析权限时联系管理员授权。

保存冲突表示他人已修改反馈或档案款号/版本变化，当前修改不覆盖服务器结果；先保留需要的文字，再点击「重新读取」并确认放弃草稿，核对后重新提交。读取失败可重试，不能将失败当作没有风险。经营决策入口只适用于商品档案，普通协作表格和选款登记不提供此功能。
