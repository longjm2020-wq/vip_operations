# 开始使用与常见问题

更新日期：2026-09-16。适用范围：当前衣序内部经营系统。

系统使用 XUTI 品牌 LOGO，登录页、导航和浏览器图标保持一致。主操作采用暖橙色，配合米白背景及深棕导航；成功、异常和警告仍使用状态提示色。品牌外观更新不改变业务数据和操作权限。

## 登录与权限

使用管理员分配的用户名和密码登录。菜单和操作按钮根据账号权限显示；看不到入口或提示无权限时，请联系管理员核对角色。不要共用管理员账号。

离开工作台时点击右上角「退出」。密码忘记时由管理员在「系统设置 → 用户」重置；手册不保存任何真实账号密码或平台密钥。

## 建议的首次使用顺序

1. 管理员建立用户、角色及仓库。
2. 建立品类、品牌、供应商、颜色尺码映射。
3. 建立商品档案，再建立各颜色、尺码对应的 SKU。
4. 如需期初库存，在 SKU 库存中按实际盘点填写库存调整。
5. 创建采购订单，提交并确认；到货后创建入库单，确认到货并过账。
6. 团队协作先维护 SOP，再建立项目、配置任务并推送。

## 保存与刷新

表格、表单、画布中的编辑通常需要点击保存；关闭页面不等于保存。项目任务表「完成填写」只把内容带回项目，仍需保存草稿或推送项目。SOP 调整需要「保存模板」。

出现数据版本冲突时，先保留自己待修改内容，再刷新读取最新记录后重新编辑。批量保存可能部分成功，先核对结果再重试失败行，不要重新导入整份文件。

## 如何查手册

章节列表、搜索和下载按当前账号的模块查看权限过滤。入门和通用 Excel 说明对已登录用户开放；其他章节与对应功能菜单的查看权限一致。直接打开无权限章节链接会提示无权查看，不会显示该章节内容。账号拥有多个角色时，以合并后的实际权限为准。阅读手册不自动获得新建、编辑、确认或过账权限。

各模块右上角都有「使用手册」入口，点击后在新标签页打开当前模块对应章节，保留原页面及未保存的编辑。例如在商品档案打开商品手册，在采购单详情打开采购手册，在 SOP 页面打开流程手册。也可搜索关键词或切换章节。

可以下载当前章节留存；下载文件是当时的副本，查看最新内容应回到系统手册。线上手册随功能版本发布更新，不会自动更新已下载的副本。

## 当前边界

唯品会平台商品库与内部商品档案独立；同步成功不代表内部库存或近 7 天销量已经同步。项目任务完成也不会自动创建商品、发出采购或修改库存。各业务操作仍需在对应模块完成。

侧边栏采用精简横向 XUTI 标识与缓慢银灰渐变动效，不再重复显示品牌文字和副标题；折叠导航时显示 X 标识。系统开启减少动态效果时，品牌渐变保持静态。

登录页同样使用横向银灰渐变品牌标识。

主操作配色已提亮为鲜橙色，页面使用更明亮的暖白底色；LOGO 后续由清晰源文件替换。

各模块采用紧凑标题区，省略重复品牌提示并缩小页脚留白，为业务内容腾出空间。
