# 开始使用与常见问题

更新日期：2026-10-03。适用范围：当前衣序内部经营系统。

系统使用 XUTI 品牌 LOGO，登录页、导航和浏览器图标保持一致。主操作采用暖橙色，配合米白背景及深棕导航；成功、异常和警告仍使用状态提示色。品牌外观更新不改变业务数据和操作权限。收起侧栏时 X 标识和各菜单图标沿同一中线对齐，未选中图标为灰色线框，选中图标填充橙色，不再显示橙色底块；展开后的菜单样式不变。
鼠标悬停收起侧栏的一级菜单，子菜单显示为浅色实底卡片，卡片顶部显示所属一级菜单名称，深色文字便于阅读；悬停和选中项用淡橙色提示，长菜单可在卡片内滚动，标题保留在卡片顶部。

## 登录与权限

使用管理员分配的用户名和密码登录。菜单和操作按钮根据账号权限显示；看不到入口或提示无权限时，请联系管理员核对角色。不要共用管理员账号。

顶部账号区仅显示头像、姓名和下拉箭头。点击展开账号菜单，可查看登录用户名和已分配的中文角色；离开工作台时选择「退出登录」。密码忘记时由管理员在「系统设置 → 用户」重置；手册不保存任何真实账号密码或平台密钥。

选择账号菜单中的「更换头像」，上传 JPG、PNG 或 WebP 图片。图片会居中裁切为正方形、缩小并压缩至500 KB以下，确认圆形预览后点击「保存头像」。取消不保存，上传失败保留原头像；更换后刷新或再次登录仍显示新头像。内部用户及供应商均可更换自己的头像，无需角色管理权限，不影响用户名、角色或业务资料。

## 建议的首次使用顺序

1. 管理员建立用户、角色及仓库。
2. 建立品类、品牌、供应商、颜色尺码映射。
3. 建立商品档案，再建立各颜色、尺码对应的 SKU。
4. 如需期初库存，在库存管理点击「导入」下载模板，按实际盘点填写库存数量并上传确认；SKU 资料在商品档案详情维护。
5. 创建采购订单，提交并确认；实际发货后记录采购在途，接收方核销或签收后逐 SKU 盘点质检，合格暂存进货仓，再选择具体仓库正式入库。供应链订单可逐项关联内部 SKU 接入该流程。
6. 团队协作先维护 SOP，再建立项目、配置任务并推送。

## 保存与刷新

表格、表单、画布中的编辑通常需要点击保存；关闭页面不等于保存。项目任务表「完成填写」只把内容带回项目，仍需保存草稿或推送项目。SOP 调整需要「保存模板」。

出现数据版本冲突时，先保留自己待修改内容，再刷新读取最新记录后重新编辑。批量保存可能部分成功，先核对结果再重试失败行，不要重新导入整份文件。

## 如何查手册

章节列表、搜索和下载按当前账号的模块查看权限过滤。入门和通用 Excel 说明对已登录用户开放；其他章节与对应功能菜单的查看权限一致。直接打开无权限章节链接会提示无权查看，不会显示该章节内容。账号拥有多个角色时，以合并后的实际权限为准。阅读手册不自动获得新建、编辑、确认或过账权限。

各模块右上角都有「使用手册」入口，点击后在新标签页打开当前模块对应章节，保留原页面及未保存的编辑。例如在商品档案打开商品手册，在采购单详情打开采购手册，在 SOP 页面打开流程手册。也可搜索关键词或切换章节。

可以下载当前章节留存；下载文件是当时的副本，查看最新内容应回到系统手册。线上手册随功能版本发布更新，不会自动更新已下载的副本。

## 当前边界

唯品会平台商品库与内部商品档案独立；同步成功不代表内部库存或近 7 天销量已经同步。项目任务完成也不会自动创建商品、发出采购或修改库存。各业务操作仍需在对应模块完成。

侧边栏采用精简横向 XUTI 标识与缓慢银灰渐变动效，不再重复显示品牌文字和副标题；折叠导航时显示 X 标识。系统开启减少动态效果时，品牌渐变保持静态。

登录页同样使用横向银灰渐变品牌标识。

主操作配色已提亮为鲜橙色，页面使用更明亮的暖白底色；LOGO 后续由清晰源文件替换。

各模块采用紧凑标题区，省略重复品牌提示并缩小页脚留白，为业务内容腾出空间。

左侧菜单按运营中心、项目协作、ERP系统、供应链端、系统设置的顺序组织，子菜单在左侧展开。「项目协作」原名「项目管理」，包含新建SOP、新建项目、新建表格三个入口；新建SOP原名「操作流程 SOP」，模板查看、编辑和创建功能不变。「运营中心」打开后按唯品会、淘宝、抖音、京东、拼多多、视频号、小红书、快手八个平台 TAB 分类，默认唯品会；切换平台后刷新保留当前分类。唯品会分类下以小卡片展示「经营分析」和「选款登记」，点击卡片进入对应功能。其他平台当前显示「暂无已配置功能入口」。卡片沿用原有查看权限，具有其中任一权限才显示运营中心导航；没有功能权限时不显示对应卡片。ERP系统集中商品、库存、采购、供应商、业务基础资料和唯品会接入；系统设置保留用户、角色权限和操作日志。

侧栏和页脚统一显示核心功能摘要「经营与竞品分析 · 采购库存 · 协作表格 · 供应链订单对账」，随核心功能版本更新维护。

唯品会工作区新增「竞品分析」，预设我的品牌序缇及帕罗、米皇、笑涵阊、生活在左、金菊、南宋丝府，可添加更多品牌。按品类、价格、材质和季节查看单品牌/多品牌对比与独立TOP20；点击预览图直达官方商品详情。公开销量排名与导入的实际销量分别分析，详见「唯品会竞品分析」章节。该入口沿用经营分析查看权限，并可在个人工作台的常用工具中添加。

界面默认采用紧凑布局：导航、顶部栏、筛选区、表格及表单缩小留白，同屏显示更多记录。表格内容较长时仍可换行；窄屏工具栏自动换行，列较多时横向滚动。此调整不改变每页记录数量、权限或保存方式。

点击左侧工作区可展开或收起子菜单，当前功能以橙色标识；直接打开详情时也能看到所属菜单。顶部不再重复排列子菜单，只提供返回导航。进入具体表格时，顶部「表格列表」可返回列表；项目、商品、采购单和到货详情也在顶部返回所属列表。经营分析和选款登记顶部提供「唯品会工作区」返回平台卡片页。

顶部工作栏固定在屏幕上方，滚动业务页面时仍可访问菜单开关、返回导航、使用手册、通知和账号操作。顶部「订单中心」快捷入口已移除，供应链端下的订单菜单继续保留。窄屏返回导航自动换行，避免挤压账号操作。
顶部「我的工作台」对所有登录用户开放，并作为默认首页，按角色提供工具入口，独立保存个人待办、备忘及常用工具。自己创建的 SOP、项目、表格可选择公开，公开后显示在项目协作相应公共区域并保留创建者；详见「我的工作台」章节。

搜索输入框与搜索按钮采用统一高度，筛选操作保持对齐。

## 品牌视频背景
登录页品牌区使用静音循环视频，不显示播放或暂停按钮。手机小屏与系统减少动态效果设置下默认展示静态封面，保持静态展示。视频加载失败不影响登录。


登录页左侧品牌区保留 LOGO 与主文案「让好产品，遇见新的可能。」，减少辅助文字，突出视频画面。

登录页桌面端采用左侧品牌视频61.8%、右侧登录表单38.2%的分区，表单最大宽度420px。手机和平板窄屏改为上下布局，品牌区显示静态封面；登录方式不变。

各工作页面顶部的标题与说明在同一行显示，右侧保留操作按钮，减少顶部占用的高度。空间不足时说明文字省略，悬停可查看完整说明；窄屏操作区保持单行，可横向滚动查看按钮。

登录页先显示静态封面，桌面背景视频约 6 秒后开始加载；窄屏、减少动态效果或浏览器省流量模式下不加载视频，页面隐藏时暂停播放。业务模块在进入时按需加载，首次进入模块可能短暂显示加载提示。
