# 选款登记

更新日期：2026-09-28。入口：ERP系统 → 选款登记。需要选款登记查看权限；编辑和保存需要选款登记编辑权限。管理员、超级管理员、商品运营、采购员和采购经理默认具有这两项权限。

## 用途

选款登记用于在商品正式建档前集中收集候选款资料。每行只保存登记批次、图片、款号、供应商信息、颜色尺码、材质和价格，不会自动创建商品、SKU、采购订单或库存记录。

## 在线智能表格操作

1. 点击「添加一行」，直接在单元格中填写资料；Tab 或 Enter 可继续录入。
2. 图片列粘贴以 `http://` 或 `https://` 开头的图片网址，系统会在单元格中显示预览。
3. 填写序缇款号、供应商款号、供应商编码、颜色、尺码范围和材质，并按需要填写登记批次。
4. 填写供货价（不含税）、唯品价、直播价和吊牌价。金额可保留两位小数，且不能为负数。
5. 点击「保存登记」后才写入系统。输入无效的网址或金额时，对应单元格会提示修正原因。

## 字段

| 字段 | 说明 |
| --- | --- |
| 登记批次 | 本次选款或采购准备批次 |
| 图片 | 候选款图片的网址及预览 |
| 序缇款号 | 系统内部使用的款号 |
| 供应商款号 | 供应商提供的款号 |
| 供应商编码 | 供应商在系统或业务中的编码 |
| 颜色 | 候选款颜色 |
| 尺码范围 | 可供货的尺码范围 |
| 材质 | 面料或成分说明 |
| 供货价（不含税） | 不含税的供应商报价 |
| 唯品价 | 唯品会计划售价 |
| 直播价 | 直播渠道计划售价 |
| 吊牌价 | 商品吊牌标示价格 |

## 表格工具

「表格设置」可显示或隐藏字段；「筛选」可按批次、款号、供应商编码、颜色或材质搜索；可按登记批次、供应商编码或颜色分组，并按最近修改、登记批次、款号、供应商编码或价格排序。

勾选一行或多行后，使用「填色」标记重点记录。可切换紧凑、标准和宽松行高。填色会随登记记录一起保存，其他表格显示设置仅影响当前浏览器页面。

## 重要边界

选款登记是前置业务资料，不会自动转成商品档案。确认要正式建档时，请在「商品档案」建立商品与 SKU；采购和库存操作仍在各自模块中完成。平台商品同步资料也不会自动写入选款登记。
