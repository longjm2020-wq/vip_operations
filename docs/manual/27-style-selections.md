# 选款登记

## 跨表传送

勾选一条或多条已保存的行，点击「跨表传送」，选择目标表格并配置字段对应关系。目标可为有权编辑的其他表格、选款登记或商品档案，不可选择当前表。相同标识或名称先自动对应，仍可修改；选择「不传送」跳过字段，勾选新增未对应字段时在目标表新增对应字段定义。公开字段沿用目标表的公共字段设置，有本表查看权限的其他账号及新账号均可显示；已有空布局也会补入缺失的公开字段。私有源字段传送后仍为私有字段，归执行传送的用户，仅创建者及超级管理员可见，不会因传送自动公开。创建人、修改人、创建/修改时间、编号及收集表生成的库存、卖点等字段不传送。

点击「预览传送」核对新增行、更新行和新增字段数量，再「确认传送」。目标已有相同款号，或原行以前已传送到该表时，更新关联目标行的所选字段；未对应的已有字段保留。内容须符合目标字段类型，多条原行不能在同一批对应到同一目标款号。每次最多100行，原行需有完整编辑权，目标表的权限和保护规则也须允许写入。尚未保存的修改、未保存行和已锁定行不能传送。

源字段和目标字段均为单选、多选或自定义标签时，自动补齐目标缺少的源字段候选选项，预览显示「补齐目标字段选项」数量及逐字段清单。确认前不修改目标记录或目标字段；确认后选项与记录在同一事务中保存。目标已有选项、顺序、配色、字段类型及其他功能设置保留，新选项追加在末尾，并带入源字段已设置的选项颜色。新增字段复制完整字段定义；公开目标字段的候选项随目标表共享，私有目标字段仅创建者及超级管理员可访问，字段创建者和超级管理员的维护权限继续生效。

普通表格字段合并后最多100个候选项，商品档案共享单选字段最多50项，超过时须精简源候选项或调整对应字段再预览。单选、多选值须来自源字段已配置选项，也须符合目标的单选数量、标签数量等限制；原字段未配置的单选、多选值不会自动变成候选项，文本字段也不会自动扩展目标选项。允许自由新增的标签仍按目标标签设置校验。

传送到商品档案的共享单选字段（例如「洗涤标志核对」「面料材质核对」）时，预览标注「商品共享」，并提示新增选项将对所有有权查看该表的用户生效。确认后只追加源已配置候选项，不替换、删除或改名已有选项，也不改变商品字段类型；记录、共享选项和相关布局共同保存，任一业务校验失败时一起回滚。目标共享字段仍只能保存一个选项，多选的多个值不能直接传到共享单选字段。修改原商品共享选项沿用商品编辑权限；公开表格字段的选项配色随字段定义共享，私有字段配色仅创建者及超级管理员可访问。（2026-10-09）

登记批次按原日期传送，格式为YYYY-MM-DD，目标日期字段保留相同的年月日。

整批在服务器事务中完成。任一行业务校验失败，或预览后原行、目标行、字段或权限变化时，整批不写入，也不锁原行；按提示修正或重新预览。网络异常可重试同一次确认，成功结果不重复新增。

成功后原行仍保留，背景填充透明黑色，不能修改、删除、粘贴覆盖或改图片。行号「#」的小铅笔可恢复原行编辑，目标记录仍保留；两表不持续自动同步，后续修改需再次明确传送，再次传送更新关联目标行。

超级管理员可用小铅笔执行管理恢复，解除原行的传送锁定，不会被他人认领、普通行列编辑限制或已删除字段残留阻挡；普通管理员及协作者仍按已获权限恢复。恢复仍核验当前表格访问、记录版本及并发冲突，成功后记录审计；目标记录保留，业务校验及未注册字段的写入限制不变。（2026-10-10）

目标和字段对应配置按账号及原表保存到服务器，跨电脑、浏览器恢复；传送后的公开字段及布局随目标表共享，已打开的目标表自动补取新增字段；已有传送的缺失公开字段显示也会修复，无需再次传送。私有字段保持仅创建者及超级管理员可见，后续需由创建者在目标表字段管理中自行公开。字段公开不会授予整表查看或内容编辑权限。选择商品档案并传送有效款号会建立或更新实际商品，保留已有商品ID及SKU、库存、采购关联；不会自动创建SKU或调整库存。其余录入不会自动加入商品档案。

更新日期：2026-10-10。入口：运营中心 → 唯品会 TAB → 选款登记卡片。需要选款登记查看权限；编辑、自动保存、删除行需要选款登记编辑权限。管理员、超级管理员、商品运营、采购员和采购经理默认具有这两项权限。店铺运营已有角色补充查看权限，可查看选款资料及允许访问的图片，编辑和上传仍需独立授予编辑权限；行列保护及指定访问范围继续生效。新增入口需刷新页面后显示。

## 用途

选款登记用于在商品正式建档前集中收集候选款资料。每行保存登记批次、候选款图片、洗唛/吊牌图、款号、供应商信息、颜色尺码、材质、价格和自定义文本信息，不会自动创建商品、SKU、采购订单或库存记录。

需要独立的空表时，可到「项目协作 → 新建表格」创建。新表复用本章全部表格功能，数据、协作权限、公开布局和个人设置按表格隔离，创建步骤和范围见「新建表格」章节。

## 公开布局与个人设置同步（2026-10-09）

「仅本人」为私有字段的界面标签，普通用户只有创建者可查看和管理；超级管理员（SUPER_ADMIN）可查看、编辑和管理全部私有字段，包括公开或取消公开。普通管理员没有此例外。字段范围与内容编辑权分别校验，私有字段的创建者若只有表格查看权，仍不能填写内容。

公开字段的名称、类型、选项、选项配色及功能设置，公开列的顺序、列宽、固定和隐藏状态、仅包含公开字段的字段分组、可选行分组及排序字段列表，以及表格行高，随当前表格共享给有查看权限的用户；字段内容仍按各接收者的模块权限和保护规则显示。公开布局的修改需要本表编辑权限。只读用户操作公共列宽、顺序、固定、隐藏、公共分组或行高时立即提示并保留原公共布局；私有字段布局仍可设置。由用户自行创建的公开字段，其名称、类型、选项、功能设置、删除及公开状态由创建者或超级管理员维护；无创建者归属的原有业务字段由有编辑权限的用户维护。

私有字段的定义、显示、宽度、顺序和固定设置，以及包含私有字段的字段分组，仅按本人账号和当前表格保存。搜索、个人列筛选及排序、是否跟随共享筛选、当前行分组和排序选择、最后选中的字段分组 TAB、每页行数、页码、选区统计显示项及数字格式、字段类型目录和跨表传送配置仍为个人设置。同一账号换设备可恢复这些设置；公开字段取消公开后，除创建者及超级管理员外的其他用户实时移除字段及已保存内容，原有资料保留。

首次建立公开布局时，有编辑权限的用户可点击「统一当前字段与布局」，以当前账号已有的字段、列宽、顺序、固定列、分组和行高作为该表的公开起点；每张表仅初始化一次。只纳入升级前该账号已有的字段及已经公开的字段，新创建的私有字段不会因此自动公开。其他账号读取同一份公开起点，之后公共布局改动继续共享，个人设置保留各自选择。

设置在后台自动保存，保存中及成功时不显示文字，也不占工具栏位置。失败时显示具体原因，可点击「重试保存」；未保存设置暂存在当前浏览器的账号缓存，网络恢复后重试。云端读取失败时先显示错误并允许重新读取，不用默认配置覆盖已保存设置。其他用户或设备同时更改同一份公开或个人设置时，保留本地草稿并提示冲突，可选择「使用云端设置」或「保留当前设置」，不会静默覆盖。修改后短暂停留以便后台完成保存；已打开的空闲页面再次获得焦点时读取最新配置。

升级后首次打开仍会恢复该账号已有云端配置；尚无云端个人配置时才迁移当前浏览器旧设置，原有旧配置的归属规则继续生效。已建立公开布局的字段以共享设置为准，不恢复其他账号旧的公共布局。登录有效且有当前表格访问权限时才能同步，撤销权限后不能继续读取。临时选区、弹窗、图片预览位置及未复制的 OCR 结果不作为布局保存。

## 录入与自动保存

在网页表格中，按手动排序的整张表最后一行填写任一内容并保存成功后，末尾自动新增一行已保存的空白记录，继续录入即可；无需填满所有字段，金额 `0`、图片和自定义字段内容也算填写。批量粘贴到末尾只补一行，重复保存不会重复追加。已有末尾空白行、仅调整格式或顺序、保存失败或无新增权限时不补行；保护规则继续生效，无法新增时仍保留已获准的原行修改。打开零记录空表不会自行建行。搜索、筛选、排序和分页保持不变，新增空行可能被筛选隐藏或在下一页，可清除筛选并使用手动排序查看；选格和编辑位置不主动切换。（2026-10-09）

已应用搜索或列筛选时，在可编辑文本单元格、顶部编辑栏或展开详情中输入，当前编辑行暂留，避免内容刚变化就被筛选移出而中断输入。同一格的这三处编辑区之间切换可继续填写，自动保存持续执行；离开编辑区、切换单元格或按 Esc 后重新按原条件筛选，不再符合条件的行可能移出视图。明确修改搜索、筛选或翻页时按新范围显示；权限变更仍立即生效，只读、受保护及已锁定内容不能因此编辑。（2026-10-10）

### 多人实时同步（2026-10-09）

有编辑权限的用户保存成功后，正在查看同一张表的其他用户自动读取最新内容，无需手动刷新。仅查看用户同样接收更新；单元格文字、标签、价格、图片、格式、新增及删除行均同步，电脑编辑、手机拍图、导入、收集表确认及跨表传送的保存也生效。只同步已经保存的资料，尚未保存或保存失败的输入只留在编辑者当前页面。

每次同步按接收者当前模块权限、字段公开范围和保护区域校验。其他用户的私有字段不发送字段定义、值、图片或格式，页面也不显示该字段；「禁止查看」及内容自动隐藏的值、图片和格式不发送给该用户，仍显示隐藏标记。整表或模块查看权限被撤销后，页面清除已加载表格内容并停止同步。区域只读用户仍可查看更新。公开字段定义、布局及行高同步更新，搜索、筛选、当前分组 TAB 和分页保留个人选择，更新后不符合筛选的行可能移出当前视图。

本地有未保存输入时，其他行、其他字段的更新仍可显示，不覆盖本地正在填写的值。两人修改同一个单元格时保留本地草稿，将冲突单元格标红并暂停该行自动保存；请复制保留本地内容，再刷新核对后重新编辑。权限变化后无权编辑的草稿按最新权限移除。删除行以服务器最新结果为准，不会恢复已经删除的记录。页面隐藏或网络中断期间可能延迟，返回页面或网络恢复后自动补取最新资料；实时连接短暂不可用（包括服务更新）时自动重试，并继续定期检查更新。

已保存的单元格填色、字体颜色、水平及垂直对齐、数字格式随内容实时同步给有查看权限的用户，恢复默认格式也同步；上一笔保存处理中再恢复默认，清除操作继续保存，不会恢复上一笔格式。已建立共享公开布局时，公开列宽、固定列、表格行高及选项配色按本表共享。个人搜索、个人筛选、分页、选区统计显示及统计数字格式仍按本人账号保存。普通用户不接收他人私有字段或禁止查看区域的格式。（2026-10-10）

### 直接修改和连续添加标签（2026-10-10）

有当前单元格编辑权限时，直接点击颜色、尺码或允许输入新标签的自定义标签文字，在原标签位置输入新名称，按 Enter 或离开输入框提交并自动保存；按 Esc 取消当前未提交输入。只替换当前格的这一项，保留同格其他标签，不改字段候选项或其他记录。名称去除首尾空格后不能为空、不能含 `/`，不能与同格其他标签重名；字数、数量及字段限制继续校验，颜色和尺码合计各最多100字，尺码仍按原规则排序。无效名称不会替换原值，可修正后重新提交。

选中颜色、尺码或允许自由新增且允许多选的自定义标签单元格后，未达数量上限时显示「+ 添加标签」。点击后直接在格内输入新标签，按 Enter 提交并继续输入下一项；修改已有标签后按 Enter，也可接着添加。新增输入为空时按 Enter 结束；离开输入框提交当前非空有效输入并结束，按 Esc 只取消当前未提交输入，前面已提交的标签保留。达到数量上限或字段不允许多选时不提供继续添加；原字数、数量及排序规则仍适用。移除标签仍可使用顶部编辑栏。

未允许输入新标签的标签字段，以及单选、多选字段，点击已填标签文字打开原选项列表，只能选择已配置值；需要更多标签时在允许多选的列表中追加候选项。顶部编辑栏仍可添加、移除标签。只读、受保护或已传送锁定的格不能修改，禁止查看的内容不显示标签文字。

修改绑定「颜色」字段且该颜色已有候选款图片时，同时更新本行同色图片标签，保留原图、数量、顺序和其他图片的颜色；需要颜色与图片字段均可编辑，图片不可编辑时提示不能改名。洗唛/吊牌图及其他行不变。并发保存失败时不会覆盖他人最新资料，请按提示核对后重试。

选中非图片单元格后，顶部编辑栏右侧「展开单元格详情」打开浮动文本框，完整查看多行内容，可选中文字复制。拖动窗口标题栏可自由移动位置，未被遮挡的表格仍可操作；切换单元格时详情跟随更新，不改变编辑栏或表头高度。有编辑权限的文本字段可在详情框修改并沿用自动保存；选项、日期等字段使用原编辑栏，详情仅查看。只读和已传送锁定的文本不能改写，禁止查看的单元格不能展开。再次点击展开图标、窗口收起按钮或按 Esc 关闭，关闭不清空内容；窗口开关及位置不作为个人布局保存。（2026-10-05）

图片放大与单元格详情可同时显示：先展开文字详情，再点图片放大；文字框保留原文字单元格，继续按该格权限编辑和自动保存，不会写入图片单元格。宽屏初始图片放在左侧、文字在右侧，两者仍可分别拖动。点击另一非图片格时详情跟随更新；关闭图片只收起图片，关闭详情只收起文字框。窗口内按 Esc 关闭对应窗口。（2026-10-05）

## 删除内容与复制提示

选中一个或多个单元格后按 Delete 清空全部内容并自动保存，保留行、填色及对齐设置；图片及洗唛/吊牌图单元格分别清空对应图片关联，清空颜色时同步移除候选款图片的颜色标签但保留图片。只读账号不能清空。直接键入或双击进入文字编辑后，Delete 按正常方式删除文字；顶部编辑栏同样保留文字编辑行为。

## 固定编辑栏、对齐与列筛选

- 单元格内的文本（含多行文字）、链接、数值、日期和标签输入，以及顶部单元格编辑栏、展开详情、图片文字识别结果和添加图片网址的文字编辑区，统一取消内部边框和聚焦阴影；普通、悬停、聚焦及只读状态保持简洁显示。标签去掉细描边，保留类别配色；表格网格线、蓝色选中框和浮动窗口外框保留，录入与校验规则不变。（2026-10-10）不再弹出输入框，可直接输入，也可在表头上方固定编辑栏修改；两处同步并静默自动保存。编辑栏显示当前行和字段，表格内滚动时保留在表头上方。切换文本、日期、单选、多选或尺码时编辑栏高度保持一致，不移动表头；多行文字在编辑框内滚动，过多标签折叠显示，展开列表可查看完整选项。日期、颜色、尺码也在此栏编辑；图片仍在单元格内管理。只读账号可查看，不能修改。
- 首次单击选中单元格，再次点击已选单元格的文字可按点击位置定位光标；拖动光标可选中部分文字，继续输入替换选中文字，也可复制、剪切或删除。双击或直接键入同样进入文字编辑。此时 Ctrl/Cmd+A 全选当前格文字，Ctrl/Cmd+Shift+方向键选择文字，Delete 只处理文字；按 Esc 退出文字编辑，恢复表格快捷键。点击其他格后可重新拖动框选单元格；多格选区不会因点击其中一个文本输入框而直接进入文字编辑。只读文本仍可定位和选择复制，不能改写。
- 焦点在表格内且未进入文字编辑时，Ctrl+A（Mac 使用 Cmd+A）全选当前页的所有行和可见列单元格，可继续复制或批量设置对齐、填色；不选择其他页或被筛选隐藏的行。文字编辑、顶部编辑栏和筛选输入框内的 Ctrl+A 保留全选文字行为。
- 单击选中单元格后，Ctrl+Shift+↑/↓（Mac 使用 Cmd+Shift）选择当前列从本页第1行到最后一个非空单元格；Ctrl+Shift+←/→ 选择当前行从第1个可见字段到最后一个非空单元格。中间空白格包含在选区内，末尾空白格排除；只作用于当前页及当前搜索、筛选后的可见行列。已填写的 `0` 和图片均算有内容，占位提示及不可查看的内容不用于确定末尾；整行或整列均无内容时保留当前选区。可继续复制、填色、对齐或清空，编辑和清空仍遵守保护及权限规则。双击或开始键入进入文字编辑后，以及在顶部编辑栏中，快捷键保留文字选择行为。
- 单元格初始为水平居中、垂直居中，表头文字也居中。单击或拖选单元格后，在工具栏选择左对齐、居中或右对齐；「垂直对齐」下拉菜单提供顶端对齐、垂直居中、底端对齐。可对多个选中单元格同时设置，对齐方式随记录保存，刷新后保留；已有明确设置的对齐格式继续生效。
- 「填色」图标位于「字体颜色」图标前，两个入口仅显示图标，悬停查看名称。
- 「字体颜色」菜单可给选中单元格设置文字颜色，支持批量设置及恢复默认颜色，与背景填色独立保存；清空内容时保留字体颜色。
- 每个列标题旁的筛选按钮支持包含、等于、为空、不为空，多个列条件同时生效；自定义列也支持筛选。图片按颜色或网址匹配，金额相等按数值比较。打开对应列的筛选面板，点击底部「清除筛选」即可移除本列限制，其他列条件保留。

## 图片

配置私有对象存储的环境中，新上传的选款图片、洗唛/吊牌图、手机拍图及外部收集表图片保存到对象存储，数据库仅保存文件信息。原有图片网址不变，查看、复制和下载仍需通过原有权限校验。历史图片在后台分批迁移并核对内容校验值，暂保留数据库原始副本用于恢复；迁移失败会重试，不影响旧图片读取。对象存储不可用时，新上传会提示失败，请稍后重试；本地未配置对象存储的环境仍使用数据库保存图片。

「图片」与「洗唛/吊牌图」是各自独立的多图字段，不设置每行张数上限。单元格内每次展示一张图片，多图默认每 4 秒自动轮播，可在「字段管理 → 编辑对应图片字段 → 图片功能设置」关闭「自动轮播」；关闭后仍可点击左右箭头切换；鼠标悬停、键盘聚焦、离开屏幕可见区域或打开全部图片时暂停，系统设置减少动态效果时不自动播放。屏幕外图片进入可见区域后才创建图片组件；站内图片重复访问时重新校验登录权限与图片版本，未变化时复用浏览器缓存；「全部」宫格只在打开后加载。图片不会撑大单元格。「全部」按钮固定在图片右下角。点击「全部」打开三列、多行的图片宫格卡片，图片较多时可用鼠标滚轮、触控板或触屏纵向滚动，卡片内同样隐藏滚动条。每张图片右上角显示当前序号/总张数角标。

在有图片的单元格或打开后的大图上右键，可选择「复制当前图片」「下载当前图片」或「复制图片地址」；多图时针对右键时正在显示的那一张。复制图片地址会得到包含网站域名的完整网址，站外图片保留其原网址。只读账号也可使用。站外图片网址如禁止跨域读取，复制图片或下载可能失败；可复制地址，在新标签页打开后使用浏览器保存。浏览器需要允许剪贴板访问才能复制图片或地址。

- 点击「链接」小标签，在弹窗中粘贴以 `http://` 或 `https://` 开头的网址后按 Enter 或点击「添加」，可解析并显示图片。
- 点击「上传」小标签选择 JPG、PNG、WebP，支持多选；也可点击图片单元格后直接粘贴截图或剪贴板图片。每张上传或粘贴的图片会自动压缩至 500 KB 以下，逐张独立上传，表格只保存图片地址。将鼠标停在「上传」上可查看提示，不再在每个单元格重复展示说明文字。
- 在每张图片下方选择颜色。可选颜色来自本行「颜色」单元格的标签；图片上会叠加所选颜色标签。修改或删除颜色前，请先为关联图片重新选择颜色或移除图片。
- 点击缩略图或「全部」宫格内的图片打开浮动大图，可切换本单元格的多张图片；从宫格放大时自动收起宫格。大图打开期间可点击未被图片遮挡的单元格继续编辑、复制和粘贴，也可滚动表格；不会因点击表格而关闭。按住图片拖动调整位置，松开后保留位置；在图片上滚动鼠标滚轮或点击工具按钮缩放，工具栏还可旋转、翻转及重置位置和缩放。关闭按钮位于放大图片右上角，缩放或移动时跟随图片，超出屏幕时保留在可见区域；按 Esc 或点击关闭按钮关闭大图。一次显示一处图片预览，打开其他单元格图片会切换预览。只读账号也可预览，编辑权限保持不变。
- 点击单元格的「全部」打开图片卡片，可添加、移除图片或设置颜色。只读账号可查看全部图片，但不能更改颜色或移除图片。颜色下拉选项仅来自本行颜色字段，以 `/` 拆分；图片显示叠加颜色标签。
- 在「洗唛/吊牌图」单元格点击「+ 图片」或「全部」，点击「上传」可一次选择多张 JPG、PNG、WebP；也可逐张追加、粘贴截图或添加图片网址。图片沿用每张压缩至 500 KB 以下的规则，可轮播、放大和逐张移除，修改后自动保存。图片卡片中的「手机拍图」二维码会打开本款手机拍图页并定位到洗唛/吊牌图。洗唛/吊牌图不设置颜色标签，也不进入外部产品信息收集表；只读账号只能查看。

### 图片文字识别与复制

1. 点击单元格图片打开浮动大图，在工具栏点击「识别图片文字」，或右键大图选择同名操作，读取整张图片的中英文文字。首次使用需要加载识别资源，进度显示在「图片文字」面板；打开大图本身不会启动识别。
2. 只需图片中某一部分时，点击工具栏或大图右键菜单的「框选识别文字」，在图片上拖动框选文字区域，松开鼠标后开始识别。框选过程中暂停缩放、旋转和翻转，点击提示中的「取消」退出框选；框选过小时不启动识别。识别使用当前旋转、翻转后的图片方向，可先调整到正向再识别。
3. 识别结果保留换行，可在面板中核对、修改文字，点击「复制文字」复制全部，也可选中部分文字后使用 Ctrl/Cmd+C 或浏览器右键「复制」。大图右键的「复制图片文字」会直接复制已有结果（包含手动修改）；没有结果时先识别整图再复制。未复制成功时，结果仍保留，可选中文字重新复制。
4. 回到当前表格，选中可编辑的材质等文本单元格后粘贴，识别结果中的换行保留在同一个单元格内；选中多格粘贴时可填入各个可编辑的文本目标格。此规则用于在当前表格预览中复制的文字，从其他软件复制多行多列仍按原有表格粘贴规则分配。文字不会因识别或复制而自动写入，粘贴后的修改按原有规则自动保存。

识别在当前浏览器内进行，不上传图片到第三方识别服务。识别资源升级为较高精度的中英文模型，首次加载文件较大，之后复用浏览器模型缓存。识别会放大文字，沿用图片预览中手动调整的方向和框选区域；较低置信度时再做明暗与对比度增强。整图整体分数较高时，也会从原始图片像素单独复核最多八行低置信度文字，只有结果可靠度明显提高时才替换该行。不会根据面料名称猜测或改写数字；模糊、遮挡仍可能识别错误，务必核对材质和百分比。只读账号也可识别和复制，粘贴仍受编辑权限与区域保护限制。关闭大图、切换图片、关闭结果或点击「取消识别」会取消当前任务；未复制的结果不会保存到服务器。切换图片会清除上一张的结果，重新识别会替换当前结果。

文字模糊、倾斜或遮挡时可能漏字或误识别，尤其需核对百分比、数字及面料名称；可先转正并框选较小区域，或换清晰图片后重试。没有文字、读取失败或识别超时会在面板提示，可「重新识别」或「框选识别」。站外图片禁止跨域读取时无法识别，需使用允许读取的图片；剪贴板权限被拒绝时可在结果面板内手动选中复制。

## 表格操作

顶部搜索框采用全站统一的暖色圆角样式，桌面端固定224px宽（125%缩放时约280像素）、28px高，聚焦时只显示一层柔和橙色边框。长查询和多行查询在框内滚动查看、编辑，不撑开搜索框或导航栏，也不截断实际内容；窄屏按可用宽度收窄，必要时换到导航栏下一行，框高不变。

搜索图标和输入框统一放在顶部导航栏，已移除重复的「选款登记」标题说明行，取消“款号精确／关键词”下拉选择和工具栏「筛选」按钮（2026-10-04）。输入后直接模糊查找批次、序缇款号、供应商款号、供应商编码、颜色、尺码和材质，忽略大小写，支持输入部分款号。多个查询用英文逗号 `,`、中文逗号 `，` 或换行分隔，忽略首尾空格和重复项，匹配任意一项即显示。查找覆盖已完整读取的全部记录；清空输入取消搜索，保留列筛选，搜索与列筛选同时生效，导出遵循当前结果。禁止查看或自动隐藏的内容不参与查找。分组保留不分组、登记批次和供应商编码，其他字段可自行配置。

表格高度随可视区域调整，表内横向、纵向滚动不带走底部批量添加、分页及选区统计操作栏；筛选后记录很少时，操作栏仍保持在页面可视区域底端。窄屏顶部搜索和操作按钮可换行，表格使用剩余高度滚动，不遮挡最后一行。

工具栏排序下拉框保留手动排序、最近修改、最新登记和登记批次，移除序缇款号、供应商编码、供货价和唯品价；各字段筛选面板的升序、降序仍可使用。（2026-10-01）

- 表格底部可翻页，并选择每页 20、50、100、200、500、1000 条，默认 20 条；每页条数及最后页码按账号保存到服务器。筛选、排序或分组变更后回到第一页，行号按全部匹配结果连续编号。表头复选框只勾选或取消当前页；逐行勾选可跨页保留，供批量删除、生成收集表或按款导出。单元格框选、整行整列选择、复制和格式设置作用于当前页显示的单元格。跨页粘贴会从起始格继续写入后续已有行，超过末行时新增行。
- 单击单元格选择它；按住鼠标拖动可框选多个单元格。选择后使用「填色」为这些单元格着色，选择「无填色」可清除。选区不额外填色，保留各格原有内容和填色，内部单元格分隔线持续可见，外圈使用蓝色边框表示范围；填色也会自动保存，包括仅填色的空白行。
- 拖选时不连带选中页面文字；鼠标停在表格上、下、左、右边缘会自动滚动并延伸当前页选区，整行拖选只纵向滚动，整列拖选只横向滚动。松开鼠标、按 Esc 或窗口失去焦点后停止。点击表头选择整列时蓝色边框仅显示在数据区域，选中表头以浅橙底色标识。双击或键入进入文字编辑后仍可正常选择文字。（2026-10-04）
- 使用 Ctrl/Cmd+C 复制选中的矩形单元格。复制单个文本单元格后，拖选多个目标单元格并按 Ctrl/Cmd+V，会把同一内容填入选区内每个可编辑的文本单元格，随后自动保存；两个图片列和产品信息收集表回填的只读列会跳过。从外部表格复制多行或多列内容后，单击目标单元格并粘贴，会从该格起按行列分配；行数不足时自动追加空白行并保存。包含换行或制表符的引用单元格仍作为一格处理。图片列不接受文本批量粘贴。双击单元格或开始键入后进入文字编辑，此时粘贴作为当前单元格的文字。
- 勾选行后点击「删除行」可删除已保存或未保存的记录，删除后不能恢复。
- 拖动行号可调整行顺序，调整会自动保存；默认排序为手动排序。
- 所有业务字段的初始列宽为 120px，包括图片、收集表回填列及新增字段。拖动列标题右侧分隔线可以调整列宽，最小为 80px；也可右键表头或单元格选择「设置列宽」，输入数值并选择像素（px）或厘米（cm），点击「确定」应用，「取消」不修改。多选后在选区内右键，可统一设置所选各列的宽度，已有不同宽度时输入框先显示第一列的宽度。厘米按网页标准 1cm = 96/2.54px 换算，最终按整数像素保存，最小约 2.12cm；反复切换单位不会自行改变宽度。实际物理尺寸随屏幕与缩放变化。空值或无效数值不可确定。公开列宽需要编辑权限，保存后同步给有表查看权的其他用户；本人私有字段的列宽只作用于自己，只读账号也可设置。刷新沿用保存配置，固定列的位置同步更新。

- 列宽与行高不会随内容撑开；文本和标签在单元格内换行，超出可见范围的部分裁切。行高可切换紧凑、标准、宽松、超宽（120px）。点击文本单元格可在顶部固定编辑栏查看、换行编辑完整内容，仍然自动保存。
- 「字段管理」可新增自定义字段并维护本人字段定义；有编辑权限的用户可维护原有业务字段和公共显示布局。新字段默认私有，公开后定义及显示布局随本表共享，字段值随记录保存并继续校验内容编辑权限。

## 字段分组快捷 TAB

入口为工具栏「字段分组」，用于把相关列整理为快捷标签，与按登记批次等内容归组的行分组分别设置。

1. 点击「字段分组 → 添加分组」，填写名称（最多40字），选择一个或多个字段，可包含图片字段；同一字段可以加入多个分组。
2. 可继续添加分组、修改名称或字段，也可点击删除按钮移除分组。名称不能为空、不能重复或使用「全部字段」，每组至少选择一个字段。
3. 点击「保存分组」后，表格上方出现「全部字段」及各分组名称 TAB；取消则保留原配置。
4. 点击分组 TAB：已有可见的固定列时，将本组的非固定字段移到固定列右侧，其他字段仍显示在后面，并回到表格横向起始位置。固定列及组内字段分别按原字段顺序排列，同一字段不重复显示；点击「全部字段」恢复原字段顺序，固定列继续保留。
5. 没有可见固定列时，不改变字段顺序，横向滚动定位到该组的第一个可见字段；再次点击当前 TAB 可以重新定位。组内字段并不必须相邻。
6. 当前分组的所有可见字段表头顶部显示暖橙色粗线，包括属于本组的固定列；不属于本组的字段不标注。粗线随表头横向及纵向滚动，不改变表头高度。切换分组即时更新，点击「全部字段」清除分组标注。

分组不会隐藏其他字段、改变记录或清除数据；切换 TAB 清除当前单元格选区及复制虚线，之后的框选、快捷键及复制粘贴按当前显示的列顺序处理。隐藏或删除的字段不参与快捷定位；重新显示隐藏字段后沿用分组；整组没有可见字段时 TAB 不可点击，正在使用的该组返回「全部字段」。仅包含公开字段的分组属于共享布局，新增、修改或删除需要编辑权限；包含本人私有字段的分组仅本人使用，只读账号也可配置。

公开字段分组随本表同步，包含私有字段的分组及最后选中的 TAB 按本人账号和表格保存；刷新或换设备后恢复。没有分组 TAB 时先添加并保存分组；TAB 不可点击时，请检查组内字段是否隐藏、删除或已取消公开，再按自己的权限调整分组。

## 多人编辑

页面每约 10 秒检查资料版本。资料未变化时不下载记录；有变化时只下载新增或修改的记录，并同步删除结果及最新排序。首次打开仍完整读取一次快照，以支持跨页粘贴、分组及筛选。筛选、排序和记录内容来自同一数据库快照，避免读取期间发生修改造成遗漏。页面隐藏时暂停常规轮询与在线心跳。本地存在未保存修改时，远端刷新不会覆盖当前输入。写入仍会进行更新时间校验，冲突记录需刷新后处理。

## 表格导出与标准导入模板（2026-10-10）

入口位于表格顶部，简化为「导入」「导出」两个下拉按钮（2026-10-01）。导入菜单提供「从 Excel 导入商品」及「下载模板」，导入弹窗内也可下载模板；导出菜单提供「导出 Excel」。下载和导出需要查看权限，上传和确认导入需要编辑权限。有未保存修改时，先修正或重试保存，再进行导入导出；模板仍可下载。导出会先等待字段设置保存完成；保存失败或冲突时提示「请先处理未保存或冲突的字段设置，再导出」，处理后再试。

1. 点击「导入 → 下载模板」，或打开导入弹窗点击「下载模板」，取得 XLSX 模板，在「选款资料」填写一行一款的 13 个内置字段。序缇款号必填且唯一；款号、供应商编码按文本填写，保留前导零。日期为有效的 YYYY-MM-DD，金额非负且最多两位小数，颜色和尺码用 `/` 分开。
2. 多张图片在「图片明细」按序缇款号逐图填写颜色和图片URL；颜色必须来自本行颜色字段。也可在主表图片列逐行填写「颜色 | https://图片地址」，但同款不可同时使用两处来源。暂不解析 Excel 浮动图片，不接受公式，请先粘贴为值。
   洗唛/吊牌图在「洗唛吊牌图明细」按序缇款号逐图填写图片URL，不需要颜色；也可在主表「洗唛/吊牌图」列逐行填写网址，同款不可同时使用主表与明细表。两个图片字段分别导入和保留。
3. 点击「导入 → 从 Excel 导入商品」，在弹窗上传区点击选择或拖入 .xlsx 文件（不超过 20 MB、每批最多 500 款），查看新增/更新预览，核对后点击「确认导入」。按序缇款号匹配，已有款更新、新款新增；空白字段保留原值。填写任一组图片只会替换该组原图片，留空则保留。
4. 文件内款号重复、系统同款存在多条记录、图片颜色不匹配或字段格式错误时，不导入整批。若预览后记录被他人修改或新建，则整批不写入；重新选择文件并核对预览后再导入。网络异常可再次点击确认，重复请求不会重复新增。
5. 勾选行后点击「导出 → 导出 Excel」只导出勾选款；未勾选时导出当前筛选的全部款式（包含超过首屏 100 条的记录）。主表「表格资料」包含当前表格显示的全部字段，名称和顺序与表头一致，包括横向滚动后才能看到的列、固定列、自定义字段、系统字段及只读回填字段。已隐藏、已删除或无字段查看权限的列不进入文件。切换字段分组或调整列顺序后，导出沿用当时显示的表头顺序。

导出前重新读取已保存资料及字段布局、核验当前权限；禁止查看或自动隐藏的单元格只写入 `••••`，不输出真实内容，其他允许查看的单元格照常导出。可识别的空白草稿自动忽略，系统生成的创建、修改信息及单元格格式不算填写；数值 `0`、图片及已填自定义字段均算内容，无法确认是否为空的受保护记录保留遮罩。没有可导出记录时提示「没有可导出的资料」，没有可导出列时提示「没有可导出的可见字段」，可核对字段显示及查看权限。缺少款号或存在同号多行仍可逐行导出，不以款号合并记录。（2026-10-10）

文本保留前导零，金额等数值使用原值，多选、标签及复选框导出可读文字；系统字段沿用人员、北京时间及编号显示设置。文件不包含单元格填色、对齐、字体颜色或布局样式。可见图片列在主表显示「见图片明细」，「图片明细」按主表的 Excel 行号、字段位置及名称记录每张允许查看图片的颜色和网址；未显示或受保护图片不进入明细及隐藏图片内容表。（2026-10-10）

可见字段导出文件用于查看和留存当前表格资料，不能直接作为标准导入文件。需导入时使用「导入 → 下载模板」，模板仍只包含 13 个内置字段及两组图片明细，不包含自定义列、填色和布局；款号必填、唯一及上述导入校验继续生效，更新已有款时保留自定义列和布局设置。系统内图片地址需登录同一系统查看，不能当作公开图片链接分享。旧版内嵌图片拆分保存在隐藏「图片内容」工作表，请保留该表；导入时会先将内嵌图片独立上传，再确认写入款式资料。取消导入不会创建或更新款式。

## 右键设置单元格格式

选中单元格或拖选区域后，右键选择「设置单元格格式」。右键选区内保留多选范围，右键选区外改为选择该格。只读账号不可修改格式。

- 「数字格式」提供常规、数值、货币、会计专用、日期、时间、百分比、分数、科学记数、文本、千位分隔样式、特殊（六位编号）、自定义（预设格式）。支持设置 0–8 位显示小数；自定义从预设样式中选择，不支持任意 Excel 格式表达式。分数近似为分母不超过 100 的数值。
- 「单元格」设置水平对齐、垂直对齐、背景填色；「文本」设置字体颜色。批量设置只应用本次修改的项目，其他样式保持各格原设置。
- 点击「应用」后静默自动保存，刷新保留；点击「取消」不更改。保存失败与其他编辑一样显示未保存提示。
- 数字格式仅影响页面显示，点击编辑恢复原始内容；顶部编辑栏、复制和导出仍使用原值。图片、颜色、尺码保持原展示，不应用数字格式。日期接受有效 YYYY-MM-DD，时间接受 HH:mm 或 HH:mm:ss；无法转换的内容保留原文，不把数字推算为日期。超过安全整数范围的账号等长数字不转换。
- 业务校验不受格式影响：价格仍非负且最多两位小数，登记批次仍为有效日期。清空内容保留单元格格式。

空白图片单元格只显示「+ 图片」。点击后打开图片管理卡片，可添加链接或上传；也可直接选中单元格粘贴 http(s) 图片网址，多张图片每行一个网址，自动追加并显示。链接无法加载或不是图片时显示「无效图片」标识，可在「全部」中移除并重新添加；网站禁止外链、需要登录或链接过期也可能导致加载失败。无效文字、非 http(s) 链接会提示修正，不写入其他单元格。只读账号不可粘贴添加。

字段标题不再显示前置小方框符号，仅保留名称与右侧筛选按钮。

## 高级列筛选（2026-10-10）

每个字段（包括图片、颜色、尺码及自定义字段）右侧的筛选按钮打开紧凑面板。选项列表随内容收起，高度最多 180px，更多选项在列表内滚动。勾选、颜色、条件及排序修改后点击「确认」应用；「取消」或关闭面板不应用尚未提交的草稿。可设置该列升序、降序或取消排序。列排序及「导出本列筛选结果」按字段类型比较：数字类型字段（含负数、小数）及价格字段按数值，文本和款号按自然文本顺序，纯数字款号仍按文本类型处理；升序、降序时空白值均排末尾。清除入口统一在对应列面板底部的「清除筛选」，立即保存并应用，步骤见下文。

- 「按选项」列出本列完整内容、空白项及出现次数。选项统计遵循其他列已生效的筛选；颜色/尺码按整组内容统计，不拆成单个标签。搜索忽略大小写，支持空格分隔的任一关键词，可按名称或计数升降序排列选项。输入搜索只缩小面板显示范围，不改变明确勾选的草稿；填写搜索关键词后点击「确认」，筛选取全部搜索匹配项与草稿已勾选项的交集。没有匹配项时显示 0 行；确认前清空搜索保留原草稿勾选。全选和反选作用于全部搜索结果；重复项选择次数大于 1 的内容，唯一项选择仅出现一次的内容。选项每批显示 200 项，确认、全选、计数和筛选均覆盖尚未「加载更多」的全部结果。

## 图片查找同款（2026-10-10）

### 同款反馈与本表学习

普通点击候选卡片只选中查看，不累计学习反馈。核对无误后点「是同款并选择」，保存同款确认并进入该款；点「不是同款」保存否定反馈，按钮变为「已反馈不是同款」，本次不移除卡片，仍可查看或点「是同款并选择」纠正。每次完成查找形成独立查找会话，同一次查找对同一候选的重复反馈不增加确认次数，正负纠正替换该次原反馈；不同查找会话的有效确认可累计。

一次同款确认即可成为本表后续查找的参考案例。仅参考当前表近期有效、关联图片仍可查看且未变化的反馈；相近查询图片的确认可合并参考。对同一款在不同查找会话累计至少两次一致确认、相近案例没有矛盾的否定反馈，且本次比较评分至少98%时，如有其他达标候选还须领先第二名至少2个百分点，才仅显示1款。其他情况仍严格按综合视觉评分大于60%的门槛显示最多3款。否定反馈会使该款的相近案例停止参与学习加分及仅显示1款的判断，原有图片比较继续进行，因此后续仍可能出现该款。

反馈只在当前表格保存图片比较特征和确认记录，不保存查询原图，不跨表共享学习案例；关闭窗口不撤销已保存反馈。这是本表案例学习，不训练通用识别模型，也不保证不同背景、姿态或颜色的图片都能正确识别，即使仅显示1款仍需人工核对。只读账号可对允许查看的候选反馈，不因此获得款式资料或图片编辑权限。

点击候选或提交反馈前会再次核验图片及查看权限；图片已变化、删除或不再允许查看时，清除旧候选并提示重新查找，反馈过期时重新查找后再确认。关闭窗口会清除本次查询图和结果，页面不再接收本次结果。

常见失败：外链或暂时无法读取的图片不参与比较，窗口会显示跳过数量，可在当前表上传款式图片后重试；没有可比较图片或未找到相似候选时，可补图或换图再查。格式无效、图片无法解码或超过1600万像素时，换完整静态图片或缩小尺寸；查询图须压缩至500 KB以下。本表可查看的款式图片超过2,000张时不截取部分图片搜索，须按提示拆分表格后再试。系统繁忙或约24秒超时会提示稍后重试，超时不返回部分结果；可点击「重新查找」或换较小图片。

## 编辑字段名称

在「字段管理」点击字段的编辑图标，修改名称后点击「保存」，最多 40 个字符，不能为空或与现有字段重名；取消不修改。本人创建的字段由本人或超级管理员改名，无创建者归属的原有业务字段由有编辑权限的用户维护。公开字段改名同步给有查看权限的其他用户，私有字段跨设备保存，仅创建者及超级管理员可访问。表头、筛选面板、编辑栏及可见字段 Excel 导出使用新名称，不改变字段数据、类型和校验；标准 Excel 导入模板继续使用标准字段名称。

## 整行、整列与拖动选区

点击表头字段名选中该列当前页筛选显示的全部单元格，按住并横向拖过表头可选择连续多列；先点击起始表头，再按住 Shift 点击末尾表头也可选择连续多列，继续 Shift 点选可调整范围，普通点击重新设置起点。选中表头显示浅橙底色，即使筛选后无记录仍可选择字段并设置列宽或固定列；隐藏字段不参与选择，切页、切换字段分组 TAB 或选择单元格后重新点击起始表头。点击左侧行号选中整行，按住并上下拖过行号可选择连续多行，同时勾选这些行供删除行或按款导出使用。单元格内按住鼠标拖动可选择矩形区域，松开鼠标结束选择。选区可统一填色、对齐、设置格式或按 Delete 清空，也可右键批量固定选区涉及的列或设置列宽。整行选择只包含当前显示的字段，整列选择只包含当前页筛选显示的记录。行排序可拖动行号下方的小手柄；列排序可在字段管理中调整。

## 外部产品信息收集表

需要选款登记编辑权限。勾选已保存的款式，点击「产品信息收集表」，填写名称并生成，一张表最多 100 款。复制链接或分享二维码给填写人；默认 7 天有效，内部可在「查看 / 管理」中提前关闭或重新生成 7 天链接，重新生成后旧链接立即失效。链接仅在生成时显示，请及时复制保存。持有链接的人无需登录即可查看和填写，请只发给对应填写人。

外部只能看到本次所选款式的图片、序缇款号、供应商款号、颜色、尺码范围、材质成分、供货价（不含税）、产品卖点/简介、翻单周期和库存。序缇款号只读，不开放供应商编码、其他销售价格、内部备注等资料。原表字段显示名称不改变外部收集表的标准字段名称。

1. 外部打开链接，可搜索序缇款号或供应商款号，选择款式填写。卖点/简介最多 1000 字符；翻单周期为非负整数天；价格非负且最多两位小数。填写后自动保存草稿，切换款式前会等待当前修改保存完成；失败时保留输入并提示，可点「重试保存」。修改颜色、尺码会保留仍匹配组合的库存，移除组合后对应草稿库存也会移除。
2. 库存数显示现货加做货的合计，点击打开明细。每个颜色与尺码组合分别填数量，现货库存和支持做货库存通过 TAB 切换。无库存填 0；现货大于零需填写预计售罄日期，做货大于零需填写预计出货日期。这里只收集供应能力，不创建系统仓库库存流水。
3. 选择颜色后点击「拍照上传」：电脑端弹出当前款二维码，手机扫码免登录进入本款拍图区；移动端直接调用相机，也可从相册/电脑上传。每张压缩至 500 KB 以下，每款最多 30 张、每张收集表累计最多上传 500 张。移除图片只修改收集表草稿，内部确认前不影响原款。图片已有颜色时须保留该颜色，或先移除对应图片。
4. 填写完一款点击「提交」，只提交当前款，成功后自动进入下一款未提交或被退回的款式；全部提交后提示完成。也可在表格视图勾选多款，或点击「全选待提交」选中所有待提交款，再点「提交所选」一次提交；所选款式逐一校验，任一款不完整时整批均不提交。草稿可先保存，提交时图片至少一张，供应商款号、颜色、尺码范围、材质成分、供货价（不含税）、产品卖点/简介、翻单周期（天）、库存数均必填。库存需覆盖每个颜色尺码组合，无库存可填 0；价格 0 和翻单周期 0 可提交。序缇款号仅内部可填写，允许留空提交。左侧始终按「第1款」至「第N款」编号，标注填写中、已提交、已确认或已退回。已提交款在内部确认前可「撤回编辑」，修改后再次提交；已确认款不可撤回。内部可逐款确认、退回，也可批量处理全部待确认款式；确认后写回选款登记，未提交款不受影响；供货价等未开放字段之外的数据不会被外部修改。序缇款号始终保持原值。
5. 内部可填写原因「退回补充」，外部凭仍有效链接继续修改并再次提交该款。链接过期需重新生成。每款确认后外部保持只读，其他未提交款仍可继续填写。
6. 内部确认时，系统按字段合并分享时原始资料、当前选款登记和外部填写稿。外部未修改的收集字段保留内部最新值；外部修改的收集字段以外部稿为准，即使内部也修改过同一字段，逐款或批量确认均可完成。管理弹窗会列出将被外部稿覆盖的内部字段，可展开查看当前资料及分享时原始资料；如果不希望覆盖，请先退回该款，让外部修正后再提交。序缇款号、供应商编码、其他价格等未开放给外部的字段保持内部值。若内部修改导致合并后的颜色、尺码和库存不再匹配，则整组收集字段采用已提交的外部稿，保证写回资料一致。原款已删除时不能确认，应撤回该款并重新选择记录。外部多人/多设备同时修改草稿仍检查版本，冲突保留当前输入，请先复制保留再重新打开核对。
7. 确认后的产品卖点/简介、翻单周期和库存数在选款登记中显示；这三项当前为收集结果只读字段，库存数可点开查看两类明细。重复收集前可重新生成表格。图片及其他原有字段仍可按原方式维护。

## 图片压缩标准

自本次更新起，全站新上传、拍照或粘贴的图片统一自动压缩至 500 KB 以下（500×1024 字节），包含头像、项目附件、需求示例图、供应链资料、选款登记与外部收集表。文件类型支持 JPG、PNG、WebP；压缩失败会提示并阻止上传。文档限制仍为 50 MB。历史已保存图片和仅引用的外部图片网址不做追溯压缩。

选中整行或整列后可直接 Ctrl/Cmd+C 复制，按当前显示行列顺序输出，可粘贴到 Excel。图片复制为图片地址，库存复制总数，数值 0 保留。连续多单元格仅显示外围蓝色选中框，内部边框隐藏；复制状态的流动虚线也仅显示在外围。分组之间分别显示各组选区边界。

库存日期可在草稿中逐步输入，自动保存不要求提前填完；点击「提交」时校验有效日期及现货/做货对应日期必填。外部表右上角不再单独显示手机拍图按钮。

手机端收集表将款列表收进「全部 / 待提交 / 已提交」三个入口，显示对应数量，点击展开，再次点击收起。待提交包含填写中和已退回，已提交包含待内部确认和已确认。选择款式后自动收起；搜索款号时展开全部搜索结果。电脑端仍显示左侧款列表。

收集表按移动屏幕宽度适配并设置禁止页面手势缩放。手机库存明细保持颜色、尺码、库存数量、预计日期四列表格，缩小列宽与间距以适配屏幕，不使用纵向卡片；电脑保留常规表格。预计售罄日期、预计出货日期均可点击日期输入框使用设备日期选择器，清空日期仍遵循提交时的必填校验。系统强制缩放设置可能覆盖页面限制。

### 右下角选区统计（2026-09-29）

右上方记录数、行数和单元格数已移除。表格右下角根据当前可见选中单元格实时统计，支持整行、整列和多单元格选区；点击统计图标可勾选求和、平均值、计数、数值计数、最大值、最小值，选择「无」隐藏所有统计结果。默认显示求和、平均值、计数。

计数统计非空单元格；数值计数仅含有效数字（含零和负数），文本、日期、图片不参与数值计算，图片单元格有图时计为一个非空格。库存使用汇总数量。无数字时数值结果显示「—」。格式支持普通数字、中文万单位、千分位、万位分隔，仅影响统计显示，最多六位小数；不改变单元格数据。显示设置按账号及表格保存到服务器，刷新或换设备后恢复。

### 拖动调整单项或多项行列顺序（2026-10-10）

1. 拖过左侧行号选择多行，或拖过字段表头选择多列；多列也可先点击起始表头，再按住 Shift 点击末尾表头选择范围。
2. 多选后，再次从所选组内任一行号或表头拖向目标，目标显示橙色提示框后松开；按住 Shift 拖动也支持。整组一起移动：向前拖放在目标前方，向后拖放在目标后方，组内保持原相对顺序；拖到所选组内不改变顺序。未选多项时，按住 Shift 从行号或表头拖动可移动单行或单列。
3. 行顺序自动保存；公开列顺序保存后同步给有查看权限的用户，本人私有列顺序按本人布局保存。只调整顺序，不改字段值、字段标识或保护规则。

仅按住 Shift 点击表头仍选择连续多列，不调序；从多项选区外开始的普通拖动仍框选行列，单元格内普通拖动仍框选单元格。Esc、窗口失焦或在目标之外松开取消移动。行移动要求编辑权限、手动升序且未分组，保存或删除处理中不可移动；表内存在受保护、锁定或他人认领的行时不能调整行顺序。修改公开列顺序需要编辑权限，只读用户仍可调整自己的私有列布局，不能借多列拖动改变公开列顺序。行号下方的小手柄仍只移动单行；字段管理内列调序仍可使用。

列拖动仅在同一显示分区内移动，所选列和目标须处于同一区域：固定列与非固定列不能跨区；有固定列且当前字段分组 TAB 将非固定列分区时，本组列与其他列也不能跨区。提示跨区域移动时，要跨固定区域先取消固定，要跨本组与其他列的区域先切回「全部字段」，再重新选择并拖动。拖动不会自动改变固定状态或字段分组归属。


## 字段管理（2026-10-10）

入口为工具栏「字段管理」，也可点击表头末尾「＋」添加字段。所有有本表查看权限的用户，包括只读账号，都可新增字段；填写字段名称、选择类型及必要选项后点击「保存」。新字段默认「仅本人」，字段定义、已保存值、格式及图片仅向创建者及超级管理员提供；刷新或换设备仍可恢复。新增字段不授予内容编辑权限，只读账号仍不能填写单元格、上传图片或增加记录。

字段列表用「仅本人／公开」标签标明自建字段范围。创建者可编辑自己字段的名称、类型、选项和功能设置，也可删除；除超级管理员外的其他用户不能维护其定义或公开状态，即使具备本表编辑权限。无创建者归属的原有业务字段仍由有编辑权限的用户维护。字段可搜索，通过眼睛图标显示或隐藏、上移下移调整顺序；公开列的显示、顺序属于共享布局，修改需要编辑权限，私有列只改变本人设置。隐藏不会删除内容。

新字段保存后，创建者或超级管理员在字段列表点击「公开」，有本表查看权限的其他用户实时获得字段定义及允许查看的已保存内容；公开仅面向系统内有权限的用户，不是互联网分享。点击「取消公开」后，除创建者及超级管理员外的其他用户立即不再显示该字段及内容，已有资料保留，创建者及超级管理员仍可查看。请求处理中按钮暂不可重复操作，保存失败会提示原因，可重试；尚未保存的单元格输入不会因公开而成为已保存资料。字段公开不绕过模块权限、保护区域或内容自动隐藏规则。

工具栏的按钮和下拉控件按文字、图标自然适配宽度，已取消统一固定宽度，并缩小内边距与间距；无提示时不留空白占位。下拉列表按选项内容展开，窄屏工具栏自动换行；选款登记、新建表格和商品档案共用此规则。（2026-10-05）

每个字段右侧的垃圾桶图标用于删除字段，包括原有业务字段、自定义字段和系统字段。本人或超级管理员可删除自建字段，无创建者归属的业务字段删除需要编辑权限，存在未保存修改时须先处理。点击后核对字段名称及影响范围并确认：删除私有字段从创建者及超级管理员的字段列表移除；删除公开字段从此表所有用户的字段列表移除并同步更新。取消不修改，服务器中的已有资料保留，不删除实际业务列，也不解除保护规则。字段管理不提供已删除字段的列表或恢复入口；新建同名字段使用新的标识，不取回旧资料。已删除字段不参与显示、分组定位或列排序。

### 字段类型管理

### 保护区域与多人填表（2026-10-10）

入口为表格工具栏「保护区域」，提供区域权限、抢占填表、内容自动隐藏三个选项。有本表保护管理权限的用户才可调整规则：选款登记为具有保护管理权限的用户及管理员、超级管理员；项目表格为创建者及超级管理员；商品档案为超级管理员。普通协作用户可以查看开关状态并管理自己认领的行。配置按当前表格保存到服务器，对电脑、手机和其他浏览器同时生效；无需登录的外部收集表继续按分享人的当前权限检查。设置前先处理未保存修改。

区域权限：先选中单元格、行或列，再打开区域权限，点击「添加保护区域」。填写名称，选择保护选中单元格、整行、整列或当前工作表。可在卡片内调整所选行及字段，并添加指定用户，分别设置可编辑、仅查看、禁止查看；其他人也能独立选择这三种权限。选择「仅我可编辑」时只给当前保护管理者指定编辑权限，其他人的权限仍按下方选项配置。保存规则后开启「区域权限」才会生效。整列包含后续新增行，整行包含后续新增字段，当前工作表包含两者。指定单元格以实际行记录和字段标识绑定，改名、排序、分组和筛选不改变对应关系。多个区域重叠时采用更严格的权限；本表保护管理者不受区域规则限制，内容编辑仍须具有相应模块编辑权限。区域授权不会赋予用户原本没有的选款登记查看或编辑模块权限。

仅查看区域无法输入、粘贴、删除、填色或修改格式，可以复制可见内容。禁止查看的单元格显示 ••••，真实字段值和图片不发送到客户端；复制只得到隐藏标记。导出前重新检查权限，无字段查看权限的列不进入文件，禁止查看或自动隐藏的单元格只导出 `••••`，其真实内容及图片不会进入主表、图片明细或隐藏图片内容表；同一行其他允许查看的单元格仍可导出。直接图片地址、手机拍图、导入、删除行、排序改行和收集表内部确认均在服务端检查权限。保护开启时，其他用户使用个人字段筛选，共享筛选由本表保护管理者管理，避免把共享筛选中的私密字段值发送给其他用户。与选款及收集表相关的原始审计记录仅向管理员提供。字段定义及布局修改不改变服务器保护权限；区域管理权限也不将其他人的私有字段变为公开。

抢占填表：本表保护管理者开启后，选中一行单元格，在工具栏点击「认领本行」，或首次保存该行修改时自动认领。每人同时认领一行，同一行只能由一位用户认领；其他普通协作用户不能修改，但仍按区域权限决定是否可查看。选中自己的行点击「完成填表 / 释放」，或在保护区域的抢占填表页释放自己的行，再填写下一行。保护管理者可释放他人认领的行，但显式认领前也需先释放原认领人。关闭抢占填表会释放全部行。手机标准拍图页点击「完成本款 · 下一款」会释放自己的认领，自定义图片手机页提供释放按钮。关闭浏览器不会自动释放，需自己或保护管理者释放。

新增空白行不会自动认领；填写后才认领。抢占开启时，普通用户批量导入或确认外部稿若需同时填写多行，会按一人一行规则拒绝并回滚整批；请逐款处理并释放认领，或由保护管理者关闭抢占后批量操作。

内容自动隐藏按所设置的隐藏区域生效，未纳入区域的单元格照常显示；区域权限、抢占填表和字段公开范围仍各自校验，不能互相替代。

1. 在表格中先选中需隐藏的单元格、行或列，再打开「保护区域 → 内容自动隐藏」，点击「添加隐藏区域」。未选区域时不会默认隐藏整表。

4. 可在区域卡片编辑名称及范围，或删除不再需要的区域；可额外选择指定查看人，同一份指定人名单适用于本表全部隐藏区域。

在已开启的隐藏区域内，已填写值在字段访问范围内仅对本表保护管理者、该行创建人、该字段最近填写人和额外指定查看用户显示；私有字段仍仅创建者及超级管理员可访问。其他人看到 ••••，真实内容、图片及单元格格式不发送给该用户；空白字段仍可根据区域权限填写。区域的禁止查看不会被自动隐藏的指定查看人覆盖。历史字段以记录创建人为可见人，不虚构历史填写人；开启后发生的实际字段修改会记录最近填写人。记录及字段标识绑定所选区域，排序、筛选、分组和字段改名不会改变隐藏对象；隐藏区域重叠不扩大到区域外。

升级前已开启整表自动隐藏的表格保留原保护范围，显示为「原整表自动隐藏」区域；请编辑该区域缩小范围，或删除后重新添加所需区域。升级前未开启的表格不自动建立整表区域。

外部收集表链接不会绕过保护：分享人不再具备所收集字段的查看和编辑权限时，现有链接暂不可访问，内部也无法查看其草稿；保护管理者可关闭链接或恢复授权。有保护管理权限的分享人主动生成的外部分享仍由该分享人授权，保护其他内部用户不会自动关闭其创建的链接。

修改权限后空闲页面自动同步；服务器每次读写按当前权限校验。权限变化时界面更新为服务器资料，尚未保存的编辑不覆盖受保护内容。保护管理者并发修改同一份配置时，后保存的人会收到冲突提示，请重新打开设置核对。无法开启自动隐藏时先保存至少一条有效隐藏区域；提示行未保存时先保存行再设置；范围外仍隐藏时检查是否保留「原整表自动隐藏」区域、其他重叠隐藏区域或区域禁止查看规则。认领冲突时请释放自己已认领的行，或联系保护管理者释放他人认领；禁止编辑时请核对模块角色及保护区域中的指定人权限。

### 系统字段类型（2026-10-01）

在「字段管理 → 添加字段」选择创建人、最后修改人、创建时间、最后修改时间或编号，也可把已有自定义字段改成这些类型；原有业务字段仍按存储兼容性限制类型。系统字段自动生成，不支持手动输入、粘贴或删除其值。改变类型只改变显示，不清空原有手填内容，改回原类型后原值仍保留。

创建人及最后修改人支持姓名、账号、姓名和账号三种显示方式。人员来自服务器记录；创建人保持不变，最后修改人随保存、导入、拍图及内部确认更新。历史记录未明确记录最后修改人时显示「未记录」，不凭猜测回填。创建时间、最后修改时间支持日期或日期时间，按北京时间显示。编号以记录唯一 ID 生成，可设置前缀、后缀及1至20位最少数字位数；不足位数补0，超过时保留完整编号。保存前显示「保存后生成」，排序、筛选及删除其他行不会重排编号，序号允许有空缺。系统字段可加入允许访问的分组、排序和字段筛选，字段设置按公开或私有范围保存；当前显示且有查看权限的系统字段进入可见字段 Excel 导出，沿用人员、时间及编号显示设置，仍不进入标准 Excel 导入模板或外部收集表。
