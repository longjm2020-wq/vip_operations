# 选款登记

更新日期：2026-09-28。入口：ERP系统 → 选款登记。需要选款登记查看权限；编辑和保存需要选款登记编辑权限。

## 用途

选款登记用于集中记录候选款和选款决策。每行独立保存款号、选款名称、品类、来源供应商、状态、选款人、预估成本、到样日期、参考链接和备注。该模块不自动创建商品、SKU、采购订单或库存记录。

## 在线智能表格操作

1. 点击「添加一行」，填写款号和选款名称；两项为必填。可直接在单元格中修改内容，Tab 或 Enter 继续录入。
2. 按需要选择品类、来源供应商、选款状态和选款人。品类仅可选择已启用的末级（三级）品类；选款状态包括待选款、已入选、待复核和不选。
3. 填写预估成本、到样日期、参考链接和备注。参考链接需以 http:// 或 https:// 开头。
4. 点击「保存登记」后才写入系统。保存时逐行校验；失败行会保留在页面中，修正后可再次保存。

## 表格工具

「表格设置」可显示或隐藏字段；「筛选」可按关键词、状态、品类、供应商和选款人过滤；可按状态或供应商分组，并按最近修改、登记时间、款号、成本或到样日期排序。

勾选一行或多行后，使用「填色」标记重点记录。可切换紧凑、标准和宽松行高。填色会随登记记录一起保存，其他表格显示设置仅影响当前浏览器页面。

## 重要边界

选款登记是前置业务资料，不会因状态改为已入选而自动转成商品档案。确认要正式建档时，请在「商品档案」建立商品与 SKU；采购和库存操作仍在各自模块中完成。平台商品同步资料也不会自动写入选款登记。
