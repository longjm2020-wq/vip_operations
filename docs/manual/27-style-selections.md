# 选款登记

更新日期：2026-09-28。入口：ERP系统 → 选款登记。需要选款登记查看权限；编辑、自动保存、删除行需要选款登记编辑权限。管理员、超级管理员、商品运营、采购员和采购经理默认具有这两项权限。

## 用途

选款登记用于在商品正式建档前集中收集候选款资料。每行保存登记批次、图片、款号、供应商信息、颜色尺码、材质、价格和自定义文本信息，不会自动创建商品、SKU、采购订单或库存记录。

## 录入与自动保存

1. 点击「添加一行」建立空白行。空白行不会写入系统；任一字段录入后约一秒自动保存。
2. 登记批次以小标签显示，未填写时显示「日期」；点击标签打开日期选择器，选择后点击「确定」，按 `YYYY-MM-DD` 显示和保存。
3. 颜色和尺码范围以紧凑小标签显示，多项可在单元格内换行。点击单元格可展开完整标签编辑器；输入后按 Enter 添加，也可一次输入多个值，以 `/` 分开。标签右侧的关闭图标可逐一删除。尺码提供 XS、S、M、L、XL、2XL 至 6XL 的可选项。
4. 供货价（不含税）、唯品价、直播价、吊牌价均以 `￥` 显示；金额最多两位小数且不能为负数。
5. 自动保存静默执行，不弹出成功或失败消息，也不显示保存进度文字。失败时保留本地输入，仅将相关单元格标红，悬停可查看具体原因；顶部出现「未保存 · 重试」。不会不断自动重试：格式问题修改后继续自动保存，网络恢复后可点击「未保存 · 重试」。
6. 保存过程中继续输入的内容会保留，并在上一笔保存完成后继续保存。出现并发冲突时，系统不会覆盖其他人的最新修改；请先复制保留尚未保存的输入，再刷新核对并重新编辑。

## 图片

图片不设置每行张数上限，缩略图横向排列，可通过底部滚动条、触控板或触屏左右滑动查看，不会撑大单元格。图片管理浮层也支持横向滑动。

- 点击「链接」小标签，在弹窗中粘贴以 `http://` 或 `https://` 开头的网址后按 Enter 或点击「添加」，可解析并显示图片。
- 点击「上传」小标签选择 JPG、PNG、WebP，支持多选；也可点击图片单元格后直接粘贴截图或剪贴板图片。每张上传或粘贴的图片会自动压缩至 1 MB 以下，逐张独立上传，表格只保存图片地址。将鼠标停在「上传」上可查看提示，不再在每个单元格重复展示说明文字。
- 在每张图片下方选择颜色。可选颜色来自本行「颜色」单元格的标签；图片上会叠加所选颜色标签。修改或删除颜色前，请先为关联图片重新选择颜色或移除图片。
- 点击缩略图可放大预览，支持缩放和切换本行多张图片；按 Esc 或点击关闭按钮返回表格。只读账号也可预览。
- 已有图片时，点击单元格右侧「+」打开图片管理，可添加、移除图片或设置颜色；该浮层中可查看被单元格裁切的全部图片。

## 表格操作

- 单击单元格选择它；按住鼠标拖动可框选多个单元格。选择后使用「填色」为这些单元格着色，选择「无填色」可清除。
- 使用 Ctrl/Cmd+C 复制选中的矩形单元格，Ctrl/Cmd+V 可将制表符或换行分隔的数据粘贴到当前单元格开始的位置。图片列不接受文本批量粘贴。
- 勾选行后点击「删除行」可删除已保存或未保存的记录，删除后不能恢复。
- 拖动行号可调整行顺序，调整会自动保存；默认排序为手动排序。
- 所有列默认宽度为 120px，拖动列标题右侧分隔线可以调整列宽；拖动列标题可以改变列顺序。
- 列宽与行高不会随内容撑开；文本和标签在单元格内换行，超出可见范围的部分裁切。行高可切换紧凑、标准、宽松。点击文本单元格可在浮层中查看、换行编辑完整内容，仍然自动保存。
- 「表格设置」中可隐藏内置字段、拖动调整列顺序，或新增自定义文本列。自定义列的名称和顺序保存在当前浏览器，已经填写的自定义字段值会随记录保存。

## 多人编辑

页面每约 10 秒刷新在线状态与没有本地修改的记录。顶部会显示其他在线协作者的昵称及其编辑状态；本地存在未保存修改时，远端刷新不会覆盖当前输入。写入仍会进行更新时间校验，冲突记录需刷新后处理。

## 字段

| 字段 | 说明 |
| --- | --- |
| 登记批次 | 按日期记录的选款或采购准备批次 |
| 图片 | 多张候选款图片及其颜色标签 |
| 序缇款号 | 系统内部使用的款号 |
| 供应商款号 | 供应商提供的款号 |
| 供应商编码 | 供应商在系统或业务中的编码 |
| 颜色 | 可添加多个颜色标签 |
| 尺码范围 | 可添加多个尺码标签 |
| 材质 | 面料或成分说明 |
| 供货价（不含税） | 不含税的供应商报价 |
| 唯品价 | 唯品会计划售价 |
| 直播价 | 直播渠道计划售价 |
| 吊牌价 | 商品吊牌标示价格 |

## 重要边界

选款登记是前置业务资料，不会自动转成商品档案。确认要正式建档时，请在「商品档案」建立商品与 SKU；采购和库存操作仍在各自模块中完成。平台商品同步资料也不会自动写入选款登记。
