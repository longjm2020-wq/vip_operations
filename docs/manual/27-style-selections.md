# 选款登记

更新日期：2026-09-29。入口：ERP系统 → 选款登记。需要选款登记查看权限；编辑、自动保存、删除行需要选款登记编辑权限。管理员、超级管理员、商品运营、采购员和采购经理默认具有这两项权限。

## 用途

选款登记用于在商品正式建档前集中收集候选款资料。每行保存登记批次、候选款图片、洗唛/吊牌图、款号、供应商信息、颜色尺码、材质、价格和自定义文本信息，不会自动创建商品、SKU、采购订单或库存记录。

## 录入与自动保存

1. 点击「添加一行」建立空白行，约一秒后自动保存为空白记录，刷新后仍保留，也可供手机端按顺序填写。任一字段录入后继续自动保存。
   表格底部可选择 10、20、50、100、200 行后点击「添加 N 行」，一次加入多行；这些空白行同样会自动保存。只读账号不可添加。
2. 登记批次直接显示日期文字，不带边框或底色；未填写时显示「+ 日期」。可在单元格直接输入 `YYYY-MM-DD`，也可选中后在表头上方固定编辑栏输入或选择日期，填写完整后自动保存。
3. 颜色和尺码范围以紧凑小标签显示，多项可在单元格内换行。点击单元格后在表头上方固定编辑栏编辑标签；输入后按 Enter 添加，也可一次输入多个值，以 `/` 分开。标签右侧的关闭图标可逐一删除。尺码提供 XS、S、M、L、XL、2XL 至 6XL、F 的可选项；末尾「其他」用于补充自定义尺码，选择后输入并按回车或点击「添加」，也可取消。「其他」本身不会保存为尺码。选中后按此顺序排列，与点击顺序无关，例如先选 L 再选 S，显示 S/L；自定义尺码排在标准尺码之后，保留其输入顺序。粘贴、导入及保存使用同一排序规则，已有数据在页面读取时按此顺序显示。
4. 供货价（不含税）、唯品价、直播价、吊牌价均以 `￥` 显示；金额最多两位小数且不能为负数。
5. 自动保存静默执行，不弹出成功或失败消息，也不显示保存进度文字。失败时保留本地输入，仅将相关单元格标红，悬停可查看具体原因；顶部出现「未保存 · 重试」。不会不断自动重试：格式问题修改后继续自动保存，网络恢复后可点击「未保存 · 重试」。
6. 保存过程中继续输入的内容会保留，并在上一笔保存完成后继续保存。出现并发冲突时，系统不会覆盖其他人的最新修改；请先复制保留尚未保存的输入，再刷新核对并重新编辑。

填写「序缇款号」时，系统会按去除首尾空格后的完整款号检查所有选款登记行，包括当前搜索或筛选隐藏的行。相同款号出现两行及以上时，这些行的款号单元格以黄色高亮，选中后顶部编辑栏显示重复行数；修改或清空后立即更新。大小写不同视为不同款号，空白不计入。高亮仅提示核对，不阻止自动保存；单元格已有填色仍保留，重复期间由黄色提示覆盖显示。保存失败的红色提示优先显示。

默认使用「超宽行高」，可在工具栏切换紧凑、标准或宽松行高；选项不显示像素数值。

## 删除内容与复制提示

选中一个或多个单元格后按 Delete 清空全部内容并自动保存，保留行、填色及对齐设置；图片及洗唛/吊牌图单元格分别清空对应图片关联，清空颜色时同步移除候选款图片的颜色标签但保留图片。只读账号不能清空。直接键入或双击进入文字编辑后，Delete 按正常方式删除文字；顶部编辑栏同样保留文字编辑行为。

Ctrl+C / Cmd+C 复制所选单元格后显示缓慢流动的虚线框，按 Esc、修改内容或粘贴后结束提示。开启系统减少动态效果时虚线保持静止。虚线仅提示复制范围，不影响系统剪贴板。

## 固定编辑栏、对齐与列筛选

- 文本单元格输入时不显示内部橙色边框，只保留单元格选中框；不再弹出输入框，可直接输入，也可在表头上方固定编辑栏修改；两处同步并静默自动保存。编辑栏显示当前行和字段，表格内滚动时保留在表头上方。日期、颜色、尺码也在此栏编辑；图片仍在单元格内管理。只读账号可查看，不能修改。
- 焦点在表格内时，Ctrl+A（Mac 使用 Cmd+A）全选当前筛选结果中的所有行和可见列单元格，可继续复制或批量设置对齐、填色；不选择被筛选隐藏的行。顶部编辑栏和筛选输入框内的 Ctrl+A 保留全选文字行为。
- 单击或拖选单元格后，在工具栏选择左对齐、居中或右对齐；「垂直对齐」下拉菜单提供顶端对齐、垂直居中、底端对齐，默认垂直居中。可对多个选中单元格同时设置，对齐方式随记录保存，刷新后保留。
- 「填色」图标位于「字体颜色」图标前，两个入口仅显示图标，悬停查看名称。
- 「字体颜色」菜单可给选中单元格设置文字颜色，支持批量设置及恢复默认颜色，与背景填色独立保存；清空内容时保留字体颜色。
- 每个列标题旁的筛选按钮支持包含、等于、为空、不为空，多个列条件同时生效；自定义列也支持筛选。图片按颜色或网址匹配，金额相等按数值比较。清除此列筛选或清除列筛选可恢复显示。
- 列筛选覆盖已完整读取的全部记录，可选择仅自己可见或共享给协作者。按款导出遵循列筛选；勾选可见行时只导出所勾选的可见行。导出文件不包含对齐和字体颜色样式。

## 图片

「图片」与「洗唛/吊牌图」是各自独立的多图字段，不设置每行张数上限。单元格内每次展示一张图片，多图每 4 秒自动轮播，也可点击左右箭头切换；鼠标悬停、键盘聚焦或打开全部图片时暂停，系统设置减少动态效果时不自动播放。图片不会撑大单元格。「全部」按钮固定在图片右下角。点击「全部」打开三列、多行的图片宫格卡片，图片较多时可用鼠标滚轮、触控板或触屏纵向滚动，卡片内同样隐藏滚动条。每张图片右上角显示当前序号/总张数角标。

- 点击「链接」小标签，在弹窗中粘贴以 `http://` 或 `https://` 开头的网址后按 Enter 或点击「添加」，可解析并显示图片。
- 点击「上传」小标签选择 JPG、PNG、WebP，支持多选；也可点击图片单元格后直接粘贴截图或剪贴板图片。每张上传或粘贴的图片会自动压缩至 500 KB 以下，逐张独立上传，表格只保存图片地址。将鼠标停在「上传」上可查看提示，不再在每个单元格重复展示说明文字。
- 在每张图片下方选择颜色。可选颜色来自本行「颜色」单元格的标签；图片上会叠加所选颜色标签。修改或删除颜色前，请先为关联图片重新选择颜色或移除图片。
- 点击缩略图可放大预览并缩放；在「全部」图片宫格内放大后，可切换本行多张图片；关闭按钮位于放大图片右上角，缩放或移动时跟随图片，超出屏幕时保留在可见区域；按 Esc 或点击关闭按钮返回表格。只读账号也可预览。
- 点击单元格的「全部」打开图片卡片，可添加、移除图片或设置颜色。只读账号可查看全部图片，但不能更改颜色或移除图片。颜色下拉选项仅来自本行颜色字段，以 `/` 拆分；图片显示叠加颜色标签。
- 在「洗唛/吊牌图」单元格点击「+ 图片」或「全部」，点击「上传」可一次选择多张 JPG、PNG、WebP；也可逐张追加、粘贴截图或添加图片网址。图片沿用每张压缩至 500 KB 以下的规则，可轮播、放大和逐张移除，修改后自动保存。洗唛/吊牌图不设置颜色标签，也不进入手机拍图和外部产品信息收集表；只读账号只能查看。

## 表格操作

- 单击单元格选择它；按住鼠标拖动可框选多个单元格。选择后使用「填色」为这些单元格着色，选择「无填色」可清除。选中时保留填色，使用蓝色边框表示选区；填色也会自动保存，包括仅填色的空白行。
- 使用 Ctrl/Cmd+C 复制选中的矩形单元格。复制单个文本单元格后，拖选多个目标单元格并按 Ctrl/Cmd+V，会把同一内容填入选区内每个可编辑的文本单元格，随后自动保存；两个图片列和产品信息收集表回填的只读列会跳过。从外部表格复制多行或多列内容后，单击目标单元格并粘贴，会从该格起按行列分配；行数不足时自动追加空白行并保存。包含换行或制表符的引用单元格仍作为一格处理。图片列不接受文本批量粘贴。双击单元格或开始键入后进入文字编辑，此时粘贴作为当前单元格的文字。
- 勾选行后点击「删除行」可删除已保存或未保存的记录，删除后不能恢复。
- 拖动行号可调整行顺序，调整会自动保存；默认排序为手动排序。
- 所有列默认宽度为 120px，拖动列标题右侧分隔线可以调整列宽；拖动列标题可以改变列顺序。
- 列宽与行高不会随内容撑开；文本和标签在单元格内换行，超出可见范围的部分裁切。行高可切换紧凑、标准、宽松、超宽（120px）。点击文本单元格可在顶部固定编辑栏查看、换行编辑完整内容，仍然自动保存。
- 「表格设置」中可隐藏内置字段、拖动调整列顺序，或新增自定义文本列。自定义列的名称和顺序保存在当前浏览器，已经填写的自定义字段值会随记录保存。

## 多人编辑

页面每约 10 秒刷新在线状态与没有本地修改的记录。顶部会显示其他在线协作者的昵称及其编辑状态；本地存在未保存修改时，远端刷新不会覆盖当前输入。写入仍会进行更新时间校验，冲突记录需刷新后处理。

## 字段

| 字段 | 说明 |
| --- | --- |
| 登记批次 | 按日期记录的选款或采购准备批次 |
| 图片 | 多张候选款图片及其颜色标签 |
| 洗唛/吊牌图 | 多张洗唛或吊牌图片，不设置颜色标签 |
| 序缇款号 | 系统内部使用的款号 |
| 供应商款号 | 供应商提供的款号 |
| 供应商编码 | 供应商在系统或业务中的编码 |
| 颜色 | 可添加多个颜色标签 |
| 尺码范围 | 可添加多个尺码标签 |
| 材质 | 面料或成分说明 |
| 供货价（不含税） | 不含税的供应商报价 |
| 唯品价 | 唯品会计划售价 |
| 直播价 | 直播渠道计划售价 |
| 吊牌价 | 商品吊牌标示价格 |

## 重要边界

选款登记是前置业务资料，不会自动转成商品档案。确认要正式建档时，请在「商品档案」建立商品与 SKU；采购和库存操作仍在各自模块中完成。平台商品同步资料也不会自动写入选款登记。

## 按款导入、导出与模板

入口位于表格顶部：「按款导出」「导入资料」「模板下载」。下载和导出需要查看权限，导入需要编辑权限。有未保存修改时，先修正或重试保存，再进行导入导出。

1. 点击「模板下载」取得 XLSX 模板，在「选款资料」填写一行一款的 13 个内置字段。序缇款号必填且唯一；款号、供应商编码按文本填写，保留前导零。日期为有效的 YYYY-MM-DD，金额非负且最多两位小数，颜色和尺码用 `/` 分开。
2. 多张图片在「图片明细」按序缇款号逐图填写颜色和图片URL；颜色必须来自本行颜色字段。也可在主表图片列逐行填写「颜色 | https://图片地址」，但同款不可同时使用两处来源。暂不解析 Excel 浮动图片，不接受公式，请先粘贴为值。
   洗唛/吊牌图在「洗唛吊牌图明细」按序缇款号逐图填写图片URL，不需要颜色；也可在主表「洗唛/吊牌图」列逐行填写网址，同款不可同时使用主表与明细表。两个图片字段分别导入和保留。
3. 点击「导入资料」选择 .xlsx 文件（不超过 20 MB、每批最多 500 款），查看新增/更新预览，核对后点击「确认导入」。按序缇款号匹配，已有款更新、新款新增；空白字段保留原值。填写任一组图片只会替换该组原图片，留空则保留。
4. 文件内款号重复、系统同款存在多条记录、图片颜色不匹配或字段格式错误时，不导入整批。若预览后记录被他人修改或新建，则整批不写入；重新选择文件并核对预览后再导入。网络异常可再次点击确认，重复请求不会重复新增。
5. 勾选行后「按款导出」只导出勾选款；未勾选时导出当前筛选的全部款式（包含超过首屏 100 条的记录）。导出要求每款有唯一序缇款号，重复款可先勾选唯一记录。导出文件可以再次导入。

模板只包含 13 个内置字段及两组图片明细，不包含自定义列、填色和布局；更新已有款时保留这些设置。系统内图片地址需登录同一系统查看，不能当作公开图片链接分享。旧版内嵌图片拆分保存在隐藏「图片内容」工作表，请保留该表；导入时会先将内嵌图片独立上传，再确认写入款式资料。取消导入不会创建或更新款式。

## 右键设置单元格格式

选中单元格或拖选区域后，右键选择「设置单元格格式」。右键选区内保留多选范围，右键选区外改为选择该格。只读账号不可修改格式。

- 「数字格式」提供常规、数值、货币、会计专用、日期、时间、百分比、分数、科学记数、文本、千位分隔样式、特殊（六位编号）、自定义（预设格式）。支持设置 0–8 位显示小数；自定义从预设样式中选择，不支持任意 Excel 格式表达式。分数近似为分母不超过 100 的数值。
- 「单元格」设置水平对齐、垂直对齐、背景填色；「文本」设置字体颜色。批量设置只应用本次修改的项目，其他样式保持各格原设置。
- 点击「应用」后静默自动保存，刷新保留；点击「取消」不更改。保存失败与其他编辑一样显示未保存提示。
- 数字格式仅影响页面显示，点击编辑恢复原始内容；顶部编辑栏、复制和导出仍使用原值。图片、颜色、尺码保持原展示，不应用数字格式。日期接受有效 YYYY-MM-DD，时间接受 HH:mm 或 HH:mm:ss；无法转换的内容保留原文，不把数字推算为日期。超过安全整数范围的账号等长数字不转换。
- 业务校验不受格式影响：价格仍非负且最多两位小数，登记批次仍为有效日期。清空内容保留单元格格式。

空白图片单元格只显示「+ 图片」。点击后打开图片管理卡片，可添加链接或上传；也可直接选中单元格粘贴 http(s) 图片网址，多张图片每行一个网址，自动追加并显示。链接无法加载或不是图片时显示「无效图片」标识，可在「全部」中移除并重新添加；网站禁止外链、需要登录或链接过期也可能导致加载失败。无效文字、非 http(s) 链接会提示修正，不写入其他单元格。只读账号不可粘贴添加。

字段标题不再显示前置小方框符号，仅保留名称与右侧筛选按钮。

## 高级列筛选

每个字段（包括图片、颜色、尺码及自定义字段）右侧的筛选按钮打开紧凑面板。选项列表随内容收起，高度最多 180px，更多选项在列表内滚动。选择后点击「确认」才应用；「取消」或关闭面板不改变现有筛选。可设置该列升序、降序或取消排序，空白值始终排末尾。

- 「按选项」列出本列完整内容、空白项及出现次数。选项统计遵循其他列已生效的筛选；颜色/尺码按整组内容统计，不拆成单个标签。搜索支持空格分隔的任一关键字；可按名称或计数升降序排列选项。全选和反选作用于搜索结果；重复项选择次数大于 1 的内容，唯一项选择仅出现一次的内容。大量选项分批加载，但全选、计数和筛选覆盖全部结果。
- 「按颜色」支持按背景填色或字体颜色勾选，包含无填色、默认字体；「不限颜色」移除颜色限制。
- 「按条件」支持包含、不包含、等于、不等于、开头/结尾、大于/小于（含等于）、介于、为空、不为空。数字按数值比较，日期请使用 YYYY-MM-DD；区间含边界。选项、颜色和条件同时生效，多个列之间也同时生效。
- 「清除筛选」清除本列草稿，点击确认生效；取消排序需单独选择。取消不保存任何草稿设置。
- 「导出」可导出本列选项与计数，或按当前面板草稿导出本列筛选结果（附款号）。要导出完整款式资料，确认后使用表格工具栏「按款导出」。
- 开启「筛选对所有人可见」并确认，需要选款登记编辑权限。共享筛选与列排序存于服务器，有查看权限的协作者约 10 秒内同步；不共享数据编辑，不丢弃未保存内容。其他人正在设置面板时暂停切换，版本冲突会提示重新打开核对，不能覆盖对方的更新。
- 关闭共享开关后确认只作用于自己，不删除公共筛选。可点工具栏「使用共享筛选」重新跟随。仅查看账号可进行自己的本地筛选，不能发布共享筛选。个人筛选刷新后恢复共享状态；共享不包含全局关键词搜索、分组或列显示设置。

## 手机扫码拍图

仅用于选款登记，不涉及商品档案、供应商产品库或企业证件图片。电脑表格工具栏新增「手机拍图」，图片管理卡片也有该入口。逐款二维码需等待该行资料自动保存完成后使用。

1. 打开二维码，用手机扫码；未登录时先用有选款登记权限的内部账号登录，登录后保留当前款入口。二维码仅包含页面地址和记录编号，不包含登录凭证，也不会授权匿名访问。
2. 手机顶部搜索框固定显示，可随时按序缇款号、供应商款号、供应商编码查找。结果分页显示，点击对应款进入；清空搜索可查看全部款式。
3. 页面显示序缇款号、供应商款号、供应商编码、全部颜色与各颜色图片数量。选择颜色，查看「当前拍图」，点击「拍照上传」调用手机相机，或「相册选择」批量上传。仅支持 JPG、PNG、WebP，每张自动压缩至 500 KB 以下；实际拍照入口由手机浏览器决定，请允许相机/相册访问。
4. 已有颜色时直接补拍，序缇款号未填写也可上传。缺少颜色时点击「编辑款号 / 颜色」或「补充资料」，填写后保存。点击手机端「新增款式」会按电脑表格手动排序从上到下进入第一条空白行，并打开资料表单；若没有空白行，则在末尾自动建立一行。已填写序缇款号、供应商款号、供应商编码等资料，或已添加候选款图片、洗唛/吊牌图的行，均不会作为空白行复用。只有填色或格式、没有填写资料的行仍可使用。资料表单至少填写一种颜色，序缇款号、供应商款号/编码均选填；保存后同步到电脑端。已有图片使用的颜色不能直接移除，需要先移除相关图片。颜色总长度不超过 100 个字符。
5. 图片按所选颜色追加，不替换其他图片；点击缩略图可放大。删除按钮确认后同步移除电脑端该图片关联；不会删除整款。未标颜色的历史图片另列保留。
6. 上传完成后点击「完成本款 · 下一款」，按表格手动排序顺序进入当前搜索范围内的下一款；到最后一款会提示，可重新搜索或新增。此按钮不会将该款标记为业务审核完成，也不要求每色必须拍满固定张数。
7. 电脑端无未保存编辑时约 10 秒内自动刷新图片；电脑端存在未保存内容时保留本地输入，保存遇到冲突需刷新核对，避免覆盖手机新图。手机追加/删除采用独立图片操作，多人补拍不会互相覆盖。

上传失败保留失败项，可「重试失败图片」，重复请求不会重复追加同一图片；离开或刷新手机页面会丢失尚未上传的本地文件，请先处理完成。查看账号只能搜索/预览，新增、编辑、拍摄与删除需要选款登记编辑权限。手机的筛选范围仅按顶部搜索，不跟随电脑高级列筛选。

手机拍图页面按手机屏幕宽度适配，已移除右上角「电脑表格」入口。页面设置禁止手势缩放，并避免输入框聚焦时自动放大；部分浏览器的系统级强制缩放设置可能覆盖页面设置。

## 编辑字段名称

在「表格设置」中直接点击任意字段名称输入新名称，回车或离开输入框后保存。内置字段和自定义字段均支持，最多 40 个字符；留空恢复原名称，Esc 撤销本次输入。表头、筛选面板及编辑栏同步显示新名称，当前浏览器刷新后保留，不同步给其他设备。改名仅改变显示名称，不改变字段数据、类型和校验；Excel 导入导出模板继续使用标准字段名称。

## 整行、整列与拖动选区

点击表头字段名选中该列当前筛选显示的全部单元格，按住并横向拖过表头可选择连续多列。点击左侧行号选中整行，按住并上下拖过行号可选择连续多行，同时勾选这些行供删除行或按款导出使用。单元格内按住鼠标拖动可选择矩形区域，松开鼠标结束选择。选区可统一填色、对齐、设置格式或按 Delete 清空。整行选择只包含当前显示的字段，整列选择只包含当前筛选显示的记录。行排序改为拖动行号下方的小手柄；列排序仍可在表格设置中拖动字段调整。

## 外部产品信息收集表

需要选款登记编辑权限。勾选已保存的款式，点击「产品信息收集表」，填写名称并生成，一张表最多 100 款。复制链接或分享二维码给填写人；默认 7 天有效，内部可在「查看 / 管理」中提前关闭或重新生成 7 天链接，重新生成后旧链接立即失效。链接仅在生成时显示，请及时复制保存。持有链接的人无需登录即可查看和填写，请只发给对应填写人。

外部只能看到本次所选款式的图片、序缇款号、供应商款号、颜色、尺码范围、材质成分、供货价（不含税）、产品卖点/简介、翻单周期和库存。序缇款号只读，不开放供应商编码、其他销售价格、内部备注等资料。原表字段显示名称不改变外部收集表的标准字段名称。

1. 外部打开链接，可搜索序缇款号或供应商款号，选择款式填写。卖点/简介最多 1000 字符；翻单周期为非负整数天；价格非负且最多两位小数。填写后自动保存草稿，切换款式前会等待当前修改保存完成；失败时保留输入并提示，可点「重试保存」。修改颜色、尺码会保留仍匹配组合的库存，移除组合后对应草稿库存也会移除。
2. 库存数显示现货加做货的合计，点击打开明细。每个颜色与尺码组合分别填数量，现货库存和支持做货库存通过 TAB 切换。无库存填 0；现货大于零需填写预计售罄日期，做货大于零需填写预计出货日期。这里只收集供应能力，不创建系统仓库库存流水。
3. 选择颜色后点击「拍照上传」：电脑端弹出当前款二维码，手机扫码免登录进入本款拍图区；移动端直接调用相机，也可从相册/电脑上传。每张压缩至 500 KB 以下，每款最多 30 张、每张收集表累计最多上传 500 张。移除图片只修改收集表草稿，内部确认前不影响原款。图片已有颜色时须保留该颜色，或先移除对应图片。
4. 填写完一款点击「提交」，只提交当前款，成功后自动进入下一款未提交或被退回的款式；全部提交后提示完成。左侧始终按「第1款」至「第N款」编号，标注填写中、已提交、已确认或已退回。已提交款在内部确认前可「撤回编辑」，修改后再次提交；已确认款不可撤回。内部可逐款确认、退回，也可批量处理全部待确认款式；确认后写回选款登记，未提交款不受影响；供货价等未开放字段之外的数据不会被外部修改。序缇款号始终保持原值。
5. 内部可填写原因「退回补充」，外部凭仍有效链接继续修改并再次提交该款。链接过期需重新生成。每款确认后外部保持只读，其他未提交款仍可继续填写。
6. 期间若内部修改过原款，确认会提示冲突，整批不更新；请核对后重新生成收集表。外部多人/多设备同时修改时也检查版本，冲突保留当前输入，请先复制保留再重新打开核对，不自动覆盖。
7. 确认后的产品卖点/简介、翻单周期和库存数在选款登记中显示；这三项当前为收集结果只读字段，库存数可点开查看两类明细。重复收集前可重新生成表格。图片及其他原有字段仍可按原方式维护。

## 图片压缩标准

自本次更新起，全站新上传、拍照或粘贴的图片统一自动压缩至 500 KB 以下（500×1024 字节），包含头像、项目附件、需求示例图、供应链资料、选款登记与外部收集表。文件类型支持 JPG、PNG、WebP；压缩失败会提示并阻止上传。文档限制仍为 50 MB。历史已保存图片和仅引用的外部图片网址不做追溯压缩。

选中整行或整列后可直接 Ctrl/Cmd+C 复制，按当前显示行列顺序输出，可粘贴到 Excel。图片复制为图片地址，库存复制总数，数值 0 保留。连续多单元格仅显示外围蓝色选中框，内部边框隐藏；复制状态的流动虚线也仅显示在外围。分组之间分别显示各组选区边界。

库存日期可在草稿中逐步输入，自动保存不要求提前填完；点击「提交」时校验有效日期及现货/做货对应日期必填。外部表右上角不再单独显示手机拍图按钮。

手机端收集表将款列表收进「全部 / 待提交 / 已提交」三个入口，显示对应数量，点击展开，再次点击收起。待提交包含填写中和已退回，已提交包含待内部确认和已确认。选择款式后自动收起；搜索款号时展开全部搜索结果。电脑端仍显示左侧款列表。

收集表按移动屏幕宽度适配并设置禁止页面手势缩放。手机库存明细保持颜色、尺码、库存数量、预计日期四列表格，缩小列宽与间距以适配屏幕，不使用纵向卡片；电脑保留常规表格。预计售罄日期、预计出货日期均可点击日期输入框使用设备日期选择器，清空日期仍遵循提交时的必填校验。系统强制缩放设置可能覆盖页面限制。

### 收集表视图 / 表格视图（2026-09-29）

外部产品信息收集表顶部可通过 TAB 切换两种视图，默认使用收集表视图。表格视图汇总各款状态、图片、款号、颜色、尺码、材质、供货价、卖点、翻单周期和库存；点击对应行「填写 / 查看」从右侧弹出当前款编辑卡片，表格不再插入展开行，沿用自动保存、库存明细、拍照上传、提交与撤回流程。序缇款号仍只读，已提交款需先撤回，已确认款不可编辑。切换视图或款式前会等待草稿保存；保存失败保留当前输入并提示。提交只处理当前款，成功后仍自动进入下一待提交款。

两种视图共享搜索和当前款。电脑表格可在表格内部横向滚动查看字段；手机端将每行字段纵向排列，避免页面左右滑动。库存汇总可直接点开明细，需选择该款为当前款后才可编辑。

表格视图的侧边栏关闭前自动保存草稿；保存失败保持打开并显示原因。提交成功后侧边栏继续显示下一待提交款，手机端侧边栏按屏幕宽度显示，收集表视图仍保留原来的逐款表单。

手机端从款列表选择款式（包括再次选择当前款）或提交后进入下一款，自动定位到该款编辑卡片开头，并避开顶部固定页头；侧边栏切换款式时回到顶部。扫码拍图链接仅首次打开时定位拍图区，之后手动选款回到卡片开头。

### 右下角选区统计（2026-09-29）

右上方记录数、行数和单元格数已移除。表格右下角根据当前可见选中单元格实时统计，支持整行、整列和多单元格选区；点击统计图标可勾选求和、平均值、计数、数值计数、最大值、最小值，选择「无」隐藏所有统计结果。默认显示求和、平均值、计数。

计数统计非空单元格；数值计数仅含有效数字（含零和负数），文本、日期、图片不参与数值计算，图片单元格有图时计为一个非空格。库存使用汇总数量。无数字时数值结果显示「—」。格式支持普通数字、中文万单位、千分位、万位分隔，仅影响统计显示，最多六位小数；不改变单元格数据。显示设置在当前页面会话内保留。

### Shift 拖动调整行列顺序（2026-09-29）

按住 Shift 后从行号或字段表头开始拖动，移到目标行号或表头松开，移动该行或列到目标位置。目标显示橙色提示框；普通拖动仍选择多行、多列。Esc、窗口失焦或在目标之外松开取消移动。行移动要求编辑权限、手动升序且未分组，保存中不可移动；行顺序自动保存。列移动调整当前页面显示顺序，刷新后沿用原有列设置加载规则。原有行小手柄和表格设置内列拖动仍可使用。
