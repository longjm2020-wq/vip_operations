# 对账中心（供应商）

更新日期：2026-09-17。入口：供应链端 → 对账中心。供应商入驻审核通过后可查看、导出本人的账单，不能查看其他供应商资料。

选择月、季度、年度或自定义起止日期，按交易事项筛选。顶部显示交易成功货款、退款扣减、本期应结货款和换货完成笔数。下方明细可点击订单号核对对应订单和售后动态。

- 订单交易成功后自动计入应结货款。
- 退货退款经供应商确认收到退货、序缇确认处理完成后，自动扣减原成交单价乘退货数量的货款。只提交申请不会扣款。
- 换货完成保留记录，货款变动为0。

周期采用北京时间，包含首尾日期全天；按事件发生时间记账。跨月退款在退款完成当期扣减，原成交月份不改动。例如8月成交100元，9月完成退货退款20元，则8月仍记100元，9月记−20元。应结货款不代表已收到银行打款。

点击「导出本期账单」下载Excel，导出所有符合筛选条件的明细及汇总，覆盖全部分页。在线页面约每15秒刷新，可手动刷新。未送达或退款未处理完成时，不会提前记入对应交易事项。

数据有疑问时，核对日期筛选、原订单和售后状态，并联系序缇供应链负责人。账单记录不能直接修改或删除。
