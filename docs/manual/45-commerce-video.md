# 服装口播视频

更新日期：2026-11-28。

## 开始制作

手边已有照片和录音时，可在同一入口选择「原声对口型」直接生成口播。该模式只需要「使用 AIGC 创作」权限和已连接的 fal 服务。素材规格及费用见「AIGC 创作空间 → 原声对口型」。

需要同时拥有「使用 AIGC 创作」和「查看商品」权限。脚本使用已验证的共享 OpenRouter 连接。数字人模板主播使用已配置的数字人服务，系统音色需要启用该服务的文字口播。已配置 fal 时，也可上传本人或已获授权的照片，搭配复刻音色制作短口播。页面会分别提示缺少的连接、音色或主播。

1. 在商品档案勾选一个已保存的款号，点「用小序拍视频」。也可以从「AIGC → 服装口播视频」打开，或在小序输入「帮我拍一条服装带货口播视频」进入。小序会把指令带入创作框。
2. 核对款号和主播，输入一句拍摄要求。例如「做 15 秒竖屏，先讲通勤穿搭，中段给袖口一个特写」。默认使用商品档案中的首张可用商品图，也可以展开选图，最多选四张。可用素材是档案中已上传的 JPG、PNG 或 WebP 商品图。看到只有外部图片链接的款号时，先将实拍图上传到商品档案。
3. 点「生成视频」即提交制作。应用使用有权查看的商品资料写台词，生成数字人口播，再叠加商品图与中文字幕。复刻音色需设置本次配音费用上限，脚本和视频费用按各自供应商计费。上传照片的 fal 短口播为 5～15 秒，刊例为 0.08 美元／秒。提交后将授权照片与合成配音提供给 fal。脚本会按短片长度编排，配音过长时页面会提示缩短文案后再生成。
4. 成片可在卡片中播放、下载，也可在 AIGC 作品库的数字人分类中找到。关闭页面后任务在后台继续，重新打开口播页可从最近任务恢复查看。

## 按款批量制作

打开「服装口播 → 商品口播」，选择「按款批量」。搜索并选中 2 至 10 个商品档案款号，填写一条共同的拍摄要求，再选择授权主播。每款分别读取自己的商品资料，默认使用首张可用实拍图。使用复刻音色时填写每款配音预算上限，脚本、配音、视频分别按各供应商计费。

提交后打开批次进度查看各款状态，点「查看」可播放或修改已完成的单款视频。缺图或生成失败会记在对应条目，其他款号继续。可在「最近批次」重新打开。账号同时最多排队 10 条批量口播任务，超过时等待前面的任务办理。

## 保存和使用主播

在「设置主播」或「主播」中选择数字人形象及音色。可选用已启用的形象模板，也可为 fal 上传一张宽高均至少 256 像素、10 MB 以内的 JPG、PNG 或 WebP 照片。确认使用授权后保存。选择上传照片的 fal 形象时，请绑定已经可用的复刻音色。同账号可在后续款号直接选用保存的主播。

### 使用百炼复刻音色

1. 管理员打开「AIGC 服务配置 → 百炼音色连接」，可单独保存百炼北京业务空间和 API Key，也可复用已有小序语音连接。点「核验音色连接」可只读检查音色接口及业务空间的模型推理权限，过程不上传录音或发起合成。保存配置后再创建音色。已有 AgentAI 克隆音色也可继续选用。
2. 点「设置主播」并打开百炼音色，选择 Qwen Audio 3.1 TTS Plus、CosyVoice 3.5 Plus 或 CosyVoice 3.5 Flash。上传本人或已授权的清晰单人 WAV、MP3 或 M4A，建议 10～20 秒。参考样本需至少包含 5 秒清晰人声，最长 60 秒，文件不超过 10 MB。勾选录音授权，并同意提交给百炼。
3. 音色可用后可填写短台词试听，再选择此音色并保存主播。按百炼北京刊例创建音色免费，试听和正式配音按合成文字收费。Qwen Audio 3.1 TTS Plus 每万字符 1.4 元，CosyVoice 3.5 Plus 为 1.5 元，CosyVoice 3.5 Flash 为 0.8 元。费用以供应商回执为准。
4. 同一音色绑定所选模型和创建时的北京业务空间。换模型时需要为该模型创建一份音色。删除音色会影响使用该音色的主播。撤销主播后，后续任务需选择其他授权主播。已完成作品可继续查看。

收到百炼 403 时，检查 API Key 的授权范围与北京业务空间的模型权限，包括音色管理接口使用的 `voice-enrollment` 和所选合成模型。修正后可用同一段录音重新提交。页面显示百炼请求编号时，可用它查询对应回执。模型授权查询可见范围取决于密钥权限。

## 查看和修改

展开「分镜」查看台词和匹配的商品图。成片后可替换一镜的商品图或改为纯口播，后台复用已有音轨与数字人视频重新合成。输出为 720×1280 MP4，实际时长取决于生成的语音。字幕时间按各段台词长度分配，发布前请试听并检查字幕、商品颜色和款型。

如果页面提示服务未就绪，请管理员核对脚本与数字人连接。某个商品缺少照片时可先制作其他款号。显示提交结果待核对时，请先核对已有任务和供应商记录，避免重复计费。

## 爆款复刻工作流（全流程制作）

在服装口播页面切换至「爆款复刻工作流」，支持从同行爆款采集、逆向拆解、分镜脚本与分镜图生成、CozyClay 三维预演到多模型视频与口播成片合成的完整闭环，并提供 **人工介入修改** 与 **全自动模式** 两种执行方式。

1. **抖音 / 小红书一键拆解复刻**：可直接粘贴抖音、小红书分享文案/链接导入，或安装仓库 `apps/browser-extension` 提供的 Chrome / Edge 插件。安装并在插件设置中填写 XUTI 站点地址后（自动复用浏览器登录态），在抖音或小红书浏览作品时右键点击「一键拆解复刻到 XUTI」即可自动创建工作流并开始逆向拆解。
2. **资产融合与全环节模型配置**：绑定数字人主播、商品档案款号与实拍图，上传多角色形象图、道具图与场景背景图并填写拍摄需求。每个环节均可独立选择执行模型：
   - **逆向拆解 / 分镜脚本模型**：支持 Gemini 4 Neon、ChatGPT 6.2 Astra、GPT 6.1 Sol 及已接入的 AgentAI / 中转站模型。
   - **分镜图模型**：支持 AgentAI GT Image 2.6 Sunburst / Flare、GM NB 2.1 Image 等。
   - **克隆音频模型**：支持 Qwen Audio 3.1 TTS Plus、CosyVoice 3.5 Plus、CosyVoice 3.5 Flash。
   - **对口型模型**：MiniMax H3 Max Lip Sync（fal）。
   - **视频生成模型**：支持百炼 MiniMax H3、AgentAI MiniMax H3、Seedance 2.5 及通过动态目录接入的 Magi-2，且支持单镜覆盖。
3. **CozyClay 三维预演**：管理员在「AIGC 服务设置 → CozyClay 三维预演」配置独立部署的 CozyClay Web 地址后，可在工作流第 ⑤ 步一键导出标准 `.cclayproject`（v5）工程草稿并在内嵌 iframe（支持全屏）中进行 3D 机位、走位与道具交接预演，完成后回传灰模视频与首尾帧绑定对应分镜。
4. **全自动 / 人工介入修改**：人工介入模式下，逆向拆解结果、分镜脚本（增删改与镜头类型切换）、分镜图（重绘或手动替换）、CozyClay 预演与单镜视频均可随时编辑或重试；也可随时点击「全自动跑完剩余步骤」自动完成后续生产与 FFmpeg 混剪合成。
