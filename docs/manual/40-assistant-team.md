# 历史协作档案

更新日期：2026-11-22。

拥有小序使用权限的账号可从「我的工作台 → 任务与文件」展开「历史协作档案」，查看本人以前的独立团队记录。

- 「历史任务」显示本人最近 30 个旧协作任务。打开详情可查看执行状态、验收意见、正文和已保存文件。
- 「知识档案」可查询以前归档的成果及其来源。未通过独立验收的旧版本沿用原状态。
- 新工作从「AI 员工」进入，点员工头像独立交办，或在「小序派单」提交协作目标。打开、刷新历史记录仅查询已有数据。
- 空列表表示当前账号在对应分类没有可显示的记录。打开文件仍须具备当前账号的访问权限。

员工配置、排队、暂停及成果复用见「AI 员工工作台」。原团队实际产生的费用可由有权限的管理员在「AI 模型管理」查询历史记录。

切换期间，旧团队中尚在排队的任务会停止排队。执行中断的任务会保留已保存的文件和步骤，并提示核对结果。需要继续工作时，可将所需文件附到 AI 员工的新任务上。
