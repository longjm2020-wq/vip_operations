# 智能体团队

修订日期：2026-11-08

## 入口与前提

从小序聊天输入栏的模型菜单选择「智能体团队」，输入目标或使用麦克风听写，核对后提交。文字、团队进度与交付、实时语音记录共用同一个聊天面板。选择具体对话模型可继续普通提问，原草稿与记录保留。实时语音仍采用独立语音配置；选中团队不会自动把通话变成团队任务。

需要具有个人助理使用权限，并已启用和验证共享 AI 创作服务。新任务统一使用网站团队，提供成员配置、办公文档、已配置的图片视频工具、逐步独立验收和知识归档；不再提供另一套 DeerFlow 新任务入口。面板显示服务未就绪时不能提交任务，原因会显示在面板中。

输入区仅保留附件、模型／团队选择、麦克风和主按钮。旧的「团队协作」说明条与「返回个人助理」按钮已移除。成员配置、任务档案与知识档案位于「更多 → 团队设置」，设置后用「返回聊天并使用团队」继续。每次新任务会带入本人最近12条已保存聊天背景，每条最多1,200字，包含文字、已保存语音和关联团队成果；不自动携带旧附件原文或未发送内容。后续普通对话可以追问团队的实际结果。

## 统一团队与历史任务

「系统设置 → AI 模型管理」只保留「智能体团队」一行，默认模型与实际新任务一致。成员、协作设置与本次任务模型选择均可使用，既有个人配置保留。旧 DeerFlow 服务是否配置不再决定新任务路由，也不会阻止网站团队使用。

已提交的 DeerFlow 任务保留原执行方式、进度、停止操作和文件，在「团队设置 → 协作任务」继续查看；重复提交同一任务标识仍返回原任务，不改换执行方式或重复计费。历史交付仍按原验收状态展示，不因合并自动标为验收通过，也不会自动加入知识档案。旧服务连接仅供已提交任务继续处理；尚有运行任务时需保持该服务可用。

网站团队提供上述创作与验收能力。本站历史 DeerFlow 部署主要提供公开研究和隔离的文本文件交付，未接入办公文档、图片视频专用工具及独立验收归档流程；其历史交付仍适用这些能力限制。

团队文字模型使用已有创作服务的服务端密钥，当前支持该服务目录中的型号；无须为每个成员重新填写密钥。图片生成使用图像目录，视频生成还需要 AIGC 使用权限和已配置的 AIGC 视频服务。千问实时语音的余额与团队创作服务的余额分别以对应供应商账户为准。

## 默认团队与新增成员

默认提供七个成员：

| 成员 | 职责 |
| --- | --- |
| 小序 · 主脑 | 理解目标、制定实施方案、拆分步骤及依赖、分配负责人，汇总实际完成的成果 |
| 小序 · 调度与验收 | 从知识档案获得资料简报，分发执行背景；按验收标准独立检查交付，退回具体修改意见 |
| 小序 · 知识库 | 挑选相关已验收资料，整理交付摘要与标签，归档可复用成果 |
| 小序 · 研究员 | 查询公开资料、趋势和素材来源，附可核验引用 |
| 小序 · 编剧 | 编写文案、剧本、分镜说明和办公文件 |
| 小序 · 设计师 | 使用授权参考图进行图像编辑、设计或生成 |
| 小序 · 视频制作 | 剪辑已有视频，或调用已配置的视频模型生成参考图短片 |

在团队配置中可修改名称、职责、模型，新增自定义成员，或停用执行成员。主脑、调度验收和知识归档三个基础角色各须保留一个且启用。最多24个成员；添加角色本身不会授予更多业务、电脑或外部服务权限。

修改后点击保存团队配置，立即按当前账号独立保存。若其他页面已修改，保存会提示冲突，保留当前草稿，需刷新核对。每个任务使用提交时的配置快照，后续修改用于新任务，不改变运行中的成员职责和模型策略。

## 独立模型与自动匹配

每个成员可选择「自动选择」或「指定模型」。团队设置展示具体型号，便于分配专业能力；文字推理与小序共享多模态目录，仅保留支持文字和图片输入、文字回复及工具调用的模型。图像和视频生成模型与文字推理模型分别选择，实时语音继续使用专用配置。

文字模型优先级为：本次任务指定模型 → 成员指定模型 → AI 模型管理的功能默认值 → 自动匹配。团队面板「本次任务设置」中的模型覆盖只作用于文字推理，不改变成员的图像或视频生成模型。固定型号不可用、不具备所需输入或结构化输出能力时，任务会说明原因，不在失败后悄悄换型号重试。

自动模式由主脑在计划中评估每一步的简单、标准或复杂程度，服务器再结合当前目录的工具、视觉、PDF及结构化输出能力筛选。主脑默认优先较强能力，简单整理偏向快速模型。选型是当前目录内的能力策略，不是全球模型排名，也不承诺最便宜。执行详情展示步骤实际使用的模型与选择理由。

简单任务选定型号后，若同一型号另有已配置且满足输入能力的快速模式，会优先使用该模式；不会仅因型号名称含有 `flash` 就假定已关闭额外推理，也不会擅自设置目录未提供的模式。固定选择保留原型号及其模式。

团队文字执行使用同步对话接口，型号中明确标记为 `:batch`、`:async` 等批处理或异步模式的选项不进入团队可选目录，也不会被自动选中。同一能力档位保留服务目录的优先顺序，不按内部型号编号排序。旧配置或本次任务固定指定异步型号时，会在调用前提示不兼容；不会发起该型号的执行请求或自动换成其他型号。

## 提交目标与执行

1. 从聊天输入栏模型菜单选择「智能体团队」，输入需要的结果、受众、用途和验收要求。例：「根据附件商品资料，先核实公开趋势，再写三版短视频脚本，分别给出开头、分镜、口播与行动引导，最后整理成文档」。
2. 需要处理图片、文档或视频时，使用原附件按钮添加素材。附件仍遵守现有格式、数量和大小限制。可展开团队面板的「本次任务设置」，选择本次文字模型及是否复用已验收的团队知识档案；未选择时不检索旧档案。
3. 团队配置中的联网开关决定研究成员能否查询公开网页。搜索只应提交公开关键词，公开资料附来源；不会读取你的浏览器登录状态或自行抓取本机文件。
4. 提交后主脑生成方案与步骤，独立步骤按并行上限执行，有依赖的步骤等待前置交付通过验收。关闭面板不取消后台任务，刷新后可从任务列表查看。历史任务列表可独立滚动，点击任务后在下方查看完整目标、进度和交付详情。
5. 每一步先产生真实交付，再由调度验收成员检查。需要文档、图片、视频的步骤必须有实际文件；研究交付必须有查询返回的来源。排队回执、提示词、计划和口头承诺不算完成。
6. 验收未通过时保存驳回版本和具体修改意见，由原负责人重新处理；通过后由知识成员整理标签及摘要归档，再由主脑汇总。

默认最多8个步骤、同时执行2个步骤、每个步骤最多退回修改1次。可在设置中调整：最多12步、并行1至3步、退回0至2次。每账号最多3个排队或运行中的团队任务。自动重做也可能再次调用模型或生成服务并产生费用，按实际用量计费。

执行成员只给出正文却声称文件或研究交付已经完成时，团队会在同一步骤内最多纠正一次遗漏的文档创建或公开搜索调用，再按真实结果判断。明确缺少资料或工具、服务已经失败时，不强迫继续执行；已有成功回执的图片、视频任务不会因此重复提交。仍未取得所需文件或来源时，会如实保留未完成原因，不把漏调用工具误报为系统没有对应能力。

## 交付、档案与停止

任务详情显示负责人、任务难度、实际模型、依赖、处理次数、状态及验收意见。交付物保留正文、真实文件和引用；未通过的版本仍在该任务中可见。知识档案仅收录当前账号已验收成果，可检索并供后续任务选用，不与其他用户共享，不把个人记忆当作知识库。摘要和标签描述内容主题与用途，流程状态以任务和档案状态为准。

独立验收意见先保存，知识摘要和标签是辅助信息。若摘要模型没有返回有效结果，系统不换型号、不重试该调用，仍将已验收的原始产物和验收意见实际归档，并明确标注「知识摘要未生成，原始产物与验收意见已归档」；原文仍可用于检索。取消任务、权限或执行租约失效、实际归档写入失败时不会标记为已归档。

复用知识时，选中档案的当前数据库状态、已保存验收意见和仍可用的本人文件信息会直接交给执行与验收成员；简报转述或历史正文中的「待归档」等旧描述不能覆盖当前状态。实际文件正文或视觉内容由服务器在所有权校验后提供，仍保留正文截断、无法提取及视频抽样等限制。

选择「停止团队任务」会停止后续调度，取消关联的排队任务并中止本机可取消的运行处理。已提交给远端生成服务的请求不保证能停止或退费；任务不会自动重新提交。中断、服务失败和无法核验的结果会保留已完成的部分并说明需处理事项。

缺少必要资料、没有可用服务、指定型号不兼容或超过修改次数时，状态显示需要用户补充。核对已有交付和错误后，补充条件再发起目标，已验收档案可以继续复用。系统不会无限重试，也不会自动充值、关闭费用保护、发送邮件、发布作品或删除业务数据。

## 创作能力范围

- 文档支持 Word、Excel、PPT、Markdown、文本和 CSV；生成新文件，不执行宏、代码或表格公式。文件名已含所选格式扩展名时不重复追加。
- 图片支持当前目录提供的生成和参考图编辑。素材范围包括任务主动附加的文件、已验收依赖的文件、启用知识复用后选中档案仍存在的文件，以及本步骤被驳回版本的文件。是否支持参考图及画幅由具体模型决定。每步执行和验收的可用文件合计最多30份，超过时明确暂停并请求缩小范围。
- 视频剪辑支持现有素材的裁切、拼接、变速、静音和画幅调整。视频生成复用已配置的 AIGC 服务，每个生成任务为1至15秒短片、1至4张参考图，实际数量、时长、画幅按所选模型目录校验，不擅自延长时长或丢弃参考图。长视频可规划为多个生成步骤后再剪辑；超出步骤或服务限制时需调整目标。
- 网络研究交付公开信息与图片、视频、音频素材的来源链接，不自动下载、购买、转载或确认素材使用权。需要编辑具体文件时请将文件附加到任务。
- 验收结合实际正文、文件及可用视觉输入。视频使用抽样画面和元数据，不代表完整观看、识别音轨或逐帧检查；要求超出可观察证据时会提出人工核对，不虚构验收结论。
- 团队后台不会因成员职责文字而获得网页点击、桌面控制、商品修改或发送消息权限。实时语音页面操作与电脑任务继续走原有独立授权通道。

## 常见问题

「团队服务未就绪」：请管理员检查已有 AI 创作服务是否启用、验证及账户是否可用。语音已可用不等于创作服务已配置。

「指定模型不可用」：刷新目录，核对成员或本次任务指定的型号；该任务不会自动切换付费服务。

模型步骤在发起调用前记录所选型号和理由，调用失败后仍可核对。错误提示仅显示安全的 HTTP 状态及已知分类；404 表示型号或请求资源不可用，不能仅凭状态认定为密钥问题。验收标准检查交付本身的内容、来源与文件；独立验收、归档和主脑汇总由系统依次执行，不作为作者交付前必须完成的条件。

「达到模型输出额度」表示供应商明确报告结果被截断，系统不会执行其中可能不完整的工具参数，也不会自动重试。「未返回可用正文」表示没有可用文字，不能仅凭空结果认定具体原因；已通过验收的产物不会因为可选知识摘要缺失而丢失。

「没有视频生成模型」：检查当前账号 AIGC 使用权限和 AIGC 服务配置；仍可剪辑已上传视频。不同模型对首帧、多图、时长和画幅要求不同。

「需要用户补充」：展开具体步骤查看原因。已完成的交付保留；需要核对远端任务时，先查看任务与文件中的真实结果，避免重复提交付费生成。

## 全站模型管理（2026-11-08）

「系统设置 → AI 模型管理」统一显示智能体团队的默认模型、API 来源、状态和实际用量。任务或成员指定优先，未固定型号时再采用功能默认值。所选期间内网站团队和历史 DeerFlow 的文字用量合并展示，原始记录不变；各计费单位分开合计，未知用量不视为零。接通状态和最近调用信息只依据网站团队，不能用历史 DeerFlow 成功记录证明当前团队可用。图像和视频等子调用统计在相应生成服务行，团队文字 Token 并非整个任务总费用。
