# 采购建议

更新日期：2026-09-16。入口：采购建议。

## 生成与处理

1. 点击生成采购建议，选择 SKU，明确填写目标库存天数。
2. 查看生成结果中的新增、已有及跳过数量；核对页面给出的依据。
3. 确认实际采购量。修改系统建议量需填写原因；不采用建议时可忽略并填写原因。
4. 可使用「表格确认采购量」集中处理当前页待确认建议，保存前逐行核对。

## 当前限制

未接入真实销售数据时，不生成貌似有效的补货建议，可到采购订单手工建单。唯品会商品资料同步不代表销量同步，不能据此认为已有近 7 天销量。重新生成已忽略建议时需说明原因；避免反复生成后重复采购。

系统建议量与实际确认量分开保留。表格保存是确认业务操作，不只是暂存文字。
