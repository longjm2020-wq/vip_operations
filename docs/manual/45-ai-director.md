# AI 导演台

更新日期为 2026-11-27。具有小序使用权限的账号可从工作台打开「AI 导演台」。项目、分镜和导出版本独立保存，使用当前账号的素材与已授权的 Windows 电脑。无需启用 AIGC。

## 创建项目与准备素材

在导演台新建项目，填写一句创作要求，例如「给第一次选通勤衬衫的顾客做一条 30 秒竖屏短视频，先讲版型，再展示面料细节」。也可以在小序自动识别模式附上文件，并直接发送创作要求。项目支持 9:16、16:9、1:1，可指定只需要脚本或生成成片。人工模式也可以从空白分镜开始。

从工作台上传或选择素材，或在 Windows 导演台选择本机文件、素材文件夹。检查每个素材的角色。商品图片和视频用于成片，商品文档提供事实，参考片用于研究表达方式。授权肖像与授权音色分别用于口播画面与声音合成。已经录好的正式配音可直接使用。系统根据文件名及类型建议角色，重名、含义不明或推断错误时可自行改选。本人或授权素材的使用许可在项目中勾选。素材名称与授权记录都属于当前项目。

工作台接收 WAV、MP3、M4A 音频，每个文件最多 20 MB、时长最多 30 分钟。本机文件保存在所选电脑上。在页面选择「拆解参考片」可查看时间点、构图和节奏。分析工作台视频时服务端抽取画面。本机视频需要在保存素材的电脑上选择拆解，将抽取的画面传给分析服务。参考片只用于分析；创建分镜时使用自己的素材。

**整包导入本机素材。** 在 Windows 桌面端 1.3.1 或更新版本打开项目，点「导入本机文件夹」，一次选择素材根目录。导演台会扫描它及子文件夹中的图片、音频和视频。压缩包请先解压。也可用「导入本机文件」多选。一个项目最多容纳 500 份素材，单文件和整包可达几十 GB，单份音视频最长 24 小时。导入时可以看到已检查的文件数。结束时会显示新增、重复、跳过的情况；已满的项目可另建项目接着导入。确认素材角色后点「保存项目」。

新版会在本机记录原文件的位置，导入时只读取必要的媒体信息。预览、取帧和剪辑时需要访问同一份原文件。请保留原位置，使用移动硬盘时保持连接。若移动、改名或替换了文件，请恢复原件，或重新导入并在分镜里改选。旧版已导入的素材仍可使用已保存的副本。导出时需为成片及镜头缓存预留空间。

## 导演与剪辑

- **人工确定**。逐镜填写台词、字幕、时长、素材、起始位置和动效，可调整顺序、替换镜头或比较候选。点击「确认分镜并后台剪辑」执行保存好的版本。
- **智能导演**。按简报、商品资料和参考片分析形成原创分镜。选择「脚本」可在编排后查看和导出。选择生成成片并在可渲染的桌面端发起，可继续后台剪辑。缺少素材、模型或设备时，页面保留当前项目并提示要补的项目。
- **局部修改**。锁定整镜或镜头中的文案、素材、动效，然后重编其他部分。可对单镜试剪，或保存后导出完整版本。改动镜头后可复用仍适用的渲染缓存。

模型使用系统设置「AI 模型管理」中的导演创作与分镜、导演参考片拆解。工作台视频优先从画面切换附近取样。把参考片的同名 SRT 一起上传为文字资料，例如「同行参考.mp4」和「同行参考.srt」，分析就能结合带时间点的台词。没有字幕时只分析画面。填写素材备注和可核实的商品事实能改善脚本质量。

## 本机执行和交付

在「我的电脑」连接并授权 Windows 设备，使用支持导演台的 1.3.0 或更新桌面端，并安装包含 libx264、AAC 的 FFmpeg。可将其 bin 目录加入 PATH，或将 XUTI_DIRECTOR_FFMPEG 指向 ffmpeg.exe 的完整路径后重新启动小序。普通浏览器也能编排项目和下载分镜稿。导出在本机后台执行，鼠标和前台窗口可继续使用。

在「后台进度与交付」查看进度、暂停或继续，结束后可以打开交付目录。每版包含 MP4 成片、分镜稿、SRT 字幕和 edit-plan.json，可回看选用的素材与每个镜头的时序。锁定的镜头和已导出的版本可用来比较改稿前后效果。

正式配音配有人工字幕时使用填写的字幕。留空字幕并在执行电脑配置 AutoSubs 后，客户端可按录音的实际语句和时间点生成 SRT。已有脚本也可用于字幕。

内置动效包括推近、淡入淡出、标注和尺码卡。配置好 Lottie 引擎后，可直接选用随包的 product-title 商品标题模板；按镜头标题自动替换文字。高级模板需要在该电脑登记 Lottie、PAG 或 After Effects 工程，并准备相应引擎。可替换模板使用镜头标题、标注或字幕、项目名称；镜头选用商品图片时可替换模板的商品图层。原生 AEP 需要有可用的 After Effects 渲染器。Qwen3-TTS Base 声音克隆、MuseTalk 1.5 肖像口型由本机媒体引擎执行。没有配置相应引擎时仍可选择商品素材、录音及内置动效制作视频。管理员可按桌面发布包中的媒体引擎配置说明启用对应能力。

## 遇到问题

- 「模型连接不可用」时，请管理员检查通用模型连接以及导演功能型号。可以继续手写分镜。
- 信息不足时，通过素材角色、备注和镜头素材选择修正。换电脑后应使用原执行电脑继续本地项目，或重新导入所需文件。
- 项目在其他页面更新后，先载入最新修订再编辑。后台导出以启动时的版本为准。
