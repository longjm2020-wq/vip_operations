# AI 导演台

更新日期为 2026-11-27。具有小序使用权限的账号可从工作台打开「AI 导演台」。项目、分镜和导出版本独立保存，使用当前账号的素材与已授权的 Windows 电脑。无需启用 AIGC。

## 第一次做一条短片

1. 点「新建项目」并命名。在「整理素材」点「导入素材」→「导入本机文件」。选好文件后，点素材行即可预览并核对用途。若商品视频被标为「文字资料」，选中后点「用作商品画面」即可更改。
2. 选中用作商品素材的图片或视频，点「用此素材创建分镜」。导演台会把画面绑定到新镜头，并打开「编排分镜」。编辑脚本、字幕或时长，点时间线上的镜头即可切换。也可以直接进「编排分镜」，从「新增空白分镜」开始，或填写创作要求后请 AI 起草。
3. 点「交付导出」。浏览器和桌面端都能导出分镜脚本；在已授权且具备剪辑能力的 Windows 电脑上，还可启动后台剪辑，在同页查看进度和产物。

顶部工具栏可以切换项目、展开「项目设置」或「保存项目」。名称、画幅、目标时长、创作方式和交付目标都在设置里。工具栏下方的「整理素材」「编排分镜」「交付导出」可随时切换，当前步骤带有下划线。切换步骤会保留编辑，离开项目前请点「保存项目」。再次进入导演台时也可从「继续制作」打开最近编辑的项目。

导演台使用与其他页面相同的外边距。收起侧栏时，工作区会随之变宽。在桌面整理素材时，选中的图片或视频按原比例使用可用的预览空间。窄屏上，素材列表与预览上下排列，可纵向滚动查看。

工作台图片可以直接查看，浏览器支持的视频和音频可在页面播放。在原电脑已连接并授权、FFmpeg 可用时，本机图片和视频会在预览区显示静帧。选择分镜后，视频画面取自该镜头的起始位置。取帧预览在本机完成，点「在本机预览」可以打开原文件完整播放。

## 创建项目与准备素材

在导演台新建项目，填写一句创作要求，例如「给第一次选通勤衬衫的顾客做一条 30 秒竖屏短视频，先讲版型，再展示面料细节」。也可以在小序自动识别模式附上文件，并直接发送创作要求。项目支持 9:16、16:9、1:1，可指定只需要脚本或生成成片。人工模式也可以从空白分镜开始。

网页端和 Windows 桌面端的「导入素材」菜单都有五项。「导入本机文件」支持多选，「导入本机文件夹」支持整包导入。「从工作台文件选择」引用账号里已有的文件。「粘贴作品链接」可添加参考片。「文件夹模板」提供按用途整理的空目录。通过导演台导入本机素材时，原文件留在电脑上。

在网页端或已连接授权的 Windows 桌面端 1.3.3 及以上，点本机文件、文件夹或用途旁的加号，都会直接打开系统选择窗口。选好并确认后才开始登记和显示进度。点「取消」可直接回到项目，继续选其他素材。旧版桌面端在弹出选择窗口前会先校验项目权限，网络较慢时可能需要等待。

「按用途导入」显示每类素材的数量。点用途名称可以筛选，点旁边的加号可直接选文件并指定用途。点「全部」可查看完整列表。每份素材都带有用途图标和文字标签。

| 用途 | 在项目中的作用 |
| --- | --- |
| 商品素材 | 商品图片或视频，作为分镜画面 |
| 授权肖像 | 本人或获准使用的肖像图片，用于口播画面 |
| 授权音色 | 声音样本，用于合成配音 |
| 正式配音 | 已录好的旁白，用作分镜音轨 |
| 参考片 | 分析节奏和构图，作为分镜创作参考 |
| 文字资料 | 提供商品事实、字幕或其他创作资料 |

**按文件夹整理一批素材。** 在「导入素材」→「文件夹模板」下载并解压 ZIP，把文件放进六个用途中对应的目录，可按款号继续建子目录。再点「导入素材」→「导入本机文件夹」，选择最外层目录。网页端和 Windows 桌面端 1.3.2 及以上会按目录名归类，跳过与指定用途不符的文件，并对其余目录中的文件推断用途。旧版桌面端可逐类点加号指定用途。

网页端保存项目时会登记文件名、用途和用于识别原件的标识。刷新或重开项目后，选中素材点「重新关联原文件」即可恢复预览，也可重新选择原文件夹以一次关联多份素材。需要 AI 使用本机文档里的卖点时，可将所需文字填入创作要求。

导入会根据文件名、类型和创作要求建议用途。同批有多份录音时，可以在要求中写明每个文件名及用途，也可选中文件，在「素材角色」中修改。改选后列表标记和分类数量会一起更新。授权肖像和授权音色另外显示「待确认授权」或「已确认授权」。取得许可后，在该文件下勾选「我已取得在此项目中的授权」并保存项目。改选为肖像或音色时需单独确认授权。

分析已有工作台视频时，选中参考片并点「拆解参考片」，由服务端抽取画面。对于网页端或桌面端导入的本机视频，点「发送关键帧并拆解」，由当前设备抽取少量画面发给分析服务。可在结果中查看时间点、构图和节奏。创建分镜时使用自己的商品素材。

**整包导入本机素材。** 在 Windows 桌面端 1.3.1 或更新版本打开项目，点「导入素材」→「导入本机文件夹」，一次选择素材根目录。导演台会扫描它及子文件夹中的图片、音频和视频。压缩包请先解压。一个项目最多容纳 500 份素材，单文件和整包可达几十 GB，单份音视频最长 24 小时。导入时可以看到已检查的文件数，完成后可核对新增、重复、跳过的情况。确认素材角色后点「保存项目」。

新版会在本机记录原文件的位置，导入时只读取必要的媒体信息。预览、取帧和剪辑时需要访问同一份原文件。请保留原位置，使用移动硬盘时保持连接。若移动、改名或替换了文件，请恢复原件，或重新导入并在分镜里改选。旧版已导入的素材仍可使用已保存的副本。导出时需为成片及镜头缓存预留空间。

## 导演与剪辑

**拆解分享链接。** 从抖音、小红书等平台复制作品链接或含链接的分享文案，点「导入素材」→「粘贴作品链接」→「解析并拆解」。服务临时读取公开视频并抽取关键帧，项目保存作品链接和拆解结果。选中参考片可查看各时间点的画面分析，也可点「查看原作品」。若拆解失败而链接已保存，点「拆解参考片」即可重试。若作品需要登录、链接失效或无法取得视频，可点「参考片」旁的加号导入原视频。

**用授权音色配音。** 从「授权音色」旁的加号导入声音样本，确认已获得这个项目的使用授权。选中样本可填写样本原文并查看本机引擎提示。在「编排分镜」选中镜头，填写口播脚本，展开「更多镜头设置」，在「合成音色」选择该样本。后台剪辑时由已配置 Qwen3-TTS Base 的 Windows 电脑合成该镜头的配音。若已有录制好的旁白，可导入为「正式配音」并在镜头中选用。

在「编排分镜」，时间线按顺序列出镜头和各自的时长，上方色条按时长比例显示每镜在整片中的占比。镜头编辑默认显示名称、画面素材、时长、口播脚本和字幕。展开「更多镜头设置」可调整入点、配置配音和动效、锁定内容、查看文案候选或单镜试剪。收起时也会显示已锁定的内容。

- **人工确定**。逐镜填写台词、字幕、时长、素材、起始位置和动效，可调整顺序、替换镜头或比较候选。点击「确认分镜并后台剪辑」执行保存好的版本。
- **智能导演**。按简报、商品资料和参考片分析形成原创分镜。选择「脚本」可在编排后查看和导出。选择生成成片并在可渲染的桌面端发起，可继续后台剪辑。缺少素材、模型或设备时，页面保留当前项目并提示要补的项目。
- **局部修改**。锁定整镜或镜头中的文案、素材、动效，然后重编其他部分。可对单镜试剪，或保存后导出完整版本。改动镜头后可复用仍适用的渲染缓存。

模型使用系统设置「AI 模型管理」中的导演创作与分镜、导演参考片拆解。工作台视频优先从画面切换附近取样。如果工作台已有与参考片同名的 SRT，可通过「从工作台文件选择」将它作为文字资料加入项目，例如「同行参考.mp4」和「同行参考.srt」。分析时就能结合带时间点的台词。没有字幕时只分析画面。填写素材备注和可核实的商品事实能改善脚本质量。

## 本机执行和交付

在「我的电脑」连接并授权 Windows 设备，使用支持导演台的 1.3.0 或更新桌面端，并安装包含 libx264、AAC 的 FFmpeg。可将其 bin 目录加入 PATH，或将 XUTI_DIRECTOR_FFMPEG 指向 ffmpeg.exe 的完整路径后重新启动小序。普通浏览器也能编排项目和下载分镜稿。导出在本机后台执行，鼠标和前台窗口可继续使用。

要用网页端导入的本机素材剪成视频，请在执行剪辑的 Windows 桌面端重新导入这些原文件，并在分镜中选用桌面端登记的素材。

在「后台进度与交付」查看进度、暂停或继续，结束后可以打开交付目录。每版包含 MP4 成片、分镜稿、SRT 字幕和 edit-plan.json，可回看选用的素材与每个镜头的时序。锁定的镜头和已导出的版本可用来比较改稿前后效果。

正式配音配有人工字幕时使用填写的字幕。留空字幕并在执行电脑配置 AutoSubs 后，客户端可按录音的实际语句和时间点生成 SRT。已有脚本也可用于字幕。

内置动效包括推近、淡入淡出、标注和尺码卡。配置好 Lottie 引擎后，可直接选用随包的 product-title 商品标题模板；按镜头标题自动替换文字。高级模板需要在该电脑登记 Lottie、PAG 或 After Effects 工程，并准备相应引擎。可替换模板使用镜头标题、标注或字幕、项目名称；镜头选用商品图片时可替换模板的商品图层。原生 AEP 需要有可用的 After Effects 渲染器。Qwen3-TTS Base 声音克隆、MuseTalk 1.5 肖像口型由本机媒体引擎执行。没有配置相应引擎时仍可选择商品素材、录音及内置动效制作视频。管理员可按桌面发布包中的媒体引擎配置说明启用对应能力。

## 遇到问题

- 「模型连接不可用」时，请管理员检查通用模型连接以及导演功能型号。可以继续手写分镜。
- 信息不足时，通过素材角色、备注和镜头素材选择修正。换电脑后应使用原执行电脑继续本地项目，或重新导入所需文件。
- 项目在其他页面更新后，先载入最新修订再编辑。后台导出以启动时的版本为准。
