# 供应链入驻与资质审核

更新日期：2026-09-17。入口：供应链端 → 入驻审核 / 邀请码。需要“入驻、资质审核及邀请码管理”权限。

## 邀请供应商

在“我的邀请码”生成邀请码，默认有效30天、可注册100个账号。将页面显示的注册链接和邀请码自行提供给供应商。邀请码记录创建人、使用数量、到期时间，可以停用；停用不影响已注册账号。邀请码所有者被停用或失去审核权限后，该码不能继续注册。

## 审核材料

待审核列表区分首次入驻与资质更新。打开材料，核对商务及财务联系、主体、证件、银行收款及开票信息。证件照片需人工核验是否清晰真实；复印件必须加盖红色公章。

资质更新可切换查看原生效资料进行对比。材料合格后“审核通过”，本次版本立即生效；不合格时填写明确驳回原因，再“驳回并反馈原因”，供应商可修改重提。系统禁止审核自己的申请，已被其他负责人处理的版本不能再次审核。

每次提交及审核保留记录，操作日志只记录流程结果，不复制身份证、银行卡或证件图片。不要把证件或银行账户粘贴到驳回原因中。企业信用代码已被另一已入驻主体使用时，系统拒绝重复生效。

审核详情采用宽屏侧栏。身份证号及统一社会信用代码在提交和审批时执行格式、日期及校验位校验；识别结果仅辅助填写，不替代原件真实性审核。不符合新校验规则的待审资料应退回供应商核对后重新提交。

在生效资料或最近申请资料中可点击「核对证件」，后台比对身份证姓名、号码及营业执照公司名称、信用代码、法定代表人与申请内容。仅在未可靠识别或信息不一致时显示简短提醒；不显示识别进度及大块结果面板。此操作仅在当前页面核对，不修改申请或生效资料；未识别的字段需人工核对。银行账户未接入外部核验时不能视为已认证，户名与入驻公司名称不同仅作提醒。
