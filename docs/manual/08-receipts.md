# 到货入库

更新日期：2026-09-16。入口：ERP系统 → 到货入库；新单从采购订单创建。

## 操作步骤

1. 打开已确认或部分到货的采购单，点击「创建入库单」。
2. 对照实际到货填写本次数量，表格方式按采购明细匹配 SKU。分次到货只填本次合格数量，核对剩余量。
3. 保存后检查入库单，点击「确认到货」。此时尚未增加库存。
4. 有过账权限的人员核对后点击「核对并过账」。成功后查询 SKU 库存和库存流水确认。

## 修改与异常

未过账且允许修改的单据显示「编辑单据」，可修订数量。已过账单据不可直接改历史数量。次品、少货可以记录保存，但当前异常过账规则尚未完成，不能按正常合格入库直接过账。

同一批到货不要重复建单或另做库存增加。网络中断时先查询原单状态，不要直接新建一张重复入库单。
