# 到货入库

更新日期：2026-10-01。入口：ERP系统 → 到货入库；原正常到货单从尚未使用配送质检流程的采购单创建。

## 新的配送质检流程

采购发货包裹在「库存管理 → 采购配送」确认送达并进行逐 SKU 盘点质检。准确且完好的数量进入「进货仓待入库」，再选择实际仓库及数量正式入库，才增加在仓库存；问题数量填写漏发、错发、破损、瑕疵、污渍或品质原因与说明，保留给供应商查看并补发。无需物流的四位码核销及快递签收均不表示商品验收通过。已走配送质检的采购单不能重复从原到货单过账。

## 操作步骤

1. 打开已确认或部分到货的采购单，点击「创建入库单」。
2. 对照实际到货填写本次数量，表格方式按采购明细匹配 SKU。分次到货只填本次合格数量，核对剩余量。
3. 保存后检查入库单，点击「确认到货」。此时尚未增加库存。
4. 有过账权限的人员核对后点击「核对并过账」。成功后查询库存管理和库存流水确认。

## 修改与异常

未过账且允许修改的原单据显示「编辑单据」，可修订数量。已过账单据不可直接改历史数量。原到货单仅支持正常合格数量过账，次品或少货不能按正常数量直接过账；有配送质检需求时先取消未过账原单，再从采购配送流程记录包裹、质检合格数和问题明细。

同一批到货不要重复建单或另做库存增加。网络中断时先查询原单状态，不要直接新建一张重复入库单。
