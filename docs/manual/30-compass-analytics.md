# 经营分析与每日邮件

更新日期：2026-10-04。入口：运营中心 → 唯品会 TAB → 经营分析卡片。查看需要「经营分析查看」权限；导入、生成分析、配置邮箱和发送日报需要「经营分析导入与邮件配置」权限。模型配置另限具有该权限的超级管理员。

## 导入与分析

1. 在魔方罗盘下载中心下载「按款号（近30天）」「按货号（近30天）」「按条码（近30天）」原始 Excel。首列应为日期，包含连续每日明细；不要改动平台 ID 或编码。
2. 点击「导入报表」，可一次选择三张。每张最多 100MB、200000 行、100 列，支持 `.xlsx` 和 UTF-8 CSV。后台解析文件，分批上传；整张报表完整后才替换对应维度的面板数据。
3. 导入中断时重新选择原始文件继续。重复文件不会重复累计；较旧统计区间不能覆盖较新报表。近期导入记录保留 45 天，当前使用的报表始终保留。每次分析使用当前对应维度的一张报表。
   新版本补充保留原始报表的售龄和首次上架时间；旧版本导入时未保存这两列的报表，可重新导入同一原始文件补齐。新版会建立独立解析版本并在完整上传后替换面板来源，不重复累计，也不修改之前保存或分享的报告快照。
   2026-10-04起同时保留原始「退货率(退货件数/销售量)」的每日百分比（例如20%存为0.2，空白保留缺失），供库存明细计算众数参考。旧版本报表须重新导入原始条码文件补齐；经营分析的期间退货率仍按累计退货件数/销售件数重算，原口径不变。报表来源覆盖完整30天后，刷新库存明细即可读取渠道日销众数、退货率众数以及窗口内已提供销售件数合计乘参考退货率的预估销退，详见库存管理章节。只读取最新已完成的条码来源，不要求款号、货号来源同步完成。
4. 选择按款号、货号或条码分析，「统计日期」前方提供近1、7、15、30天四个快捷标签，选中项以浅橘色标记；旁边下拉框只提供日、周、月、季、年或自定义，不重复列出最近周期。选择月、季、年时分别打开月份网格、季度卡片、年份网格，点击具体周期后才更新统计区间。月和季可切换年份，年可按十年翻页；季度卡片显示对应三个月。未来周期不可选，当前月/季/年仅统计至昨日；历史周期取完整起止日期。点击日期区间可重新打开当前周期面板，点击取消、面板外区域或按 Esc 关闭，不改动原筛选。最近周期默认相对该维度最新报表截止日；已有手选日期时，相对当前截止日计算。日、周按当前区间终点取整，周一为一周起点。选择自定义后可直接修改起止日期，区间最多366天，截止日不能晚于昨日。「最新报表」恢复相对最新来源的最近周期，自定义或自然周期恢复为近7天。
5. 右上角输入框支持模糊查找单个款号、货号、条码、尺码或分类；多个编码用英文逗号`,`、中文逗号`，`或换行隔开，按完整款号、货号或条码匹配，忽略大小写、空白项及重复编码，最多100项、每项150字符，总输入最多5000字符。输入框可自动展开至4行。同一查询中的多个编码按「任一匹配」取并集，不重复累计商品；销售汇总、趋势、TOP20和明细共用筛选范围，分页、排序和导出仍作用于该范围。单个没有分隔符的输入保持模糊搜索。点击排行或款号明细进入对应货号，再点击货号进入条码；顶部范围标签可关闭。「查看全部」清除范围和关键词。
6. 明细表格提供「自定义、流量、转化、售后、库存」五个视图，不改变当前统计日期、搜索或下钻范围。流量显示曝光、商详、点击率、收藏、加购；转化显示销售额、净销售、销量、客户数、购买转化率和件均价；售后显示退货、拒收、换货件数/金额及期间比例；库存显示销量和截止日库存快照。
7. 在「自定义」视图点击「字段设置」，勾选需要显示的字段，可隐藏商品图片或全部数据指标，商品标识列始终保留。卡片随窗口自动调整位置，字段区可滚动，底部保留取消与应用按钮。「应用」后生效，「取消」不保存，可恢复默认配置。视图及字段选择按账号、款号/货号/条码维度保存在当前浏览器，换浏览器需重新配置。条码报表缺少的曝光、商详 UV、点击率和购买转化率不可选；流量视图仍显示报表已有的收藏与加购指标。
8. 明细表内部支持纵向滚动，表头保持在滚动区域顶部；横向滚动时，商品图片及款号/货号/条码标识列固定在左侧。底部显示结果总条数和分页，可选择每页20、50、100、200、500或1000条；调整每页条数时回到第一页，日期、筛选和排序保持不变。明细、销售排行及AI重点商品关注中的商品编码前显示缩略图；明细仍可在字段设置中隐藏图片。鼠标悬停缩略图显示120×120像素预览，点击可放大、缩放和旋转；按 Esc 或关闭按钮返回，点击编码仍用于下钻。图片缺失或加载失败时显示占位图。
9. 点击数值列表头的小三角，按对应指标降序排列；明细右上角不再提供排序下拉框。排序列的数据加粗显示，不额外填充背景颜色，表头保持原底色。切换排序字段时保留页面及表内滚动位置，加载期间表格继续显示并提示正在更新，不跳回网页顶部；新结果仍从第一页显示。排序作用于当前全部筛选结果，再分页显示；比例按累计分子和分母重算，缺失值排在最后。切换视图保留排序；切换到条码时，若原排序字段在条码报表中不存在，恢复为销售额排序。「导出当前页」导出当前视图显示的字段和当前筛选、排序下的一页结果，百分比为百分数字符串，图片为链接；商品编码保持文本格式。数据正在更新时暂不可导出，完成后恢复。

BI 看板包含销售额、净销售额、销量、期间退货率与可售库存五张指标卡，以及每日销售/退货趋势和销售额 TOP 20 排行。排行按当前日期、关键词和下钻范围取销售额最高的20项，款号、货号、条码各自统计，与明细每页数量和排序字段无关；结果不足20项时显示实际数量。排行卡片内可滚动查看，点击商品编码继续下钻。悬停或键盘聚焦趋势图日期点，会显示小卡片，日期、销售额与退货金额分行排列，较长金额自动换行。卡片限制在图内，键盘焦点以数据点周围的小圆环标识；按 Esc 可关闭提示。切换日期后，已不在区间内的提示自动清除。AI 侧栏中的趋势图使用相同提示样式。

销售、净销售和退货使用原始报表指标，跨日累计。三个维度是独立统计口径，不能相加。库存只使用截止日期当天的快照，不累计每天的库存；没有该日库存数据时显示「—」。报表导入不会覆盖 ERP 实物库存。

每个维度当前只查询一张完整导入的来源报表，原始近30天报表不能提供完整季度或全年明细。选择超出来源范围的日期时显示数据覆盖不足及来源覆盖区间，只展示实际已有数据；不会补零或虚构历史。导入完成后清理45天前的历史批次，当前正在使用的三张来源始终保留。原始 Excel 不保存在服务器文件桶，服务器保存归一化每日明细和来源信息。

客户数、曝光 UV、商详 UV 等由每日指标累计，跨日未去重。点击率与购买转化率按累计分子和分母重算。件均价 = 销售额 / 销售件数。期间退货率 = 当期退货件数 / 当期销售量，期间拒收率 = 当期拒收件数 / 当期销售量，可能超过 100%，不代表同一批订单的退货/拒收率；分母为零或缺失时显示「—」。条码报表没有曝光和商详 UV，不显示这些指标。面板不推算未提供的成本或利润。

## 更多明细字段

款号、货号、条码后显示迷你折线图，范围沿用当前统计日期。自定义显示每日销售额，流量显示每日商详UV（条码使用加购UV），转化显示每日销售件数，售后显示每日退货件数，库存显示每日可售库存。悬停可查看指标说明，点击打开该商品的「每日数据趋势」，不切换商品维度或改变表格的滚动位置。

趋势面板按自定义、流量、转化、售后、库存分TAB展示，可多选当前分类的指标。不同单位单独绘图；悬停、聚焦或点击日期点显示当日数值。库存使用每日快照，比例按当日分子和分母重算；售龄使用当天报表值，首次上架时间仅作为信息展示。缺失日期和指标保留空缺，不填0或连线补齐；超出来源报表覆盖的日期不会虚构历史。报表已经更新时会提示先刷新经营分析，避免将旧表格与新来源混用。手机端图表逐项排列。关闭面板后仍停留在原表格位置。

在「字段设置」可以选择收藏率、加购率、期间换货率、期间拒退率、售龄（天）和首次上架时间，并支持表头排序和当前页导出。流量视图默认包含收藏率、加购率；售后视图包含换货率和拒退率；款号与货号的库存视图包含售龄及首次上架时间。

收藏率 = 累计收藏人数 / 累计商详 UV，加购率 = 累计加购用户数 / 累计商详 UV；不平均每日百分比。期间换货率 = 累计换货件数 / 累计销售件数，期间拒退率 =（累计拒收件数 + 累计退货件数）/ 累计销售件数；分母缺失或不大于0时显示「—」。条码原始报表没有商详 UV、售龄和首次上架时间，因此不提供这四个字段，仍显示已提供的收藏、加购人数。

售龄取当前期间最后一条有值记录中的平台报表值，不把每日售龄相加或自行换算。首次上架时间取当前商品记录中最早的有效时间，保留报表给出的日期和时分秒。首次上架时间不等同于最后数据日期；缺失值显示「—」。

## 每日自动更新

本机 Codex 定时采集任务每天北京时间 08:00 使用已登录的 Chrome 下载三个报表，并导入本系统。电脑、Chrome、Codex 应保持在线，罗盘账号需保持登录。登录失效、报表过期或平台尚未生成当天报表时，需要处理后更新，不会以旧报表冒充新数据。该采集不是服务器上的官方罗盘 API；官方指标接口尚未开通。

「ERP系统 → 唯品会接入」另提供罗盘官方取数的配置检查与单页只读验证，详见「唯品会接入」章节。该验证不会切换经营分析的数据来源；正式取数仍需商务开通、登记公钥及核对指标 API code 和字段口径。

服务器邮件任务在每天 08:00 后检查最新报表。三张报表都覆盖截至昨日的完整近 30 天，且邮件配置已开启并通过 SMTP 验证后，才生成日报。平台更新延迟时等待完整数据，完成后补发。

## OpenRouter AI 经营分析

1. 超级管理员在「系统设置 → AI 模型设置」配置和验证连接，详见对应设置章节。固定使用 `openai/gpt-6.1-sol`，供应商由 OpenRouter 在同一模型下路由；不会随新版本自动更换模型。
2. 三张报表须有相同截止日期并覆盖完整近30天。页面底部不再常驻AI分析卡片；点击经营分析右上角「AI 经营分析」，从右侧展开大面板；有导入与邮件配置权限时可点击「生成分析」。模型接收近1/3/7/15/30天汇总、30天每日趋势和三个维度近7天 TOP10 商品编码，不接收原始 Excel、邮箱、图片或 ERP 凭据。
3. 面板优先显示经营摘要、当日销售额、近7天日均销售额、期间退货率及截止日库存，再展示30天趋势和近1/7/15/30天日均对比。较前一日/较30天日均的比例在基数为零或缺失时显示「—」，不把缺失库存当作零。
4. 「重点商品关注」按款号、货号、条码切换，只检查各维度近7天销售 TOP10。优先展示售罄且有销量或发生退货的商品，最多10项；这不是全量库存预警。「建议先做这几件事」显示前三条建议；「完整经营观察、建议与风险」保留全文。摘要中的「查看完整解读」会展开全文并滚动到对应位置。摘要、建议卡片及完整正文中，匹配到报告快照商品图片的款号、货号、条码以可点击文字显示：悬停或键盘聚焦显示120×120像素预览，点击放大，支持缩放、旋转及Esc关闭。图片打开后按Esc只关闭图片，报告面板继续保留，可继续查看或分享。编码按完整标识匹配，较短款号不会误匹配到更长货号或条码内部。没有匹配图片的编码保留原文，不虚构商品图片；图片来自同一份报告快照，不因当前页面筛选而改变。
5. 图表来自生成解读时同一批数据的保存快照，与页面筛选无关；旧的缓存分析在来源仍一致时补存图表及商品缩略图，不会因此再次付费调用模型。缩略图供页面预览使用，不发送至模型服务。分析面板只显示数据截止日和生成时间，不展示模型及供应商名称；模型配置仍在超级管理员的系统设置页维护。刷新读取已有结果。同一批数据与同一分析版本复用生成结果，多邮箱共用一份分析，每次最多4096个输出 token（包含推理）。

## 外部分享与手机查看

有导入与邮件配置权限的用户可在 AI 分析侧栏点击「分享报告」，选择1、7或30天有效期，再点击「创建分享链接」。分享面板会显示链接和二维码，可复制发送或在手机扫码查看。只有已经生成的报告才能创建分享；生成状态或报表来源变化时，先刷新分析。

外部访客持有有效链接即可查看，无需注册或登录。分享内容包括经营摘要、销售/退货/库存指标、图表、商品图片及完整解读；不提供经营系统导航、报表导入、模型设置或邮箱配置。链接保存创建时的报告快照，后续导入报表或刷新分析不会改变已分享内容。模型/供应商名称、凭据、原始文件及邮箱不包含在分享内容中。

新链接只在创建后显示，请及时复制保存；「我创建的链接」保留最近30条记录，可撤销仍有效的链接。创建者可撤销自己的链接，超级管理员也可通过接口撤销其他用户的链接。撤销立即阻止新的读取；已打开页面保存的内容不能远程收回。过期、撤销或无效链接统一提示无法查看；可重新创建新链接。

手机端指标卡按两列排列，图表和建议卡片纵向排列，重点商品关注改为逐项卡片，完整正文自动换行。商品编码和图片仍可点击放大；趋势图可点击日期点查看提示。分享不会自动发送邮件或消息，也不会再次付费生成分析。

AI 仅生成解读，不改变原始统计、库存、采购或调拨。不同日期长度的比较应依据日均数据；不推算缺失的成本、利润或采购周期。模型输出须通过格式与模型标识验证，截断、拒绝或其他模型的结果不采用。单份数据生成失败后至少间隔一分钟重试，最多三次；超时或进程退出的未确认结果会提示管理员核对。更换报表后生成新分析。

每日邮件在 AI 开启并验证后调用同一模型，附加 AI 分析；生成进行中时等待结果。未开启、未验证或调用失败时，邮件明确列出 AI 状态，继续提供报表汇总，不把规则汇总标成 AI 报告。已发送邮件不会因补做 AI 分析再次发送。

## 配置邮件

1. 管理员在部署环境为 API 和 Worker 设置相同的 `COMPASS_MAIL_KEY`（32 字节随机密钥的 64 位十六进制形式）。不要把密钥放在表格、手册或聊天中。
2. 点击「每日邮件」，填写一个或多个收件邮箱，逗号分隔，最多 20 个，重复地址自动去重。各收件邮箱单独发送。
3. QQ 邮箱 SMTP 服务器使用 `smtp.qq.com`、465 TLS 端口；也支持其他服务的 587 STARTTLS。发件邮箱须与 SMTP 账号一致。QQ 邮箱开启 SMTP 后填写邮箱授权码，不使用登录密码。
4. 开启每日邮件并点击「保存并验证」。授权码在服务器加密保存，不回显；已保存时留空保留，变更 SMTP 账号、地址或端口需重新填写并验证。
5. 数据齐备后可以点击「发送今日报告」。每日按数据日期和收件邮箱防止重复发送；已经由邮件服务器接收的报告不会再次发送。

日报包含近 1、3、7、15、30 天款号汇总、三个维度的近 7 天汇总及各维度 TOP 10，列明数据截止日期和统计口径。最近发送记录显示每个邮箱的结果。「邮件服务器已接收」不保证进入收件箱，请同时检查垃圾邮件。

认证失败时检查 SMTP 是否开启以及授权码；连接失败时检查服务器网络和发件地址/端口。自动任务只对确认失败的发送有限重试；发送途中网络断开或进程退出导致结果不明时不自动重复发信，应先核对收件箱，由管理员处理。未配置授权码或未验证时不会发送邮件。可关闭「开启每日邮件」暂停发送，本机报表采集任务由 Codex 自动化设置管理。
