# 经营分析与每日邮件

更新日期：2026-10-21。入口：运营中心 → 唯品会 TAB → 经营分析卡片。查看需要「经营分析查看」权限；更新数据、导入、管理罗盘服务器登录、生成分析、配置邮箱和发送日报需要「经营分析导入与邮件配置」权限。模型配置另限具有该权限的超级管理员。

「搜索款号 / 货号 / 条码」位于顶部导航栏，采用全站统一的暖色圆角样式，桌面端固定224px宽（125%缩放时约280像素）、28px高；长内容或换行不会撑开导航栏，窄屏按可用宽度收窄，框高不变。输入后按原规则查询当前分析维度；日期区间和其他条件继续在分析页面设置，多编码批量查询及原有输入校验继续生效。

## 复制编号（2026-10-21）

销售额 TOP20、明细表、分析范围和每日数据趋势窗口中的款号、货号、条码旁均提供复制图标。点击复制完整编号并显示成功提示，前导零保留；复制不改变分析维度、筛选或页面位置，原编号点击仍按原规则下钻。AI 报告的关注商品及已关联商品图片的文中编号也可复制，分享报告沿用相同操作。无图片的关注商品仍可复制编号。浏览器拒绝剪贴板权限时，请按提示允许访问或选中文字使用 Ctrl+C / Cmd+C。

## 导入与分析

1. 在魔方罗盘下载中心下载「按款号（近30天）」「按货号（近30天）」「按条码（近30天）」原始 Excel。首列应为日期，包含连续每日明细；不要改动平台 ID 或编码。
2. 点击「导入报表」，可一次选择三张。每张最多 100MB、200000 行、100 列，支持 `.xlsx` 和 UTF-8 CSV。后台解析文件，分批上传；整张报表完整后才替换对应维度的面板数据。
3. 导入中断时重新选择原始文件继续。重复文件不会重复累计；较旧统计区间不能将当前分析来源退回过去。近期导入记录保留 45 天，当前使用的报表始终保留。经营分析每次仍使用当前对应维度的一张报表；完整条码导入还会保存按日归一化历史，专供库存经营参考的较长周期查询。
   新版本补充保留原始报表的售龄和首次上架时间；旧版本导入时未保存这两列的报表，可重新导入同一原始文件补齐。新版会建立独立解析版本并在完整上传后替换面板来源，不重复累计，也不修改之前保存或分享的报告快照。
   2026-10-04起同时保留原始「退货率(退货件数/销售量)」的每日百分比（例如20%存为0.2，空白保留缺失）。库存明细现在按所选周期计算每日销量中位数、每日退货率中位数，以及期间销量合计乘退货率中位数的预估销退；不再使用众数。可选近3、7、15、30天、近3个月、近半年或近1年，默认近30天，以最新完整条码来源截止日为终点；月、年周期按日历滚动。窗口有完整按日历史覆盖后才采用自动参考，未匹配、存在歧义或数据不足时明确提示并保留人工参考。旧版本报表须重新导入原始条码文件补齐每日退货率；经营分析自身的期间退货率仍按累计退货件数/销售件数重算，原口径不变，不要求款号、货号来源同步完成。操作与计算细节见库存管理章节。
4. 选择按款号、货号或条码分析，「统计日期」前方提供近1、7、15、30天四个快捷标签，选中项以浅橘色标记；旁边下拉框只提供日、周、月、季、年或自定义，不重复列出最近周期。选择月、季、年时分别打开月份网格、季度卡片、年份网格，点击具体周期后才更新统计区间。月和季可切换年份，年可按十年翻页；季度卡片显示对应三个月。未来周期不可选，当前月/季/年仅统计至昨日；历史周期取完整起止日期。点击日期区间可重新打开当前周期面板，点击取消、面板外区域或按 Esc 关闭，不改动原筛选。最近周期默认相对该维度最新报表截止日；已有手选日期时，相对当前截止日计算。日、周按当前区间终点取整，周一为一周起点。选择自定义后可直接修改起止日期，区间最多366天，截止日不能晚于昨日。「最新报表」恢复相对最新来源的最近周期，自定义或自然周期恢复为近7天。
5. 右上角输入框支持模糊查找单个款号、货号、条码、尺码或分类；多个编码用英文逗号`,`、中文逗号`，`或换行隔开，按完整款号、货号或条码匹配，忽略大小写、空白项及重复编码，最多100项、每项150字符，总输入最多5000字符。输入框保持单行显示高度，多行内容可用滚轮或方向键在框内上下查看、编辑，换行继续作为批量查询分隔符；长单行内容可在框内横向查看。同一查询中的多个编码按「任一匹配」取并集，不重复累计商品；销售汇总、趋势、TOP20和明细共用筛选范围，分页、排序和导出仍作用于该范围。单个没有分隔符的输入保持模糊搜索。点击排行或款号明细进入对应货号，再点击货号进入条码；顶部范围标签可关闭。「查看全部」清除范围和关键词。
6. 明细表格提供「自定义、流量、转化、售后、库存」五个视图，不改变当前统计日期、搜索或下钻范围。流量显示曝光、商详、点击率、收藏、加购；转化显示销售额、净销售、销量、客户数、购买转化率和件均价；售后显示退货、拒收、换货件数/金额及期间比例；库存显示销量和截止日库存快照。
7. 在「自定义」视图点击「字段设置」，勾选需要显示的字段，可隐藏商品图片或全部数据指标，商品标识列始终保留。卡片随窗口自动调整位置，字段区可滚动，底部保留取消与应用按钮。「应用」后生效，「取消」不保存，可恢复默认配置。视图及字段选择按账号、款号/货号/条码维度保存在当前浏览器，换浏览器需重新配置。条码报表缺少的曝光、商详 UV、点击率和购买转化率不可选；流量视图仍显示报表已有的收藏与加购指标。
8. 明细表内部支持纵向滚动，表头保持在滚动区域顶部；横向滚动时，商品图片及款号/货号/条码标识列固定在左侧。底部显示结果总条数和分页，可选择每页20、50、100、200、500或1000条；调整每页条数时回到第一页，日期、筛选和排序保持不变。明细、销售排行及AI重点商品关注中的商品编码前显示缩略图；明细仍可在字段设置中隐藏图片。鼠标悬停缩略图显示120×120像素预览，点击可放大、缩放和旋转；按 Esc 或关闭按钮返回，点击编码仍用于下钻。图片缺失或加载失败时显示占位图。
9. 点击数值列表头的小三角，按对应指标降序排列；明细右上角不再提供排序下拉框。排序列的数据加粗显示，不额外填充背景颜色，表头保持原底色。切换排序字段时保留页面及表内滚动位置，加载期间表格继续显示并提示正在更新，不跳回网页顶部；新结果仍从第一页显示。排序作用于当前全部筛选结果，再分页显示；比例按累计分子和分母重算，缺失值排在最后。切换视图保留排序；切换到条码时，若原排序字段在条码报表中不存在，恢复为销售额排序。「导出当前页」导出当前视图显示的字段和当前筛选、排序下的一页结果，百分比为百分数字符串，图片为链接；商品编码保持文本格式。数据正在更新时暂不可导出，完成后恢复。

BI 看板包含销售额、净销售额、销量、期间退货率与可售库存五张指标卡，以及每日销售/退货趋势和销售额 TOP 20 排行。排行按当前日期、关键词和下钻范围取销售额最高的20项，款号、货号、条码各自统计，与明细每页数量和排序字段无关；结果不足20项时显示实际数量。排行卡片内可滚动查看，点击商品编码继续下钻。悬停或键盘聚焦趋势图日期点，会显示小卡片，日期、销售额与退货金额分行排列，较长金额自动换行。卡片限制在图内，键盘焦点以数据点周围的小圆环标识；按 Esc 可关闭提示。切换日期后，已不在区间内的提示自动清除。AI 侧栏中的趋势图使用相同提示样式。

销售、净销售和退货使用原始报表指标，跨日累计。三个维度是独立统计口径，不能相加。库存只使用截止日期当天的快照，不累计每天的库存；没有该日库存数据时显示「—」。报表导入不会覆盖 ERP 实物库存。

经营分析每个维度当前只查询一张完整导入的来源报表，单张原始近30天报表不能提供完整季度或全年明细。选择超出来源范围的日期时显示数据覆盖不足及来源覆盖区间，只展示实际已有数据；不会补零或虚构历史。导入完成后清理45天前的历史批次，当前正在使用的三张来源始终保留；库存经营参考另存的条码每日历史不随该批次清理而删除。原始 Excel 不保存在服务器文件桶，服务器保存归一化每日明细和来源信息。

客户数、曝光 UV、商详 UV 等由每日指标累计，跨日未去重。点击率与购买转化率按累计分子和分母重算。件均价 = 销售额 / 销售件数。期间退货率 = 当期退货件数 / 当期销售量，期间拒收率 = 当期拒收件数 / 当期销售量，可能超过 100%，不代表同一批订单的退货/拒收率；分母为零或缺失时显示「—」。条码报表没有曝光和商详 UV，不显示这些指标。面板不推算未提供的成本或利润。

## 为库存经营参考补充历史

库存明细中选择近3个月、近半年或近1年，需要相应日期范围的完整条码每日历史；仅上传当前近30天报表不会生成其余日期。可从罗盘取得原始条码日报，通过「导入报表」分段上传，每张统计区间最多90天，并确认每张均完整导入。页面的历史覆盖天数／应覆盖天数用于核对缺口；不足时库存显示「历史覆盖不足」，有人工参考则继续使用并注明来源，不以局部数据冒充所选完整周期。

同一日期再次完整导入时，以较新完成的该日完整数据整体替换旧快照，包括删除旧快照中存在、在新数据中已不存在的商品；不会将重叠报表叠加累计。较早截止日，或与当前相同截止日但起始日较晚、覆盖更短的条码导入，只补日历史，不替换当前经营分析来源；相同或更完整的区间，以及更新的截止日，可正常替换。上传未完成、解析失败或缺少有效指标时不能冒称历史齐全；每天是否有完整报表与某个商品是否有有效样本分别判断。

库存参考的期间终点随最新完整条码来源截止日更新。手动「更新数据」只下载截至昨日的近30天三维报表；选择较长经营参考周期不会扩大服务器下载范围，也不会追溯平台未提供的历史。补历史不修改 ERP 实物库存、已保存的 AI 报告或外部分享快照。

## 更多明细字段

款号、货号、条码后显示迷你折线图，范围沿用当前统计日期。自定义显示每日销售额，流量显示每日商详UV（条码使用加购UV），转化显示每日销售件数，售后显示每日退货件数，库存显示每日可售库存。悬停可查看指标说明，点击打开该商品的「每日数据趋势」，不切换商品维度或改变表格的滚动位置。

趋势面板按自定义、流量、转化、售后、库存分TAB展示，可多选当前分类的指标。不同单位单独绘图；悬停、聚焦或点击日期点显示当日数值。库存使用每日快照，比例按当日分子和分母重算；售龄使用当天报表值，首次上架时间仅作为信息展示。缺失日期和指标保留空缺，不填0或连线补齐；超出来源报表覆盖的日期不会虚构历史。报表已经更新时会提示先刷新经营分析，避免将旧表格与新来源混用。手机端图表逐项排列。关闭面板后仍停留在原表格位置。

在「字段设置」可以选择收藏率、加购率、期间换货率、期间拒退率、售龄（天）和首次上架时间，并支持表头排序和当前页导出。流量视图默认包含收藏率、加购率；售后视图包含换货率和拒退率；款号与货号的库存视图包含售龄及首次上架时间。

收藏率 = 累计收藏人数 / 累计商详 UV，加购率 = 累计加购用户数 / 累计商详 UV；不平均每日百分比。期间换货率 = 累计换货件数 / 累计销售件数，期间拒退率 =（累计拒收件数 + 累计退货件数）/ 累计销售件数；分母缺失或不大于0时显示「—」。条码原始报表没有商详 UV、售龄和首次上架时间，因此不提供这四个字段，仍显示已提供的收藏、加购人数。

售龄取当前期间最后一条有值记录中的平台报表值，不把每日售龄相加或自行换算。首次上架时间取当前商品记录中最早的有效时间，保留报表给出的日期和时分秒。首次上架时间不等同于最后数据日期；缺失值显示「—」。

## 更新数据与服务器登录

「更新数据」使用服务器后台浏览器复用独立的魔方罗盘会话，下载原始报表并在服务器内部完成导入。用户电脑、Chrome 和 Codex 可以关闭，服务器导入不再通过经营系统网页登录；当前流程仍使用罗盘网页下载，官方罗盘指标接口尚未开通。仅有查看权限的账号显示「更新状态」，可以查看最近任务，不能启动更新或打开登录画面。

1. 点击经营分析右上角「更新数据」。后台目标固定为截至北京时间昨日的连续近30天，涵盖按款号、按货号、按条码三个维度，与当前面板选中的统计区间和搜索条件无关。
2. 第一次使用时，在更新面板点击「扫码登录罗盘」，使用唯品会 App 扫描服务器浏览器中的二维码，按平台要求确认登录、协议或验证，然后点击「核验并保存」。画面支持点击和滚动；密码输入区域遮蔽，本窗口不提供文字输入。登录画面仅限发起登录的有管理权限用户查看。
3. 核验成功后，会话加密保存在服务器。若本次已经发起更新，或任务正在等待登录，保存后继续当前更新；只管理登录、没有待继续的请求时，不会额外发起下载。已保存的服务器会话供后续更新复用，本机浏览器的登录不会自动共享到服务器。
   二维码过期或扫码后画面停在水印时，先点击「刷新登录画面」：保留当前临时浏览器会话，重新加载当前官方页面；供应商页面仍停在旧的固定主页路径时，会移除旧路径，让平台按当前账号选择实际主页后重新加载。刷新扫码页不会先跳回供应商主页，也不清除已完成扫码的登录资料；刷新后仍须核验，页面恢复不代表登录已保存。
   若刷新后仍持续空白、只有水印或反复回到无法操作的旧页面，可点击「重新获取二维码」并选择「重新获取」。本次未保存的扫码进度重新开始，服务器从官方供应商主页重新打开登录入口，不沿用当前临时浏览器的旧登录资料；已核验保存的正式会话和已有报表保留。选择「继续当前登录」不重新开始。重新扫码后仍须核验并保存；该操作不延长当前登录窗口或草稿的有效期，平台访问受限时也可能无法恢复，按画面提示处理。
   扫码完成不等于会话已保存，须点击「核验并保存」并看到「罗盘登录已保存」。扫码窗口正文可上下滚动，底部的核验和关闭按钮保持在视口内，不会随登录画面被推到屏幕底部之外。点击遮罩或按 Esc 不会关闭扫码窗口；登录尚未保存时，点击右上角关闭或「关闭登录窗口」会先询问是否取消，选择「继续扫码」保留当前画面，选择「确认取消登录」才丢弃本次未保存会话。已保存后点击「返回更新面板」直接返回，不再询问取消。
4. 更新面板先显示服务器当前「本次目标」日期，再显示任务实际区间。款号、货号、条码分别提供阶段进度条及准备、下载、解析、导入、校验五步：准备阶段注明查找目标报表或等待平台生成；下载等待文件完整返回；解析完成后显示实际行数；导入按成功写入的行数和已提交批次更新；完整性及来源核验通过后，该维度才显示「已导入并核验」。整体阶段完成度按三个维度的五步等权计算，导入一步按成功写入比例推进，三张报表和任务均完成才显示100%。该百分比不是预计耗时，下载和解析没有可靠总量时不伪造字节、行数或随时间增长的进度。
   运行中约每2秒刷新，显示发起、开始、结束及最近实际进展时间。等待登录、平台验证或失败时保留最后确认的阶段和计数，并标明暂停或停止；刷新暂时失败也保留最后结果，连接恢复后继续读取。旧任务没有保存明细时仅标示核验结果，不补造历史步骤。
   历史已结束任务与本次目标区间不一致时，明确显示「上次更新结果」和本次目标尚未更新，不把旧的完成进度显示成本次成功。关闭面板不取消已启动的后台任务；再次点击「查看更新进度」可以返回。只有完整导入并核验后才替换该维度来源，完成后自动刷新经营分析及 AI 来源状态。
5. 同一目标日期正在执行的更新不会因重复点击另建任务。三个维度已齐备时直接返回来源核验结果，不重复导入；部分完成后重试只补缺失维度，原始文件重复导入不会累计两次。以三个维度的起止日期、文件名和行数，以及页面底部「数据来源与计算口径」为准。

扫码过程中，服务器会加密暂存当前登录进度，固定保留30分钟。若页面导航、画面读取或报表核验中断，同一经营系统账号在有效期内重新打开「扫码登录罗盘」，会尝试复用该进度；重新打开不会延长原有效期，平台已使登录失效时仍需重新扫码。此草稿仅供继续登录，不表示核验成功，也不能用于下载更新；仍须点击「核验并保存」并看到「罗盘登录已保存」。选择「确认取消登录」会删除当前窗口的草稿，「断开罗盘会话」会清除全部登录草稿及已保存会话；过期草稿自动清除。其他账号不能复用该草稿，浏览器登录数据不会返回到页面。

服务器保存的登录状态仅限罗盘及核准的官方登录页面，包括 Cookie、本地存储、IndexedDB 和当前会话存储，统一加密保存；不采集输入框密码或窗口名称。恢复时保留页面已更新的会话内容，避免旧登录状态覆盖新状态。是否可用于更新仍以重新打开后台浏览器后的报表访问核验为准。

服务器下载程序未启用、离线或登录加密未配置时，面板明确提示，不会把无法执行的请求显示为排队成功；如果三张报表本来已齐备，仍可以返回已核验结果。登录失效、平台拦截、报表尚未生成、下载或导入失败时保留已有来源，不以旧报表冒充当天更新。点击「重试更新」会重新核验并补缺；平台会话过期或要求验证时，需在本面板重新扫码或处理平台提示，保存会话不保证永久登录。

「管理罗盘登录」可以再次打开服务器登录画面；「断开罗盘会话」经确认后清除保存的会话，后续下载需重新扫码。不要在聊天、字段或手册中粘贴密码、验证码、Cookie 或登录文件。本站「保持登录 30 天」仅控制用户浏览器的经营系统登录，不是后台任务的身份凭据，也不延长罗盘平台会话。

服务器首次登录、会话复用核验和下载从官方供应商主页进入；「刷新登录画面」重新加载当前官方页面并保留当前会话。之后通过页面上可见的「魔方罗盘」及自助报表、下载中心菜单访问报表，不直接打开罗盘首页。核验会为平台正常的单点登录跳转短暂等待，仍须读到款号、货号、条码三张近30天报表才算成功，供应商门户或水印不算核验通过。对于标题为「重要提醒」、提供「已知晓」确认且不包含协议、条款、授权、交易或验证要求的普通提示，后台可自动关闭并继续；涉及协议、授权、交易、人工验证或输入的提醒仍需本人处理。已过期的会话或平台错误页不会因等待而变为登录成功。

后台优先处理登录窗口操作。自动暂存读取较慢时，超过等待上限则保留之前的草稿，不持续阻塞画面和重新获取二维码；迟到的旧暂存不覆盖重新开始后的进度。暂存超时不代表登录已保存，仍须通过报表访问和会话复用核验。

供应商主页的「本页面有若干条关联的公告」若为普通公告，且平台阅读倒计时已结束、显示可用的「关闭」按钮，后台会关闭该公告再进入罗盘；不点击「查看详情即不再弹窗提醒」，不提前绕过倒计时。含协议、授权、交易、输入或人工验证要求的公告仍需本人处理，核验不会因公告消失就判断登录成功。

会话复用核验同样等待普通公告的阅读倒计时，单次最多等待60秒。罗盘「重要提醒」中的普通确认按钮支持「已知晓」及「已知悉」；已知的断货、授权待补货和订阅待补货统计提醒只确认已阅，不点击补货、订购或授权操作。只读的品牌筛选展示不视为需要输入；实际协议、权限授予、交易或人工验证仍需本人处理。

下载中心切换后，后台会等待对应报表行完成加载，单次最多10秒且不超过当前下载等待期限，再判断是否已有文件可下载；不把加载中的空列表立即当作需要生成报表。平台原始文件名中的连续数字日期（例如 `20260913-20261012`）用于校验统计区间，仍需完整解析原始 Excel 并核验日期与行数才更新来源。

平台菜单附带图标时仍按实际菜单文字定位「自助报表」「下载中心」；窄窗口中文件名省略显示时，可使用页面已提供的完整悬浮提示定位对应报表，不读取隐藏账号资料或绕过平台页面。

下载、生成等按钮文字前后的空格或换行不会影响识别；只使用对应报表行内可见、可用的按钮，不操作编辑、禁用或删除报表。

下载响应若未提供有效的 XLSX/CSV 文件名，可使用该报表行已公开显示的完整原始文件名。仍检查下载完成状态、100MB限制及文件内容格式，并完整解析工作表、维度、统计日期和行数；登录页、错误响应或不符合原始报表结构的文件不导入。

菜单已经显示后才出现的普通公告，也可能遮挡点击。后台遇到这种遮挡时，会重新检查页面，只在处理已识别的普通公告后重试一次菜单；不强制穿过未知弹层，协议或人工验证提示仍需本人处理。

## 手动更新与邮件检查

系统已移除 Dot 更新说明及报表定时更新入口。报表仅通过「更新数据」手动发起服务器任务；升级时关闭原服务器定时开关并停止尚未结束的定时更新任务，已经核验的来源保留。手动发起的任务仍可在后台继续执行。

「ERP系统 → 唯品会接入」另提供罗盘官方取数的配置检查与单页只读验证，详见「唯品会接入」章节。该验证不会切换经营分析的数据来源；正式取数仍需商务开通、登记公钥及核对指标 API code 和字段口径。

服务器邮件任务在每天 08:00 后检查最新报表。三张报表都覆盖截至昨日的完整近 30 天，且邮件配置已开启并通过 SMTP 验证后，才生成日报。平台更新延迟时等待完整数据，完成后补发。

## OpenRouter AI 经营分析

1. 超级管理员在「系统设置 → AI 模型设置」配置和验证连接，详见对应设置章节。固定使用 `openai/gpt-6.1-sol`，供应商由 OpenRouter 在同一模型下路由；不会随新版本自动更换模型。
2. 三张报表须有相同截止日期并覆盖完整近30天。页面底部不再常驻AI分析卡片；点击经营分析右上角「AI 经营分析」，从右侧展开大面板；有导入与邮件配置权限时可点击「生成分析」。模型接收近1/3/7/15/30天汇总、30天每日趋势和三个维度近7天 TOP10 商品编码，不接收原始 Excel、邮箱、图片或 ERP 凭据。
3. 面板优先显示经营摘要、当日销售额、近7天日均销售额、期间退货率及截止日库存，再展示30天趋势和近1/7/15/30天日均对比。较前一日/较30天日均的比例在基数为零或缺失时显示「—」，不把缺失库存当作零。
4. 「重点商品关注」按款号、货号、条码切换，只检查各维度近7天销售 TOP10。优先展示售罄且有销量或发生退货的商品，最多10项；这不是全量库存预警。「建议先做这几件事」显示前三条建议；「完整经营观察、建议与风险」保留全文。摘要中的「查看完整解读」会展开全文并滚动到对应位置。摘要、建议卡片及完整正文中，匹配到报告快照商品图片的款号、货号、条码以可点击文字显示：悬停或键盘聚焦显示120×120像素预览，点击放大，支持缩放、旋转及Esc关闭。图片打开后按Esc只关闭图片，报告面板继续保留，可继续查看或分享。编码按完整标识匹配，较短款号不会误匹配到更长货号或条码内部。没有匹配图片的编码保留原文，不虚构商品图片；图片来自同一份报告快照，不因当前页面筛选而改变。
5. 图表来自生成解读时同一批数据的保存快照，与页面筛选无关；旧的缓存分析在来源仍一致时补存图表及商品缩略图，不会因此再次付费调用模型。缩略图供页面预览使用，不发送至模型服务。分析面板只显示数据截止日和生成时间，不展示模型及供应商名称；模型配置仍在超级管理员的系统设置页维护。刷新读取已有结果。同一批数据与同一分析版本复用生成结果，多邮箱共用一份分析，每次最多4096个输出 token（包含推理）。

## 外部分享与手机查看

有导入与邮件配置权限的用户可在 AI 分析侧栏点击「分享报告」，选择1、7或30天有效期，再点击「创建分享链接」。分享面板会显示链接和二维码，可复制发送或在手机扫码查看。只有已经生成的报告才能创建分享；生成状态或报表来源变化时，先刷新分析。

外部访客持有有效链接即可查看，无需注册或登录。分享内容包括经营摘要、销售/退货/库存指标、图表、商品图片及完整解读；不提供经营系统导航、报表导入、模型设置或邮箱配置。链接保存创建时的报告快照，后续导入报表或刷新分析不会改变已分享内容。模型/供应商名称、凭据、原始文件及邮箱不包含在分享内容中。

新链接只在创建后显示，请及时复制保存；「我创建的链接」保留最近30条记录，可撤销仍有效的链接。创建者可撤销自己的链接，超级管理员也可通过接口撤销其他用户的链接。撤销立即阻止新的读取；已打开页面保存的内容不能远程收回。过期、撤销或无效链接统一提示无法查看；可重新创建新链接。

手机端指标卡按两列排列，图表和建议卡片纵向排列，重点商品关注改为逐项卡片，完整正文自动换行。商品编码和图片仍可点击放大；趋势图可点击日期点查看提示。分享不会自动发送邮件或消息，也不会再次付费生成分析。

AI 仅生成解读，不改变原始统计、库存、采购或调拨。不同日期长度的比较应依据日均数据；不推算缺失的成本、利润或采购周期。模型输出须通过格式与模型标识验证，截断、拒绝或其他模型的结果不采用。单份数据生成失败后至少间隔一分钟重试，最多三次；超时或进程退出的未确认结果会提示管理员核对。更换报表后生成新分析。

每日邮件在 AI 开启并验证后调用同一模型，附加 AI 分析；生成进行中时等待结果。未开启、未验证或调用失败时，邮件明确列出 AI 状态，继续提供报表汇总，不把规则汇总标成 AI 报告。已发送邮件不会因补做 AI 分析再次发送。

## 配置邮件

1. 管理员在部署环境为 API 和 Worker 设置相同的 `COMPASS_MAIL_KEY`（32 字节随机密钥的 64 位十六进制形式）。不要把密钥放在表格、手册或聊天中。
2. 点击「每日邮件」，填写一个或多个收件邮箱，逗号分隔，最多 20 个，重复地址自动去重。各收件邮箱单独发送。
3. QQ 邮箱 SMTP 服务器使用 `smtp.qq.com`、465 TLS 端口；也支持其他服务的 587 STARTTLS。发件邮箱须与 SMTP 账号一致。QQ 邮箱开启 SMTP 后填写邮箱授权码，不使用登录密码。
4. 开启每日邮件并点击「保存并验证」。授权码在服务器加密保存，不回显；已保存时留空保留，变更 SMTP 账号、地址或端口需重新填写并验证。
5. 数据齐备后可以点击「发送今日报告」。每日按数据日期和收件邮箱防止重复发送；已经由邮件服务器接收的报告不会再次发送。

日报包含近 1、3、7、15、30 天款号汇总、三个维度的近 7 天汇总及各维度 TOP 10，列明数据截止日期和统计口径。最近发送记录显示每个邮箱的结果。「邮件服务器已接收」不保证进入收件箱，请同时检查垃圾邮件。

认证失败时检查 SMTP 是否开启以及授权码；连接失败时检查服务器网络和发件地址/端口。自动任务只对确认失败的发送有限重试；发送途中网络断开或进程退出导致结果不明时不自动重复发信，应先核对收件箱，由管理员处理。未配置授权码或未验证时不会发送邮件。可关闭「开启每日邮件」暂停发送；报表下载与导入由「更新数据」手动发起，暂停邮件不会暂停导入，邮件检查也不会发起报表更新。
