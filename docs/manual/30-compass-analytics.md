# 经营分析与每日邮件

更新日期：2026-10-02。入口：ERP系统 → 经营分析。查看需要「经营分析查看」权限；导入、配置邮箱和发送日报需要「经营分析导入与邮件配置」权限。

## 导入与分析

1. 在魔方罗盘下载中心下载「按款号（近30天）」「按货号（近30天）」「按条码（近30天）」原始 Excel。首列应为日期，包含连续每日明细；不要改动平台 ID 或编码。
2. 点击「导入报表」，可一次选择三张。每张最多 100MB、200000 行、100 列，支持 `.xlsx` 和 UTF-8 CSV。后台解析文件，分批上传；整张报表完整后才替换对应维度的面板数据。
3. 导入中断时重新选择原始文件继续。重复文件不会重复累计；较旧统计区间不能覆盖较新报表。近期导入记录保留 45 天，当前使用的报表始终保留。每次分析使用当前对应维度的一张报表。
4. 选择按款号、货号或条码分析，选择近 1、3、7、15、30 天。默认以该维度最新报表的截止日期为终点；可手动选择截止日期。超出报表范围会显示日期覆盖不足，旧报表会显示更新提示。
5. 右上角输入框支持模糊查找款号、货号、条码、尺码或分类。点击排行或款号明细进入对应货号，再点击货号进入条码；顶部范围标签可关闭。「查看全部」清除范围和关键词。
6. 明细支持按销售额、净销售额、销量、退货数或可售库存排序。「导出当前页」导出当前筛选及排序下的一页分析结果。

BI 看板包含销售额、净销售额、销量、期间退货率与可售库存五张指标卡，以及每日销售/退货趋势和商品销售排行。悬停或键盘聚焦趋势图日期点可查看当日数值；切换日期后，已不在区间内的提示自动清除。

销售、净销售和退货使用原始报表指标，跨日累计。三个维度是独立统计口径，不能相加。库存只使用截止日期当天的快照，不累计每天的库存；没有该日库存数据时显示「—」。报表导入不会覆盖 ERP 实物库存。

客户数、曝光 UV、商详 UV 等由每日指标累计，跨日未去重。点击率与购买转化率按累计分子和分母重算。期间退货率 = 当期退货件数 / 当期销售量，可能超过 100%，不代表同一批订单的退货率；分母为零或缺失时显示「—」。条码报表没有曝光和商详 UV，不显示这些指标。面板不推算未提供的成本或利润。

## 每日自动更新

本机 Codex 定时采集任务每天北京时间 08:00 使用已登录的 Chrome 下载三个报表，并导入本系统。电脑、Chrome、Codex 应保持在线，罗盘账号需保持登录。登录失效、报表过期或平台尚未生成当天报表时，需要处理后更新，不会以旧报表冒充新数据。该采集不是服务器上的官方罗盘 API；官方指标接口尚未开通。

服务器邮件任务在每天 08:00 后检查最新报表。三张报表都覆盖截至昨日的完整近 30 天，且邮件配置已开启并通过 SMTP 验证后，才生成日报。平台更新延迟时等待完整数据，完成后补发。

## 配置邮件

1. 管理员在部署环境为 API 和 Worker 设置相同的 `COMPASS_MAIL_KEY`（32 字节随机密钥的 64 位十六进制形式）。不要把密钥放在表格、手册或聊天中。
2. 点击「每日邮件」，填写一个或多个收件邮箱，逗号分隔，最多 20 个，重复地址自动去重。各收件邮箱单独发送。
3. QQ 邮箱 SMTP 服务器使用 `smtp.qq.com`、465 TLS 端口；也支持其他服务的 587 STARTTLS。发件邮箱须与 SMTP 账号一致。QQ 邮箱开启 SMTP 后填写邮箱授权码，不使用登录密码。
4. 开启每日邮件并点击「保存并验证」。授权码在服务器加密保存，不回显；已保存时留空保留，变更 SMTP 账号、地址或端口需重新填写并验证。
5. 数据齐备后可以点击「发送今日报告」。每日按数据日期和收件邮箱防止重复发送；已经由邮件服务器接收的报告不会再次发送。

日报包含近 1、3、7、15、30 天款号汇总、三个维度的近 7 天汇总及各维度 TOP 10，列明数据截止日期和统计口径。最近发送记录显示每个邮箱的结果。「邮件服务器已接收」不保证进入收件箱，请同时检查垃圾邮件。

认证失败时检查 SMTP 是否开启以及授权码；连接失败时检查服务器网络和发件地址/端口。自动任务只对确认失败的发送有限重试；发送途中网络断开或进程退出导致结果不明时不自动重复发信，应先核对收件箱，由管理员处理。未配置授权码或未验证时不会发送邮件。可关闭「开启每日邮件」暂停发送，本机报表采集任务由 Codex 自动化设置管理。
