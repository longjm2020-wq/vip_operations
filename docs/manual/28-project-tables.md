# 新建表格

## 跨表传送

与选款登记共享「跨表传送」：勾选最多100条已保存、未锁定且有完整编辑权的行，选择另一张可编辑表格，配置字段对应后预览并确认。空表可以作为目标；勾选新增未对应字段后新增对应字段定义和记录。目标字段定义和原表对应配置按账号、表格保存到服务器。两表各自的模块权限、访问范围及保护规则都须允许操作。

目标已有相同款号或上次传送的关联行时，更新所选字段，保留未对应字段。所有值按目标字段类型校验，商品档案另受商品业务校验；任一行失败或预览后发生冲突时整批回滚。成功后原行保留，填充透明黑色且禁止编辑；行号小铅笔可释放原行，目标记录仍保留。后续修改不会自动传送，需再次明确操作。配置、预览和恢复步骤见「选款登记 → 跨表传送」。

两边对应字段均为单选、多选或自定义标签时，预览列出将追加至目标的源候选选项，确认时与记录一起保存。目标已有选项、顺序、颜色、类型及其他设置保留；追加选项带入源字段已设置的颜色。普通表格候选项补齐按账号及目标表保存，预览不写入目标记录或字段。普通表格字段合并后最多100项，商品档案共享单选最多50项，原单选、多选内容未配置或不符合目标限制时须先修正。文本字段不自动扩展选项。商品档案共享单选的新增项在预览标注「商品共享」，确认后对所有用户生效，沿用商品编辑权限；只追加候选项，保留原选项与字段类型，仍只能保存一个值。共享选项、目标记录及个人布局在同一事务中保存，失败时全部回滚。（2026-10-05）

## 权限与用途

搜索框统一放在顶部导航栏，继续搜索当前表格；表格名称保留在页面。搜索框采用全站统一的暖色圆角样式，桌面端固定224px宽（125%缩放时约280像素）、28px高，聚焦时只显示一层柔和橙色边框；长内容及多行查询在框内滚动查看、编辑，不撑开导航栏，也不截断查询内容。窄屏按可用宽度收窄，框高不变。表格随可视区域高度展开，批量添加、分页和选区统计操作栏保持在可视区域底端，滚动表内内容时持续可见，窄屏按剩余高度调整。

所有内部角色均已补齐项目查看和创建权限，可使用新建表格；供应商角色不参与此次授权。查看列表和打开有权访问的表格需要项目查看权限，创建表格、录入或删除行需要项目创建权限。新建表格与选款登记采用独立的模块权限，能够使用表格不会自动获得选款登记查看或编辑权限。无需先创建一个流程项目。管理员可在每张表内配置保护区域、指定用户的查看和编辑权限、抢占填表及内容自动隐藏。流程项目及其任务表仍使用原有权限。新增入口需刷新页面后显示。

## 显示、公开范围与回收站

「内容范围」选择全部可访问、公共区域或我创建的；公共区域只显示公开表格，并显示创建者。顶部「我的工作台」集中显示本人创建的表格，可在那里切换公开范围，更新同一张表格。

列表上方「卡片 / 列表」切换显示，当前浏览器按账号记住选择。新表默认不公开，创建时可选择公开范围；已有表保留原先的公开范围。公开表允许系统内有项目查看权限的用户打开，录入另需项目创建权限，表内保护规则继续限制具体内容和编辑，不会公开到互联网。不公开时，仅创建者、管理员和保护设置明确授权的用户可访问；撤销指定用户的区域授权后，私有表访问同时收回。

创建者或管理员在有项目创建权限时，通过「⋯」设置公开范围或「移至回收站」。确认删除后，整表记录、图片、手机拍图和外部收集链接立即停止访问。回收站显示本人创建的表格，管理员可管理全部，30 天内可恢复原数据、保护权限、公开范围和仍有效的收集链接。服务器中的个人字段与布局设置也保留。

达到 30 天即不可恢复，系统每小时检查并彻底清理表格的独立数据空间、记录、图片、收集表和令牌；文件存储故障自动重试。审计保留操作元信息，清除被删表格的原内容。单独发布的产品收集链接属于明确的外部分享授权，不受系统内公开开关影响；移至回收站会停用这些链接。

## 创建与再次打开

1. 打开「新建表格」，点击右上角「新建表格」。
2. 填写表格名称，最多 100 个字符，点击「创建空表」。创建成功后直接进入该表。
3. 新表初始化为零字段、零记录的空表，不预置文本字段或空白记录，也不复制选款登记或其他表的资料、图片、收集表、保护规则及个人布局。表头右侧「＋」添加字段，最后一行左侧「＋」添加记录；也可使用工具栏「添加一行」或底部批量添加按钮。字段和记录添加后使用与选款登记相同的边框、表头、列间距、默认超宽行高及编辑功能；左侧复选框列、行号列独立，显示行拖动手柄。刷新、再次打开和创建请求重试都不会自动补入字段或记录。
4. 点击顶部工作栏「返回表格列表」可查看已创建的表，正文不再重复显示返回入口。点击表名或「打开表格」再次进入，刷新后数据仍保留。

创建失败时留在名称窗口，检查提示后重试；同一次创建请求重试不会重复建立表格。没有创建按钮时，请管理员检查项目创建权限。表格不存在或账号无权访问时不会回退显示选款登记的数据。

已有表格保留原来的字段和记录，不会被重新初始化。旧版预置的文本字段和空白记录继续保留；新表的全部字段及记录由用户自行添加。左侧复选框可勾选记录，表头复选框选择全部可见行；点击或拖动行号仍可选择整行。行高可通过工具栏切换紧凑、标准、宽松或超宽，表头高度保持一致。仅查看账号不能添加字段或记录。

## 表内功能与独立性

新表与选款登记共用同一套表格组件，功能修正和更新同步生效，包括：单元格录入、自动保存、复制粘贴、拖选和填色、Shift 行列拖动、字段管理及字段类型设置、图片及轮播设置、手机扫码拍图、搜索、列筛选、分组排序、行高和格式、统计、Excel 导入导出、产品信息收集表及多人协作。

点击单元格直接录入或在顶部固定编辑栏填写，修改后自动保存；失败时相关单元格标红，可检查提示并重试。编辑栏高度固定，切换字段类型时表头位置不变；多行文字在框内滚动，过多标签折叠显示，展开列表可查看完整选项。多项文本、颜色或尺码按字段类型填写，可将外部多行多列内容粘贴到对应单元格区域。表头右侧「＋」添加字段，字段管理可修改名称、类型及图片上传设置。图片字段可在单元格上传多图或通过手机扫码拍图，上传和换行继续写入当前表格。只读或受保护的区域不能修改；主表选款资料不会因本表录入而改变。需要更多共享控件的说明且具有选款查看权限时，可参考「选款登记」章节。

已设置货币等数字格式的可编辑单元格，包括空白格，可单击后直接键入。编辑时显示原始内容，离开后恢复所设格式，清空仍留白；内容继续按字段类型校验。（2026-10-05）

所有新增字段的初始列宽统一为120px；拖动表头右侧分隔线可调整，已保存的个人列宽继续生效。单选、多选的空单元格初始留空，单击只选中，默认不展开列表，点击右下角下拉图标再选择，再次点击可收起；键盘聚焦后按 Enter、空格或向下箭头也可展开。表格滚轮、滚动条横向或纵向滚动以及页面滚动会自动收起列表，保留已选值，选项列表内部仍可滚动。已填项显示居中的圆角标签；多选可组合多个不同颜色的标签，增删或清空后自动保存。字段管理编辑窗口的「选项标签颜色」可为每项选择网站配套的八种颜色，立即更新已有标签，配色随字段设置按账号保存到服务器。只读账号仅查看标签。

单元格默认水平居中、垂直居中，表头文字也居中。选中单元格后可用工具栏修改水平和垂直对齐，保存后按各格的设置显示；未设置格式的单元格使用居中默认值。多格选区保持透明，不增加填色，原有填色、文字和内部单元格分隔线继续可见，外圈显示蓝色边框。

首次点击选格，再次点击已选格的文字可定位光标，拖动可选择部分文字，继续输入、粘贴、删除或剪切选中文字。双击或直接键入也可进入编辑；文字编辑时 Ctrl/Cmd+A 全选当前格文字，Ctrl/Cmd+Shift+方向键选择文字，Delete 只处理文字。按 Esc 退出文字编辑，点击其他格后恢复框选；只读格可选择复制，不能改写。

单击单元格后，Ctrl+Shift+↑/↓ 可选当前列从本页第1行到最后一个非空格，Ctrl+Shift+←/→ 可选当前行从第1个可见字段到最后一个非空格；Mac 使用 Cmd+Shift。包含中间空白格，排除末尾空白格，只作用于当前页的可见行列。`0` 和已填图片计入内容；文字编辑状态及顶部编辑栏保留文字选择行为。点击图片打开浮动大图后，可拖动图片调整位置，并继续编辑未被遮挡的单元格、滚动表格；大图工具栏支持缩放、旋转、翻转、切换多图及重置，图片右键支持复制、下载和复制完整地址，按 Esc 或关闭按钮收起。

浮动大图的工具栏及图片右键菜单提供「识别图片文字」「框选识别文字」；框选时拖动图片上的文字区域，松开后识别中英文。结果在「图片文字」面板中显示，可核对、修改后「复制文字」，也可选中文字用快捷键或浏览器右键复制。大图右键「复制图片文字」会复制已有修改后的结果，无结果时先识别整图。识别和复制不会自动写入；在当前表格中粘贴到文本单元格时保留换行在同一格内，多格选区可填入各个可编辑的文本目标格。外部表格复制仍按原有多行多列规则粘贴。

识别按需在浏览器内运行，不上传图片到第三方识别服务。识别资源升级为较高精度的中英文模型，首次加载文件较大，之后复用浏览器模型缓存。识别会放大文字，沿用图片预览中手动调整的方向和框选区域；较低置信度时再做明暗与对比度增强。整图整体分数较高时，也会从原始图片像素单独复核最多八行低置信度文字，只有结果可靠度明显提高时才替换该行。不会根据面料名称猜测或改写数字；模糊、遮挡仍可能识别错误，务必核对材质和百分比。 首次加载可能需要等待，只读账号也可识别复制，粘贴仍受表内权限限制。关闭大图、切换图片、关闭结果或取消识别会取消任务，结果不保存在服务器。可先把图片旋转、翻转至正向；文字模糊或遮挡可能误识别，需核对数字、百分比及名称。未识别到文字、读取失败或用时过长时，可重新识别、框选较小区域或更换清晰图片。站外图片禁止跨域读取时无法识别；剪贴板复制失败时可手动选中结果复制。

各表的数据、款号重复检查、图片、收集表、共享列筛选及排序、在线协作状态、保护规则和认领状态相互独立。同一个序缇款号可以在不同表中使用，同一张表内不能新增重复款号。手机二维码携带所属表格信息，换款和上传继续保存在该表；外部收集表根据分享令牌访问其所属表格。

标准手机拍图页的颜色标签右侧提供小铅笔。颜色及图片字段均可编辑时，可修改颜色名称并「保存颜色」，同步修改本款颜色及该颜色下全部候选款图片的标签，保留图片、数量、顺序及其他字段，仍保存在当前表格。颜色不能为空、不能含 `/`、不能与本款其他颜色重名，合计最多100字；上传中或该颜色存在待重试图片时暂不可改名。并发修改提示冲突时，关闭窗口，读取最新资料后重新核对保存；只读或受保护字段不显示改名按钮。此操作只适用于标准候选款图片颜色，自定义图片页继续使用其既有字段设置。（2026-10-05）

右键列标题或单元格选择「固定此列」，可把列固定在行号右侧，横向滚动时持续显示；固定列按原字段顺序排列。拖动表头框选连续多列，或先点击起始表头再按住 Shift 点击末尾表头，随后在选区内右键「固定所选 N 列」可一次固定多列。矩形单元格选区涉及的多列也可批量固定。在所选固定列内右键「取消固定所选 N 列」仅取消这些列；混合选区固定时保留其他已有固定列，右键选区外改为单列操作。右键也可「取消固定此列」或「取消所有固定列」恢复原顺序，操作后清除多列选区。Shift 点选不调整顺序，Shift 拖动仍可调序。只读账号也可使用，固定后复制粘贴及快捷键按当前显示的列顺序处理；无记录时也能通过表头选列。

表头和单元格右键菜单提供「设置列宽」，可输入像素（px）或厘米（cm）；多选后在选区内右键可统一设置多列，输入框先显示第一列宽度。点击「确定」应用并按账号保存到服务器，取消不修改；固定列的位置同步更新，最小 80px（约 2.12cm）。厘米按网页标准 1cm = 96/2.54px 换算，最终保存整数像素，反复切换单位不会自行改变宽度；屏幕与页面缩放会影响实际物理尺寸。无效数值不可确定，只读账号也可设置。

「字段分组 → 添加分组」可填写最多40字的名称并选择多个字段，包含图片字段，同一字段可以属于多组。名称不能为空、不能重复或使用「全部字段」，每组至少一个字段；可修改或删除分组，点击「保存分组」生效，取消保留原配置。保存后表格上方显示快捷 TAB：有固定列时，选中组的非固定字段移到固定列右侧，其他字段继续显示，按原字段顺序排列且不重复；没有固定列时保持顺序，横向定位到本组第一个可见字段，再次点击 TAB 可重新定位。「全部字段」恢复原顺序，保留固定列。隐藏或删除的字段不参与快捷定位，重新显示隐藏字段后沿用分组；整组无可见字段时 TAB 不可点击，当前组返回「全部字段」。只读账号也可配置，切换 TAB 清除单元格选区和复制虚线，不改记录，后续复制粘贴按显示的列顺序处理。此功能与按字段内容归组的行分组独立。

选择分组 TAB 后，该组所有可见字段的表头顶部显示暖橙色粗线，包括组内固定列，其他字段不标注；切换分组即时更新，点击「全部字段」清除。粗线随表头滚动，不改变表头行高。

「字段管理」中的「初始化字段类型」已移除，改为「字段类型管理」。管理窗口可搜索、启用或停用内置类型；「新增类型」填写1至40字的唯一名称并选择基础类型。单选、多选须填写默认候选项，每行一个，自定义标签可不填；最多100项，每项最多80字且不能含 `/`。保存后在添加或编辑字段的类型下拉框选择新名称，沿用基础类型的控件和校验，候选项带入字段后可独立调整和配色。名称不能与现有类型重复，取消不新增。

停用立即保存，使该类型不再供新选择，已有字段及数据继续可用，编辑时显示「已停用」，重新启用恢复选择。新增命名类型不会增加自定义程序、公式或关联能力，也不会绕过业务存储限制；内容不兼容时仍拒绝更改字段类型。只读账号可查看类型目录，新增及开关变更需要项目创建权限和本表编辑权限。目录按账号及表格保存到服务器，刷新或换设备可恢复，不改服务器权限。

字段定义、名称、类型、选项和功能设置、删除/隐藏状态、字段顺序、列宽、固定列、字段分组及最后选中的 TAB，均按账号及表格保存到服务器。搜索、个人列筛选及排序、是否跟随共享筛选、行分组及排序配置、行高、每页行数和页码、统计显示项与数字格式也会恢复；同一账号换浏览器或设备可读取云端最新设置。服务器数据和保护权限不会因此丢失。字段删除保留服务器中的已有数据；字段管理已移除「已删除字段」入口、列表和恢复操作。新增同名字段使用新标识，不取回旧字段资料。无TAB时先添加并保存分组；TAB不可点击时显示其隐藏字段，或编辑分组移除已删除字段。
