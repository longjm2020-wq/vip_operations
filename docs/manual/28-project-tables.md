# 新建表格

更新日期：2026-10-04。入口：项目协作 → 新建表格。

## 权限与用途

所有内部角色均已补齐项目查看和创建权限，可使用新建表格；供应商角色不参与此次授权。查看列表和打开有权访问的表格需要项目查看权限，创建表格、录入或删除行需要项目创建权限。新建表格与选款登记采用独立的模块权限，能够使用表格不会自动获得选款登记查看或编辑权限。无需先创建一个流程项目。管理员可在每张表内配置保护区域、指定用户的查看和编辑权限、抢占填表及内容自动隐藏。流程项目及其任务表仍使用原有权限。新增入口需刷新页面后显示。

## 显示、公开范围与回收站

「内容范围」选择全部可访问、公共区域或我创建的；公共区域只显示公开表格，并显示创建者。顶部「我的工作台」集中显示本人创建的表格，可在那里切换公开范围，更新同一张表格。

列表上方「卡片 / 列表」切换显示，当前浏览器按账号记住选择。新表默认不公开，创建时可选择公开范围；已有表保留原先的公开范围。公开表允许系统内有项目查看权限的用户打开，录入另需项目创建权限，表内保护规则继续限制具体内容和编辑，不会公开到互联网。不公开时，仅创建者、管理员和保护设置明确授权的用户可访问；撤销指定用户的区域授权后，私有表访问同时收回。

创建者或管理员在有项目创建权限时，通过「⋯」设置公开范围或「移至回收站」。确认删除后，整表记录、图片、手机拍图和外部收集链接立即停止访问。回收站显示本人创建的表格，管理员可管理全部，30 天内可恢复原数据、保护权限、公开范围和仍有效的收集链接。浏览器中的个人字段与布局设置也保留。

达到 30 天即不可恢复，系统每小时检查并彻底清理表格的独立数据空间、记录、图片、收集表和令牌；文件存储故障自动重试。审计保留操作元信息，清除被删表格的原内容。单独发布的产品收集链接属于明确的外部分享授权，不受系统内公开开关影响；移至回收站会停用这些链接。

## 创建与再次打开

1. 打开「新建表格」，点击右上角「新建表格」。
2. 填写表格名称，最多 100 个字符，点击「创建空表」。创建成功后直接进入该表。
3. 新表初始只有一个「文本」字段和三行空白记录，边框、表头、列间距和默认超宽行高与选款登记统一；左侧复选框列、行号列各自独立，显示行拖动手柄。表格紧接单元格编辑栏，不再使用独立圆角外框或额外内边距。不会复制选款登记或其他表的记录、图片、收集表、保护规则和字段配置。点击单元格开始录入，表头右侧「＋」添加字段，最后一行左侧「＋」添加记录；也可使用工具栏「添加一行」或底部批量添加按钮。三行空白记录在创建时保存，刷新不会重复添加，删完后也不会自动补回。
4. 点击顶部工作栏「返回表格列表」可查看已创建的表，正文不再重复显示返回入口。点击表名或「打开表格」再次进入，刷新后数据仍保留。

创建失败时留在名称窗口，检查提示后重试；同一次创建请求重试不会重复建立表格。没有创建按钮时，请管理员检查项目创建权限。表格不存在或账号无权访问时不会回退显示选款登记的数据。

已有表格保留原来的字段和记录，不会被重新初始化。初始「文本」字段可以修改名称、类型、删除或隐藏；其他字段由用户自行添加。左侧复选框可勾选记录，表头复选框选择全部可见行；点击或拖动行号仍可选择整行。行高可通过工具栏切换紧凑、标准、宽松或超宽，表头高度保持一致。仅查看账号不能添加字段或记录。

## 表内功能与独立性

新表复用选款登记的完整表格功能：单元格录入、自动保存、复制粘贴、拖选和填色、Shift 行列拖动、字段管理及字段类型设置、图片及轮播设置、手机扫码拍图、搜索、列筛选、分组排序、行高和格式、统计、Excel 导入导出、产品信息收集表及多人协作。

点击单元格直接录入或在顶部固定编辑栏填写，修改后自动保存；失败时相关单元格标红，可检查提示并重试。多项文本、颜色或尺码按字段类型填写，可将外部多行多列内容粘贴到对应单元格区域。表头右侧「＋」添加字段，字段管理可修改名称、类型及图片上传设置。图片字段可在单元格上传多图或通过手机扫码拍图，上传和换行继续写入当前表格。只读或受保护的区域不能修改；主表选款资料不会因本表录入而改变。需要更多共享控件的说明且具有选款查看权限时，可参考「选款登记」章节。

所有字段的初始列宽统一为 120px，包括新表的「文本」列和之后新增的字段；拖动表头右侧分隔线可调整，已保存的个人列宽继续生效。单选、多选的空单元格初始留空，单击后下拉选择，已填项显示居中的圆角标签；多选可组合多个不同颜色的标签，增删或清空后自动保存。字段管理编辑窗口的「选项标签颜色」可为每项选择网站配套的八种颜色，立即更新已有标签，配色随字段设置保存在当前浏览器。只读账号仅查看标签。

单元格默认水平居中、垂直居中，表头文字也居中。选中单元格后可用工具栏修改水平和垂直对齐，保存后按各格的设置显示；未设置格式的单元格使用居中默认值。

单击单元格后，Ctrl+Shift+↑/↓ 可选当前列从本页第1行到最后一个非空格，Ctrl+Shift+←/→ 可选当前行从第1个可见字段到最后一个非空格；Mac 使用 Cmd+Shift。包含中间空白格，排除末尾空白格，只作用于当前页的可见行列。`0` 和已填图片计入内容；文字编辑状态及顶部编辑栏保留文字选择行为。点击图片打开浮动大图后，可拖动图片调整位置，并继续编辑未被遮挡的单元格、滚动表格；大图工具栏支持缩放、旋转、翻转、切换多图及重置，图片右键支持复制、下载和复制完整地址，按 Esc 或关闭按钮收起。

各表的数据、款号重复检查、图片、收集表、共享列筛选及排序、在线协作状态、保护规则和认领状态相互独立。同一个序缇款号可以在不同表中使用，同一张表内不能新增重复款号。手机二维码携带所属表格信息，换款和上传继续保存在该表；外部收集表根据分享令牌访问其所属表格。

右键列标题或单元格选择「固定此列」，可把一列或多列固定在行号右侧，横向滚动时持续显示；固定列按原字段顺序排列。右键选择「取消固定此列」或「取消所有固定列」恢复原顺序。只读账号也可使用，固定后复制粘贴及快捷键按当前显示的列顺序处理。

「字段分组 → 添加分组」可填写最多40字的名称并选择多个字段，包含图片字段，同一字段可以属于多组。名称不能为空、不能重复或使用「全部字段」，每组至少一个字段；可修改或删除分组，点击「保存分组」生效，取消保留原配置。保存后表格上方显示快捷 TAB：有固定列时，选中组的非固定字段移到固定列右侧，其他字段继续显示，按原字段顺序排列且不重复；没有固定列时保持顺序，横向定位到本组第一个可见字段，再次点击 TAB 可重新定位。「全部字段」恢复原顺序，保留固定列。隐藏或删除的字段暂停显示，恢复后沿用分组；整组无可见字段时 TAB 不可点击，当前组返回「全部字段」。只读账号也可配置，切换 TAB 清除单元格选区和复制虚线，不改记录，后续复制粘贴按显示的列顺序处理。此功能与按字段内容归组的行分组独立。

字段名称、类型、删除/隐藏状态、列宽、固定列、字段分组快捷 TAB、个人行分组排序字段配置和每页行数继续保存在当前浏览器，按表格分别保存；刷新保留字段分组定义，默认打开「全部字段」，更换浏览器或设备不会自动同步这些本机设置。服务器数据和保护权限不会因此丢失。字段删除保留原有数据，可以在字段管理中恢复。无 TAB 时先添加并保存分组；TAB 不可点击时恢复或显示其字段。

新表沿用选款登记的数据格式和业务校验；不自动创建商品、库存、订单或流程项目。整表删除使用回收站，目前不提供重命名。
