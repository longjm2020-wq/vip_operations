# 新建表格

## 工具箱（2026-10-20）

表格工具栏「手机拍图」后提供工具箱图标，点击在侧边面板搜索、维护颜色和尺码映射，关闭后继续操作原表格。映射属于系统共用商品资料，查看需商品查看权限，维护需商品编辑权限；项目或表格编辑权限不自动授予这些权限。原表格搜索及选区保留，保存映射不自动修改选区或生成 SKU。具体步骤及限制见「颜色尺码映射」。

## 撤销与重做（2026-10-16）

单张表格工具栏左侧提供「撤销」「重做」，最多保留当前页面最近 10 步本人操作，包括单元格输入、批量粘贴、清空、查找替换、格式、新增/删除行及调序、字段新增/删除和设置、列顺序与宽度、隐藏/固定、字段分组、行高及可选分组/排序字段配置。批量操作整体按一步处理；文字连续输入和连续调整同一列宽会合并。表格选区或表头可用 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z，输入框内保留原生文字撤销。

恢复后沿用自动保存，保存失败按提示修正或重试；历史不跨刷新、登录、电脑或表格保留，撤销后新修改清空重做。搜索、筛选、分页和当前标签不计步数；导入、AI 标题确认、跨表传送、释放传送锁及权限/可见范围变化后重新记录。共享、公开状态、保护和认领权限不通过撤销恢复。

当前权限和多人冲突重新检查，不能覆盖他人已修改的相关内容。删除行仅凭本人、本表 24 小时内的服务器删除记录恢复，最多 5000 行一批，保留原 ID 和创建信息；款号冲突、权限变化及原有业务限制仍会阻止操作，失败保留历史。完整步骤及限制见「选款登记 → 撤销与重做」。

## 跨表传送

超级管理员传送原行时，不受区域、私有字段范围、自动隐藏或他人认领限制，历史字段残留也不再误拦整行权限检查；未注册字段不能任意映射写入，残留值及格式留在原表，不新增、复制或公开。字段映射、迁移锁及目标业务校验继续执行；完整边界见「选款登记 → 跨表传送」。（2026-10-16）

与选款登记共享「跨表传送」：勾选最多100条已保存、未锁定且有完整编辑权的行，选择另一张可编辑表格，配置字段对应后预览并确认。空表可以作为目标；勾选新增未对应字段后新增对应字段定义和记录。公开字段沿用目标表公共字段，私有源字段在目标表仍为私有，归执行传送的用户，未公开前不会传播给其他用户。原表的目标选择及对应配置仍按账号、表格保存。两表各自的模块权限、访问范围及保护规则都须允许操作。

目标已有相同款号或上次传送的关联行时，更新所选字段，保留未对应字段。所有值按目标字段类型校验，商品档案另受商品业务校验；任一行失败或预览后发生冲突时整批回滚。成功后原行保留，填充透明黑色且禁止编辑；行号小铅笔可释放原行，目标记录仍保留。后续修改不会自动传送，需再次明确操作。配置、预览和恢复步骤见「选款登记 → 跨表传送」。

超级管理员可用小铅笔执行管理恢复，解除原行的传送锁定，不会被他人认领、普通行列编辑限制或已删除字段残留阻挡；普通管理员及协作者仍按已获权限恢复。恢复仍核验当前表格访问、记录版本及并发冲突，成功后记录审计；目标记录保留，业务校验及未注册字段的写入限制不变。（2026-10-10）

两边对应字段均为单选、多选或自定义标签时，预览列出将追加至目标的源候选选项，确认时与记录一起保存。目标已有选项、顺序、颜色、类型及其他设置保留；追加选项带入源字段已设置的颜色。公开字段候选项随目标表共享，私有字段仅创建者及超级管理员可访问，创建者和超级管理员的字段维护权限继续生效；预览不写入目标记录或字段。普通表格字段合并后最多100项，商品档案共享单选最多50项，原单选、多选内容未配置或不符合目标限制时须先修正。文本字段不自动扩展选项。商品档案共享单选的新增项在预览标注「商品共享」，确认后对有权查看该表的用户生效，沿用商品编辑权限；只追加候选项，保留原选项与字段类型，仍只能保存一个值。共享选项、目标记录及相关布局在同一事务中保存，失败时全部回滚。（2026-10-09）

打开单张表格后，工具栏上方不再重复显示表格名称与说明标题行，表名仍在顶部导航显示；选款登记和商品档案采用相同布局。（2026-10-11）

三类在线协作表格统一移除最下方的品牌说明行，表格填满可视区域，批量添加、分页及选区统计保持在底端。「空白行自动保存」及原底部操作说明收进「添加 N 行」右侧的小提示图标；悬停或点击查看快捷键、行列选择、调序和图片录入说明，点击外部收起，不修改内容或保存设置。触屏使用点击，找不到提示时查看表格底部操作栏；只读账号也可查看，图片录入说明改为仅查看提示。（2026-10-11）

本表其他在线协作者显示在工具栏右侧的小图标中，点击打开用户卡片，查看昵称、在线状态和有权查看的选中位置；没有其他用户时显示团队图标和空状态。选中不等同于正在输入，无查看权限或未读取的位置只显示「正在查看本表」。状态约2秒更新，关闭或断网后最迟约45秒过期，读取失败可点击「重新读取」。拖动调整列宽、松开及后台保存时保留当前横向和纵向查看位置，不重新跳到分组首列；明确切换分组时仍按原规则定位。（2026-10-11）

每页超过200条时按可视区域渲染，保留当前编辑行；整页选择、复制、统计、跨页粘贴、查找和导出仍按完整范围处理。创建时间粘贴的输入错误、逐行保存及冲突处理见「选款登记 → 修改与批量粘贴创建时间」；单元格权限、保护和传送锁定继续生效，保存记录修改日志，创建人保持不变。（2026-10-11）

选区右键「复制选区为图片」将选中资料及表头复制为 PNG，按当前显示顺序生成，包含当前页屏幕外的已选行；保留文字、图片、标签和单元格显示格式，未选中的间隔位置留空，受保护内容只显示保护标记。表头右键「复制表头」按所选列复制字段名称，空表有字段时也可复制表头或表头图片。只读成员可以复制有权查看的内容，不修改记录或布局；图片读取失败会显示占位并提示数量，超大选区需分段复制。步骤和剪贴板要求见「选款登记 → 表格操作」。（2026-10-13）

按标准颜色导入的图片跨表传送到另一张表的「图片」时，须同时配置该标准颜色字段的对应，系统将图片关联改为目标表的实际标准颜色字段；目标须为可访问、类型支持的标准颜色字段，不能依靠两表偶然同名的存储位置省略对应。预览核对目标最终颜色，关联不符或字段不可访问时整批不写入。传送为洗唛/吊牌图时去掉颜色标签及关联；传送至普通自定义图片字段时只保留普通颜色标签。产品信息收集表沿用已保存图片的关联，供应商颜色修改不要求标准颜色图片采用供应商名称。（2026-10-11）

## 拖动选择单元格（2026-10-11）

在普通文本框内拖动可选择文字；按住鼠标移出原单元格边界后，转为连续矩形单元格选区。已有高亮文字也可作为起点，文字拖放不会移动或改写资料。靠近表格上下或左右边缘时自动滚动，越靠近边缘速度越快，离开边缘回到中间则停止滚动；单击不触发滚动。选区限当前页显示字段及逻辑行，包含尚未渲染的行，不自动翻页。松开鼠标、按 Esc 或窗口失焦结束拖选，选区保留；选择不会保存内容，后续复制、粘贴或替换仍按权限执行。

## 查找与替换（2026-10-11）

打开本表，在表格操作区按 Ctrl+F 打开「查找」TAB，按 Ctrl+H 打开「替换」TAB；点击工具栏「查找/替换」默认打开「替换」。两个 TAB 共用查找内容和选项，「查找」页不显示替换输入框及替换按钮。支持普通文字、区分大小写及整格匹配，符号不作为正则表达式；查找不能为空，替换可以留空。页面搜索框和无关弹窗保留自己的快捷键。

面板关闭时，用快捷键打开会优先把当前单元格中已选中的部分文字填入「查找内容」；没有文字选区时，填入当前格的可查看文字。面板已打开时，点击 TAB 或再按 Ctrl+F / Ctrl+H 只切换页面并回到查找输入，保留查找、替换内容及原选区；关闭后重新打开才重新记录选区，用快捷键重新打开时再次预填当前格文字。图片及无权查看的内容不用于预填。

桌面面板宽480px，窄屏按可用宽度收窄。可用鼠标或手指拖动「查找/替换」标题栏，移动到浏览器可视区域内任意位置；同页关闭再打开保留位置，刷新后恢复默认位置。窗口变小或结果展开时自动调整越界位置，长内容在面板内滚动；未被遮挡的表格仍可操作和滚动。

打开面板时选中多个单元格，默认使用「打开时的选区」，否则默认「当前筛选的可见字段」；可手动切换范围。整列或多列选区覆盖当前筛选结果的全部分页，矩形单元格选区只包含当前页实际选中的格。选区在打开时固定，定位不会扩大它。可见字段范围覆盖当前筛选结果及当前字段分组内的可见、可读文字，包含其他分页；「查找全部」查看匹配位置，结果列表每页50项，「上一个」「下一个」跨页定位。只读及系统值可查找；图片和无权查看的内容不参与，不搜索其他项目表。

在可见字段范围执行「全部替换」时，弹出整表范围确认，列明本次实际修改的可编辑匹配单元格数量、查找内容和替换内容；选区覆盖全部可查找单元格时也会提醒。点击「取消」不修改任何内容；「确认全部替换」才执行。确认和执行期间查找、替换及范围控件停用，执行前重新核对最新内容、范围及编辑权限；变化时拒绝原操作，需重新查找。

「替换当前」「全部替换」只修改具有本表编辑权及对应单元格编辑权的匹配，跳过只读。替换前校验本次全部目标的类型、选项、字数、权限及业务规则，任一失败则本次整批不改。完整含斜杠的单选、多选选项不会拆成其他标签；替换不新增候选项，颜色变更须保留图片颜色的有效对应。

替换后按本表原规则自动保存，关闭窗口不会撤销修改。服务器逐行保存，网络失败或保存时权限、记录版本变化可能部分成功，失败行保留未保存提示，需核对并重试。只读成员可以查找，不能执行替换；匹配数量不能作为保存成功数量。

## 权限与用途

搜索框统一放在顶部导航栏，继续搜索当前表格；表格名称保留在页面。搜索框采用全站统一的暖色圆角样式，桌面端固定224px宽（125%缩放时约280像素）、28px高，聚焦时只显示一层柔和橙色边框；长内容及多行查询在框内滚动查看、编辑，不撑开导航栏，也不截断查询内容。窄屏按可用宽度收窄，框高不变。表格随可视区域高度展开，批量添加、分页和选区统计操作栏保持在可视区域底端，滚动表内内容时持续可见，窄屏按剩余高度调整。

所有内部角色均已补齐项目查看和创建权限，可使用新建表格；供应商角色不参与此次授权。查看列表和打开有权访问的表格需要项目查看权限，创建新表需要项目创建权限；录入、新增或删除行还须具有当前表格的可编辑权限，公开表默认仅查看，不能仅凭项目创建权限改动别人的表。所有有当前表格查看权限的用户，包括只读用户，可自行新增字段，默认仅创建者及超级管理员可见；新增字段不授予内容编辑或新增行权限。新建表格与选款登记采用独立的模块权限，能够使用表格不会自动获得选款登记查看或编辑权限。无需先创建一个流程项目。表内保护、抢占填表及内容自动隐藏继续限制具体内容访问和修改。

表格创建者及超级管理员可在「保护区域 → 内容自动隐藏」添加隐藏区域，选择单元格、整行、整列或明确选择当前工作表，保存至少一条区域后开启；普通编辑成员及普通管理员不能管理别人的表内保护。隐藏仅作用于所选区域内已填写内容，区域外照常显示，指定查看人适用于本表全部隐藏区域。关闭开关保留配置，删除最后一条区域自动关闭。升级前已开启整表自动隐藏的表格保留「原整表自动隐藏」区域，可编辑缩小范围或删除重建；详细步骤及失败处理见「选款登记 → 保护区域与多人填表」。（2026-10-10）

## 显示、公开范围与回收站

「内容范围」选择全部可访问、公共区域或我创建的；公共区域只显示公开表格，并显示创建者。顶部「我的工作台」集中显示本人创建的表格，可在那里切换公开范围，更新同一张表格。

列表上方「卡片 / 列表」切换显示，当前浏览器按账号记住选择。新表默认不公开，创建时可选择公开范围；已有表保留原先的公开范围。公开表允许系统内获准用户默认仅查看，编辑需明确授权，表内保护规则继续限制具体内容和编辑，不会公开到互联网。不公开时，仅创建者、超级管理员及明确授权的协作成员可访问；普通管理员不具有默认访问权。已明确设置禁止查看的用户，即使整表公开也不能访问。

创建者或超级管理员在表格卡片或列表的「⋯ → 成员权限」选择用户，点击「添加成员」，为每个成员选择「可编辑」「仅查看」或「禁止查看」，再「保存权限」。添加时默认仅查看，取消不写入。可编辑仅授权内容修改，不授予成员管理、公开范围设置或整表删除资格；禁止查看优先于整表公开范围。移除成员设置后恢复该账号的默认范围：公开表仅查看，不公开表不可访问，原内容保留。创建者和超级管理员固定可查看、编辑及管理，不能通过成员设置降低其权限。成员权限发生并发修改时保留本地草稿，点击「使用最新成员设置」核对后重新修改并保存；失败提示原因，可重试。整表公开范围与成员权限分开保存。

超级管理员也不受表内区域仅查看、禁止查看、内容自动隐藏、私有字段或他人认领限制，可直接编辑、删除他人认领的行。已删除或未注册字段残留不阻止整行操作，但不会恢复其定义或允许写入未知字段。传送锁仍须点击小铅笔释放，计算字段、格式和并发等业务校验继续执行；普通管理员、表格创建者及协作者不因这项例外获得额外权限。旧页面若仍显示权限不足，刷新后重试；完整边界见「角色权限 → 超级管理员」。（2026-10-16）

创建者或超级管理员通过「⋯」设置公开范围或「移至回收站」，普通编辑成员不能执行。确认删除后，整表记录、图片、手机拍图和外部收集链接立即停止访问。回收站显示本人创建的表格，超级管理员可管理全部，30 天内可恢复原数据、保护权限、公开范围、成员权限和仍有效的收集链接。服务器中的公开字段布局、私有字段及个人设置也保留。

达到 30 天即不可恢复，系统每小时检查并彻底清理表格的独立数据空间、记录、图片、收集表和令牌；文件存储故障自动重试。审计保留操作元信息，清除被删表格的原内容。单独发布的产品收集链接属于明确的外部分享授权，不受系统内公开开关影响；移至回收站会停用这些链接。

## 文本字数限制（2026-10-11）

「字段管理 → 添加字段 / 编辑字段」选择「文本」，在「文本功能设置」选择「汉字数」或「总字符数」，填写1至2000的整数「字数上限」，点击「保存」生效；清空上限取消额外限制，原系统长度上限仍生效。汉字数只统计汉字，总字符数按 Unicode 码点统计，包含字母、数字、标点、空格和换行，普通 emoji 算一个字符，组合表情可能计多个字符。自建文本按保存的完整内容计数，顶部编辑栏及展开的单元格详情显示当前计数和上限。

## AI 商品标题生成（2026-10-12）

在线协作表格工具栏依次显示「AI 商品标题」「产品信息收集表」「手机拍图」「查找/替换」「添加一行」等入口，按权限显示可用按钮；「查找/替换」位于手机拍图之后、添加一行之前。

入口为工具栏「AI 商品标题」，或长标题、短标题列/单元格右键「AI 填补空白标题」。适用于选款登记、商品档案和项目协作表格，分别保存在当前表；不自动跨表更新。需本表编辑权限、已保存且有序缇款号的记录，以及可编辑、可查看的长标题或短标题文本字段。私有字段、保护、自动隐藏、认领及传送锁定继续生效；只读成员不能调用生成或填补。

先完成资料和字段设置保存。有选中行时处理选中行；没有选中行时，多格选区或选中的标题格限定对应行；选择标题整列则处理当前筛选结果，包含其他页。没有上述选区时处理当前筛选结果。窗口显示实际有空白标题的款数，勾选长标题、短标题或两者；已有标题始终保留。没有可填补目标时提示，不创建新记录或字段。

点击「生成候选标题」，结合本款有权查看的成分、类目、描述、可读取商品图片及本表少量已有标题示例生成。示例只参考格式与语气，不移植别款材质或设计。长标题采用【有依据的卖点】和产品描述，短标题精简；可在「标题偏好与规则」选择尝试原创诗意款名，填写语气与用词偏好。图片识别后可补充符合本款的领型、袖型、设计、季节、风格及电商搜索词，例如有依据的通勤、休闲、新中式等；本款已有季节资料优先于图片推断，不能加入相冲突的季节。图片不可读取时，季节及设计描述须有本款文字依据。偏好不是商品事实；材质比例、非遗资质、工艺、功能必须有本款文字依据，不能从图片猜测。成分中的全角数字、百分号会规范后核对，标题显示及字数仍按原文计算；具体纤维名称和比例须有对应部位的依据，不能把里料或配料写成主面料，也不能凭泛称推断更具体的纤维。系统不执行实时热词排名、商标或影视 IP 检索，搜索词需符合商品，不宣称代表实时热度；款名仍需核对，不保证不会与已有名称相同。

长、短标题及原创款名均不写服装颜色词，也不写「面料、里料、填充物、配料、辅料」等成分部位标签。材质不足100%时省略数字比例；贵重材质保留真实卖点，化纤、聚酯、涤纶、氨纶等普通材质不写入标题。成分中的胆料、毛领、帽沿、袖口及小部分填充物分别核对，不混入主材质。例如毛领为水貂毛皮时可写「水貂毛领」，不能推断整衣或其他部位为水貂。鹅绒、鸭绒作为填充材质时，可结合「羽绒服」「羽绒外套」「羽绒马甲」等品类明确用途，无需写「填充物」标签；不能将其写成外层织物。资料中的「白鹅绒」等完整物料名称可保留，其中的字不用于描述服装颜色。绒子含量与充绒量不是材质纤维比例，标题省略这些数字；有小部分普通填充物时，不以此宣称「纯鹅绒」「100鹅绒」等卖点。人工编辑候选也受相同校验，失败时本次不填入；核对各部位资料后可重新生成。（2026-10-12）
