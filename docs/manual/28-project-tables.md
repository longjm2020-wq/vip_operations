# 新建表格

## 跨表传送

与选款登记共享「跨表传送」：勾选最多100条已保存、未锁定且有完整编辑权的行，选择另一张可编辑表格，配置字段对应后预览并确认。空表可以作为目标；勾选新增未对应字段后新增对应字段定义和记录。公开字段沿用目标表公共字段，私有源字段在目标表仍为私有，归执行传送的用户，未公开前不会传播给其他用户。原表的目标选择及对应配置仍按账号、表格保存。两表各自的模块权限、访问范围及保护规则都须允许操作。

目标已有相同款号或上次传送的关联行时，更新所选字段，保留未对应字段。所有值按目标字段类型校验，商品档案另受商品业务校验；任一行失败或预览后发生冲突时整批回滚。成功后原行保留，填充透明黑色且禁止编辑；行号小铅笔可释放原行，目标记录仍保留。后续修改不会自动传送，需再次明确操作。配置、预览和恢复步骤见「选款登记 → 跨表传送」。

超级管理员可用小铅笔执行管理恢复，解除原行的传送锁定，不会被他人认领、普通行列编辑限制或已删除字段残留阻挡；普通管理员及协作者仍按已获权限恢复。恢复仍核验当前表格访问、记录版本及并发冲突，成功后记录审计；目标记录保留，业务校验及未注册字段的写入限制不变。（2026-10-10）

两边对应字段均为单选、多选或自定义标签时，预览列出将追加至目标的源候选选项，确认时与记录一起保存。目标已有选项、顺序、颜色、类型及其他设置保留；追加选项带入源字段已设置的颜色。公开字段候选项随目标表共享，私有字段仅创建者及超级管理员可访问，创建者和超级管理员的字段维护权限继续生效；预览不写入目标记录或字段。普通表格字段合并后最多100项，商品档案共享单选最多50项，原单选、多选内容未配置或不符合目标限制时须先修正。文本字段不自动扩展选项。商品档案共享单选的新增项在预览标注「商品共享」，确认后对有权查看该表的用户生效，沿用商品编辑权限；只追加候选项，保留原选项与字段类型，仍只能保存一个值。共享选项、目标记录及相关布局在同一事务中保存，失败时全部回滚。（2026-10-09）

## 权限与用途

搜索框统一放在顶部导航栏，继续搜索当前表格；表格名称保留在页面。搜索框采用全站统一的暖色圆角样式，桌面端固定224px宽（125%缩放时约280像素）、28px高，聚焦时只显示一层柔和橙色边框；长内容及多行查询在框内滚动查看、编辑，不撑开导航栏，也不截断查询内容。窄屏按可用宽度收窄，框高不变。表格随可视区域高度展开，批量添加、分页和选区统计操作栏保持在可视区域底端，滚动表内内容时持续可见，窄屏按剩余高度调整。

所有内部角色均已补齐项目查看和创建权限，可使用新建表格；供应商角色不参与此次授权。查看列表和打开有权访问的表格需要项目查看权限，创建新表需要项目创建权限；录入、新增或删除行还须具有当前表格的可编辑权限，公开表默认仅查看，不能仅凭项目创建权限改动别人的表。所有有当前表格查看权限的用户，包括只读用户，可自行新增字段，默认仅创建者及超级管理员可见；新增字段不授予内容编辑或新增行权限。新建表格与选款登记采用独立的模块权限，能够使用表格不会自动获得选款登记查看或编辑权限。无需先创建一个流程项目。表内保护、抢占填表及内容自动隐藏继续限制具体内容访问和修改。

表格创建者及超级管理员可在「保护区域 → 内容自动隐藏」添加隐藏区域，选择单元格、整行、整列或明确选择当前工作表，保存至少一条区域后开启；普通编辑成员及普通管理员不能管理别人的表内保护。隐藏仅作用于所选区域内已填写内容，区域外照常显示，指定查看人适用于本表全部隐藏区域。关闭开关保留配置，删除最后一条区域自动关闭。升级前已开启整表自动隐藏的表格保留「原整表自动隐藏」区域，可编辑缩小范围或删除重建；详细步骤及失败处理见「选款登记 → 保护区域与多人填表」。（2026-10-10）

## 显示、公开范围与回收站

「内容范围」选择全部可访问、公共区域或我创建的；公共区域只显示公开表格，并显示创建者。顶部「我的工作台」集中显示本人创建的表格，可在那里切换公开范围，更新同一张表格。

列表上方「卡片 / 列表」切换显示，当前浏览器按账号记住选择。新表默认不公开，创建时可选择公开范围；已有表保留原先的公开范围。公开表允许系统内获准用户默认仅查看，编辑需明确授权，表内保护规则继续限制具体内容和编辑，不会公开到互联网。不公开时，仅创建者、超级管理员及明确授权的协作成员可访问；普通管理员不具有默认访问权。已明确设置禁止查看的用户，即使整表公开也不能访问。

创建者或超级管理员在表格卡片或列表的「⋯ → 成员权限」选择用户，点击「添加成员」，为每个成员选择「可编辑」「仅查看」或「禁止查看」，再「保存权限」。添加时默认仅查看，取消不写入。可编辑仅授权内容修改，不授予成员管理、公开范围设置或整表删除资格；禁止查看优先于整表公开范围。移除成员设置后恢复该账号的默认范围：公开表仅查看，不公开表不可访问，原内容保留。创建者和超级管理员固定可查看、编辑及管理，不能通过成员设置降低其权限。成员权限发生并发修改时保留本地草稿，点击「使用最新成员设置」核对后重新修改并保存；失败提示原因，可重试。整表公开范围与成员权限分开保存。

创建者或超级管理员通过「⋯」设置公开范围或「移至回收站」，普通编辑成员不能执行。确认删除后，整表记录、图片、手机拍图和外部收集链接立即停止访问。回收站显示本人创建的表格，超级管理员可管理全部，30 天内可恢复原数据、保护权限、公开范围、成员权限和仍有效的收集链接。服务器中的公开字段布局、私有字段及个人设置也保留。

达到 30 天即不可恢复，系统每小时检查并彻底清理表格的独立数据空间、记录、图片、收集表和令牌；文件存储故障自动重试。审计保留操作元信息，清除被删表格的原内容。单独发布的产品收集链接属于明确的外部分享授权，不受系统内公开开关影响；移至回收站会停用这些链接。

## 创建与再次打开

1. 打开「新建表格」，点击右上角「新建表格」。
2. 填写表格名称，最多 100 个字符，点击「创建空表」。创建成功后直接进入该表。
3. 新表初始化为零字段、零记录的空表，不预置文本字段或空白记录，也不复制选款登记或其他表的资料、图片、收集表、保护规则及个人布局。表头右侧「＋」添加字段，最后一行左侧「＋」添加记录；也可使用工具栏「添加一行」或底部批量添加按钮。字段和记录添加后使用与选款登记相同的边框、表头、列间距、默认超宽行高及编辑功能；左侧复选框列、行号列独立，显示行拖动手柄。刷新、再次打开和创建请求重试都不会自动补入字段或记录。
4. 点击顶部工作栏「返回表格列表」可查看已创建的表，正文不再重复显示返回入口。点击表名或「打开表格」再次进入，刷新后数据仍保留。

创建失败时留在名称窗口，检查提示后重试；同一次创建请求重试不会重复建立表格。没有创建按钮时，请管理员检查项目创建权限。表格不存在或账号无权访问时不会回退显示选款登记的数据。

已有表格保留原来的字段和记录，不会被重新初始化。旧版预置的文本字段和空白记录继续保留；新表的全部字段及记录由用户自行添加。左侧复选框可勾选记录，表头复选框选择全部可见行；点击或拖动行号仍可选择整行。行高可通过工具栏切换紧凑、标准、宽松或超宽，表头高度保持一致，修改公共行高需要本表编辑权限。仅查看账号可添加自己的私有字段，不能添加记录或编辑内容。

## 字段公开与布局同步（2026-10-09）

「仅本人」为私有字段的界面标签，普通用户只有创建者可查看和管理；超级管理员（SUPER_ADMIN）可查看、编辑和管理全部私有字段，包括公开或取消公开。普通管理员没有此例外，字段范围也不会给只读创建者授予内容编辑权限。

通过「字段管理 → 添加字段」或表头末尾「＋」，填写名称、类型及必要选项后保存。新字段显示「仅本人」标签，定义、已保存内容、格式和图片仅创建者及超级管理员可访问；只读用户也可创建并维护自己的字段定义，但录入、上传、清空等仍需项目创建权限及对应区域编辑权。

创建者或超级管理员在字段列表点击「公开」后，有本表查看权限的其他用户实时读取该字段及允许查看的已保存内容；点击「取消公开」后，除创建者及超级管理员外的其他用户立即不再显示该字段及内容，已有资料保留。范围开关处理中暂不可重复操作，失败提示原因，可重试。字段公开仅在当前表格的授权用户间生效，不会改变整表公开范围，也不向互联网开放。除超级管理员外的其他人不能修改自建字段的名称、类型、选项、功能、公开状态或删除；无创建者归属的原有业务字段由有本表编辑权限的用户维护。

公开字段定义、选项配色、公开列顺序及宽度、固定和隐藏状态、仅包含公开字段的字段分组、可选行分组及排序字段列表和表格行高共享，修改公共布局需要本表编辑权限。只读用户操作公共列宽、顺序、固定、隐藏、公共分组或行高时立即提示并保留原公共布局；私有字段布局仍可设置。私有列的布局和包含私有字段的分组仅本人使用。搜索、当前字段分组 TAB、个人筛选排序、当前行分组和排序选择、页码、页大小、统计、字段类型目录和跨表传送配置仍按本人账号及表格保存；是否跟随共享筛选也保留个人选择。

尚未建立公开布局的表格，有编辑权限的用户可点击一次「统一当前字段与布局」，以当前账号已有设置作为起点。初始化只纳入升级前该账号已有字段和已经公开字段，新创建的私有字段不会自动公开。设置冲突时保留当前草稿，可选「使用云端设置」或「保留当前设置」；保存失败可重试，不以默认配置覆盖云端资料。删除私有字段从创建者及超级管理员的字段列表移除；删除公开字段同步从所有用户的字段列表移除，服务器资料保留，无恢复入口，新建同名字段不取回原内容。

## 表内功能与独立性

有当前单元格编辑权限时，直接点击颜色、尺码或允许输入新标签的自定义标签文字，可在原标签位置修改这一项，按 Enter 或离开输入框提交并自动保存，按 Esc 取消当前未提交输入。只替换当前格的这一项，保留同格其他标签，不改字段候选项或其他记录。名称去除首尾空格后不能为空、不能包含 `/`，也不能与同格其他标签重名；原字数、数量及字段限制继续校验，尺码按原规则排序，无效名称不会替换原值。（2026-10-10）

选中颜色、尺码或允许自由新增且允许多选的自定义标签单元格后，未达数量上限时显示「+ 添加标签」。点击后直接在格内输入新标签，按 Enter 提交并继续输入下一项；修改已有标签后按 Enter，也可接着添加。新增输入为空时按 Enter 结束；离开输入框提交当前非空有效输入并结束，按 Esc 只取消当前未提交输入，前面已提交的标签保留。达到数量上限或字段不允许多选时不提供继续添加。移除标签仍可使用顶部编辑栏。（2026-10-10）

未允许输入新标签的标签字段，以及单选、多选字段，点击文字打开原选项列表，只能选择已配置值；需要更多标签时在允许多选的列表中追加候选项。顶部编辑栏仍可添加、移除标签。只读、受保护及已锁定的格不能修改，禁止查看的内容不显示标签文字。（2026-10-10）

修改绑定「颜色」字段且该颜色用于本行候选款图片时，同步更新这些图片的颜色标签，保留图片、数量、顺序及其他图片颜色；需要颜色与图片字段均可编辑，图片不可编辑时提示不能改名。洗唛/吊牌图、其他行及其他表格不变，仍保存到当前表格。并发保存失败时按提示核对最新资料后重试。（2026-10-10）

登记批次及日期类型字段在单元格内以无输入框边框、无默认底色的文字显示，沿用单元格颜色和对齐；只读时不能改写。可直接填写 `YYYY-MM-DD`，顶部编辑栏仍可使用日期选择器，空白显示「+ 日期」。此次样式调整不改变已保存日期及校验，也不清除用户设置的单元格填色。（2026-10-10）

网页表格按手动排序的最后一行填写任一内容并保存成功后，自动在末尾新增一行已保存的空白记录；无需填写全部字段，金额 `0`、图片及自定义字段内容均计入。批量粘贴只补一行，重复保存不重复追加。末尾已有空白行、仅调整格式或顺序、保存失败或保护规则不允许新增时不补行，已获准的原行编辑仍可保存。新表初始零记录及重新打开空表时不自动建行。搜索、筛选、排序和分页保持，新增空行可能被隐藏或在下一页；编辑位置不主动切换。（2026-10-09）

多人打开同一张表时，编辑者保存成功后，有本表查看权限的在线用户自动读取最新单元格、图片、格式及行增删；只读账号也会更新，无需手动刷新。更新按接收者的模块、字段范围和区域权限过滤，其他人的私有字段定义、内容、格式和图片均不发送，禁止查看的区域不发送真实内容；整表或模块查看权限撤销后清除已加载内容并停止同步。公开字段和布局随本表更新，个人搜索、当前 TAB、筛选及分页保留自己的选择。未保存的本地输入保留，其他行和字段继续同步；同一格并发修改时标红并暂停该行保存，先复制草稿，再刷新核对。隐藏页面及断网恢复后自动补取资料，实时连接不可用时定期检查更新。（2026-10-09）

已保存的单元格填色、字体颜色、水平及垂直对齐、数字格式随内容实时同步给有本表查看权限的用户，恢复默认格式也同步；上一笔保存处理中再恢复默认，清除操作继续保存，不会恢复上一笔格式。已建立共享公开布局时，公开列宽、固定列、表格行高及选项配色按本表共享。个人搜索、个人筛选、分页、选区统计显示及统计数字格式仍按本人账号及当前表格保存。普通用户不接收他人私有字段或禁止查看区域的格式。（2026-10-10）

新表与选款登记共用同一套表格组件，功能修正和更新同步生效，包括：单元格录入、自动保存、复制粘贴、拖选和填色、Shift 行列拖动、字段管理及字段类型设置、图片及轮播设置、手机扫码拍图、搜索、列筛选、分组排序、行高和格式、统计、Excel 导入导出、产品信息收集表及多人协作。

工具栏「导出 → 导出 Excel」导出勾选范围，未勾选时导出当前筛选范围。主表「表格资料」包含当前表格显示的全部字段，名称和顺序与表头一致，包括横向滚动后才能看到的列、自定义字段、系统字段及只读回填字段。已隐藏、已删除或无字段查看权限的列不导出；导出前重新读取已保存资料及字段布局、核验当前权限，禁止查看或自动隐藏的单元格只写入 `••••`，不输出真实内容。需要本表查看权限，存在未保存修改时先完成保存。导出会先等待字段设置保存完成；保存失败或冲突时提示「请先处理未保存或冲突的字段设置，再导出」，处理后再试。（2026-10-10）

可识别的空白草稿自动忽略，系统生成的创建、修改信息和格式不算填写，数值 `0`、图片及已填自定义字段均算内容；无法确认是否为空的受保护记录保留遮罩。没有可导出记录时提示「没有可导出的资料」，没有可导出列时提示「没有可导出的可见字段」，可核对字段显示及查看权限。缺少款号或存在同号多行仍可逐行导出。文本保留前导零，金额等数值使用原值，多选、标签及复选框导出可读文字；系统字段沿用人员、北京时间及编号显示设置。文件不包含单元格填色、对齐、字体颜色或布局样式。（2026-10-10）

「字段分组 → 添加分组」可填写最多40字的名称并选择多个字段，包含图片字段，同一字段可以属于多组。名称不能为空、不能重复或使用「全部字段」，每组至少一个字段；可修改或删除分组，点击「保存分组」生效，取消保留原配置。保存后表格上方显示快捷 TAB：有固定列时，选中组的非固定字段移到固定列右侧，其他字段继续显示，按原字段顺序排列且不重复；没有固定列时保持顺序，横向定位到本组第一个可见字段，再次点击 TAB 可重新定位。「全部字段」恢复原顺序，保留固定列。隐藏或删除的字段不参与快捷定位，重新显示隐藏字段后沿用分组；整组无可见字段时 TAB 不可点击，当前组返回「全部字段」。只含公开字段的分组需编辑权限，含本人私有字段的分组仅本人保存、只读账号也可配置；切换 TAB 清除单元格选区和复制虚线，不改记录，后续复制粘贴按显示的列顺序处理。此功能与按字段内容归组的行分组独立。

选择分组 TAB 后，该组所有可见字段的表头顶部显示暖橙色粗线，包括组内固定列，其他字段不标注；切换分组即时更新，点击「全部字段」清除。粗线随表头滚动，不改变表头行高。

「字段管理」中的「初始化字段类型」已移除，改为「字段类型管理」。管理窗口可搜索、启用或停用内置类型；「新增类型」填写1至40字的唯一名称并选择基础类型。单选、多选须填写默认候选项，每行一个，自定义标签可不填；最多100项，每项最多80字且不能含 `/`。保存后在添加或编辑字段的类型下拉框选择新名称，沿用基础类型的控件和校验，候选项带入字段后可独立调整和配色。名称不能与现有类型重复，取消不新增。

## 图片查找同款（2026-10-10）

本表网页及标准手机拍图页搜索框的相机图标「拍照或上传图片查找同款」打开查找窗口。有本表查看权限即可使用，只读成员也可查找；网页有未保存资料时先完成保存。点击「拍照查找」调用设备相机，或「上传图片查找」选择一张 JPG、PNG、WebP 静态图片。查询图仅用于本次查找，不保存为表格图片。

仅比较当前表内允许查看的「图片」字段，不查其他表、洗唛/吊牌图或自定义图片字段。仅显示图片综合视觉评分严格大于60%的候选，按评分从高到低显示最多3款；等于60%或低于门槛的候选不显示，没有达到门槛的候选时不显示款式。门槛针对综合视觉评分，各项比较因素不单独设60%的门槛。评分来自本系统的图片比较，不代表识别为同款的概率。请核对款号及图片再选：角度、背景和相似颜色可能误排，不同颜色的同款可能漏掉。网页选中后临时只显示该行，款号为空也可定位；原文字搜索及列筛选暂不作用但保留设置，编辑仍按原权限，工具栏 Excel 导出也限定位行。「清除图片查找」恢复原文字搜索及列筛选，输入文字也清除定位；仅当前用户使用，不发布共享筛选。手机选中后进入该款拍图，原搜索、款号缺失筛选及分页状态保留，查找和选择不修改表格资料或图片。自定义图片字段单款二维码页没有此入口。

普通点击候选卡片只选中查看，不累计学习反馈。核对无误后点「是同款并选择」，保存同款确认并进入该款；点「不是同款」保存否定反馈，按钮变为「已反馈不是同款」，本次不移除卡片，仍可查看或点「是同款并选择」纠正。每次完成查找形成独立查找会话，同一次查找对同一候选的重复反馈不增加确认次数，正负纠正替换该次原反馈；不同查找会话的有效确认可累计。

一次同款确认即可成为本表后续查找的参考案例。仅参考当前表近期有效、关联图片仍可查看且未变化的反馈；相近查询图片的确认可合并参考。对同一款在不同查找会话累计至少两次一致确认、相近案例没有矛盾的否定反馈，且本次比较评分至少98%时，如有其他达标候选还须领先第二名至少2个百分点，才仅显示1款。其他情况仍严格按综合视觉评分大于60%的门槛显示最多3款。否定反馈会使该款的相近案例停止参与学习加分及仅显示1款的判断，原有图片比较继续进行，因此后续仍可能出现该款。

反馈只在当前表格保存图片比较特征和确认记录，不保存查询原图，不跨表共享学习案例；关闭窗口不撤销已保存反馈。这是本表案例学习，不训练通用识别模型，也不保证不同背景、姿态或颜色的图片都能正确识别，即使仅显示1款仍需人工核对。只读成员可对允许查看的候选反馈，不因此获得表格资料或图片编辑权限。

选择或反馈前再次核验图片及查看权限，候选图片变化或不再可查看时清除候选并提示重新查找；反馈过期时重新查找后再确认。关闭窗口清除本次查询图及结果，页面不再接收本次结果。外链或暂时无法读取的图片跳过并显示数量，可在本表上传款式图后重试；无相似候选可换图。格式无效、无法解码或超过1600万像素时，换完整静态图或缩小尺寸，查询图须压缩至500 KB以下。本表可查看款式图片超过2,000张时不截取部分图片搜索，按提示拆分表格后再试。系统繁忙或约24秒超时可稍后「重新查找」或换较小图，超时不返回部分结果。
