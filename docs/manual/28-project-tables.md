# 新建表格

更新日期：2026-10-01。入口：项目管理 → 新建表格。

## 权限与用途

需要选款登记查看权限才能查看表格列表和打开表格；需要选款登记编辑权限才能创建表格、录入或删除行。无需先创建一个流程项目。表格对具有选款登记查看权限的内部用户开放，管理员可在每张表内配置保护区域、指定用户的查看和编辑权限、抢占填表及内容自动隐藏。流程项目及其任务表仍使用原有权限。

## 创建与再次打开

1. 打开「新建表格」，点击右上角「新建表格」。
2. 填写表格名称，最多 100 个字符，点击「创建空表」。创建成功后直接进入该表。
3. 新表包含选款登记的默认字段，没有任何数据行；不会复制选款登记或其他表的记录、图片、收集表、保护规则和字段配置。点击「添加一行」或底部批量添加按钮开始录入，空白行和修改内容自动保存。
4. 点击「返回表格列表」可查看已创建的表。点击表名或「打开表格」再次进入，刷新后数据仍保留。

创建失败时留在名称窗口，检查提示后重试；同一次创建请求重试不会重复建立表格。没有创建按钮时，请管理员检查选款登记编辑权限。表格不存在或账号无权访问时不会回退显示选款登记的数据。

## 表内功能与独立性

新表复用选款登记的完整表格功能：单元格录入、自动保存、复制粘贴、拖选和填色、Shift 行列拖动、字段管理及字段类型设置、图片及轮播设置、手机扫码拍图、搜索、列筛选、分组排序、行高和格式、统计、Excel 导入导出、产品信息收集表及多人协作。操作细节见「选款登记」章节。

各表的数据、款号重复检查、图片、收集表、共享列筛选及排序、在线协作状态、保护规则和认领状态相互独立。同一个序缇款号可以在不同表中使用，同一张表内不能新增重复款号。手机二维码携带所属表格信息，换款和上传继续保存在该表；外部收集表根据分享令牌访问其所属表格。

字段名称、类型、删除/隐藏状态、列宽、个人分组排序字段配置和每页行数继续保存在当前浏览器，按表格分别保存；更换浏览器或设备不会自动同步这些本机设置。服务器数据和保护权限不会因此丢失。字段删除保留原有数据，可以在字段管理中恢复。

新表沿用选款登记的数据格式和业务校验；不自动创建商品、库存、订单或流程项目。目前表格列表提供新建和打开，不提供整表删除或重命名。
