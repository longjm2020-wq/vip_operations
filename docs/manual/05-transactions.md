# 库存流水

更新日期：2026-10-03。入口：ERP系统 → 库存流水，或运营中心 → 唯品会 → 库存明细的 SKU 行「库存流水」。

## 操作步骤

1. 打开库存流水，查找目标 SKU、仓库和相关记录。
2. 核对变动数量、来源、操作者和时间；展开记录查看页面提供的详细字段。
3. 如需留档，可导出当前页数据。记录较多时需分别查看后续页。

## 使用规则

历史流水只读，不可直接修改。发现数量问题时先核对原业务单据；需要纠正库存时由有权限人员进行有原因、可追溯的调整，不删除历史记录。查询不到预期流水时检查原单据是否已过账，以及所选仓库和 SKU 是否正确。

采购正式入库、原到货入库、调拨出库、调拨入库、库存调整和盘点调整分别显示来源类型。包裹送达或合格暂存不修改在仓数量，不产生仓库增减流水；正式入库才产生采购或调拨入库流水。调拨发货先产生源仓负数流水，目标仓入库再产生正数流水，不能把在途数当作两边都有货。
