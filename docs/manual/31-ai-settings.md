# AI 模型设置

更新日期：2026-10-02。入口：系统设置 → AI 模型设置。仅同时具有超级管理员角色和经营分析导入与邮件配置权限的账号可访问；普通管理员不能读取或修改配置。

## 配置与验证

1. 固定使用 `openai/gpt-6.1-sol` 与 OpenRouter 官方 API；不能在页面更换地址。供应商由 OpenRouter 在该模型下路由。
2. 在页面填入 OpenRouter API Key，开启「AI 经营分析」。密钥在服务器使用 `COMPASS_MAIL_KEY` 加密保存，不回显，不写入审计明文。已配置时留空保留原密钥。
3. 点击「保存并验证模型」。先保存设置，再调用少量测试内容验证模型连接；测试会产生 API 费用。重复验证至少间隔一分钟。更换密钥后必须重新验证。
4. 显示「模型连接已验证」后，可以在运营中心的经营分析页面生成分析。每份最多4096个输出 token（包含推理），同一批数据复用已有分析。实际计费可通过页面 OpenRouter 链接查看。

开启后将经营汇总、趋势与三个维度 TOP10 商品编码发送给 OpenRouter 和模型供应商。原始 Excel、邮箱、图片和 ERP 凭据不发送。此配置对系统的经营分析和每日邮件共同生效，不是个人模型偏好。

「清除密钥」经确认后清除连接并关闭 AI；每日邮件仍可提供报表汇总，明确标注 AI 状态。邮件的 SMTP 设置独立配置。

## 常见问题

仅配置好密钥不等于模型已验证；验证失败请检查授权、余额及模型供应商可用性，不会自动改用其他模型。服务器加密配置未准备好时不能保存密钥，请管理员检查 API 与 Worker 的部署配置。密钥不要放在聊天、协作表格、截图或使用手册中。

普通管理员或其他角色直接访问页面/API 时会被拒绝；无权限账号也不会收到此手册章节。已有的有效模型连接不会因入口移动而被清除。
