# AI 模型管理

更新日期：2026-11-08。入口：系统设置 → AI 模型管理（`/settings/ai`）。仅同时具有超级管理员角色和经营分析管理权限的账号可访问及修改配置。

## 全站功能列表

列表登记小序对话、公开搜索、网站识别、电脑识屏、图像创作、原有团队、DeerFlow 团队、经营分析、商品资料生成、AIGC、语音、输入框麦克风听写和本地 OCR。每行显示功能、直达入口、当前模型或路由规则、能力边界、API 来源、接通状态及 Token / 积分 / 金额。

可搜索功能、型号或来源，按分类筛选，并选择近 24 小时、7 天、30 天、90 天或全部已记录用量。「刷新」重新读取真实配置；服务器短时缓存模型目录，目录列出不代表本账号密钥已获授权。

点击「直达」进入对应功能；小序入口会打开对应面板。打开语音设置不会启动麦克风或创建通话。

## 切换模型

1. 在目标行下拉框选择型号，保存成功后作用于后续请求。「系统默认」「跟随本次对话」「按任务自动选型」恢复对应的默认策略。
2. 小序对话及共享的 OpenRouter 文字推理目录只保留支持文字和图片输入、文字回复及工具调用的多模态模型；纯文本或能力信息不足的新增型号不会进入可选列表。商品资料还需要结构化输出；批处理和异步模式不能用于同步对话。旧配置中的型号不再符合要求时，管理页提示不可用，调用前要求重新选择，不自动换型号重试。图像、视频与实时语音仍使用各自的专用目录或配置。
3. 单次对话手动选择优先于管理页默认。原有团队依次采用：本次任务指定 → 成员指定 → 管理页默认 → 自动匹配。DeerFlow 使用独立默认值，不继承原有团队的固定型号。搜索及网站识别未单独指定时跟随本次对话。
4. AIGC 脚本、图片、视频可选择已配置线路的默认型号，约 10 秒刷新到创作服务。新项目采用新默认值；已有项目明确选择和任务保存的型号继续生效。官方 xAI、星火线路仍仅限超级管理员，普通账号使用获准公共线路。
5. 实时通话、分段语音和麦克风听写通过「切换 / 配置」打开专用设置。听写与分段语音共用识别模型及音频连接，修改后两处的新请求均生效。选择「千问 · 北京」时，识别为 `qwen3.8-omni-flash`，朗读为 `qwen3-tts-flash`，管理页分别显示实际型号；实时通话保留独立配置。本地 OCR 不提供远端模型切换。

多人同时修改同一功能时，旧版本保存会提示刷新核对，避免覆盖。切换默认值不等于验证成功，也不修改正在进行的通话。

聊天模型菜单只显示已接通的多模态型号：共享连接须启用、密钥和加密配置齐全且验证通过，并且该型号在当前连接配置更新后的最近一次调用已收到可核对型号的成功回执。没有调用记录、最近调用失败或响应型号未核实的型号不显示；更换或重新保存连接后需重新验证。独立音频、AIGC 或其他线路的成功记录不用于证明共享聊天连接可用。刷新列表只读取记录，不自动发起收费测试。

管理员仍可在本页配置目录中选择待接通型号，以完成连接配置和验证；配置目录与聊天菜单的用途不同。旧选择不再接通时，聊天保留草稿并提示重新选择；没有已接通模型时显示空状态，暂停普通文字发送。不会自动改用其他型号。

## API 来源及连接配置

小序、原有团队、DeerFlow 网站模型网关、经营分析、商品资料和小序图像创作通过 `https://openrouter.ai/api/v1`。OpenRouter 是聚合路由服务；型号名称不表示本站分别持有 OpenAI、Google 等厂商直连密钥。

实时语音使用独立 OpenAI、阿里云百炼或火山引擎通道；麦克风听写、分段语音与朗读可使用千问北京业务空间或 OpenRouter 音频连接。千问设置可在服务器内复制已保存的千问实时语音密钥与业务空间，复制后独立保存，不改变实时通话配置或供应商计费开关。切换服务保留另一服务的配置；清除密钥仅清除当前音频服务并停用分段语音与听写。听写由网站服务器转发录音，只返回可编辑草稿。AIGC 按实际线路显示来源，包括 OpenRouter、配置的第三方中转、xAI 官方、RunningHub 和 OpenTalking 网关。中转站自定义型号不作为其官方上游型号认证。

**千问音频验证（2026-11-08）**：保存后点击「验证并试听」，先用语音合成模型生成一句短语音，再用指定识别模型转写；两次请求均成功后才显示连接已验证。不采集麦克风，测试按供应商实际用量计费。型号、密钥、业务空间或音色变化后需重新验证。验证失败不自动更换模型或关闭供应商费用保护，麦克风录音需在实际使用时核对。

页面右上角的「连接配置」打开简洁的 OpenRouter 连接弹窗，只保留 API Key、启用开关、连接状态、保存验证和清除密钥。各功能的模型继续在主列表选择，弹窗不重复展示模型。

密钥由服务器使用 `COMPASS_MAIL_KEY` 加密保存，不回显，留空保留原值。启用连接后点击「保存并验证」，使用当前经营分析模型及少量测试内容，会产生 API 用量，重复验证至少间隔一分钟。关闭连接时按钮改为「保存」，不再发起验证调用。更换密钥需重新验证。「清除密钥」确认后关闭依赖共享连接的功能；日报仍可发送报表汇总，独立语音和 AIGC 媒体凭据另行维护。数据发送范围及计费说明见本章下文。

AIGC 行的「连接配置」可维护编译、图像、视频及增强渠道 Key、RunningHub 工作流、数字人网关；仍需 AIGC 使用和管理权限。运行任务及已有数字人资源继续遵守原服务的配置限制。

## 接通状态

- 已配置或密钥已保存：存在连接信息，当前型号尚未证实调用成功。
- 最近调用成功：服务器收到了匹配型号的响应，不保证后续余额、限流或服务始终正常。
- 语音连接已验证：专用通道验证通过，不代表麦克风、扬声器和实际通话均已测试。
- 未配置、已关闭、型号不可用：按具体原因处理；错误不回显密钥或供应商敏感原文。

## 实际消耗与统计覆盖

统一计量自页面显示的启用时间开始，仅补录已有供应商回执的经营分析历史，不补造缺失记录。所选期间内的型号切换、测试、重试和失败请求已返回的消耗均保留。子调用归到对应搜索、图像、语音或视频功能，主对话数字并非整个团队任务的总费用。

Token、积分和金额只采用服务器收到的供应商回执，不以模型标价、估算或客户端自报数据冒充账单。OpenRouter 的 `usage.cost` 显示为 **OpenRouter credits**；供应商积分按来源分开统计；明确以美元微单位返回的实际费用换算为 USD。不同单位分别列出，不直接相加或估算成人民币。重复供应商回执只计一次消耗；异步任务最终账单更新同一任务记录。

「未知」代表未返回、未记录或无法读取，不等于免费。请求数为零显示「暂无调用记录」。已显示数字可能仅覆盖部分请求，可在「查看明细说明」检查输入、输出、无回执数量及最近实际型号。供应商最终账单为准。[OpenRouter 用量回执说明](https://openrouter.ai/docs/cookbook/administration/usage-accounting)

WebRTC 音频直连供应商，本站无法取得完整的服务器计费回执，对应 Token / 额度 / 费用可能未知；不能采信浏览器自报账单。麦克风听写的供应商回执独立计入「输入框麦克风听写」，不重复计入分段语音；旧版本浏览器听写的历史用量未知。千问朗读按供应商回执另外显示「合成输入字符」，字符数不换算成 Token、积分或金额；供应商没有返回的费用仍为未知，未回传型号也不计入「已确认型号成功」。本地 Tesseract.js OCR 不调用收费模型 API，本站模型 API 费用为 0。

## 数据与故障处理

经营分析发送报表汇总与商品编码，商品资料生成发送有权查看的成分、类目和图片；小序发送消息、最近对话、主动附件及按权限查询的数据，日程和个人记忆须开启对应选项才附带。公开搜索只发送必要检索词，网站名称识别只发送名称，不因此读取已登录浏览器。电脑画面只在执行已授权任务时发送。标题与标准建议仍需人工核对。

计量表仅保存功能、型号、来源域名、请求编号、用量和安全错误代码，不保存提示词、原始音视频、密钥或供应商错误全文。加密配置未就绪、密钥权限不足、余额不足或型号下架时请核对对应连接。API 与 Worker 必须共用数据库和凭据配置。

后续新增或修改任何 AI 模型调用功能，都必须在同一版本更新本列表、实际路由、能力边界、来源、状态、计量覆盖和相关手册；此规则已写入项目 `AGENTS.md`。
