# AI 模型管理

更新日期：2026-11-08。入口：系统设置 → AI 模型管理（`/settings/ai`）。仅同时具有超级管理员角色和经营分析管理权限的账号可访问及修改配置。

## 全站功能列表

列表登记小序对话、公开搜索、网站识别、电脑识屏、图像创作、原有团队、DeerFlow 团队、经营分析、商品资料生成、AIGC、语音、浏览器听写和本地 OCR。每行显示功能、直达入口、当前模型或路由规则、能力边界、API 来源、接通状态及 Token / 积分 / 金额。

可搜索功能、型号或来源，按分类筛选，并选择近 24 小时、7 天、30 天、90 天或全部已记录用量。「刷新」重新读取真实配置；服务器短时缓存模型目录，目录列出不代表本账号密钥已获授权。

点击「直达」进入对应功能；小序入口会打开对应面板。打开语音设置不会启动麦克风或创建通话。

## 切换模型

1. 在目标行下拉框选择型号，保存成功后作用于后续请求。「系统默认」「跟随本次对话」「按任务自动选型」恢复对应的默认策略。
2. 只提供协议和能力适用的选项。商品资料需要图片输入和结构化输出；电脑识屏需要图片；团队文字执行需要工具调用，批处理和异步模式不能用于同步对话。固定型号不可用时提示重新选择，不自动换型号重试。
3. 单次对话手动选择优先于管理页默认。原有团队依次采用：本次任务指定 → 成员指定 → 管理页默认 → 自动匹配。DeerFlow 使用独立默认值，不继承原有团队的固定型号。搜索及网站识别未单独指定时跟随本次对话。
4. AIGC 脚本、图片、视频可选择已配置线路的默认型号，约 10 秒刷新到创作服务。新项目采用新默认值；已有项目明确选择和任务保存的型号继续生效。官方 xAI、星火线路仍仅限超级管理员，普通账号使用获准公共线路。
5. 实时通话和分段语音通过「切换 / 配置」打开专用设置，保留各自的密钥、声音、费用保护和验证流程。浏览器听写和本地 OCR 不提供远端模型切换。

多人同时修改同一功能时，旧版本保存会提示刷新核对，避免覆盖。切换默认值不等于验证成功，也不修改正在进行的通话。

## API 来源及连接配置

小序、原有团队、DeerFlow 网站模型网关、经营分析、商品资料和小序图像创作通过 `https://openrouter.ai/api/v1`。OpenRouter 是聚合路由服务；型号名称不表示本站分别持有 OpenAI、Google 等厂商直连密钥。

实时语音使用独立 OpenAI、阿里云百炼或火山引擎通道；分段语音与朗读使用独立 OpenRouter 音频密钥。AIGC 按实际线路显示来源，包括 OpenRouter、配置的第三方中转、xAI 官方、RunningHub 和 OpenTalking 网关。中转站自定义型号不作为其官方上游型号认证。

「连接配置」维护共享 OpenRouter Key。密钥由服务器使用 `COMPASS_MAIL_KEY` 加密保存，不回显，留空保留原值。开启服务后点击「保存并验证连接」，使用当前经营分析模型及少量测试内容，会产生 API 用量，重复验证至少间隔一分钟。更换密钥需重新验证。「清除密钥」确认后关闭依赖共享连接的功能；日报仍可发送报表汇总，独立语音和 AIGC 媒体凭据另行维护。

AIGC 行的「连接配置」可维护编译、图像、视频及增强渠道 Key、RunningHub 工作流、数字人网关；仍需 AIGC 使用和管理权限。运行任务及已有数字人资源继续遵守原服务的配置限制。

## 接通状态

- 已配置或密钥已保存：存在连接信息，当前型号尚未证实调用成功。
- 最近调用成功：服务器收到了匹配型号的响应，不保证后续余额、限流或服务始终正常。
- 语音连接已验证：专用通道验证通过，不代表麦克风、扬声器和实际通话均已测试。
- 未配置、已关闭、型号不可用：按具体原因处理；错误不回显密钥或供应商敏感原文。

## 实际消耗与统计覆盖

统一计量自页面显示的启用时间开始，仅补录已有供应商回执的经营分析历史，不补造缺失记录。所选期间内的型号切换、测试、重试和失败请求已返回的消耗均保留。子调用归到对应搜索、图像、语音或视频功能，主对话数字并非整个团队任务的总费用。

Token、积分和金额只采用服务器收到的供应商回执，不以模型标价、估算或客户端自报数据冒充账单。OpenRouter 的 `usage.cost` 显示为 **OpenRouter credits**；供应商积分按来源分开统计；明确以美元微单位返回的实际费用换算为 USD。不同单位分别列出，不直接相加或估算成人民币。重复供应商回执只计一次消耗；异步任务最终账单更新同一任务记录。

「未知」代表未返回、未记录或无法读取，不等于免费。请求数为零显示「暂无调用记录」。已显示数字可能仅覆盖部分请求，可在「查看明细说明」检查输入、输出、无回执数量及最近实际型号。供应商最终账单为准。[OpenRouter 用量回执说明](https://openrouter.ai/docs/cookbook/administration/usage-accounting)

WebRTC 音频直连供应商，本站无法取得完整的服务器计费回执，对应 Token / 额度 / 费用可能未知；不能采信浏览器自报账单。浏览器听写没有本站可读取的用量接口。本地 Tesseract.js OCR 不调用收费模型 API，本站模型 API 费用为 0。

## 数据与故障处理

经营分析发送报表汇总与商品编码，商品资料生成发送有权查看的成分、类目和图片；小序发送消息、最近对话、主动附件及按权限查询的数据，日程和个人记忆须开启对应选项才附带。公开搜索只发送必要检索词，网站名称识别只发送名称，不因此读取已登录浏览器。电脑画面只在执行已授权任务时发送。标题与标准建议仍需人工核对。

计量表仅保存功能、型号、来源域名、请求编号、用量和安全错误代码，不保存提示词、原始音视频、密钥或供应商错误全文。加密配置未就绪、密钥权限不足、余额不足或型号下架时请核对对应连接。API 与 Worker 必须共用数据库和凭据配置。

后续新增或修改任何 AI 模型调用功能，都必须在同一版本更新本列表、实际路由、能力边界、来源、状态、计量覆盖和相关手册；此规则已写入项目 `AGENTS.md`。
