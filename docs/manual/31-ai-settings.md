# AI 模型管理

更新日期为 2026-11-27。在系统设置中打开「AI 模型管理」（`/settings/ai`）。仅同时具有超级管理员角色和经营分析管理权限的账号可访问及修改配置。

## 智选模型与算力中转站（2026-11-23）

入口：本页顶部「智选模型」按钮，或在「AgentAI 连接」内点击「智选策略与中转站」。

1. **接入算力中转站**：输入中转站链接（仅接受公开网络且不含凭据的 HTTPS 地址）与 API Key，选择自动识别或指定 AgentAI 计费协议 / OpenAI 兼容协议后点击「接入并智能解析」。密钥在服务器使用 `COMPASS_MAIL_KEY` 加密保存，不回显。
2. **自动分类与 4 维度评估**：同步目录后自动将模型划分为「聊天」「图片」「视频」「音频」「其他」五类，并联合 AgentAI 渠道表现、OpenRouter、百炼及近 7 天本站实际调用回执（`ai_model_usage`），从**稳定、价格、速度、质量**四个维度计算 0～100 综合分。未提供实测数据时如实标为「估测」或「待实测」，不把估测或目录列出冒充实测成功。
3. **自动屏蔽过滤与人工干预**：默认屏蔽停用渠道、24h 实测成功率低于阈值（默认 85%）、平均耗时超过分类上限、同模型相对中位价溢价过高（默认超过 2.5 倍）、本站连续失败（默认 2 次）或综合评分低于门槛（默认 60 分）的低分渠道与模型。「AgentAI 连接」展开各型号渠道列表时默认折叠已屏蔽渠道，可随时点击「查看已屏蔽渠道」核对原因，也可手动置顶、解除屏蔽或屏蔽单个渠道。
4. **按智能体用途自动分配**：
   - **编排与审查智能体**：默认质量与能力优先，优选强推理与稳定渠道（如主智能体、验收协调与复杂规划）。
   - **执行与检索智能体**：默认极速低成本优先，优选响应快、价格低的轻量渠道。
   - **图像生成与设计智能体**：默认质量优先，优先匹配最新高质量图像模型（如 ChatGPT Image 2.6、Google Nano Banana 2.1 等）。
   - **视频与音频制作**：按四维均衡优选可用渠道并屏蔽低分渠道。
   - 点击「一键应用智选方案到全站功能」可将已验证且满足能力边界的最优默认型号写入全站对应功能；未通过测速或能力验证的模型不会强制应用。
5. **中转站模型测速验证**：新接入中转站的聊天模型需点击「测速验证」发送一次轻量回显校验，产生少量实际用量并在服务器记录真实耗时与成功状态后，才可作为已验证模型进入小序对话与 AI 员工自动路由池。

## 全站功能列表

「商品标题与描述」共用于商品档案、选款登记和项目协作表格。每批最多10款，通过已启用且已验证的共享 OpenRouter 连接，调用该功能配置的多模态结构化模型。批内逐款校验并返回合格候选与跳过原因。每个有可生成款式的批次调用模型一次，跳过的款式可由用户单独重试。实际用量统一计入本功能，供应商未返回的费用或用量显示未知。（2026-11-24）

「工作台 AI 员工」的派单与执行简报合并为一次工作模型请求。普通单项文字任务经过派单、员工执行和独立验收，系统直接保存并展示已验收正文。缺少必需资料时可在原任务补充，已用次数继续累计。文件工具、多项交付、公开搜索和返工按实际调用记录。归档与结果展示由系统完成。

员工任务每个后台工作进程默认并行 6 单，文档、图像和视频任务各有独立处理名额。并行请求仍按员工配置及本页默认路由选择模型和连接。用量按供应商返回的每次请求回执记入对应功能，排队等待不产生模型请求。供应商的限流和额度仍适用。

「工作台 AI 员工」独立登记工作模型、默认路由与实际对话用量，直达工作台右栏员工窗口。员工保存的固定／候选／主备策略优先；自动模式跟随本行默认配置。固定策略不自动替换型号，限定候选和主备仅在允许范围内处理已知访问、额度错误；媒体提交结果不明时不重新生成。员工图像用量归小序图像，搜索归公开检索，视频归 AIGC 视频；本行不是整个任务的费用合计。员工配置目录列出与保存不构成调用验证，未知费用仍显示未知。岗位 SKILL.md 随新任务保存为技能快照，执行沿用最多 4000 字符的限制；内置十份模板均可完整带入。批量配齐、导入和保存技能本身不调用模型，不扩展工具或数据权限，不改变已提交任务的快照。具体入口见「AI 员工工作台」。（2026-11-16）

列表登记小序对话、公开搜索、网站识别、电脑识屏、独立浏览器、图像创作、工作台 AI 员工、经营分析、商品资料生成、AIGC、语音、输入框麦克风听写和本地 OCR。每行显示功能、直达入口、当前模型或路由规则、能力边界、API 来源、接通状态及 Token / 积分 / 金额。

可搜索功能、型号或来源，按分类筛选，并选择近 24 小时、7 天、30 天、90 天或全部已记录用量。「刷新」重新读取真实配置；服务器短时缓存模型目录，目录列出不代表本账号密钥已获授权。

点击「直达」进入对应功能；小序入口会打开对应面板。打开语音设置不会启动麦克风或创建通话。

公司知识库的绘图、读写与文字检索都在应用内执行，不单独调用模型。获授权 AI 员工执行任务时，相关笔记片段会进入既有工作模型请求；实际用量仍记录在「工作台 AI 员工」等原有调用项中。

员工同时具备公开搜索能力且任务匹配内部笔记时，会先处理公开搜索，再将内部段落交给工作模型。分开处理可能增加一次工作模型请求，沿用该任务的调用上限和模型计量。

## 切换模型

1. 在目标行下拉框选择型号，保存成功后作用于后续请求。「系统默认」「跟随本次对话」「按任务自动选型」恢复对应的默认策略。
2. 共享 OpenRouter 文字推理目录只保留支持文字和图片输入、文字回复及工具调用的多模态模型；该目录的纯文本或能力信息不足型号不会进入可选列表。AgentAI 按下文独立验证能力，可开放纯文字聊天。商品资料还需要结构化输出；批处理和异步模式不能用于同步对话。旧配置中的型号不再符合要求时，管理页提示不可用。图像、视频与实时语音使用各自的专用目录或配置。
3. 单次对话手动选择优先于管理页默认。员工的「自动匹配」读取工作台 AI 员工的默认配置。指定型号或限定候选时按员工配置执行。文字对话自动触发的公开搜索使用「小序公开网页检索」的 OpenRouter 型号，未指定时使用该功能的默认型号。网站识别单独配置；未指定时，OpenRouter 对话沿用本次对话型号，百炼或 AgentAI 对话使用网站识别的默认型号。
4. AIGC 脚本、图片可选择已配置线路的默认型号，约 10 秒刷新到创作服务。「AIGC 视频生成」提供百炼北京 `MiniMax/MiniMax-H3` 及已适配的 AgentAI 图片参考视频型号；已提交任务保留原路由。H3 连接可复用已保存的百炼语音密钥，但须另有 H3 模型权限。百炼视频连接测试会创建一条收费的 4 秒视频，确认前显示费用说明。AgentAI 目录连接验证不会生成视频。
5. 实时通话、分段语音和麦克风听写通过「切换 / 配置」打开专用设置。听写与分段语音共用识别模型及音频连接，修改后两处的新请求均生效。选择「千问 · 北京」时，识别为 `qwen3.8-omni-flash`，朗读为 `qwen3-tts-flash`，管理页分别显示实际型号；实时通话保留独立配置。本地 OCR 不提供远端模型切换。

AIGC 连接抽屉按用途折叠分组，默认展开视频生成。图片、增强与工作流、脚本、数字人和历史视频连接可分别展开，底部统一保存。每个分组显示已保存密钥状态，H3 另显示真实生成验证状态；旧渠道凭据保留供历史任务查询，不会重新进入新视频下拉框。

多人同时修改同一功能时，旧版本保存会提示刷新核对，避免覆盖。切换默认值不等于验证成功，也不修改正在进行的通话。

聊天模型菜单只显示当前连接已接通的型号。OpenRouter 和百炼沿用多模态目录；AgentAI 可验证纯文字聊天，图片输入则需要其目录声明支持。连接须启用、密钥和加密配置齐全，并且该型号在当前配置更新后的最近一次调用已收到可核对型号的成功回执。没有调用记录、最近调用失败或响应型号未核实的型号不显示；更换或重新保存连接后需重新验证。其他来源或媒体任务的成功记录不能代替聊天验证。刷新列表只读取记录，不自动发起收费测试。

管理员仍可在本页配置目录中选择待接通型号，以完成连接配置和验证；配置目录与聊天菜单的用途不同。OpenRouter 或百炼默认及已选型号未接通时，小序聊天保留已有自动改用策略：改用一个已接通且支持识图的原线路型号并显示原因；没有已接通模型时暂停发送。认证、权限或额度类错误可按原规则重试一次，内容类错误不换型号。显式选择 AgentAI 的任务不采用跨来源回退，失效时提示验证或重新选择。不会调用已关闭或未验证的连接，也不自动充值或关闭费用保护。

## API 来源及连接配置

小序及 AI 员工 可使用 OpenRouter 或已适配的独立 AgentAI 连接；小序另支持百炼聊天。经营分析、商品资料和小序图像创作仍通过 `https://openrouter.ai/api/v1`。聚合平台显示的型号名称不表示本站分别持有其上游厂商直连密钥。

实时语音使用独立 OpenAI、阿里云百炼或火山引擎通道；麦克风听写、分段语音与朗读可使用千问北京业务空间或 OpenRouter 音频连接。千问设置可在服务器内复制已保存的千问实时语音密钥与业务空间，复制后独立保存，不改变实时通话配置或供应商计费开关。切换服务保留另一服务的配置；清除密钥仅清除当前音频服务并停用分段语音与听写。听写由网站服务器转发录音，只返回可编辑草稿。AIGC 按实际线路显示来源，包括 OpenRouter、配置的第三方中转、xAI 官方、RunningHub 和 OpenTalking 网关。中转站自定义型号不作为其官方上游型号认证。

**千问音频验证（2026-11-08）**：保存后点击「验证并试听」，先用语音合成模型生成一句短语音，再用指定识别模型转写；两次请求均成功后才显示连接已验证。不采集麦克风，测试按供应商实际用量计费。型号、密钥、业务空间或音色变化后需重新验证。验证失败不自动更换模型或关闭供应商费用保护，麦克风录音需在实际使用时核对。

页面右上角的「连接配置」打开简洁的 OpenRouter 连接弹窗，只保留 API Key、启用开关、连接状态、保存验证和清除密钥。各功能的模型继续在主列表选择，弹窗不重复展示模型。

密钥由服务器使用 `COMPASS_MAIL_KEY` 加密保存，不回显，留空保留原值。启用连接后点击「保存并验证」，使用当前经营分析模型及少量测试内容，会产生 API 用量，重复验证至少间隔一分钟。关闭连接时按钮改为「保存」，不再发起验证调用。更换密钥需重新验证。「清除密钥」确认后关闭依赖共享连接的功能；日报仍可发送报表汇总，独立语音和 AIGC 媒体凭据另行维护。数据发送范围及计费说明见本章下文。

AIGC 行的「连接配置」可维护编译、图像、视频及增强渠道 Key、RunningHub 工作流、数字人网关；仍需 AIGC 使用和管理权限。运行任务及已有数字人资源继续遵守原服务的配置限制。

### 价格与渠道

「同步模型目录」同时读取账号实付价格；「同步价格」可单独更新，价格至少缓存 5 分钟并使用供应商 ETag。价格读取失败仅显示价格提示，不将已连接的目录改为验证失败，也不会将未知价格记为零。更换或重新保存连接后旧价格失效。

聊天展示输入、输出的每百万 Token 单价范围；其他型号展示供应商默认参数的整单参考价。展开型号查看各渠道的计费方式、输入输出单价、默认参数整单价及近 24 小时表现。一个型号不同渠道可能按 Token、按次或按秒计费，不能仅按“图片／视频／音频”分类推断费率，也不能把整单价直接标成每秒或每字符价格。实际生成前仍须按所选时长、清晰度、档位及素材获取本次报价。

仅标明实时来源的统计展示为近 24 小时实测成功率和平均耗时；估测来源明确标为估测，不将默认 95% 或 0 秒当作实测。价目含账号代理加价，按账号私有保存，不公开到共享缓存。价格同步时间与供应商价目时间分别记录。

聊天与媒体使用 `balanced` 智能调度，综合成功率、延迟和价格选择可用渠道，交由平台处理故障回退。新任务不锁定单条渠道。报价显示备用渠道费用上界；供应商要求按明显不同的新价重做时，网站不自动接受或重复收费提交。同一型号的不同 Seedance 版本仍是不同型号，不跨版本偷偷替换。

聊天型号逐个提供「验证聊天」「验证工具」「验证结构化」。每项发送一次少量测试内容，会产生供应商实际用量；只有返回准确型号、可核对调用回执及该项要求的结果才标记成功。验证按型号声明支持的低推理档执行，GM-4 的 `thinking_budget` 与其他型号的推理字段分别处理；普通任务保留其原推理参数。单次验证最多等待90秒，超时提示核对供应商调用日志，不自动重试或标记成功。聊天验证通过后可在小序中选择；纯文字型号显示「仅文字」，图片请求须另选支持图片输入的型号。未验证工具的型号只回复文字，不执行工具。AI 员工 要求工具和结构化验证均通过，还按任务检查图片等能力。选择 AgentAI 后实际请求独立接口，不使用旧 OpenRouter 密钥；原选择失效时保留选择并提示验证或重选，不自动换到另一来源。

AgentAI 不用于现有公开检索、网站名称识别、独立浏览器规划、电脑识屏、经营分析、商品 AI 或 AIGC 脚本编译。这些功能仍使用各自已适配连接；小序或员工需要公开搜索时也通过独立的 OpenRouter 搜索配置。两个音频型号提供独立「语音制作」入口，可合成语音、创建本人授权的克隆音色、查看任务与播放下载，详见「AgentAI 语音制作与音色克隆」；不替换实时语音、听写或分段朗读设置。

小序的 AgentAI 实际对话与模型能力验证使用同一套请求编号校验，优先读取正文中的编号，正文未提供有效编号时读取服务商的 `X-Request-Id`。用于对话的返回型号必须与选择的型号一致，回复和工具调用还须通过完整性校验。缺少可验证的编号、型号不符或输出被截断时会提示对应原因。用量按实际回执记录，同一服务商回执按原规则去重。（2026-11-21）

计量记录真实 Token；供应商明确返回的 `cost_rmb / cost_currency=CNY` 或费用响应头按 CNY 记录，异步任务 `actual_cost_micro_usd` 按 USD 记录。冻结额、报价及账户余额不计入本次费用，缺失字段保持未知。不同币种与来源积分分别统计。HTTP 401/403 请核对密钥或权限，402 请核对该平台余额；失败不自动充值，也不重复提交媒体生成。

## 接通状态说明

- 已配置或密钥已保存：存在连接信息，当前型号尚未证实调用成功。
- 最近调用成功：服务器收到了匹配型号的响应，不保证后续余额、限流或服务始终正常。
- 语音连接已验证：专用通道验证通过，不代表麦克风、扬声器和实际通话均已测试。
- 未配置、已关闭、型号不可用：按具体原因处理；错误不回显密钥或供应商敏感原文。

## 实际消耗与统计覆盖

工作台中栏的文字与语音按每条指令自动选择执行方式。右栏浏览器的地址栏默认在本机打开网页。切到「云端独立浏览器」后可查看标签、导航和网页画面。关闭云端标签结束该网页会话。手动打开网址、切换浏览方式、收起栏目和拖动分隔线不调用模型。中央管理页的「直达」链接打开对应栏目。

「小序公开网页检索」在普通文字对话识别到明确的公开搜索请求或需要核查的时效性公开问题时自动调用。此时直接使用已验证的 OpenRouter 连接和检索型号回答。每条匹配的提问发起一次搜索服务请求，检索最多 4 个结果。回复须带有效的「参考来源」，连接不可用或缺少可核对来源时显示原因。该次检索的 Token 和费用归此功能，按供应商回执记录，供应商未返回的字段显示未知。（2026-11-25）

「小序操作意图识别」服务于工作台的「自动识别」。常见操作和明确提问由规则直接区分。遇到自然措辞的续操作时，服务端先查上一步的任务，再将本条短句和目标类型交给此项选择的 OpenRouter 结构化输出模型。送往分类模型前会替换成对引号中的文字和连续数字；不附带聊天历史、截图或授权信息。模型只判断意图，实际操作由独立的电脑或网页任务完成。连接未验证、判断不明确或结果无效时，请补充操作目标。修改型号对之后的识别生效，费用及 Token 按供应商回执在本行记录，缺失费用显示未知。（2026-11-26）

「小序电脑识屏与操作」处理指定设备上的任务。XUTI DESKTOP 工作台可复用已记住跨窗口授权、能接收任务的本机。1.2.9 或更新的客户端收到单条打开或切换记事本指令时，可在本机核对前台窗口并回报结果。此流程不上传截图，不产生识屏模型调用。1.2.10 起，连续输入普通文字也可在核对原记事本文档后由本机完成。需要点击菜单等识屏步骤时，使用本行配置的 OpenRouter 型号，按供应商实际回执记录用量。听写、分段语音和实时通话按各自通道计量。

1.2.11 起，在桌面新建普通文件夹或文本文件时，由本机核对资源管理器窗口，后续界面操作继续使用本行配置。能验证归属的标准右键菜单可提供单独的菜单画面。定位起始目录和查看步骤回执均无需模型调用。Windows 1.2.12 及以上的资源管理器和 Mac Finder 助手可按用户给出的源与目标路径执行复制快捷键。Windows 1.2.13 起，先建桌面文件夹再复制源目录内容也走同一条本机流程。Windows 1.2.14 起，普通文件复制默认在本机后台执行，可同时使用鼠标、键盘和剪贴板。文件复制和结果核验无需模型。其他前台任务在窗口空闲后需要重新观察时，新规划按供应商实际返回的用量计量。（2026-11-26）

「小序独立浏览器」使用单独管理行和默认型号，通过已有 OpenRouter 连接逐步规划网页操作；任务建立后固定该型号，后续修改默认值只影响新任务。在中栏直接输入或说出外站任务，也可从右栏标签菜单把当前网页写进草稿。这个管理项用于服务器浏览器的模型调用。语音下达任务时，音频用量仍归实时语音；服务器每次页面规划的实际 Token 和供应商返回费用归「小序独立浏览器」。打开接管画面、手动输入、暂停和继续本身不调用模型，恢复自动操作后才继续按步骤调用。没有供应商账单字段时显示未知，不将浏览器运行时间估算成模型费用。（2026-11-21）

Windows 桌面端 1.2.16 起，按明确编号范围批量创建桌面文件夹时，目录清单由本机执行并核验，无需识屏模型。1.2.17 起，紧接着为每个子目录创建同名文本，也由本机直接执行和核验。1.2.18 起，将建目录和创建同名文本合在一条指令里，同样使用本机后台批处理。1.2.19 起，把聊天附件分发到指定桌面子目录时，由客户端接收文件、后台复制并核验内容，也无需识屏或识图模型。1.2.20 起，该流程也支持多附件、建目录后分发以及复用上一条任务核验的目录清单。Windows 桌面端 1.2.15 起，单纯打开或定位企业微信由已授权电脑核实前台窗口，无需上传截图或调用识屏模型。搜索联系人、准备草稿等后续识屏步骤使用「小序电脑识屏与操作」配置的型号，按供应商回执计量。语音下达指令时，语音用量仍归相应通道。（2026-11-27）

Windows 本地浏览器使用设备上的 WebView2。手动导航和登录不调用模型；明确要求小序操作本地网页时，沿用「小序电脑识屏与操作」的模型、设备授权和实际用量记录。模型只接收本次所选窗口的画面与可见控件；实时语音的用量仍单独记录。

浏览器地址栏直接打开网址、前进、后退、刷新、调整网页尺寸和本人输入均不调用模型，即使模型未接通也可在浏览器服务就绪时使用。只有中栏提交的自动操作目标才使用该管理行、中央模型配置及实际用量记录。自动任务完成后保留同一浏览器，下一条目标使用新任务的模型配置，不复用旧目标或旧操作。普通聊天模型选择不改变这个入口的型号。展开／收起面板、切换历史任务或刷新画面不会调用模型；服务器运行与存储费用另计，不记为模型 Token。（2026-11-16）

Token、积分和金额只采用服务器收到的供应商回执，不以模型标价、估算或客户端自报数据冒充账单。OpenRouter 的 `usage.cost` 显示为 **OpenRouter credits**；供应商积分按来源分开统计；明确以美元微单位返回的实际费用换算为 USD。不同单位分别列出，不直接相加或估算成人民币。重复供应商回执只计一次消耗；异步任务最终账单更新同一任务记录。

## 数据与故障处理

**独立浏览器（2026-11-15）**：模型接收当前网页的可见文字、有限控件信息和遮挡输入区域的截图，页面内容不作为更改用户目标或授权的指令。登录、密码、验证码及其他敏感步骤暂停自动操作，由本人在同一远端浏览器画面中接管；人工输入内容不进入模型请求或日志。登录态按当前账号加密保存，不复制网站业务模块已有的会话，也不使用你的本机 Cookie。浏览器服务未就绪时明确提示，不能自动退回我的电脑。模型或网络失败会保留真实任务状态，不自动换型号、充值、放宽限制或重放操作。操作与接管流程见「电脑操作」说明。

**电脑识屏错误（2026-11-15）**：电脑任务卡保留安全错误分类和诊断编号，管理员可据此定位权限、预算、服务拒绝或格式问题。该功能使用 OpenRouter，实时语音的百炼余额和验证记录不能证明它可用；403 本身不能证明余额不足。服务器诊断只记录受控错误代码及请求信息，不记录截图、控件文字、提示词或供应商错误全文。失败请求仍通过统一计量记录；未返回 Token 或费用时显示未知。不会因识屏失败自动换模型、放宽服务限制或重放电脑动作。

经营分析发送报表汇总与商品编码，商品资料生成发送有权查看的成分、类目和图片。小序普通对话发送消息、最近对话、主动附件及按权限查询的数据，日程和个人记忆须开启对应选项才附带。普通文字对话触发的公开搜索只发送本条查询，最多 500 字符，历史消息、附件和站内资料留在原流程。网站名称识别只发送名称，公开搜索不读取已登录的浏览器。电脑画面只在执行已授权任务时发送。标题与标准建议仍需人工核对。

计量表仅保存功能、型号、来源域名、请求编号、用量和安全错误代码，不保存提示词、原始音视频、密钥或供应商错误全文。加密配置未就绪、密钥权限不足、余额不足或型号下架时请核对对应连接。API 与 Worker 必须共用数据库和凭据配置。

后续新增或修改任何 AI 模型调用功能，都必须在同一版本更新本列表、实际路由、能力边界、来源、状态、计量覆盖和相关手册；此规则已写入项目 `AGENTS.md`。

## 百炼 DeepSeek 聊天（2026-11-08）

点击本页「百炼聊天连接」，填写北京业务空间 ID 与 API Key，或勾选「使用已保存的百炼语音连接」在服务器内复制已保存的千问实时语音连接。复制后独立加密保存，不改变语音、AIGC 或 OpenRouter 设置。密钥须在百炼获授权使用准确型号 `deepseek-v4.1-flash-1017`。
