# 我的工作台

更新日期：2026-10-02。入口：顶部「我的工作台」或登录后的默认首页。所有已登录用户均有独立工作台，供应商也可使用。

## 角色初始工作台

第一次打开时，根据已分配角色提供默认常用工具：运营关注经营分析与选款；买手关注选款、采购与供应商；商品岗位关注商品和表格；仓储关注库存与到货；财务关注经营与对账；供应链管理关注入驻、产品、采购和对账；供应商关注本企业产品、订单、资质和结算；管理员关注经营、协作和账号管理。多角色合并工具，最多8个默认入口。自定义角色根据实际权限提供工具。

所有入口仍受原有角色与模块权限约束，工作台不会授予新权限。供应商仍只能查看原本允许访问的企业业务。

## 自定义与私有记录

1. 点击「自定义工具」，选择自己已有权限的入口，用上下箭头调整顺序；「恢复角色默认工具」仅重置工具选择。
2. 点击「应用」后在工作台查看效果，再点击「保存工作台」保存。取消工具窗口不应用更改。
3. 在「个人待办」填写事项，可选择截止日期，点击「添加」；勾选完成，垃圾桶移除事项。最多200项，每项160字。逾期数按北京时间计算，已完成事项不计入。
4. 「私有备忘」最多4000字，与工具和待办一起通过「保存工作台」保存。未保存时显示提示，刷新可能丢失未保存更改。

配置存入数据库并随账号同步，换设备或重新登录后可恢复。待办和备忘只有本人在应用中读取与编辑，管理员的工作台也不会显示他人的个人记录。这些记录不写入公共操作日志；有数据库管理权限的运维人员仍能维护数据库。个人待办不会自动创建或完成项目任务。

工作台在其他页面已更新时，保存会提示冲突，保留当前输入；先复制未保存内容，再刷新核对，不会静默覆盖。

## 自己创建的内容与公共区域

「我创建的内容」按 SOP、项目、表格分类，可切换卡片或列表，显示创建者与公开范围；只包含本人创建且未移至回收站的记录。「新建 / 管理」进入对应列表创建内容，仍需该模块创建权限。

在内容的「⋯」选择「设为公开」或「设为不公开」，确认后立即生效。公开内容使用原有同一份记录，出现在项目协作相应列表的「公共区域」，不会复制数据；系统内有该模块查看权限的人可查看，始终显示创建者。选择不公开后从公共区域移除，已授权协作成员和原有管理员管理权限仍保留。表格保护规则继续生效，公开不表示任何人可编辑，也不公开到互联网。

个人待办与私有备忘不属于 SOP、项目或表格，不通过这个开关公开。删除协作内容先移至回收站，30天内可恢复，期满自动清理；个人待办的移除通过保存工作台生效，不使用协作内容回收站。

## 常见问题

没有某个工具或内容分类时请管理员检查角色权限。角色权限撤销后，相应工具不再显示，也不能保存未授权工具。保存失败不会清除当前编辑，检查错误并重试；请不要共享账号。
