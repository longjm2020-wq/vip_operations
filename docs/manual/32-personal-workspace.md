# 我的工作台

更新日期：2026-11-03。入口：左侧菜单「我的工作台」或登录后的默认首页。所有已登录用户均有独立工作台，供应商也可使用。左侧入口在所有登录后的业务页面保留，顶部不再重复显示工作台入口；收起侧栏时可通过房屋图标进入。

## AI 工作区与布局

工作台以居中的 AI 核心与对话输入区为主，顶部保留问候、日期和「保存工作台」。下方入口提供「日程」「个人待办」「私有备忘」「常用工具」和有权限时的「我的内容」。这些面板默认收起，点击入口展开，点击「收起工作台面板」返回中心工作区。关闭或切换面板保留本页尚未保存的编辑、待办输入和日程月份，不会自动保存；刷新或离开工作台仍可能丢失未保存内容。已有工具顺序、待办、备忘和保存方式继续沿用账号配置。手机上通过顶部展开按钮打开工作区导航，展开面板适应屏幕宽度。

工作台使用炭黑底色与蓝色光效。亮暗模式统一使用蓝色主色（#435EE5）：主按钮均为蓝底白字，暗色下的链接和选中项使用更明亮的蓝色，正文和辅助说明使用随主题变化的中性色。LOGO 的缓慢流光也使用同一蓝色系，并适配亮暗背景。

原「专属 AI 工具」三张卡片及经营分析摘要已移除。经营分析从常用工具或「运营中心 → 唯品会 → 经营分析」进入；商品标题与安全标准仍在商品档案、选款登记原有工具箱中，按权限提供。工作台首页不再读取经营分析报告。

顶部太阳／月亮按钮切换全站亮色或暗色主题，表格、图表、菜单、弹窗和个人助理同步切换。默认暗色，亮色使用浅色底色与蓝色点缀。主题立即独立保存到当前账号，无需点击「保存工作台」，也不会保存或清除尚未提交的日程、备忘和表格草稿。重新登录或换浏览器会读取服务器偏好；已打开的其他设备在回到页面或约一分钟后同步。保存失败会重新读取并提示；若其他设备先更新，读取最新主题后再次选择。登录前及公开分享页只保存在本浏览器，不修改任何账号。商品图片与用户指定的单元格配色保持原样，未填色但指定文字颜色的单元格使用适合该文字的中性底色。

AI 核心使用蓝色同心轨道与中心光效，按助理实际的空闲、思考、聆听和朗读状态显示反馈。空闲光效不表示正在调用模型，只有主动发送消息才处理问题。启用系统「减少动态效果」后，核心和 LOGO 保持静态。只有有权使用个人助理的账号显示该 AI 区域；其他账号仍可使用自己的日程、待办、备忘和已有权限的工具，模型设置仍由有权限的超级管理员管理。

## AI 个人助理

### 小序形象与全站互动（2026-11-03）

蓝色机器人「小序」作为全站悬浮助理自由寻找空位，不固定在侧栏或某张卡片中，切换页面后继续存在且只显示一份；点击形象直接开始 智能语音，不打开大面板或遮挡页面；文字对话从角标的「文字对话」或工作台「打开个人助理」进入，跨页面保留本次输入。形象旁只显示角标，名字、状态、互动按钮及动态反馈默认收起；点击角标展开，点击外部区域或按 Escape 收起。展开区只保留文字对话、语音和设置入口，已移除打招呼和复位图标。形象不随侧栏展开或收起而固定；手机工作台需先展开导航才能访问侧栏菜单。

小序是透明悬浮形象，不放在卡片或底座中。直接拖动形象即可自由放置，支持鼠标和触屏；聚焦形象后可用方向键微调，Home 键重新寻找空位。手动位置按账号保存在当前浏览器，窗口变小时限制在可视区域，切换页面、滚动或内容变化后会避让新出现的文字和操作区。拖动不会误触发对话。

桌面端空闲约20秒后，小序会在整个可视页面寻找空白处活动，包括侧栏和面板中的空隙，不限定在顶部或固定区域。停留位置避开文字、按钮、输入框、AI 核心及鼠标操作区；穿行时不拦截点击，经过内容时暂时隐去，进入空白处再出现。没有足够空间时保持静止或缩小形象。开始输入、点击、滚动、悬停形象或打开弹窗时暂停，回复或后台任务执行中也暂停。手动拖动后至少停留30秒。手机及启用「减少动态效果」时不自动游动，仍可拖动和对话。亮暗主题同步生效。

日程到时、项目进展或任务状态产生新提醒时，小序用不超过32字的短文字提示，约8秒后收起；页面初次打开不逐条播报历史，仅提示当前需关注的事项，不调用模型。点击角标后可查看完整状态和最近反馈，再点反馈进入完整动态面板。没有未读动态时保留省略号角标，仍可展开操作。展开或收起角标不会自动把动态标为已读。

回复或可见后台任务正在执行时显示「工作中」；语音输入时侧身聆听、耳灯闪动，思考时抬手侧头，朗读时张嘴、点头并摆手；这些动作随实际语音阶段切换，并暂停自动游动。启用减少动态效果后保留静态表情和文字状态。有新动态时显示提醒，接口失败或回复失败时提示关注；空闲90秒可显示「摸鱼中」趣味表情。这些表情不表示已经完成任何业务操作，实际结果以动态或对话记录为准。没有 AI 对话权限时仍可打开自己有权查看的动态反馈。

「动态反馈」分为日程、项目、任务：日程展示本人已保存的今天至未来7天安排，开始前30分钟标记需关注，经过开始/结束时间后显示进行中/已结束，不代表本人已完成事项；项目显示本人可读的近7天站内通知和本人发起或参与的最近10个非草稿项目，进度按已验收任务数统计；任务展示有权查看的近7天聚水潭库存同步、罗盘更新和每日经营日报发送结果。库存同步按已匹配/目标商品数反馈；心跳中断或超时显示需关注，不能视为完成。日报「邮件服务器已接收」不保证进入收件箱。未配置的其他定时任务和外部行程不会凭空出现。

动态在页面在线时约每30秒更新，保存日程后即时重新读取；点击可打开原模块处理。没有系统推送或离线弹窗，关闭网站后再次打开可查看已有反馈。已看过标记仅保存在当前浏览器，状态变化后会重新作为新动态显示，不改变原项目通知的已读状态。不自动调用 AI、启动任务、重试采集或发送邮件；反馈记录也不会自动附带到模型对话。

同时具有经营分析查看及管理权限，或同时具有商品查看及编辑权限，或同时具有选款查看及维护权限的账号可使用个人助理。复用系统管理员配置的智能服务，需已开启并验证。未就绪时「打开个人助理」可查看原因，不会自动测试或更换模型。

1. 在主区域输入要完成的工作，按 Enter 发送（Shift+Enter 换行），或点击「打开个人助理」继续对话。可以规划工作、拟写文案、查找已有权限的工具，或提出具体日程安排。
2. 默认发送本条消息、最近16条对话及按本次问题查询到的授权业务数据给已配置的 已配置的智能服务。可勾选「附带已保存日程与待办」，本次增加未来60天内最多50条已保存日程和最多50条未完成待办；未保存的草稿不会发送，私有备忘始终不发送。「使用个人记忆」单独控制是否附带本人保存的记忆。曾在对话中发送或回答中引用的内容仍属于对话历史。
3. 助理给出的日程显示为「待确认日程」。核对日期、起止时间和备注后点击「加入日程草稿」，助理对话自动收起，工作台展开日程面板；若正在业务页面，会先打开工作台并加入草稿。核对后点击「保存更改」，或收起面板后点击「保存工作台」保存。重新打开助理时，已加入的卡片不可重复添加。可在月历中点击相应日程编辑。建议不会自动变更商品、库存或业务表格，也不会发送邮件或日历邀请。工具链接只跳转到现有权限范围内的模块。
4. 对话随账号保存在服务器，最多保留最近40条消息；「清空助理对话」经确认清空本人的对话并取消尚未提交的操作卡片，不影响个人记忆、工作台记录或已提交的后台任务。回复不展示型号和服务商名称，错误保留可操作的原因，不会自动重试；跨页面并发或版本冲突时先刷新对话。

主动发送文字或语音提问后才处理问题；普通文字提问每账号每小时最多20条，智能语音提问和朗读没有网站设置的条数上限，也不占用文字提问额度。语音识别、声音生成及需要推理的提问按服务商实际用量收费，仍受 智能服务 余额、密钥额度及服务限流影响。页面打开、刷新、查看历史和编辑记忆不调用模型。一条普通提问最多执行6个工具调用、4次助理模型请求，每次最多5000个输出 token（含推理）。明确的站内语音导航、同步指令直接走授权功能，不额外调用推理模型。助理可处理主动附加的文件；联网须先勾选，不读取已登录网站。它不具备桌面控制、离线唤醒或全站任意操作能力；经营报表详细分析仍在经营分析模块。文本回答需核对，模型建议不代表系统已执行。

### 智能语音对话

入口：直接点击小序形象，或工作台输入区「智能语音」。身旁只展开简短字幕及语音操作，不弹出大对话窗口，不自动抢占输入焦点。使用管理员配置并验证的声音服务；服务失败不自动切换。采用一段语音识别、现有工作台助理处理、智能服务生成声音的流程，轮流说话，不是双向同时通话。

从小序角标或语音气泡的齿轮进入「语音设置」。有经营分析管理权限的超级管理员可在其中配置：填写专用服务密钥，选择声音服务并启用，点击「保存语音设置」，再点击「验证并试听」。验证会真实生成一句简短语音，按 API 用量收费；验证成功仅代表声音生成通路已通过，麦克风和识别需开始对话后实测。密钥加密保存在服务器，读取接口不返回密钥，不会写入浏览器存储；留空保存保留原密钥，清除时同时停用。更换密钥、模型或声音需要重新验证。订阅产品与网站智能服务分别计费。

1. 工作台原有 智能服务 助理也需启用并验证。语音识别和声音生成使用专用语音密钥；思考及业务工具沿用原有默认助理能力和配置。三部分分别计费。建议在 智能服务 为语音密钥设置消费上限。
2. 主动点击小序或「智能语音」后才申请麦克风；未就绪时只提示检查设置，不录音。说完停顿约1.3秒自动发送，也可点击「发送这段」；每段最多25秒。回答生成后逐段播放 小序的声音，最多朗读600字，完整文字与业务卡片保存在「互动对话」。识别的商品编码、数字、日期应核对。
3. 播放中可点击「打断并说话」，停止当前音频并开始下一段；生成回复时暂不收音。静音会丢弃尚未发送的录音片段，取消静音可继续。没有识别到完整可用文字或只有静音时，自动丢弃该段并重新聆听，不弹出中断提示、不重复上传该录音，也不调用助理或执行操作。每次最多10分钟，45秒未检测到语音自动结束。点击电话／关闭图标、按气泡内的 Escape、打开文字对话或语音设置、隐藏网页或退出网站均停止麦克风和播放。在网站内部切换业务页可继续对话，气泡跟随形象并限制在窗口内；拖动形象不会重新申请麦克风。权限、余额、网络或模型服务失败仍显示具体原因，需手动重试。
4. 音频经网站服务器转发给 已配置的智能服务，网站不保存录音。识别文字进入本人助理历史，后续回答按现有最近16条历史处理；气泡只显示最近一句的前三行，完整记录从气泡的「查看完整对话」或角标「文字对话」进入。日程、待办和记忆只有勾选对应选项后附带，私有备忘不发送。语音生成接收助理回复正文，不额外读取整站资料。
5. 沿用原有助理权限，不限制语音条数；同一账号同时处理一条语音请求，避免声音重叠或重复执行。库存、项目和任务只能按现有权限查询；日程、记忆和普通提问产生的同步建议仍需核对卡片。语音直接启动同步仅限下述明确指令。点击「查看完整对话」可核对卡片；中断语音不能撤销已经提交的后台任务。

浏览器需要 HTTPS、麦克风及 Web Audio 支持。未检测到设备、麦克风权限被拒绝、智能服务 余额/密钥额度不足、模型不可用会显示原因；普通文字输入仍可使用。声音是 AI 生成的，并非真人录音。

### 语音打开页面与启动更新

在小序语音对话中说「打开经营分析」「打开库存明细」「打开商品档案」等现有工具名称，直接进入有权访问的页面，无需再点链接，语音会话继续。说「更新罗盘数据」「更新罗盘报表」或「同步聚水潭库存」，明确的单条指令会按当前账号权限提交现有后台任务，并读出提交或失败结果；进度可从小序动态反馈和原页面查看，已提交不等于已完成。可以加「请」「帮我」「小序」等称呼。指令识别使用完整句匹配，不会因为提到某个功能就执行；否定句、疑问句、多个混合指令及不明确的表述按普通对话处理。普通文字对话不自动导航或执行同步。

同步仍需原模块权限及有效登录会话；聚水潭仅允许有库存调整权限的超级管理员。重复的同一请求不重复提交；不会自动重试失败任务、上架下架、编辑商品或发送邮件。语音识别的商品编码、日期等仍应核对。导航与更新结果保存在本人的对话中，打开历史或朗读旧回复不会再次执行。

### 语音输入与播报

点击输入框旁的麦克风开始中文语音识别，再点停止结束；一次最长60秒。识别文字进入输入框，核对或编辑后再发送，识别本身不会发送消息或自动执行任务。只有主动点击才申请麦克风权限，不持续监听唤醒词。关闭助理窗口、切换助理页签或隐藏网页会停止录音和朗读。

语音识别取决于浏览器和网络，建议使用支持该功能的 Chrome / Edge；浏览器可能把音频交给其在线识别服务，不能视为离线识别。网站不保存录音。权限被拒绝、未检测到麦克风或服务连接失败时保留文字输入并显示原因。

询问小序如何语音对话时，会提示点击小序形象或浏览器语音输入入口；助理不能替你开启麦克风或语音开关。

「语音回复」默认关闭。开启后，互动对话的新回复自动使用当前已配置并验证的 智能声音；也可单独点击「小序朗读」。只把当前账号这条已保存回复的正文送去生成声音，不重新回答问题或执行操作，不申请麦克风，每次最多朗读600字，长回复的完整内容保留在文字中。生成时小序思考，播放时张嘴、点头并摆手；可以「打断朗读」或再次点击该条回复停止。关闭窗口、切换页签、隐藏网页、发送新问题或开始麦克风对话会停止播放。浏览器阻止自动播放时点击「播放小序声音」即可。语音未配置或失败时保留文字和具体原因，不切换为浏览器机械声音。

「播报新提醒」仍独立使用浏览器中文声音，默认关闭。开启后仅在页面在线且小序未忙于对话或语音时朗读新的简短提醒，不补播历史，也不把提醒文字交给模型。两个开关仅对当前打开的网站会话有效，智能朗读按 API 用量计费，网站不保存音频。

### 查询业务与执行同步

业务回复先给出简短结论，详细数值可展开查询结果卡核对。新增计算字段按库存页相同的字段标识和公式读取，保留原结果及小数；不会由助理重新估算。查询卡保留6项原始库存指标，计算字段最多显示前4项，超出时提示到库存明细查看。

- 例：「查 XFA16X31196L 的库存」。须有库存查看权限，查询已完整同步的聚水潭杭州总仓快照，显示来源时间、全部匹配行汇总和最多12条明细；保留完整条码，颜色尺码分行。缺失数据不当作0，快照不代表实时库存；个人可见且未隐藏的计算字段按原配置计算。展开「库存查询」可核对服务器返回结果并进入明细。
- 例：「查看我参与的项目进度」。须有项目查看权限，同时遵守项目成员、公开范围及禁止查看设置；无关键词仅返回本人创建或参与的最近项目，可按名称搜索有权查看的项目，最多展示10项。按已验收任务数反馈进度，不修改项目任务。
- 例：「查看最近的同步任务结果」。读取有权查看的动态；只有勾选附带日程时，才把日程反馈也交给模型。查询不会启动、重试任务或发送邮件。
- 例：「同步聚水潭库存」「更新罗盘报表」。小序生成待执行卡片，点击「开始执行」后才调用现有后台任务。聚水潭仍需超级管理员及库存调整权限；罗盘仍需经营分析管理权限，并分别满足原模块会话和工作器条件。提交成功显示「已提交」或「执行中」，只有真实任务完成才显示「已完成」。可以到动态反馈或原模块查看详细进度；失败保留原因，人工重试，同一张卡片不会重复提交。未提交卡片24小时失效；执行时再次检查当前账号权限。

### 个人记忆

打开助理「个人记忆」，可新增、编辑、删除或清空本人偏好，立即独立保存到服务器，无需「保存工作台」。最多40条，每条名称40字、内容500字，按账号隔离；不提供他人记忆访问入口，也不写入公共操作日志。可记录汇报格式、工作偏好等，不要填写密码或密钥。

对话中明确要求记住时，助理只生成「待保存记忆」；点击「核对并记住」进入编辑，点击「保存记忆」后才写入。只有勾选「使用个人记忆」才随新消息附带保存的内容；取消勾选或删除记忆不会抹去此前对话已经引用的内容，可另行清空对话。多页面同时编辑会提示版本冲突，保留当前输入，刷新核对后重试，不静默覆盖。

## 日程面板

点击工作台下方「日程」展开月历。月历按北京时间显示，左右箭头切换月份，「今天」返回当天；有安排的日期带标记，点击日期查看当天安排。收起后再次展开会保留本页选择的月份与日期。日程仅本人可见，按账号保存并支持跨设备恢复。

在展开的面板中点击「新增日程」或「添加日程」，填写名称、日期，可选全天或同日起止时间，填写备注后点击「应用日程」。然后点击面板底部「保存更改」，或收起面板后点击工作台顶部「保存工作台」完成服务器保存；有未保存内容时显示提示。两个保存入口都保存本页全部已应用的工作台更改，包括日程、待办、备忘和工具选择。日程按开始时间排列，全天排在前面。

点击当天安排可修改或删除，再保存工作台生效。最多500条日程，名称160字、备注1000字；结束时间必须晚于开始时间，跨天安排请分日添加。已保存日程通过小序提供站内提醒，不邀请参与人、不连接外部日历，也不自动变成项目任务。

## 角色初始工作台

第一次打开时，根据已分配角色提供默认常用工具：运营关注经营分析与选款；买手关注选款、商品资料与协作；商品岗位关注商品和表格；仓储关注库存明细与协作；财务关注经营与对账；供应链管理关注入驻、产品、采购和对账；供应商关注本企业产品、订单、资质和结算；管理员关注经营、协作和账号管理。多角色合并工具，最多8个默认入口。自定义角色根据实际权限提供工具。

工具入口按角色和模块权限显示，工作台配置本身不授予业务权限。SOP、项目和表格还检查该内容的成员权限；供应商仍只能查看获准业务。

内部角色已提供项目协作入口，可在「自定义工具」添加 SOP、项目及表格入口，并在「我创建的内容」管理自己的三类内容；供应商角色不参与此默认授权。创建者管理已有内容不要求另有该模块的新建权限，新建仍检查 SOP 维护或项目创建权限。表格入口检查项目查看及表格成员权限，选款登记仍独立检查选款权限。已保存的个人工具选择继续保留。

原「库存管理」快捷工具现显示为「库存明细」，打开运营中心的唯品会库存明细页面。已保存的库存工具自动使用新入口，无需重新添加。旧 ERP 采购订单、采购建议、到货入库、供应商快捷工具已移除，已保存的旧快捷入口会在读取工作台时自动过滤，不影响个人备忘、待办或其他工具顺序。具备接入管理权限时，可添加「唯品会接入」，指向运营中心唯品会板块的新接入页。

## 自定义与私有记录

1. 点击「常用工具」展开面板，再点击「自定义工具」，选择自己已有权限的入口，用上下箭头调整顺序；「恢复角色默认工具」仅重置工具选择。
2. 点击「应用」后查看效果，再点击面板「保存更改」或顶部「保存工作台」保存。取消工具窗口不应用更改。
3. 点击「个人待办」展开面板，填写事项，可选择截止日期，点击「添加」；勾选完成，垃圾桶移除事项。最多200项，每项160字。逾期数按北京时间计算，已完成事项不计入。收起再展开保留尚未点击「添加」的输入；该输入仍需添加后才随工作台保存。
4. 点击「私有备忘」展开编辑，最多4000字，与工具、待办和日程一起通过「保存更改」或「保存工作台」保存。收起、切换面板不会清除或自动保存草稿；未保存时显示提示，刷新可能丢失未保存更改。

配置存入数据库并随账号同步，换设备或重新登录后可恢复。待办和备忘只有本人在应用中读取与编辑，普通管理员及超级管理员的工作台均不会显示他人的这些个人记录。这些记录不写入公共操作日志；有数据库管理权限的运维人员仍能维护数据库。个人待办不会自动创建或完成项目任务。

工作台在其他页面已更新时，保存会提示冲突，保留当前输入；先复制未保存内容，再刷新核对，不会静默覆盖。

## 自己创建的内容与公共区域

有项目查看权限时，点击下方「我的内容」展开「我创建的内容」。首次展开才读取内容，按 SOP、项目、表格分类，可切换卡片或列表，显示创建者与公开范围；只包含本人创建且未移至回收站的记录。收起再展开保留本页选择的分类和显示样式。「新建 / 管理」进入对应列表，新建仍需该模块创建权限；已有内容按创建者及成员权限管理。

创建者或超级管理员在内容的「⋯」选择「设为公开」或「设为不公开」，确认后立即生效。公开内容使用同一份记录，出现在相应列表的「公共区域」，不会复制数据；有该模块查看权限且未被禁止查看的用户默认仅查看。选择不公开后从公共区域移除，创建者、超级管理员及明确获准成员仍可访问。普通管理员或账号管理权限不授予默认管理他人内容的资格。

「⋯ → 成员权限」可添加用户，新增成员默认「仅查看」，再逐人选择「可编辑」「仅查看」或「禁止查看」，点击「保存权限」生效。只有创建者或超级管理员能管理这些设置；获准编辑的成员只能编辑内容，不能更改成员、公开范围或删除内容。「禁止查看」优先于公开范围及旧成员资格，创建者和超级管理员不受禁止设置影响。移除显式设置后恢复默认访问范围。多人同时调整时会提示冲突，使用最新成员设置后核对重试。

表格保护规则及字段公开范围继续生效：表格可编辑不表示可修改被保护的区域；普通用户仍看不到他人的私有字段，超级管理员可查看及管理全部私有字段。成员权限不会把内容公开到互联网。

个人待办与私有备忘不属于 SOP、项目或表格，不通过这个开关公开。删除协作内容先移至回收站，30天内可恢复，期满自动清理；个人待办的移除通过保存工作台生效，不使用协作内容回收站。

## 常见问题

没有某个工具或内容分类时请管理员检查角色权限。角色权限撤销后，相应工具不再显示，也不能保存未授权工具。保存失败不会清除当前编辑，检查错误并重试；请不要共享账号。

AI 服务拒绝请求时，助理会保留错误类别及 HTTP 状态码，不展示服务商原始响应或凭据。出现「没有满足请求条件的服务端点」时请管理员检查固定模型与接口参数兼容性；不会自动降低数据保护要求或切换模型。

## 多模态智能体与任务文件（2026-11-03）

小序对话输入区增加“附件”、能力选择、“联网”和创作设置。“任务与文件”集中展示本人任务进度及最近100个文件；完成和失败也反馈到小序动态。所有文件按账号隔离，不写入商品档案或库存。普通页面使用能力名称，不显示供应商、型号或“实际返回”信息；旧助理回复也按相同规则展示，用户原始输入与上传文件不改写。

### 使用方法

1. 选择通用助手、深度思考、视觉理解等能力；标有“识图”的能力可看图片和视频抽样画面。切换只影响后续文字提问。不可用时明确报错，不自动替换。
2. 点击“附件”选文件，再输入处理要求并发送。每次最多6个文件，总计80MB；图片和文档每个20MB，视频每个64MB、最长30分钟。支持 PNG、JPEG、WebP、PDF、DOCX、XLSX、PPTX、CSV、JSON、TXT、Markdown、MP4、MOV、WebM。旧版 DOC/XLS/PPT 需先另存为新格式。
3. 可以说“把附件整理成 Word 周报”“将这份表格整理成 Excel”“制作五页汇报 PPT”“按这张产品图生成宣传图”“截取视频5至15秒、转为竖屏并静音”。小序据请求调用工具，任务提交后在卡片中显示进度，完成后可下载真实文件；图片及视频可预览。生成新文件，不覆盖源文件。
4. 文档可输出 Word、Excel、PPT、Markdown、文本和 CSV。表格保留长编码为文本，不执行宏或电子表格公式。视频支持多个片段按顺序裁切、拼接、0.5至2倍速、静音和画幅调整，等比缩放留边；最多12段，成片最长10分钟、100MB。不提供无素材生成视频、字幕、音轨识别或自动精确镜头定位；复杂视频创作可使用原 AIGC 模块。
5. “创作设置”选择图像能力，标有“参考图”的选项支持引用对话附件；每次生成一张。图像服务未就绪、余额不足或拒绝请求时显示失败，不以演示图代替。
6. 勾选“联网”后才能查询公开资料，回答附可打开的来源链接。联网不读取个人浏览器、已登录网站或本机文件；未勾选时不调用搜索。只有勾选日程或记忆才附加相应个人资料。

### 读取范围与任务状态

Office 文件读取正文和表格文字，不还原原排版或内嵌图片。Excel 每个工作表读取前300行、最多12张表；PPT 最多80页。单文件正文最多60,000字符，一次提问合计100,000字符，截断会告知助理。PDF 交由服务解析，扫描件质量影响准确性。视频每次提问总计最多抽取6帧，不视为已观看完整视频或识别音轨。

附件随主动发送交给智能服务处理，原件保存在本人文件库；生成文件也可“附加到对话”继续处理。后续需要再次深入读取某个附件时，请重新附加。每账号文件空间1GB，可在“任务与文件”删除不用的文件；运行中任务使用的文件暂不可删除。删除不可恢复，但不改变源业务资料。

每账号最多5个排队/运行任务。关闭面板不取消后台处理，刷新或重新登录可查看；仅排队任务可取消。失败和中断不会自动重试或重复计费，核对原因后重新提出请求。清空对话不删除任务或文件；如已删结果，任务卡明确显示结果文件已删除。模型回复“已提交”不等于任务完成，以任务状态和可下载文件为准。
