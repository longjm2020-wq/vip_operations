# AI 员工工作台

更新日期：2026-11-24。在「我的工作台」点击场景左上方「AI 员工」或右侧常驻的员工图标（`/my-workspace?assistant=employees`）。具有小序使用权限的账号可访问自己的员工与任务。

## 新建与查看

1. 点击员工区域的「＋」，选择修图师、视频师、质检员、文案师、研究员或自定义岗位，填写称呼、职责和验收标准。
2. 按需展开「模型」「技能与知识」「接单规则」。点击「保存员工」后资料保存到当前账号，刷新或换设备登录仍保留。
3. 头像显示在场景工具栏下方，单行最多六位，最多保留十八位在职员工。点击头像在右栏打开员工窗口；中栏场景和小序原聊天保持独立。
4. 员工窗口顶部只保留一行：头像、可点击切换的员工名、短状态，以及配置、新增和独立收起图标；上方不再重复浏览器、电脑和更多工具横栏。聊天与任务直接显示；点击「员工配置」齿轮进入配置，再点击「返回员工聊天」箭头回到任务。长称呼自动省略，配置、新增与收起按钮保持可点击。宽屏可直接用场景右侧图标切换工具；手机上先点员工栏最右侧「收起右侧工具栏」返回场景，再选择浏览器、我的电脑或「更多工作台工具」。切换、查看或收起右栏不会停止后台任务，也不会发起模型调用。
5. 从姓名选择器切换到「小序派单」，点击「员工管理」齿轮可查看全部员工，包括已归档员工；点击「返回小序派单」箭头回到协作任务。打开已归档员工的配置可恢复。存在尚未结束任务时不能归档，须先完成或停止任务。归档不删除历史记录。没有员工时仍可通过顶部「＋」新增，新建界面的返回箭头可回到小序派单。

配置使用版本检查；其他页面已修改时保存会提示冲突，请保留当前草稿并刷新核对。已创建任务保存员工配置快照，后来修改职责、技能、知识、模型、返工次数和步骤上限只作用于新任务。接单开关及并发容量用于当前队列调度。

## 岗位技能 SKILL.md

入口：小序派单 → 顶部「员工管理」齿轮 →「配齐岗位技能」。一次为当前账号的在职员工补齐空白技能，按称呼或岗位匹配修图师、视频师、文案师、研究员、质检员、资产管理员、剪辑师、发布员、情报员、数据分析师。已有技能、知识、职责和模型配置保留；未识别的自定义岗位列为未匹配，不猜测职责。配置版本发生变化时本次整体不写入，刷新核对后重试。

单个员工：点击头像 → 顶部「员工配置」齿轮 → 技能与知识。选择岗位模板后点击「填入模板」，或用「导入 MD」读取本地 Markdown；可切换编辑／预览，也可「下载 MD」。模板和导入会替换当前技能草稿，点击「保存员工」后才保存并用于新任务；下载仅导出当前草稿，不表示已保存。文件只接受 .md 或 .markdown，大小不超过64KB，正文不超过6000字符；建议使用 UTF-8。

执行时技能放在该员工的职责之后，最多读取前4000字符；内置十份技能都在此限制内。每个新任务保存当时的技能全文快照，旧任务、已排队任务和暂停恢复任务继续使用原快照。单独清空技能并保存后该员工不再附加技能；再次使用「配齐岗位技能」会补回匹配的空白技能。

技能文档包含接单依据、工作步骤、交付与验收、实际能力边界。发布员当前准备发布包与核对已有回执，不直接提交平台；资产管理员整理已提供素材与版本清单，不自动扫描磁盘或移动文件；数据分析师必须说明输入范围及实际计算能力，不能把样例或模型心算描述为已运行的全量计算。技能文字不能增加工具、账号权限或自动定时任务。

读取、填入、导入、下载与保存技能不调用模型；执行任务沿用既有工作模型、工具能力校验及用量计量。岗位技能源文件保存在服务端，与本版本应用一同发布，只有授权账号能通过技能接口读取；它们与使用手册是不同内容。

## 独立交办与小序派单

从工作台点击「AI 员工」进入小序派单，或直接点击员工头像交办。使用 AI 模型管理中的员工直达入口或旧团队书签时，工作台会直接展开员工窗口。查看早先的协作任务和已归档成果，可进入工作台「任务与文件 → 历史协作档案」。

- 独立交办：点击一位员工，在该员工输入框描述目标、交付形式、约束，按需通过「＋」上传素材，再点击发送。Ctrl / Command + Enter 也可发送。
- 小序派单：点击头像区域「小序派单」，输入协作目标；可指定员工，未指定时从在职且允许派单、接受新任务的员工中安排。小序制定依赖计划，程序检查可用成员与步骤上限，依赖通过验收后才继续。
- 图片到视频：创建修图师、视频师，可再创建质检员；选择「修图 → 质检 → 视频 → 质检」，上传原图并补充画幅、时长和一致性要求。修图成果通过验收后才作为视频输入，最终文件与验收意见在任务中查看。缺少视频服务或必要素材会停下并说明，不以提示词充当文件。
- 协作中的第一位质检员承担独立验收；未选择质检员时使用系统协调员。独立交办质检任务时，质检员负责报告，由系统协调员另行验收。协调与归档是系统步骤，不额外分配给执行员工。

每个任务记录交办来源、员工配置版本、执行成员、实际工作模型、步骤、验收意见、产物版本和文件。窗口显示最近三十个任务，展开「进度与产物」按需读取详细记录。可点击「将产物用于下一次任务」将已验收文件附到当前输入框，然后继续交办。切换员工或其他右栏工具保留本页尚未发送的任务草稿；刷新或退出页面会清除未发送草稿，已提交任务仍保留。

### 一次交办与补充资料

交办时写明要拿到的成果，附上必要素材。例如给修图师上传商品原图，写「做一张详情页商品图，构图由你决定」。员工按用途处理可自行决定的细节。准备、构思和自查通常合在同一个交付步骤。涉及多个成果或前后依赖时，系统分别派工，每项成果仍经过独立验收。任务卡可直接打开最多三份已验收文件；全部文件和验收意见在「进度与产物」中查看。

任务显示「待补充资料」时，在原员工窗口或「小序派单」查看缺项。最近一单等待补充且输入框为空时，输入框上方会显示「补充原任务」及原目标。填写一句说明或用「＋」上传缺少的素材即可发送，也可以只发附件。补充其他待办时点那一单的「补充这项任务」。希望另交新任务时点「另开任务」。

补充后原单重新排队，保留原附件、员工配置、调用计数和已验收成果。已有计划时从缺资料的步骤继续；派单前就发现缺项时，按补齐后的资料安排工作。原任务和补充内容合计最多六份附件、8000 字。员工已归档时需先恢复。若任务只显示「待处理」，先核对已有文件、作业及验收意见。旧记录或需要另行交办的任务，在当前会话输入框为空时可点「沿用交办内容新建」，编辑原要求和附件后发送。

文件最多六份；文档或图片单份保存上限 20MB，视频上限 64MB，具体格式和内容提取限制沿用小序附件规则。上传超限素材时系统会自动执行无损优先压缩以落入上限（支持最大 100MB 原图、60MB Office 文档、200MB 原视频；图片优先无损 PNG/WebP，Office 文档采用无损重打包，视频优先无损流重封装，仅在严格无损后仍超限时回退至高保真压缩）。仅上传或明确附到当前任务的文件可作为工具输入，写一个本地路径不代表系统已经取得文件。

员工独立交办时参考该员工最近六个已完成独立任务的目标与摘要；不会自动读取小序主聊天、其他员工独立聊天或团队知识档案。旧任务文件不会因摘要被提及而自动授权给新任务，需重新附加或使用产物复用按钮。协作成员共用本次任务目标、必要输入与通过验收的前置产物。员工产物保存在自己的任务记录，不自动进入原团队的共享知识检索。

「员工配置 → 技能与知识」还可打开公司知识库。保存笔记时可指定哪些 AI 员工能够检索它，工作台「公司知识库」以图谱显示笔记引用和员工授权。执行步骤按当前授权查阅相关笔记，产物可附带指向所用版本的引用。笔记接入、授权及历史版本详见「公司知识库与知识图谱」。

## 工作模型与执行模型

任务详情分别显示步骤的实际工作模型与文件任务的生成型号、处理状态。生成型号来自提交的服务配置，不把排队状态当作供应商成功回执；以真实文件和状态为准。

工作模型负责理解、计划、工具调用、文字报告。修图师和自定义员工另选图像模型；视频师和自定义员工另选视频模型。选项来自当前真实配置目录，不预设某个宣传型号一定已接通。

- 自动匹配：工作模型读取「AI 模型管理 → 智选模型」策略，结合稳定、价格、速度、质量 4 维度评分自动过滤低分渠道——编排与验收步骤优先匹配强能力模型，普通执行与检索步骤优先匹配高速低成本模型；修图与视频步骤在未固定型号时同样按智选评分优先匹配最新高质图像与优选视频模型（如 ChatGPT Image 2.6、Nano Banana 2.1、Seedance 2.5 等）。没有智选数据时沿用原目录能力分层。
- 固定型号：只使用选定型号，缺能力、不可用或访问失败时暂停并说明，不擅自换型号。
- 限定候选：选择二至四个型号，只在这组中匹配所需能力；工作模型发生认证、权限、额度类错误时也只能在此范围换用。
- 主用 / 备用：选择顺序代表优先顺序。工作模型优先匹配主用，已知不可用或访问、额度错误时尝试候选备用，每个型号最多一次；内容错误、超时及响应不确定不会自动切换重试。图像、视频仅在提交前从可用目录选择；提交后失败或结果不明不会自动换型号重新生成。

模型能力限制仍然有效：不支持参考图、画幅、时长或文件输入时须调整任务。修改模型需要保存，旧任务和恢复中的任务继续使用原快照。中央默认工作模型属于服务配置；员工「自动匹配」会读取执行当时的中央默认值，需锁定型号时使用固定策略。

工作模型通过已启用并验证的 OpenRouter 或独立 AgentAI 连接调用。AgentAI 型号须通过聊天、工具及结构化验证，再按当前任务筛选能力；固定选择会真实作用于后续任务，不将新型号发给旧连接。公开检索仍使用独立 OpenRouter 搜索配置。视频还要求 AIGC 使用权限及可用视频服务；岗位或提示词不能增加业务权限。保存配置、目录列出、密钥已保存都不等于该型号已经调用验证。（2026-11-16）

## 排队、暂停与停止

每位员工默认同时处理一个任务，可设为一至三个。独立任务与派单任务共用容量；协作任务保守预留所有所选员工，任一员工忙碌时排队。每个后台工作进程最多并行三个团队或员工任务。优先级为0至9，数值越大越先调度，同级按提交时间。每个账号最多三十个尚未结束的员工任务。

- 关闭「允许小序派单」：不再接受新派单，已经创建的任务继续。
- 关闭「接受新任务」：现有正在执行的任务继续，排队任务等待重新打开；仍可独立交办，任务进入等待队列。
- 「暂停任务」：排队任务立即停止调度；正在执行的任务完成当前并行步骤、验收与归档后暂停。当前生成请求不会被重发。若全部步骤已完成，正常结束。
- 「继续任务」：从已保存的安全位置继续未执行步骤，不重做已经完成的产物；若员工暂停接单或容量不足则继续等待。
- 「停止任务」：停止后续工作，保留已生成结果。已提交供应商的生成请求不保证可取消或退费。

单个员工可限制每任务最多一至八个执行步骤、最多两次返工。协作总计划最多十二个步骤。调用上限包含工作模型请求、搜索以及图像／视频生成任务预留；失败和已预留但未成功的调用也占用名额，用于限制自动执行次数，不是账单或金额预算。独立任务使用该员工上限，协作取所选员工上限合计且最高120次。达到限制后保留结果并提示处理，不自动无限追加。

## 能力与常见问题

- 当前员工可使用已有公开检索、办公文档、图片创作和短视频生成／剪辑工具。不会因创建员工而取得电脑、浏览器、业务写入或发布权限，这些入口仍有自己的授权流程。
- 视频生成保留实际后台任务及供应商任务记录，等待真实文件完成；单次最长30秒、最多4张参考图，仍按所选模型校验。AgentAI仅开放指定9个视频型号，特价固定时长与MU参考模式限制见AIGC手册。长队列按同一供应商任务号最多轮询65分钟；恢复任务只查询原编号，不重复提交。验收只看抽样画面与元数据，不替代完整视频、音轨或连续动作的人工检查。（2026-11-18）
- 「创作连接尚未启用或验证」：管理员检查 AI 模型管理中的共享连接；视频另外检查 AIGC 配置与当前账号权限。
- 「排队中」长时间不动：查看员工是否暂停接单、是否被其他协作任务占用，以及后台工作进程是否在线。
- 「待处理」：查看卡片上的具体原因。「待补充资料」按上文在原单提交。发生服务中断、达到调用或返工上限、文件提交结果不确定时，先展开步骤核对已有文件与实际状态，再决定是否另行交办。
- 产物未通过验收时在限定返工次数内修改，仍不通过则交给用户处理；不要把排队回执或模型自述当成交付证据。

工作模型用量计入中央「工作台 AI 员工」行，搜索、图像和视频分别计入各自功能。仅记录供应商实际返回的 Token、费用或积分，不补造未知用量，不将不同币种或积分相加。任务中的调用计数不能直接换算成实际费用。
