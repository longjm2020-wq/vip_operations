# 唯品会竞品分析

更新日期：2026-10-03。入口：运营中心 → 唯品会 → 竞品分析。查看沿用「经营分析查看」权限；采集设置、手动更新、新增品牌及导入沿用「经营分析导入与邮件配置」权限。

## 品牌与对比

我的品牌预设为「序缇」，竞品预设帕罗、米皇、笑涵阁（唯品会官方品牌名）、生活在左、金菊、南宋丝府，默认品牌链接已包含对应品牌ID。初始显示多个品牌；选择「单品牌对比」比较我的品牌与一个竞品，选择「多品牌对比」可同时选择最多11个竞品。新增品牌需填写名称，可选填写唯品会品牌筛选链接中的 brand_sn；最多保存40个品牌。品牌名称不可重复。拥有查看权限的内部用户共享品牌及商品样本。

顶部按品类、材质、季节、特卖价区间及商品名称/款号筛选。品牌概览显示样本款数、特卖价中位数、价格范围及详细材质覆盖；四张图表按品牌比较品类、价格、材质和季节的商品款数。材质可多选归属，同一商品可同时包含多种成分，各材质款数不能相加当作总款数。没有价格的商品不参与价格统计。

商品 TOP20 按品牌 TAB 独立显示，默认按该品牌公开销量排名，或按导入的实际销量降序排序；也可以按特卖价升序或降序查看20款。筛选先作用于已采集样本，再选出20款，结果不足20款时显示实际数量。公开排名保留来源页面内的原排名，不把不同品牌的第1名合并为市场总榜。导出TOP20保存当前品牌、筛选和排序下的商品，包括价格、详细材质、图片链接及详情链接。

每款显示特卖价、品类/季节和详细材质信息；鼠标悬停商品预览图显示120×120像素图片，点击图片、标题或「查看」在新标签页打开唯品会官方商品详情。价格为采集或报表中的当时价格，页面活动价可能随后变化。详情没有公开的成分显示「未公开 / 待补充详情」，不会从「含羊绒」等标题补造含量。未补齐详情时，品类和材质标签仅按商品标题识别；详情补齐后使用规格参数的材质及季节，并列出核对时间。

## 后台静默采集

默认每天北京时间08:00在后台按品牌依次采集。新品牌没有公开排名时会进入首次采集，不需要一直打开页面。点击「更新竞品数据」为当前对比品牌加入后台队列，页面仍可正常使用；同一品牌的进行中任务不会重复提交，5分钟内的重复更新沿用最近任务。

后台读取唯品会公开的销量排序页面及商品规格参数，不使用商家账号或用户浏览器账号。每次采集品牌销量榜第一页已加载的商品，最多120款，再逐款核对详细材质及季节；不宣称覆盖全品牌目录。价格、图片、商品链接和排名先保存，已核对的详情分批补充；新排名中的同款保留上次核对的材质及详情时间。公开页面没有给出成分时显示「未公开」。每品牌每次最多执行20分钟，已有数据始终保留。

商品详情跳转到其他商品或品牌时不写入该详情。单款读取失败会继续核对后续商品，任务标记「部分完成」；连续3款详情无法读取时停止本次详情采集，避免持续请求无效页面。需要验证时立即停止。

页面显示自动采集时间；展开「采集状态」可看各品牌是否待采集、采集中、完成、部分完成、未完成或需要验证，以及本次保存的排名和详情款数。TOP20下方保留样本范围、数据日期及保存时间。页面打开时会自动读取进度和新结果，后台任务不弹出浏览器窗口。点击「刷新」只读取已保存的数据。

「采集设置」可暂停自动采集、修改每日时间。暂停后正在进行的任务会继续完成；手动更新仍可使用。遇到验证、访问失败或平台页面变化时，该任务停止并保留上次有效数据及本次已经完成的数据，不绕过验证，不无限重复请求，也不会以空白数据替换样本。可通过「浏览器补充数据」导入正常打开页面上的公开信息，再按需更新。排名和实际销量是独立口径，不叠加或互相覆盖。

## 浏览器补充公开商品

1. 点击「采集设置」→「浏览器补充数据」，把「采集唯品会商品」按钮拖到浏览器书签栏。
2. 打开所需品牌页面，在品牌筛选中点击准确品牌，然后选择「销量」排序。向下滚动，让所需商品加载完成。点击采集书签，下载该页商品排名、特卖价、图片和详情链接的 JSON 文件。必须有品牌ID和销量排序才允许作为公开排名导入。第2页及后续页按120款的页面偏移保留原排名；当前一个排名文件作为独立样本，不会自动拼接多页。
3. 打开TOP20的商品详情，查看「规格参数」，点击同一书签，下载详细材质、季节和商品编码文件。工具只读取当前页的公开商品字段，不读取账号信息、Cookie或后台接口，不发送网络请求。
4. 回到「导入数据」，选择对应品牌，上传排名文件，核对款数后点击「确认导入」。文件日期不能晚于今天；较旧数据不能覆盖较新的排名。重复商品ID或排名、品牌不一致、非官方商品链接会被拒绝。
5. 选中同一品牌，可一次上传多个详情 JSON 文件补齐材质。只有最新排名样本中的匹配商品会更新，未匹配商品不加入排名。公开销量排名和特卖价保持原样。采集时间与详情核对时间分别保留。
   再次导入公开排名时，相同商品保留已核对的材质、季节和详情时间；较旧的详情不能覆盖新详情。商品材质发生变化时需重新采集详情补充。

登录失效、验证页面、商品尚未加载或平台结构变化时不能采集有效数据；先在唯品会正常处理并打开公开商品，再重新采集。浏览器工具只读取当前页面，不读取账号信息、Cookie或后台接口；处理浏览器中的验证不会保证后台服务器免于平台验证。

## 实际销量导入

点击「导入数据」下载销量模板，按品牌分别填写商品ID、商品名称、唯品会商品详情链接和实际销量；可补充款号、品类、特卖价、划线价、详细材质、季节及预览图链接。商品ID及编码按文本保存，避免Excel截断长数字。旧版.xls另存为.xlsx；公式须先粘贴为值。支持.xlsx、UTF-8 CSV和公开采集JSON，每个文件最多5MB、5000款商品。

上传销量报表后填写统计起止日期，核对商品款数后「确认导入」。每款销量必须是非负整数，包含0的真实数据可以保留；缺失销量不能当作0。切换顶部「实际销量报表」查看该口径下的对比及TOP20，系统不会把公开排名推算成实际销售件数。品牌统计区间或公开排名的数据日期不一致时会提示，先更新到相同区间再比较差异。未导入的品牌显示「未采集」。

同一批文件部分导入失败时，已成功的文件保留；修正失败文件后重新导入。不改变ERP库存、采购和经营分析报表，也不触发付费AI调用。
