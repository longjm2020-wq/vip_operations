# 唯品会竞品分析

更新日期：2026-10-05。入口：运营中心 → 唯品会 → 竞品分析。查看沿用「经营分析查看」权限；采集设置、手动更新、新增品牌及导入沿用「经营分析导入与邮件配置」权限。

## 云端唯品会登录

标题旁显示云端会话状态。拥有经营分析管理权限的用户点击「云端登录」或「管理云端登录」，在网站显示的云端浏览器画面中使用唯品会 App 扫码；需要勾选同意项或处理平台验证时，可直接点击或拖动画面。这里只支持扫码与鼠标操作，不提供账号密码输入，画面中的文本和密码输入区域隐藏。

扫码后点击「核验并保存」。后台检查账号登录标记、品牌商品访问，并用新建的浏览器再次验证保存的会话能够复用；全部通过才显示「云端已连接」。二维码失效时点击「刷新二维码」。保存成功后返回竞品分析，点击「更新竞品数据」开始更新；每日自动采集沿用「采集设置」中的北京时间，无需保持电脑、网站页面或 Codex 在线。

云端浏览器和本机登录相互独立。扫码保存会授权服务器使用该唯品会会话采集网站共享的竞品样本；服务器只保存唯品会域名的 Cookie 和浏览器登录状态，使用专用密钥加密，不返回给其他用户或放入源码。网站用户共用这一个后台采集会话；登录窗口画面及鼠标操作只允许打开窗口的本人读取与提交，其他管理员同时打开会提示正在使用。

每次云端登录窗口最多保留10分钟。关闭窗口、保存成功、过期或取消时清除临时画面；刷新网站可重新点击云端登录返回尚未过期的本人窗口。打开云端登录时，当前竞品采集会在下一步骤暂停并保留已经完成的数据，登录完成后可重新更新。成功保存的会话会跨后台重启保留，但唯品会可能使其提前失效；显示「云端需登录」或「云端需验证」时重新打开云端登录处理并核验。不能保证平台永远不要求重新登录或验证。

「断开云端会话」需要确认，会清除服务器保存的登录状态，正在使用该会话的采集在下一步骤停止，已有商品样本保留。断开后，后续后台采集需重新扫码，不会自动退回未登录采集。

前提：管理员在 Worker 部署环境配置稳定的 COMPETITOR_SESSION_KEY（32字节随机密钥的64位十六进制形式），并保持 Worker 在线。密钥缺失、采集程序离线、登录画面无法打开、核验失败均会明确提示。密钥更换后需重新扫码，不要把密钥或登录状态放进聊天、源码或商品表。仅本机扫码不等于云端已连接。

## 本机浏览器补充登录

在「采集设置」中点击本机「登录唯品会」弹出本机唯品会窗口，扫码登录；已登录时直接打开我的品牌销量榜。浏览器拦截窗口时允许本站弹窗，再点击「打开登录窗口」。登录和凭据输入均在唯品会官方网页完成。

将登录提示中的「核验登录并采集商品」拖到书签栏，在刚打开的唯品会窗口点击此书签。工具只通过页面已显示的登录入口核验状态，将已登录、未登录或无法确认的状态返回原竞品页面，同时下载当前页公开商品JSON；回到「导入数据」上传排名文件。只有来自该登录窗口及唯品会官方域名的返回可更新状态，不以关闭窗口或点击「我已登录」推定登录成功。

本机核验只对当前账号、当前浏览器标签会话有效，刷新可保留，30分钟后显示待核验；其他电脑不能沿用本机登录状态。唯品会可能更早使会话失效，采集要求重新登录时按官方页面处理。本机书签工具不读取、上传或保存Cookie、密码或账号标识。本机登录用于浏览器补充数据，不自动授权后台服务器。

「搜索商品 / 款号」位于顶部导航栏，随输入过滤当前竞品样本；品牌、品类、材质、季节与价格条件继续在分析页面设置，与搜索同时生效。

## 品牌与对比

我的品牌预设为「序缇」，竞品预设帕罗、米皇、笑涵阁（唯品会官方品牌名）、生活在左、金菊、南宋丝府，默认品牌链接已包含对应品牌ID。初始显示多个品牌；选择「单品牌对比」比较我的品牌与一个竞品，选择「多品牌对比」可同时选择最多11个竞品。新增品牌需填写名称，可选填写唯品会品牌筛选链接中的 brand_sn；最多保存40个品牌。品牌名称不可重复。拥有查看权限的内部用户共享品牌及商品样本。

顶部按品类、材质、季节、特卖价区间及商品名称/款号筛选。品牌概览显示样本款数、特卖价中位数、价格范围及详细材质覆盖；四张图表按品牌比较品类、价格、材质和季节的商品款数。材质可多选归属，同一商品可同时包含多种成分，各材质款数不能相加当作总款数。没有价格的商品不参与价格统计。

图表标题为「品类分布、特卖价区间、材质分布、季节分布」。鼠标悬停有商品的品牌条形图，或使用键盘选择并按回车、手机点击，可展开该品牌在对应分组中的前10款商品卡片。商品来自当前筛选后的全部样本，按当前排序取前10款；不足10款时显示实际数量。浮动列表仅显示小图、款号或商品名称和特卖价，方便整齐浏览多款商品。宽屏电脑悬停小图或用键盘将焦点移到小图，旁边同步显示该款的大图、特卖价、完整款号、详细材质和详情链接，前10款列表保持展开；屏幕右侧空间不足时卡片自动显示在左侧。移动鼠标到其他小图即可切换商品，可移入侧边卡片滚动材质或点击详情链接；关闭按钮收起侧边卡片。窄屏保留120像素图片预览，点击小图查看完整单款卡片。

点击小图或侧边卡片的大图弹出单款商品卡片，仅保留图片及下方的特卖价、完整款号、详细材质和详情链接，移除顶部标题与外围留白。「特卖价」标签在侧边卡片和弹窗中均使用与序缇图表一致的橙色。未提供的材质显示「材质未公开」，长内容可在大图卡片内滚动；按Esc、右上角关闭按钮或点击遮罩退出。点击图片不会打开外部页面；点击图片下方的文字区域或大图卡片中的「查看商品详情」，在新标签页打开唯品会官方详情。数量为0的条形图不展开商品。

商品 TOP20 按品牌 TAB 独立显示，页签仅显示品牌名称。默认按该品牌公开销量排名；也可以按特卖价升序或降序查看20款。筛选先作用于已采集样本，再选出20款，结果不足20款时显示实际数量。公开排名保留来源页面内的原排名，不把不同品牌的第1名合并为市场总榜。导出TOP20保存当前品牌、筛选和排序下的商品，包括价格、详细材质、图片链接及详情链接。竞品页面统一使用公开销量排名，已移除「实际销量报表」切换、销量模板及销量报表上传入口。

切换 TOP20 排序时，面板保持当前页面位置，当前品牌 TAB、表头位置及表格内部滚动位置均保留。新筛选结果加载期间保留面板并显示加载状态，完成后更新商品；加载期间暂不能导出，避免导出上一轮结果。切换到没有样本的品牌或筛选结果为空时，面板仍保留固定的展示区域。

每款显示特卖价、品类/季节和详细材质信息；鼠标悬停表格商品预览图显示120×120像素图片，点击图片弹出同样的单款大图卡片。点击商品标题或「查看」在新标签页打开唯品会官方商品详情。价格为采集时的价格，页面活动价可能随后变化。详情没有公开的成分显示「未公开 / 待补充详情」，不会从「含羊绒」等标题补造含量。未补齐详情时，品类和材质标签仅按商品标题识别；详情补齐后使用规格参数的材质及季节，并列出核对时间。

材质展示及导出隐藏颜色名称，例如「【烟雨蓝的面料】」显示为「【面料】」，「【烟雨蓝的里料】」显示为「【里料】」，「湖绿色/黑金/白金/芭比粉：面料：」显示为「面料：」。面料、里料等部位名称、具体成分、百分比和备注保留；不同配比的段落仍分别显示，不合并或补造含量。原始采集材质仍完整保存。

## 后台静默采集

默认每天北京时间08:00在后台按品牌依次采集。新品牌没有公开排名时会进入首次采集，不需要一直打开页面。点击「更新竞品数据」为当前对比品牌加入后台队列，页面仍可正常使用；同一品牌的进行中任务不会重复提交，5分钟内的重复更新沿用最近任务。

后台读取唯品会公开的销量排序页面及商品规格参数。启用云端登录后使用服务器加密保存的专用唯品会会话，不读取本机浏览器账号；云端未连接时停止并提示登录。每次采集品牌销量榜前50款样本，再逐款核对全部50款的详细材质及季节；榜单可用商品不足50款时保留实际数量，不补造样本，也不宣称覆盖全品牌目录。价格、图片、商品链接和排名先保存，已核对的详情分批补充；新排名中的同款保留上次核对的材质及详情时间。公开页面没有给出成分时显示「未公开」。每品牌每次最多执行20分钟，已有数据始终保留。

商品详情跳转到其他商品或品牌时不写入该详情。单款读取失败会继续核对后续商品，任务标记「部分完成」；连续3款详情无法读取时停止本次详情采集，避免持续请求无效页面。需要验证时立即停止，打开云端登录处理后核验，再按需更新。

页面显示自动采集时间；展开「采集状态」，每张品牌卡片均显示进度条、百分比、已保存榜单款数及详情核对数。待采集或尚未取得榜单为0%；保存榜单后为50%，其余50%按本次详情核对数占实际榜单款数计算，实际不足50款时以实际数量为分母。进度只来自本次服务器已保存的数量，旧样本和等待时间不会增加进度。采集中自动刷新；失败或要求登录、验证时保留已完成进度及具体原因，不显示完成。

卡片区分待采集、采集中、完成、部分完成、未完成、需要登录和需要验证。平台跳转登录页时明确显示「需要登录」，不再统一误报没有有效商品。TOP20下方保留样本范围、数据日期及保存时间；「刷新」只读取已保存的数据。

「采集设置」可暂停自动采集、修改每日时间。暂停后正在进行的任务会继续完成；手动更新仍可使用。遇到验证、访问失败或平台页面变化时，该任务停止并保留上次有效数据及本次已经完成的数据，不绕过验证，不无限重复请求，也不会以空白数据替换样本。可通过「浏览器补充数据」导入正常打开页面上的公开信息，再按需更新。

## 浏览器补充公开商品

1. 点击「采集设置」→「浏览器补充数据」，把「采集唯品会商品」按钮拖到浏览器书签栏。
2. 打开所需品牌页面，在品牌筛选中点击准确品牌，然后选择「销量」排序。向下滚动，让所需商品加载完成。点击采集书签，下载该页商品排名、特卖价、图片和详情链接的 JSON 文件。必须有品牌ID和销量排序才允许作为公开排名导入。第2页及后续页按120款的页面偏移保留原排名；当前一个排名文件作为独立样本，不会自动拼接多页。
3. 逐款打开全部50款样本的商品详情，查看「规格参数」，点击同一书签，下载详细材质、季节和商品编码文件。工具只读取当前页的公开商品字段，不读取账号信息、Cookie或后台接口，不发送网络请求。
4. 回到「导入数据」，选择对应品牌，上传排名文件，核对款数后点击「确认导入」。文件日期不能晚于今天；较旧数据不能覆盖较新的排名。重复商品ID或排名、品牌不一致、非官方商品链接会被拒绝。
5. 选中同一品牌，可一次上传多个详情 JSON 文件补齐材质。只有最新排名样本中的匹配商品会更新，未匹配商品不加入排名。公开销量排名和特卖价保持原样。采集时间与详情核对时间分别保留。
   再次导入公开排名时，相同商品保留已核对的材质、季节和详情时间；较旧的详情不能覆盖新详情。商品材质发生变化时需重新采集详情补充。

登录失效、验证页面、商品尚未加载或平台结构变化时不能采集有效数据；先在唯品会正常处理并打开公开商品，再重新采集。浏览器工具只读取当前页面，不读取账号信息、Cookie或后台接口；处理浏览器中的验证不会保证后台服务器免于平台验证。

「导入数据」仅支持公开排名和商品详情JSON，每个文件最多5MB、5000款商品。公开排名的数据日期不一致时会提示，先更新到相同日期再比较差异。未采集的品牌显示「未采集」。系统不会把公开排名推算成实际销售件数。

同一批文件部分导入失败时，已成功的文件保留；修正失败文件后重新导入。不改变ERP库存、采购和经营分析报表，也不触发付费AI调用。
