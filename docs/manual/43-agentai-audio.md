# AgentAI 语音制作与音色克隆

更新日期：2026-11-18。

## 入口与准备

入口：系统设置 → AI 模型管理 → AgentAI 连接 →「语音制作」。音频型号行也可直接打开。仅同时具有超级管理员角色及经营分析管理权限的账号可使用。

先启用独立 AgentAI 连接、保存 API Key 并同步模型目录；账号须有相应 API 权限及足够余额。当前只提供 MMX 海螺语音 2.8（`speech-2.8`）与豆包语音合成 2.0（`doubao-tts-2.0`）。制作任务及克隆音色按网站账号隔离，不与其他用户共享。

## 合成语音

1. 选择模型和该模型的预置或本人已完成克隆的音色，填写最多 5000 字符的文字。
2. 调整语速、语气；海螺可选 HD 或 Turbo，输出 MP3；豆包可选 MP3 或 WAV。
3. 点击「查看本次价格」。网站使用所选参数向供应商估价，显示账号实付预估、备用渠道费用上界、冻结额及报价有效期。更改文字或参数会使原报价失效。
4. 核对后点击「确认费用并生成语音」。系统创建持久任务，随后显示制作状态。制作中按原供应商任务号查询；可关闭窗口后重新打开继续查看。
5. 已完成任务提供播放与下载。制作任务显示输入字符；AI 模型管理的「AgentAI 语音制作」单独记录供应商返回的真实用量和费用，未回传字段保持未知。报价、冻结额与余额不作为实际消耗。

渠道采用智能调度，综合价格、成功率与耗时并处理可用渠道回退。报价不是保证最终扣费；如果供应商要求按新价重做，网站不自动重复提交。提交结果不明时显示「提交结果待核对」，应查看 AgentAI 调用日志，避免创建重复任务。

## 创建克隆音色

填写音色名称，上传 10～300 秒、20MB 以内的 MP3、M4A 或 WAV 单人清晰录音，可填写最多 300 字符的试听文字。上传前须主动勾选声音使用授权声明：本人拥有录音及声音的合法使用权，已获得声音本人的明确授权，并同意提交供应商创建音色。

点击「确认授权并创建音色」后创建克隆任务，网站记录授权版本与任务归属。克隆与试听按供应商规则计费。任务完成后，该音色出现在本人海螺语音 2.8 的音色选项中。「同步音色」只核对本人在本网站创建的音色，不导入共享供应商账号中其他人的音色。录音时长与可克隆性仍以供应商校验为准。

## 状态与常见问题

- **连接未就绪**：在 AgentAI 连接中保存密钥、启用并同步目录；保存不等于模型已生成验证。
- **报价过期或参数调整**：重新查看价格并核对参数，不沿用过期报价。
- **HTTP 401/403**：核对密钥、模型范围与 API 权限；**402**：核对余额及整单冻结额度。
- **任务较久**：点击「核对进度」查询同一任务，不会再次生成。供应商结果不明确时保留任务状态，网站不自动充值或盲目重提。
- **提交前校验失败且任务未创建**：本次尚未发起供应商生成；处理提示后重新核对价格。已经显示任务号或“提交结果待核对”的情况应先查原任务，避免重复生成。
- **换密钥后找不到旧音色**：音色按本人及密钥归属隔离，同一密钥重新保存仍保留本人音色，换密钥后需核对相应账号；已提交任务仍使用原凭据查询，已失效凭据可能无法取回供应商结果。

语音制作是独立功能，不修改小序实时通话、听写或分段朗读的现有配置。
