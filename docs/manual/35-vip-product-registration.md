# 唯品会商品建档

更新日期：2026-10-21。入口：商品档案、选款登记或项目协作表格 → 顶部「工具箱」→ 一级菜单「唯品会商品建档」。点击后打开建档面板，关闭面板返回工具箱菜单。

## 准备资料

需要当前表格查看权限及商品查看权限。生成和下载不要求商品编辑或创建权限；维护共用颜色、尺码代码仍需商品编辑权限。

先保存款式资料和字段设置，再勾选款式行，或选中款号单元格（可拖选多行）。勾选行优先于单元格选区，只处理当前筛选结果中的选中行；未选择或仅选择整列时不会自动生成全表。一次最多 500 款，颜色与尺码展开后最多 50,000 条。

必需字段为序缇款号、标准颜色、尺码范围、三级类目；三级品类、三级分类也可识别为三级类目。每个标准颜色和尺码都须在工具箱「颜色尺码映射」中有唯一启用的三位代码，色码 044 已作废。F/均码、XXL/2XL 等常用尺码别名可匹配代码；自定义尺码仍保留原表中的尺码名称。

长标题、供应商颜色及吊牌价按表格中有权查看的资料填写。缺失或无查看权限时留空并提示，请在导入唯品会前补齐平台要求的内容。多个同名来源字段不能任意选取，须先调整字段名称。

## 生成、预览和下载

1. 在原表格选择款式，打开「工具箱 → 唯品会商品建档」。系统读取所选款式的已保存资料；「重新读取选中款号」可重读并清除旧预览及临时对应。
2. 在「颜色对应」核对标准颜色和供应商颜色。两列数量相同时按当前顺序对应；数量不同时，为每个标准颜色选择对应的供应商颜色。供应商颜色整列为空或无查看权限时留空并提示。
3. 点击「生成建档资料」。预览按每款的标准颜色 × 尺码展开，可横向滚动查看全部 29 列、分页查看全部商品行。
4. 修正提示中的错误后重新生成。缺少必需字段或映射、映射不唯一、款号或条形码重复、金额格式无效、供应商颜色未对应时，整批不能下载。可展开查看其他字段的留空提示。
5. 点击「下载 Excel」，下载 `唯品会商品建档_日期.xls`。下载前会重读所选资料和映射；资料、查看权限或映射变化时须重新生成，旧预览不能直接导出。

颜色对应调整仅用于本次文件，不保存到原表。关闭面板、切换功能或刷新页面不保留预览及临时调整。如需补齐映射，关闭建档面板返回工具箱，进入「颜色尺码映射」维护后再生成。

预览表中的款号、款式编码、供应商款式编码、货号、商品编码或条形码（按本模板实际列显示）可通过旁边的复制图标单独复制，保留完整文本及前导零；复制不影响 Excel 导出内容。（2026-10-21）

## 模板规则

文件使用与提供模板一致的 Excel `.xls` 格式，仅有「商品资料」工作表，保留 A 至 AC 共 29 列及原表头顺序。首行为表头，之后为生成的数据；不包含模板的规则行、填写示例及未选中的款式。款号、货号和条形码按文本保存，前导零不会丢失。

| 模板列 | 取值规则 |
| --- | --- |
| 品牌名称 | 默认「序缇」 |
| 款号 | 序缇款号 |
| 货号 | 序缇款号 + 三位标准色码 |
| 条形码 | 序缇款号 + 三位标准色码 + 三位尺码码 |
| 商品名称 | 长标题 |
| 商品类目 | 三级类目字段；关联类目取名称 |
| 自定义尺码 | 尺码范围中本条对应的尺码名称 |
| 自定义颜色 | 本标准颜色对应的供应商颜色 |
| 市场价 | 吊牌价，按数值保存，显示两位小数；不是唯品价或唯品吊牌限价 |
| 商品类别 | 默认「普通商品」 |

副标题、标准尺码、标准颜色、产地、配件备注、重量(g)、毛重(g)、是否易碎品、是否大件、是否贵重品、是否美妆、洗涤说明、关键字、特点描述、是否原箱发货、带包装长/宽/高/重量按模板规则留空。标准颜色用于查找编码，但不写入模板中的「标准颜色」列。模板未要求计算上、下装号型，因此不会增加号型选择。

## 权限、保存效果与常见问题

读取当前用户有权查看的已登记字段，包括暂未显示在当前字段分组中的字段。禁止查看的单元格、无权查看的私有字段、已删除字段不会进入导出文件；必需字段无权查看时不能生成。权限改变后，旧颜色对应不能恢复已不可见的供应商颜色。

生成、调整颜色对应及下载只产生文件，不改写原表格、不创建系统商品或库存、不进入表格撤销历史。此功能不调用唯品会建档 API，也不自动上传文件；下载后需自行在唯品会平台核对、补齐并导入，最终以平台校验结果为准。

- 没有选中款号：关闭工具箱，勾选款式行或选择款号单元格，再打开功能。
- 提示先保存：等待自动保存完成，处理未保存资料或字段冲突后重试。
- 缺少或歧义映射：维护唯一启用的三位代码；停用和作废代码不能使用。
- 吊牌价无效：填写非负金额，最多两位小数。金额 0 与空白分别保存，不会互相替代。
- 超出条数或文字长度限制：分批选择；单个字段不得超过 Excel 的 32,767 字符限制。
- 资料或权限变化：核对最新资料及颜色对应后重新生成。
- 网络或导出组件加载失败：重试；必要时刷新页面后重新选择并生成。失败不会向平台提交资料。
