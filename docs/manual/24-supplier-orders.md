# 订单中心（供应商）

更新日期：2026-09-17。入口：供应链端 → 订单中心。入驻审核通过的供应商可查看本人订单和售后，不可查看其他供应商的订单。

## 接单配货

1. 顶部「订单中心」角标和列表「新消息」提示序缇推送的采买清单及售后动态。在线页面约每15秒刷新，可手动刷新。
2. 打开订单核对款号、颜色、尺码、数量、供货价、要求送达日期、收货信息及配货要求，按需导出清单。
3. 点击「接单并开始配货」，按清单准备整单产品。采购数量已占用库存；库存维护不得低于未发货订单占用量，也不能移除被占用的颜色尺码。如确实无法供货，联系序缇内部人员取消未发货订单并释放占用。

## 发货与完结

配齐整单后点击「完成配货 / 发货」，确认款号、颜色、尺码与数量均已核对，选择配送方式。当前按整单发货登记，一单一个配送方式、一个快递单号。

- **送货上门**：提交发货后状态为已发货；实际送到后点击「反馈已送达并完结」，填写送达与交接说明。提交即推送序缇并完结。
- **发快递**：选择快递公司，填写6至32位有效字母/数字单号，提交后为已发货。系统接入物流服务后每小时查询，签收才自动完结；运输异常、查询失败、退签等不算送达。单号或快递公司填错，可在完结前点击「更正快递信息」并填写原因，更正后跟踪新单号。

发货时系统自动扣减产品库存，不要再次手动减掉同一订单数量。重复提交或已失效的订单版本会被拦截。发货后订单不能取消；交易成功后由序缇发起售后申请。

当前未配置物流查询服务账号时，快递订单明确显示「待接入物流查询」，不会自动或手动冒充签收。配置生效后，未完结快递订单会自动继续查询。

订单变动会反馈双方后台，详情中的订单动态保留处理记录。读完可点击「标为已读」。

## 处理退货退款 / 换货

在订单详情的「退货退款 / 换货」查看申请类型、原因、颜色尺码、数量及原成交价格。序缇可申请部分或整单数量。仅序缇内部可以发起申请及最终确认完成。

1. 待处理申请可「同意并填写退货地址」，需填写收件人、有效手机号、完整地址和处理说明；不同意可「驳回申请」并反馈原因。
2. 序缇登记退回商品后，查看退回配送信息。实际收到并核对商品后「确认退货已收到」，填写说明。
3. 退货退款由序缇确认处理完成；完成前货款不扣减，完成后按原成交价格与数量在对账中心扣减。
4. 换货收到原商品后，按原款号、颜色和尺码补发，点击「登记换货发出」填写配送方式及信息。序缇确认收到合格换货商品后完成，货款不扣减。

售后数量不能超过尚可申请数量，已完成退款的数量不能重复申请。已驳回或退回前已撤销的申请释放数量。售后状态变化会提示序缇；已完成记录不能撤回。退回与补发库存需供应商检查商品品质后维护，本流程不自动调整可售库存，也不执行银行转账。

账款汇总与导出入口为「供应链端 → 对账中心」。
