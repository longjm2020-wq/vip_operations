# 对账中心（序缇内部）

更新日期：2026-09-17。入口：供应链端 → 对账中心。需要「供应链对账与账单导出」权限，管理员、超级管理员、供应链负责人默认具备。可单独授予财务等角色；查看原订单另需供应链采买权限。

## 自动记账规则

- 订单交易成功（已送达完结）时，按该订单成交含税货款记为正数，可纳入应结货款。未发货、运输中、已取消订单不记入应结货款。
- 退货退款申请本身不扣款。供应商确认退货收到、序缇确认退款处理完成后，按原成交单价乘退货数量记为负数，自动扣减应结货款。
- 换货经双方处理完成后记录为0元，不扣货款。
- 记账日期使用北京时间，以交易成功、退款完成或换货完成时点为准。跨月退款扣在退款完成月份，不重写原成交月份。历史已成功订单在功能上线时补入对应成交日期。
- 本期应结货款 = 本期交易成功货款 − 本期退款扣减。跨期退款可能使本期金额为负数，需要与供应商核对抵扣；这里不代表已经完成银行付款。

## 查看与导出

1. 选择按月、按季度、按年或自定义日期；周期包含开始、结束日期的全天。
2. 可筛选全部或指定供应商，以及交易成功、退货退款完成、换货完成等事项。顶部汇总和下方明细应用相同筛选。
3. 明细展示记账时间、订单号、供应商、售后单号、交易事项、数量和货款变动。拥有订单查看权限时，可点击订单号核对清单和售后处理记录。
4. 点击「导出本期账单」，下载Excel。导出整个筛选结果，包含汇总和全部分页明细；金额按原始精度保留两位小数，避免银行或订单编号丢失精度。

在线页面约每15秒刷新，也可手动刷新。退款尚未完成时不会出现在退款扣减中；快递尚未查询到签收的订单不计入成交货款。账单为追加记录，不能手工编辑或删除。重复提交和重复签收通知不会重复记账。

首次使用先在订单中心配置固定收货信息。若看不到菜单，检查角色是否已勾选对账权限；账单为空时检查供应商、日期和交易事项筛选。
