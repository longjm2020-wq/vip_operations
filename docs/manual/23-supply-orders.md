# 订单中心（序缇内部）

更新日期：2026-10-04。入口：供应链端 → 订单中心。需要「供应链采买、订单售后与收货设置」权限；从产品库选择产品还需供应链产品管理权限。

「搜索订单号或供应商」位于顶部导航栏，输入后按回车或点击搜索图标查询当前订单范围；状态等筛选继续在列表上方设置。

## 固定收货信息

负责人先点击「收货设置」，填写统一收货人、手机号及完整地址。所有新订单使用该信息；未配置时不能下单。更改地址仅影响新订单，已下单的收货信息保持原样。

## 从产品库下单

1. 在供应链产品库选择供应商。点击单款「采买」，或勾选多款后点击「采买已选产品」。一张清单对应一个供应商，最多100款、200条颜色尺码明细。
2. 只可采购已上架、已确认库存且颜色图完整的产品。按颜色和尺码填写正整数数量，可采购量是供应商当前库存扣除未发货订单占用量。
3. 检查含税供货单价、合计数量、金额及固定收货地址；填写要求送达日期及配货、发货要求。
4. 点击「下单并推送供应商」，系统生成订单号并向对应供应商后台推送采买清单。订单保存当时的产品名称、款号、价格、数量、地址及要求；后续产品修改不改变历史清单。

下单会占用供应商库存，供应商发货时才实际扣减。并发下单、超出可采购量、产品下架或版本变化会拒绝提交；重新打开清单核对最新数据再下单。取消未发货订单需要说明原因，取消后释放库存占用。已发货或完结订单不能取消。

## 跟进交付

订单按待接单配货、配货中、已发货、已送达完结、已取消分类，可搜索订单号和供应商。顶部「订单中心」角标及列表「新消息」提示新订单动态，在线页面约每15秒刷新；不发送短信或微信。详情可查看供应商反馈、配送方式、快递单号、物流轨迹，导出整张采买清单，或点击「标为已读」。可按进行中售后、退货退款或换货筛选订单。

尚未关联内部 SKU 的旧订单，保留供应商送货上门反馈及快递物流签收方式。关联内部 SKU 的订单，无需物流配送由接收方核验四位发货码，供应商不能代替核销；快递真实签收仅表示包裹送达。库存收货人员还需逐 SKU 盘点质检、合格暂存和正式入库。未配置物流查询或查询失败时明确提示，接入后后台每小时查询；关联包裹可由有到货编辑权限的接收方凭实际签收说明人工确认，系统记录操作者。未签收包裹可更正快递信息并填写原因。

## 关联库存与质检反馈

打开订单，在详情点击「关联内部 SKU 并接入库存」，选择内部供应商档案与预计收货仓，并逐项核对内部 SKU 的款式、颜色、尺码。需要供应链采买及采购新建权限；关联创建对应的已确认 ERP 采购单，每个内部 SKU 只允许对应一条明细，不能重复关联。不新建 SKU、不因关联增加库存。已发货历史订单可关联，保持其包裹已发货/送达事实，仍需质检后入库。

关联后供应商首次整单发货自动生成库存采购配送包裹，实际发出才计在途。接收方在详情「SKU 配送与质检跟踪」或库存管理处理交接和盘点；漏发、错发、破损、瑕疵、污渍、品质问题分别反馈订单动态。合格数量暂存进货仓并由有过账权限人员正式入库，问题件不记仓库库存，供应商可按剩余采购数量独立安排补发并重新选配送方式。

未发货供应链订单取消会同时关闭关联内部采购单。已送达完结仍只是配送完成，不表示所有 SKU 合格入库。质检反馈不自动退款，退货退款与换货流程仍需单独核对；涉及已经入库实物的售后不自动调整内部库存。

## 退货退款与换货

1. 打开交易成功（已送达完结）的订单，在「退货退款 / 换货」点击「申请退货退款」或「申请换货」。未发货订单使用取消订单；运输中订单先完成交付核对。
2. 按原款号、颜色、尺码填写申请数量和原因，支持部分数量或整单申请。可申请量扣除退款完成及正在处理的售后数量，防止重复退款；金额按原成交含税单价计算，不能手工改价。换货限原款、原颜色、原尺码，不扣货款。
3. 提交后推送供应商。同意后提供退货收件人、手机号和完整地址；驳回时说明原因，可核对后重新申请。
4. 供应商同意后，序缇点击「登记退回商品」，填写送货上门或快递公司、单号及说明。退回前可撤销，退回后不可撤销。供应商收到后点击确认收货。
5. 退货退款：供应商确认收货后，序缇核实退款事项已处理完毕，再「确认退款完成并扣款」。系统自动在完成当期扣减应结货款，不能重复扣减或撤回已完成记录。
6. 换货：供应商确认收货后登记换货发出及配送信息；序缇实际收到补发商品并核对后「确认换货收妥」。账单保留换货记录，货款变动为0。

申请、驳回、同意、退回、收货及完成均记录在订单动态并提示对方。售后运输信息用于双方交接，不会凭填写单号自动确认收到。退回商品不自动补入可售库存，需供应商检查品质后按库存维护流程处理。

订单交易成功后自动进入「对账中心」，退款完成时扣款，换货不扣款。库存关联与正式入库不执行银行转账、不改变原成交金额；未关联的订单不会进入内部库存。内部库存以实际正式入库及库存流水为准。
