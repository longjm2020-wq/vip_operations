# 供应链采购订单

更新日期：2026-09-17。入口：供应链端 → 供应链采购订单。需要「供应链采买、订单跟进与收货设置」权限；从产品库选择产品还需供应链产品管理权限。

## 固定收货信息

负责人先点击「收货设置」，填写统一收货人、手机号及完整地址。所有新订单使用该信息；未配置时不能下单。更改地址仅影响新订单，已下单的收货信息保持原样。

## 从产品库下单

1. 在供应链产品库选择供应商。点击单款「采买」，或勾选多款后点击「采买已选产品」。一张清单对应一个供应商，最多100款、200条颜色尺码明细。
2. 只可采购已上架、已确认库存且颜色图完整的产品。按颜色和尺码填写正整数数量，可采购量是供应商当前库存扣除未发货订单占用量。
3. 检查含税供货单价、合计数量、金额及固定收货地址；填写要求送达日期及配货、发货要求。
4. 点击「下单并推送供应商」，系统生成订单号并向对应供应商后台推送采买清单。订单保存当时的产品名称、款号、价格、数量、地址及要求；后续产品修改不改变历史清单。

下单会占用供应商库存，供应商发货时才实际扣减。并发下单、超出可采购量、产品下架或版本变化会拒绝提交；重新打开清单核对最新数据再下单。取消未发货订单需要说明原因，取消后释放库存占用。已发货或完结订单不能取消。

## 跟进交付

订单按待接单配货、配货中、已发货、已送达完结、已取消分类，可搜索订单号和供应商。顶部「采购订单」角标及列表「新消息」提示新订单动态，在线页面约每15秒刷新；不发送短信或微信。详情可查看供应商反馈、配送方式、快递单号、物流轨迹，导出整张采买清单，或点击「标为已读」。

送货上门订单由供应商反馈送达说明后完结。快递订单仅在物流服务返回签收后自动完结，填写快递单号不等于已签收。当前未配置物流查询账号时显示「待接入物流查询」，保持已发货；接入后后台每小时查询，失败或未签收继续重试。供应商可在签收前更正错误的快递公司和单号并填写原因。

供应链采购订单用于供应商协作，暂不自动生成ERP采购单、内部SKU或入库记录，也不执行支付或财务结算。ERP库存仍按其入库流程登记。
