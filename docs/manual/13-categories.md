# 品类

更新日期：2026-09-16。入口：ERP系统 → 品类。

## 操作步骤

1. 点击「初始化女装三级品类」可清空未被商品使用的旧品类，并建立女装、服饰配件、女上装、女下装和裙装等三级模板。该操作不会删除商品、SKU、库存或采购数据；已有商品关联品类时系统会拒绝执行。
2. 单条新建时填写品类编码和名称。一级品类不选上级；二级选择一级；三级选择二级。系统最多允许三级，不能循环引用。
3. 表格编辑或 Excel 导入使用「上级品类编码」关联父级。按一级、二级、三级的顺序排列行并保存，父级编码需已经存在或排在子级之前。
4. 商品建档只显示末级品类，并以「一级 / 二级 / 三级」完整路径展示；未设置下级的旧品类仍可继续作为末级使用。

同名品类请用编码区分。停用的品类不能用作新建上级或商品品类。唯品会品类属于平台字典，同步不会自动改写内部品类设置。
