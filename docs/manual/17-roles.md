# 角色权限

更新日期：2026-09-16。入口：系统设置 → 角色权限。

## 操作步骤

1. 打开角色记录或新建角色，填写角色代码、角色名称。
2. 选择岗位所需权限并保存。
3. 在用户管理中将角色分配给对应用户，核对其可见菜单和可操作按钮。

权限由服务端检查，角色变化在后续请求生效。查看权限和修改、确认、过账权限不同，不应为方便查看而授予全部管理权限。表格仅用于角色名称编辑，权限分配使用角色编辑入口。

项目除角色权限外还受项目成员关系限制；有项目菜单权限不代表能访问所有人的草稿。


## 超级管理员

系统内置 SUPER_ADMIN（超级管理员）角色，包含全部系统权限，权限列表不可手动修改。只有超级管理员可以编辑、删除管理员角色。仍有用户使用的角色不可删除，需先调整用户角色。新增角色不会自动分配给任何用户；超级管理员的分配与账号管理仅限超级管理员操作，首个超级管理员需由系统部署维护人员按授权配置。系统至少保留一名正常状态的管理员或超级管理员；首个超级管理员配置后，不允许停用或移除最后一名可用超级管理员。新权限随版本的初始化更新补充到内置角色。

权限按业务模块显示为中文勾选列表，支持逐项勾选、模块全选和全部取消；修改后点击保存才生效。无编辑权限时显示“查看权限”；超级管理员角色始终只读，管理员角色仅超级管理员可修改。取消全部权限后，该角色不再授予操作或查看权限；账号同时拥有其他角色时仍合并其权限。
