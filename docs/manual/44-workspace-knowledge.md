# 公司知识库与知识图谱

更新日期为 2026-11-25。在「我的工作台」场景左上方，「AI 员工」下的「公司知识库」卡片显示当前账号已保存的笔记总数。默认打开的「笔记列表」按更新时间列出最近的最多三篇，点击标题可在右栏阅读当前版本。点击卡片上的「＋」新建笔记，填写后点击「保存笔记」，卡片上的总数和列表会随之更新。

点「知识图谱」可在卡片内查看最多四篇笔记和两位获授权的在职员工。图中优先展示有引用或员工授权的笔记，有空位时再补入最近更新的笔记。超出预览范围时，图下会列出已显示的数量和总数。实线箭头表示笔记引用，虚线表示员工的阅读授权。

点击笔记节点可在右栏阅读当前版本。点击员工节点，卡片会列出这位员工有权阅读的图中笔记，点击标题即可打开。点「笔记列表」返回最近更新的笔记。窄屏也可切换这两个视图，上下滚动卡片组可看到下方内容。

点击卡片右上角的「打开」即可查看完整知识图谱。场景右侧的「更多工作台工具 → 公司知识库」、员工配置里的「技能与知识」和 `/my-workspace?assistant=knowledge` 也可进入完整知识库。卡片和右栏使用同一套笔记，均需要小序使用权限。

## 在多台电脑上维护笔记

用同一网站账号登录，可以查看保存在服务器上的同一套笔记。每个账号分别管理自己的笔记及 AI 员工。打开页面需要联网。导入本地文件只读取本次选中的文件，不会连接本机目录或启用 Obsidian 自动同步。

1. 点击「新建笔记」填写标题和 Markdown 正文；也可以点「导入 Markdown」，选取一篇 UTF-8 的 `.md` 或 `.markdown` 文件，将文件名和正文载入草稿。
2. 在「可读取此笔记的 AI 员工」中选择在职员工，每篇最多可授权 120 位。留空时仅自己可读。点击「保存笔记」后版本和授权才生效。标题最多 160 字符，正文最多 1000000 字符。
3. 打开笔记可阅读正文、编辑并再次保存。页面显示版本和更新时间；有多个版本时，可用「上一版」「下一版」核对资料。点击「复制版本链接」，在另一台电脑登录同一账号后打开，即可查阅当前选中的这一版。当前授权决定员工后续检索能读到哪些笔记。
4. 两台电脑同时编辑同一版本时，较晚保存的一方会看到冲突提示，未提交的草稿保留。点击「查看线上版本」，核对正文和员工权限后再编辑保存；需要保留两份时可以将草稿转为新笔记。
5. 在当前版本点击删除按钮并确认，会删除笔记及历史版本。之前指向它的任务引用将不能再打开。

## 阅读知识图谱

在右栏打开完整知识库时，默认的「知识图谱」显示笔记之间的引用，以及在职员工获得的笔记授权。

- 在正文中输入 `[[商品规范]]` 或 `[[商品规范#尺码|尺码要求]]` 并保存。当本账号下存在唯一对应标题时，图谱会从当前笔记向被引用的笔记画出实线箭头。没有对应笔记、存在重名或写在代码示例中的内容不会产生这条连线。
- 圆形节点代表笔记，点击打开正文。菱形节点代表获授权的员工，虚线连接其可读笔记。点击员工可突出关联线并查看可打开的笔记清单。图中关系来自已保存的引用和授权。
- 在「定位笔记或员工」中搜索节点，可以将其移至画布中央并突出关联。拖动空白处平移，使用加减按钮缩放，「图谱全览」回到完整视图。通过键盘聚焦节点后可按 Enter 或空格打开。切换至「笔记列表」可按标题或当前正文中的文字搜索。

## 让 AI 员工引用资料

先把相关笔记授权给具体员工，再到此员工窗口交办任务。例如，在《商品上新规范》中写入「尺码表必须标明测量单位」，授权质检员，然后让质检员「按商品上新规范检查这份尺码表」。执行时按任务文字从有权读取的当前笔记中查找相关章节。查看任务产物中的知识库来源，可打开当次引用的版本；之后修订正文仍可回查原版本。

来源区分执行或验收时实际引用的笔记，以及仅供查阅的笔记。检索与绘图本身不调用模型。与任务匹配的笔记片段会交给处理该步骤的工作模型。协作任务仍按工作流共享交付成果和来源。取消授权后，该员工后续检索会按新权限处理；已经交付的报告和之前已经发出的模型请求不会被撤回。此授权仅用于读取资料，操作电脑仍需单独指定设备并授权。

## 常见问题

- **卡片里找不到某篇笔记。** 小卡片仅显示部分笔记。点击「打开」，再切换到右栏的「笔记列表」，可按标题或当前正文搜索全部笔记。「暂无笔记」表示当前账号的知识库为空。加载失败时点击「重试」重新读取。
- **换电脑后看不到笔记。** 核对登录账号，以及笔记是否已点击保存。导入文件后关闭未保存的草稿不会创建版本。
- **两篇笔记没有连线。** 打开引用方笔记，核对双中括号中的目标标题和重名情况，保存后重新查看图谱。修改目标标题后也需更新引用文字。
- **员工没有引用预期规范。** 核对本篇笔记授权的员工、员工是否在职，以及任务是否提到了资料中的业务词或章节。只打开图谱或选中节点不会派发任务。
