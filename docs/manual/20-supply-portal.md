# 供应商后台

更新日期：2026-09-17。入口：供应链端 → 企业资质管理 / 供应商产品库。

## 邀请注册与入驻

1. 向序缇供应链负责人索取邀请码，打开 `/supply/register`。填写有效邀请码、用户名、联系人姓名和至少12位密码。
2. 登录后填写企业资质。商务与财务联系各自通过下拉列表单选邮箱、微信或钉钉，再填写对应内容；提交时仅保存所选方式。历史多项联系方式仍可在已生效资料中查看，重新编辑保存时改为单选；其余标星项目必填。银行卡户名、账号、完整开户支行均需填写。
3. 身份证正反面和营业执照上传原件实拍照片；复印件需加盖红色公章，由负责人核验。支持电脑选择、手机相册和拍摄，JPG、PNG、WebP，自动压缩至每张1 MB以下，上传后请核对证件文字清晰度。上传完成后需保存或提交资料。
4. 可保存草稿继续填写，完整后提交审核。审核期间不能修改。驳回原因显示在资质页面，按原因修改后重新提交。
5. 审核通过才能使用产品库。后续修改仍需提交审核；等待审核或被驳回时，原生效资料继续保留。

收款信息分为开户银行和开户支行。先选择或输入开户银行，再用地区、支行名称搜索系统已有的生效支行资料；没有匹配时可输入完整开户支行。暂未接入全国银行网点库、账号归属行识别或户名与账号核验服务，页面明确显示「银行账户待核验」。对公收款户名与入驻公司名称不同会提醒核对，该提示仅为名称比较，不能证明户名与账号是否匹配。请按银行提供的信息填写，由负责人审核。

## 产品与库存

1. 新增产品，或通过“表格批量上传”下载模板、导入 Excel、逐行添加。款号在本供应商内唯一；名称最多30个汉字或60个字符。价格可以为零但不能为空。
2. 颜色输入后回车添加，尺码支持多选及自定义。导入时颜色、尺码用中文或英文分号分隔。
3. 产品导入后先处于下架状态。点击“维护库存”，按颜色行、尺码列填写数量，每种颜色必须上传颜色图。库存为非负整数，自动汇总颜色库存和总库存。修改颜色、尺码后需重新确认库存。
4. 图片和库存补齐后点击上架，表示该款可上线售卖。下架必须选择原因；其他原因需填写说明。供应商不能修改序缇款号。
5. 搜索支持单个或多个完整款号，以中文或英文分号分隔，可搜索供应商款号及序缇款号。列表按上架、下架筛选。
6. 勾选后可导出已选产品，也可导出筛选结果或全部产品。库存支持按款、颜色、尺码及颜色尺码明细导出。产品资料中的图片导出为需要登录授权的图片链接。

各供应商资料、产品和附件相互隔离。并发编辑出现版本冲突时，刷新核对最新资料后重新操作。邀请码失效请向负责人索取新码；不完整图片、证件和库存不能用重复提交绕过校验。

点击列表的“产品详情”，从右侧展开详情卡片，查看自动编号、序缇款号、产品图、名称、材质、含税及不含税供货价、颜色、尺码、上下架状态、库存明细和产品卖点。库存明细按颜色、尺码展示，并汇总颜色库存及总库存。

产品卖点不单独占用列表列，保留在详情卡片及编辑表单中，为非必填，最多1000个汉字；表格导入及产品资料导出也包含此字段。

## 证件识别与输入校验

上传身份证正面后识别身份证号与姓名，上传营业执照后识别统一社会信用代码、公司名称与法定代表人。系统在浏览器本地识别，首次加载本系统识别资源，不向第三方OCR服务传送证件图片。支持旋转照片识别；清晰完整且文字占画面较大的照片更易识别。办公地址可能不同于证件地址，不自动替换。

打开资质编辑时，已上传的证件也会自动识别，无需重新上传。唯一识别结果只回填空白字段；已有填写与图片结果不一致时，字段旁及识别结果区持续提示，点击「采用识别值」可更新。继续修改输入时会重新比对；两张证件姓名不同会分别提示。号码须通过格式和校验位检查，无法可靠识别的字段明确提示，不视为信息一致。识别中暂停保存及提交，关闭卡片会取消识别。

可点击「重新识别已上传证件」重试；查看生效资料或审核资料时点击「识别并核对证件」，仅核对，不修改已保存内容。识别失败或不准确时请核对原件，结果不代表证件真实性认证。

身份证号检查位数、地区前缀、出生日期、顺序码和校验位；统一社会信用代码检查字符集合和校验位。名称、联系人、地址不能仅填数字或符号，办公地址需至少6个字符；手机号、邮箱、银行账号等按字段格式提示。离开输入框时显示具体错误，提交时前后端再次校验。可保留未完成草稿。校验与识别不等于证件真实性、企业资质或银行账户真实性核验，仍需负责人审核原件。

企业资质编辑、审核及产品详情均采用宽屏侧栏；手机按屏幕宽度自适应。公开注册页采用品牌与入驻流程介绍、注册表单分区展示，邀请码规则不变。

注册页品牌区采用静音循环视频，不显示播放或暂停按钮；手机小屏默认显示静态封面。系统设置减少动态效果时默认不自动播放。

产品库在「颜色」前显示「翻单周期（天）」，新增、编辑和批量上传均必填非负整数（不能留空或填写小数）。产品详情及产品资料导出也包含该字段，模板中列顺序相同。旧产品缺失时显示「待补充」，不自动填写数值；编辑保存或重新上架前补齐。旧产品维护库存时会先进入编辑产品补充周期，再继续维护库存。周期统一以天计，填写非负整数天数。
