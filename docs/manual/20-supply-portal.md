# 供应商后台

更新日期：2026-09-16。入口：供应链端 → 企业资质管理 / 供应商产品库。

## 邀请注册与入驻

1. 向序缇供应链负责人索取邀请码，打开 `/supply/register`。填写有效邀请码、用户名、联系人姓名和至少12位密码。
2. 登录后填写企业资质。商务与财务联系各自至少填写邮箱、微信、钉钉中的一项；其余标星项目必填。银行卡户名、账号、完整开户支行均需填写。
3. 身份证正反面和营业执照上传原件实拍照片；复印件需加盖红色公章，由负责人核验。支持电脑选择、手机相册和拍摄，JPG、PNG、WebP，自动压缩至每张1 MB以下，上传后请核对证件文字清晰度。上传完成后需保存或提交资料。
4. 可保存草稿继续填写，完整后提交审核。审核期间不能修改。驳回原因显示在资质页面，按原因修改后重新提交。
5. 审核通过才能使用产品库。后续修改仍需提交审核；等待审核或被驳回时，原生效资料继续保留。

开户行输入支持常用银行名称及系统已生效开户支行的精确/模糊匹配，也可直接输入完整开户支行；当前不连接银行网点数据库，也不核验账号归属，请按银行提供的信息准确填写。

## 产品与库存

1. 新增产品，或通过“表格批量上传”下载模板、导入 Excel、逐行添加。款号在本供应商内唯一；名称最多30个汉字或60个字符。价格可以为零但不能为空。
2. 颜色输入后回车添加，尺码支持多选及自定义。导入时颜色、尺码用中文或英文分号分隔。
3. 产品导入后先处于下架状态。点击“维护库存”，按颜色行、尺码列填写数量，每种颜色必须上传颜色图。库存为非负整数，自动汇总颜色库存和总库存。修改颜色、尺码后需重新确认库存。
4. 图片和库存补齐后点击上架，表示该款可上线售卖。下架必须选择原因；其他原因需填写说明。供应商不能修改序缇款号。
5. 搜索支持单个或多个完整款号，以中文或英文分号分隔，可搜索供应商款号及序缇款号。列表按上架、下架筛选。
6. 勾选后可导出已选产品，也可导出筛选结果或全部产品。库存支持按款、颜色、尺码及颜色尺码明细导出。产品资料中的图片导出为需要登录授权的图片链接。

各供应商资料、产品和附件相互隔离。并发编辑出现版本冲突时，刷新核对最新资料后重新操作。邀请码失效请向负责人索取新码；不完整图片、证件和库存不能用重复提交绕过校验。

点击列表的“产品详情”，从右侧展开详情卡片，查看自动编号、序缇款号、产品图、名称、材质、含税及不含税供货价、颜色、尺码、上下架状态、库存明细和产品卖点。库存明细按颜色、尺码展示，并汇总颜色库存及总库存。

产品卖点不单独占用列表列，保留在详情卡片及编辑表单中，为非必填，最多1000个汉字；表格导入及产品资料导出也包含此字段。
