# SKU 资料

更新日期：2026-10-05。入口：运营中心 → 唯品会工作区 → 商品档案 → 商品详情 → SKU。库存管理中的「SKU 资料」页签及原独立 SKU 管理导航已移除。

商品详情切换到「SKU」页签后，顶部导航栏显示「搜索编码或名称」。输入后按回车或点击搜索图标查询该商品的规格资料；切换其他页签时收起此搜索框，返回 SKU 页签保留原搜索条件。

## 用途

SKU 表示具体颜色、尺码的商品规格，是采购和库存操作的基础。先建立商品档案和颜色尺码映射。

2026-10-05 商品档案已按确认重置，原 SKU 资料一并清空。重新保存商品档案后，从该行「↗」打开商品详情，再建立对应颜色、尺码的 SKU；录入 SKU 后仍需另外登记实际库存。

## 操作步骤

1. 新建资料，选择所属商品。
2. 填写 SKU 编码，按需填写条码，选择颜色代码、尺码代码并核对颜色名称与尺码名称。
3. 按需填写采购成本及状态，保存。
4. 多个规格可通过表格批量新增或编辑，先检查编码和关联资料再保存。

## 常见问题

颜色名称相似时请核对代码，条码及代码中的前导零不得丢失。保存 SKU 不会增加库存；到货走采购入库，期初或盘点差异走库存调整。出现重复编码或条码时先搜索已有记录，不要随意修改编码来绕过校验。
