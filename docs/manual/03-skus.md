# SKU 管理

更新日期：2026-09-16。入口：ERP系统 → SKU 管理。

## 用途

SKU 表示具体颜色、尺码的商品规格，是采购和库存操作的基础。先建立商品档案和颜色尺码映射。

## 操作步骤

1. 新建资料，选择所属商品。
2. 填写 SKU 编码，按需填写条码，选择颜色代码、尺码代码并核对颜色名称与尺码名称。
3. 按需填写采购成本及状态，保存。
4. 多个规格可通过表格批量新增或编辑，先检查编码和关联资料再保存。

## 常见问题

颜色名称相似时请核对代码，条码及代码中的前导零不得丢失。保存 SKU 不会增加库存；到货走采购入库，期初或盘点差异走库存调整。出现重复编码或条码时先搜索已有记录，不要随意修改编码来绕过校验。
