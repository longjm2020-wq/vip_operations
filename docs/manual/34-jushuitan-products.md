# 聚水潭商品建档

更新日期：2026-10-21。入口：商品档案、选款登记或项目协作表格 → 顶部「工具箱」 → 一级菜单「聚水潭商品建档」。工具栏入口显示图标和“工具箱”文字；点击菜单后打开独立侧边面板，关闭功能面板返回工具箱菜单。

## 准备资料

需要当前表格查看权限及商品查看权限。生成和下载不要求商品编辑或创建权限；修改共用颜色、尺码映射仍需商品编辑权限。

先保存所选行及字段设置，再勾选款式行，或选中款号单元格（可拖选多行）。勾选行优先于单元格选区，只处理当前筛选结果中的选中行；仅选择整列或未选择时不会自动处理全表。一次最多 500 款，展开后最多 50,000 条商品资料。

必需资料为序缇款号、标准颜色、尺码范围、三级类目。三级品类、三级分类也可识别为三级类目。每款按标准颜色与尺码的全部组合展开。颜色和尺码名称必须在工具箱「颜色尺码映射」中有唯一启用的三位代码；色码 044 已作废，不能使用。均码、F、XXL/2XL 等常用尺码别名可匹配，歧义映射必须先处理。

## 生成与下载

1. 在原表格选择款式，打开工具箱菜单，再点击「聚水潭商品建档」。系统重新读取选中款式的已保存资料。
2. 核对「颜色对应与号型规则」。标准颜色与供应商颜色数量相同时按两列现有顺序对应，可在面板内改选；数量不同时须为每个标准颜色选择供应商颜色。供应商颜色整列为空或无查看权限时留空并提示。
3. 系统按三级类目推荐上装或下装号型，连衣裙按上装处理；无法判断时请选择。号型选择及颜色对应调整只用于本次生成，不保存到原表格。
4. 点击「生成建档资料」。处理错误后重新生成；其他字段缺失或无查看权限时会显示可展开的留空提示。缺少必需字段、款号重复、映射不唯一、商品编码重复、金额无效或尺码不适用时不能导出整批。
5. 在预览表中横向滚动核对全部列，按页查看商品行，点击「下载 Excel」。下载前再次核验资料及映射；已变化时须重新生成。

如需修改映射，关闭建档面板返回工具箱菜单，进入「颜色尺码映射」维护，再重新打开建档功能。关闭面板、切换功能或刷新页面不保留本次预览和临时调整。

预览表中的款号、款式编码、供应商款式编码、货号、商品编码或条形码（按本模板实际列显示）可通过旁边的复制图标单独复制，保留完整文本及前导零；复制不影响 Excel 导出内容。（2026-10-21）

## 模板规则

文件仅包含「商品资料」工作表的表头与生成结果，按提供模板保留 A 至 AL 共 38 列，以及 K、Y 两处「供应商名称」列；不含模板中的规则行和示例行。

| 输出内容 | 取值规则 |
| --- | --- |
| 款式编码 | 序缇款号 |
| 商品编码 | 序缇款号 + 三位色码 + 三位尺码码，按文本保存前导零 |
| 商品名称、商品简称 | 长标题、短标题 |
| 颜色及规格 | 标准颜色名称 + 英文分号 + 尺码名称 |
| 三级类目 | 对应的三级类目字段 |
| 品牌 | 序缇质造-唯品会 |
| 供应商款式编码 | 供应商款号 |
| 两处供应商名称 | 供应商名称字段；没有该字段时使用关联供应商名称或内置供应商编码 |
| 备注、商品状态、库存同步、商品属性 | 唯品会链接、启用、是、成品 |
| 市场\|吊牌价、基本售价、成本价 | 吊牌价、唯品价、供货价（不含税）；不是唯品吊牌限价 |
| 其它价格5 | 供货价（不含税）× 1.2，四舍五入保留两位小数；成本空白时留空 |
| 其它属性1 | 按上、下装及尺码计算号型 |
| 其它属性2 | 本标准颜色对应的供应商颜色 |
| 成分、安全类别、执行标准 | 对应表格字段，成分保留换行 |

下装 S/M/L 对应 155/64A(S)、160/68A(M)、165/72A(L)；上装对应 155/80A(S)、160/84A(M)、165/88A(L)。尺码每增加一档，身高增加 5cm、围度增加 4cm；XS、XXS、XL、2XL 等依次类推。均码/F 分别为下装 160/68A(F)、上装 160/84A(F)。数字尺码等不能自行推断，须先在原表及映射中整理为适用尺码。

图片、国标码、分类、虚拟分类、商品标签、重量、长宽高、体积、单位、其它价格1～4等模板未指定取值的列留空。

## 权限、保存效果与常见问题

读取当前用户获准查看的已登记字段，包括暂未显示在当前字段分组中的字段。禁止查看的单元格、无权查看的私有字段、已删除字段不会写入文件；必需字段无权查看时不能生成。无查看权限的可选字段会留空并提示。多个同名来源字段不能任意选取，须先调整字段名称。

生成、临时调整和下载只生成资料文件，不创建系统商品、SKU 或库存，不调用聚水潭接口，不自动上传文件，也不进入表格的撤销历史。下载后需自行在聚水潭核对并导入；对方系统的实际导入结果以其校验为准。

- 没有选中款号：关闭工具箱，在原表格勾选行或选择单元格，再重新打开。
- 提示先保存：完成自动保存或处理字段冲突，再重试。
- 缺少或歧义映射：进入颜色尺码映射，补齐唯一启用的三位代码；不要使用停用或作废代码。
- 资料或权限已变化：核对最新资料后重新生成，旧预览不能直接下载。
- 网络、权限或 Excel 组件读取失败：按页面提示重试；失败不会改写原表或产生部分导入。
