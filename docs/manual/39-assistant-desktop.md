# 小序桌面客户端与电脑操作

更新日期：2026-11-07。桌面客户端版本：1.2.1。入口：小序「切换助理面板 → 电脑操作」，或输入框左下角「网站内」菜单中的「连接并授权本机」（普通浏览器显示「连接电脑」）。需要当前账号具备个人助理使用权限，并启用、验证智能服务。

## 网站内操作

执行位置默认为「网站内」。发送明确的单条指令，如“打开经营分析”“打开库存明细”“更新罗盘数据”“同步聚水潭库存”，会按当前账号权限直接打开页面或提交相应任务，无需再点确认卡片。文字和智能语音均可使用；查询、否定、复合要求或带附件的消息不会被当作这类快捷指令。

更新数据使用原有后台同步流程，提交不代表同步完成，实际进度和错误在相应页面及小序动态反馈中显示。库存、项目查询仍通过受权限约束的业务工具；日程和记忆保持草稿确认流程。小序提供的其他操作卡片仍需点击后提交。

「返回到我的工作台」「回到工作台」「打开我的工作台」可直接切换至本站工作台，不需要电脑授权或模拟点击。导航也支持「返回库存明细」等已有页面名称；否定、提问和混合指令不自动跳转。

外部网页也可按名称直接打开：执行位置选择「网站内」，单独发送「打开腾讯网」「打开百度」或其他明确网站名称。常见名称立即打开；其他名称先打开等待页，查询官网后自动进入，无需再发网址。只有名称不明确或没有可靠来源时才请补充名称。仍支持「打开 https://具体网址」。普通浏览器新建标签页，1.2.0 桌面端新建内置网页窗口，原对话保留，无需重装客户端、额外开启联网或跨窗口授权。名称查询只发送该名称，不附带历史或个人资料，按智能服务和公开搜索实际用量计费。弹窗被拦截时会显示打开链接；查询失败或超时可返回原对话查看原因。桌面端回复表示已发出请求，网络失败或达到8个窗口上限时仍需查看本机提示。选择电脑执行位置时仍进入电脑任务流程；此入口不自动登录或操作网页内容，附件、混合任务和连续智能语音不触发此动作。

## Windows 桌面客户端

当前提供 Windows 10/11 x64 免安装版，将工作台、网页窗口和本机电脑操作放在一个客户端中，不需要再启动独立助手。下载包包含已编译程序与依赖，不在用户电脑上编译。

1. 在「电脑操作」点击「下载 Windows 桌面端」，完整解压，双击 `XutiDesktop.exe`，也可双击「启动小序.cmd」。同目录 DLL 文件需要保留。需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime；缺少网页环境时客户端提供微软官网下载入口。不要以管理员身份运行。
2. 首次在桌面端登录网站。桌面端使用独立的本机浏览器配置，不能直接继承 Chrome 登录。网页会话仅保存在当前 Windows 用户目录中，不复制原有浏览器 Cookie；小序设备凭据使用当前 Windows 用户加密保护。
3. 顶部「工作台」返回已打开的工作台；「连接本机」打开小序电脑操作面板；「电脑任务」打开内置的窗口选择与执行控制；「刷新」刷新工作台；「使用帮助」打开本章。网站仍支持亮暗主题，客户端外框随网站主题变化。
4. 「打开网页」新建独立网页窗口，在地址栏输入 HTTPS 地址。支持后退、前进、刷新和用户主动打开的登录弹窗；网页会话在本机保留。文件上传仍由你选择文件，下载弹出保存位置选择。麦克风、摄像头由你在客户端提示中决定是否允许本次使用。
5. 独立网页窗口也可以在「电脑任务」中选作目标，或在跨窗口授权后由小序按任务切换；工作台自身的控制界面不能被电脑任务点击。第三方网页没有本机连接、文件或执行接口。只有已逐次允许或按有效设备授权启动的任务才会抓取画面和执行输入；没有进行中的任务时不会截图。

快捷键：`Ctrl + 1` 返回工作台，`Ctrl + 2` 新建网页窗口，`Ctrl + 3` 打开电脑任务，`Ctrl + Shift + L` 打开连接面板；独立网页窗口内 `Ctrl + L` 聚焦地址栏。

网站页面随线上版本更新；客户端本体通过「下载新版桌面端」更新，退出旧版后解压到新目录即可。登录配置保存在本机用户目录，不随解压目录变化。当前下载包尚未配置代码签名，遇到系统拦截时核对来源并自行处理，不关闭安全检查。

## 连接本机并执行任务

1. 在 1.2.1 桌面端登录后，从输入框左下角「网站内 → 连接并授权本机」开始，也可在「电脑操作」面板点击同名按钮。连接与授权合并为一次流程，自动建立本机连接，直接弹出本机确认；确认后记住授权并自动选择这台电脑，新任务直接执行，无需复制配对码、切换面板或每次确认。取消确认会保留连接，可稍后点「授权本机操作」。已有有效授权时重复点击不会再次询问。网站内操作无需这项授权。
2. 已在桌面端连接的电脑也会显示在 Chrome 等浏览器的设备列表中，选择即可下达任务。需要连接其他电脑时，展开「连接其他电脑或使用配对码」，生成配对码并粘贴到对应桌面端的「电脑任务」面板。配对码10分钟有效、仅使用一次，重新生成使先前未使用的码失效。最多连接5台电脑，名称使用本机计算机名。本机已有不同账号的连接时先断开再重新连接，不静默切换账号。
3. 配对绑定当前网站账号及本次登录会话，网站退出登录、登录会话过期、账号失效或权限撤销后需重新配对；设备连接最长30天。电脑凭据及记住的跨窗口授权仅在本机当前 Windows 用户下加密保存，网站不获取浏览器 Cookie、密码或原有登录会话。
4. 在网站选择「在这台电脑执行」，回到对话输入电脑任务。也可用输入框麦克风转成文字，核对后发送，或开始实时通话直接下达电脑操作指令。电脑执行器只接收本条任务指令，不附带个人日程、记忆、对话历史或附件；文字电脑任务请关闭联网、移除附件。
5. 已记住授权时，打开要操作的应用或网页后直接发送任务，小序自动选择起始窗口并逐步观察、点击、输入或滚动。未记住授权时，可在顶部「电脑任务」选择**已经打开的应用窗口**，点击「允许本次任务」。窗口画面及可见控件名称会发送到已配置的智能服务。任务使用对话区选择的识图能力，不支持识图时需重新选择。

## 实时语音识屏点击（2026-11-07）

适用于千问、豆包及原有实时通道，沿用 1.2.0 桌面端的截图与执行能力，无需为此重装客户端；网站 API、前端和数据库迁移需一起更新。

1. 先连接电脑，在输入框左下角「执行位置」选择该电脑，选择支持看图的助理能力。需要自动开始及跨窗口识别时，在本机记住跨窗口授权；未授权时仍可创建任务，但要在本机选择窗口并允许后才会执行。
2. 开始实时通话。字幕区和语音设置显示「电脑操作 · 设备名称」，通话绑定开始时的电脑和识图能力；切换电脑或能力后需重新开始通话。未选择电脑的通话仍显示「网站内」，不能自动使用其他设备。
3. 明确说出目标，例如「点击记事本里的编辑菜单」「在当前窗口找到搜索框并输入春季新品」「向下滚动找到库存明细」。小序提交任务，本机执行器根据当前窗口截图和可见控件识别位置，每次执行后重新观察，再决定下一步；目标不明确或无法识别时请求接手，不猜坐标。
4. 普通聊天、能力咨询和任务进度查询不会作为新的电脑任务。说「返回我的工作台」等明确站内导航时，直接切换本站页面。电脑任务的提交回复不代表点击成功；在「电脑操作」查看当前步骤与最终结果，也可询问任务进度。同一台电脑已有未结束任务时，不再创建第二个任务。
5. 开口打断只停止当前语音回复；结束通话也不撤销已经提交的电脑任务。停止电脑执行请使用「电脑操作 → 暂停／停止」或本机 **Ctrl + Alt + X**。需要接手的任务保持暂停，登录、付款等步骤仍由本人完成。

电脑离线、连接失效或所选能力不支持识图时，会给出具体错误。先恢复连接或重新选择能力，再主动重开通话；不自动换电脑、换模型或重试失败操作。原有分段智能语音仍只处理站内指令，电脑任务可用输入框麦克风识别后发送。

## 记住设备的跨窗口授权

1.2.1 桌面端推荐使用「连接并授权本机」或「授权本机操作」，本机确认一次后记住；没有确认时仍为「逐次允许」。1.2.0 桌面端会打开原有「电脑任务」面板，在「设备授权 → 授权跨窗口操作」中确认，下载新版后可使用简化流程。授权绑定当前账号、配对设备和 Windows 用户，在客户端重启后保留，直到手动撤销；原登录或设备连接失效、断开、重新配对后需要重新授权，不转移到新账号或其他电脑。网站按钮只唤起本机确认，不能自行开启权限。

授权后，发往这台电脑的新任务自动选择一个可操作的起始窗口并开始，不再逐任务确认。小序可在本轮列出的已打开、未最小化的普通应用及网页窗口之间切换，每轮最多40个窗口。每次切换后先观察新窗口再操作；同一窗口的网页标题变化不要求重新授权。关闭不希望被操作的窗口后再发送任务。

跨窗口模式会向已配置的智能服务发送可用窗口的应用名和标题，以及当前操作窗口的截图和可见控件文字。不会同时发送所有窗口截图。只有正在执行任务时才发送画面；授权不授予终端、任意文件读取或管理员权限，敏感步骤仍需本人接手。

可在本机「电脑任务 → 撤销跨窗口授权」、网站「电脑操作 → 已连接电脑 → 撤销跨窗口授权」，或输入框左下角授权菜单中撤销。输入框显示所选设备的实时授权状态，并提供「查看电脑任务进度」入口。其他电脑的授权需在对应的本机客户端确认。撤销后当前任务暂停，后续回到逐次允许模式，设备连接仍保留。本机撤销立即停止本机输入；网站撤销阻止下一步许可，客户端在线时同步停止。已发出的输入可能已完成。若本机离线撤销提示同步失败，先保持任务停止，联网后确认网站授权标记消失；也可直接从网站撤销。重新开启只能在本机确认，服务器上的授权标记不会自行提升客户端权限。

## 进度、接手与停止

桌面客户端同样支持小序的实时语音通话。在网站「语音设置」启用并验证实时通道后，直接点击小序开始；第一次使用需在客户端允许麦克风。可持续交谈、开口打断、打开业务页面、启动已授权的同步任务，以及向本次通话选定的电脑提交识屏操作。实时通话不会跳过电脑任务的窗口选择与允许；退出或最小化导致页面隐藏时停止麦克风，恢复后主动重开。通道配置、计费与故障处理详见「我的工作台 → 智能语音对话」。

「电脑操作」显示设备的「逐次允许 / 已记住跨窗口授权」、任务范围、状态、最近步骤和时间；动态反馈也显示本人电脑任务。关闭外部浏览器里的网站页面不会停止已允许的本机任务，电脑和桌面客户端必须持续在线。退出小序桌面端会立即停止本机输入，并尝试将任务标记为暂停；网络不可用时云端显示可能延迟。重启保留设备授权，但不会自动恢复之前运行中或已暂停的任务，核对后主动继续。云端经营分析或库存同步任务仍按原流程运行。

可在网站或本机点击「暂停」「停止」，也可在本机按 **Ctrl + Alt + X** 停止。你手动切换窗口、移动鼠标或按键时，本机先暂停输入，再反馈网站；已授权的小序自行切换窗口可继续执行。逐次允许模式恢复时需要在本机重新选窗口并允许；记住授权后，核对结果并点击网站「继续」，或在本机选择起始窗口后点击「继续当前任务」。暂停和需要接手不会因授权保留而自行恢复。已发出的单次输入可能已经完成，停止不撤销之前的编辑。

登录、验证码、密码、付款、对外发送、删除、安装和安全设置等步骤交由你处理。逐次允许模式的弹窗或新窗口需重新选择；跨窗口模式可切换至符合范围的新窗口，受保护或无法识别的窗口仍需接手。没有逐次点击审批。

任务指令、状态与简短步骤记录保存在本人任务中，截图不落库、不保存在本机文件中。窗口截图和控件文字会交给智能服务处理，请先关闭敏感内容；模型调用产生正常服务费用。

## 限制与故障处理

- 当前支持普通权限的 Windows 应用窗口。不是远程开机服务，不支持锁屏、管理员窗口、终端、脚本执行、密码管理器或系统安全界面，也不会自动启动其他程序。
- 一台电脑同时运行一个任务。每80步或连续操作30分钟进入检查点，先核对结果，再停止旧任务并创建后续任务。不要把“已执行点击”当作业务办理成功，以页面真实结果为准。
- 网络断开时停止本机输入；恢复后需要核对窗口并主动继续，逐次允许模式仍需重新允许。已执行但反馈丢失的步骤不会重复点击或输入；结果不确定时请求接手。
- 授权按钮不可用时先连接本机；旧版客户端只支持逐次允许，需要下载新版。授权返回无效时核对网站与桌面端是否已一同更新。已记住授权却未自动开始时，检查客户端是否运行、是否有可操作窗口，以及任务是否已暂停或需要接手。
- 窗口遮挡、位置变化、无法截图或应用无响应会暂停。重新选择窗口；截取一直未响应时重启本机助手。截图黑屏或控件无法识别的应用可能不兼容，不能保证完成所有软件的操作。
- 点击网站设备的「断开」会撤销授权并停止其活动任务；本机「断开本机」移除本机保存的连接，网站仍可撤销对应设备。首次安装遇到系统提示时由用户核验来源处理，助手不绕过系统安全拦截。
- 网页不能加载时显示重连入口，也可在系统浏览器中打开工作台。缺少 WebView2 Runtime 时先安装微软官方运行环境。窗口最小化、关机或锁屏时无法继续本机操作；当前不提供托盘常驻或无人值守登录。

## 构建与维护

维护者在 Windows 运行 `pnpm build:desktop`，从固定版本的微软 SDK 构建并执行本机校验。SDK 下载核对 SHA-256，下载包保留微软许可与源代码；生成的发行包和源文件指纹一同提交。网站构建核对发行包完整性和源文件指纹，避免发布与当前源码不一致的桌面版本。网页内容无法调用终端或任意本机方法；连接桥只接受本站主页面的连接、状态、打开本机确认与控制面板请求。授权请求绑定当前设备，由本机对话框完成确认；重复请求不会切换或撤销已有授权。
