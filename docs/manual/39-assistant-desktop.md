# 小序桌面客户端与电脑操作

更新日期：2026-11-03。入口：小序「切换助理面板 → 电脑操作」，或输入框下方「连接电脑 / 进度」。需要当前账号具备个人助理使用权限，并启用、验证智能服务。

## 网站内操作

执行位置默认为「网站内」。发送明确的单条指令，如“打开经营分析”“打开库存明细”“更新罗盘数据”“同步聚水潭库存”，会按当前账号权限直接打开页面或提交相应任务，无需再点确认卡片。文字和智能语音均可使用；查询、否定、复合要求或带附件的消息不会被当作这类快捷指令。

更新数据使用原有后台同步流程，提交不代表同步完成，实际进度和错误在相应页面及小序动态反馈中显示。库存、项目查询仍通过受权限约束的业务工具；日程和记忆保持草稿确认流程。小序提供的其他操作卡片仍需点击后提交。

## Windows 桌面客户端

当前提供 Windows 10/11 x64 免安装版，将工作台、网页窗口和本机电脑操作放在一个客户端中，不需要再启动独立助手。下载包包含已编译程序与依赖，不在用户电脑上编译。

1. 在「电脑操作」点击「下载 Windows 桌面端」，完整解压，双击 `XutiDesktop.exe`，也可双击「启动小序.cmd」。同目录 DLL 文件需要保留。需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime；缺少网页环境时客户端提供微软官网下载入口。不要以管理员身份运行。
2. 首次在桌面端登录网站。桌面端使用独立的本机浏览器配置，不能直接继承 Chrome 登录。网页会话仅保存在当前 Windows 用户目录中，不复制原有浏览器 Cookie；小序设备凭据使用当前 Windows 用户加密保护。
3. 顶部「工作台」返回已打开的工作台；「连接本机」打开小序电脑操作面板；「电脑任务」打开内置的窗口选择与执行控制；「刷新」刷新工作台；「使用帮助」打开本章。网站仍支持亮暗主题，客户端外框随网站主题变化。
4. 「打开网页」新建独立网页窗口，在地址栏输入 HTTPS 地址。支持后退、前进、刷新和用户主动打开的登录弹窗；网页会话在本机保留。文件上传仍由你选择文件，下载弹出保存位置选择。麦克风、摄像头由你在客户端提示中决定是否允许本次使用。
5. 独立网页窗口也可以在「电脑任务」中选作目标；工作台自身的控制界面不能被电脑任务点击。第三方网页没有本机连接、文件或执行接口。未选定并允许任务时不会抓取窗口画面或执行输入。

快捷键：`Ctrl + 1` 返回工作台，`Ctrl + 2` 新建网页窗口，`Ctrl + 3` 打开电脑任务，`Ctrl + Shift + L` 打开连接面板；独立网页窗口内 `Ctrl + L` 聚焦地址栏。

网站页面随线上版本更新；客户端本体通过「下载新版桌面端」更新，退出旧版后解压到新目录即可。登录配置保存在本机用户目录，不随解压目录变化。当前下载包尚未配置代码签名，遇到系统拦截时核对来源并自行处理，不关闭安全检查。

## 连接本机并执行任务

1. 在桌面端登录后，点击顶部「连接本机」，在小序面板点击「连接本机」，连接成功后自动选择这台电脑作为对话执行位置。此操作只建立连接，不自动允许任何电脑任务。
2. 如从 Chrome 等其他浏览器发送任务，在网站生成配对码，粘贴到桌面端顶部「电脑任务」面板并点击「连接」；桌面端的「连接其他电脑」也可生成配对码。配对码10分钟有效、仅使用一次，重新生成使先前未使用的码失效。最多连接5台电脑，名称使用本机计算机名。本机已有不同连接时先断开再重新连接，不静默切换账号。
3. 配对绑定当前网站账号及本次登录会话，网站退出登录、登录会话过期、账号失效或权限撤销后需重新配对；设备授权最长30天。电脑凭据仅在本机当前 Windows 用户下加密保存，网站不获取浏览器 Cookie、密码或原有登录会话。
4. 在网站选择「在这台电脑执行」，回到对话输入电脑任务。也可用输入框麦克风转成文字，核对后发送。电脑任务只发送当前任务指令，不附带个人日程、记忆、对话历史或附件；请关闭联网、移除附件。连续智能语音仍执行网站内指令，不会悄悄切换到电脑操作。
5. 在顶部「电脑任务」选择**已经打开的应用窗口**，点击「允许本次任务」。窗口画面及可见控件名称会发送到已配置的智能服务。允许后小序逐步观察、点击、输入或滚动。任务使用对话区选择的识图能力，不支持识图时需重新选择。

## 进度、接手与停止

桌面客户端同样支持小序的实时语音通话（2026-11-03）。在网站「语音设置」启用并验证实时通道后，直接点击小序开始；第一次使用需在客户端允许麦克风。可持续交谈、开口打断，以及用语音打开业务页面和启动已授权的同步任务。实时通话沿用网站内操作范围，不会跳过电脑任务的窗口选择与允许；退出或最小化导致页面隐藏时停止麦克风，恢复后主动重开。通道配置、计费与故障处理详见「我的工作台 → 智能语音对话」。

「电脑操作」显示等待允许、操作中、已暂停、需要接手、已完成及已停止，以及最近步骤和时间；动态反馈也显示本人电脑任务。关闭外部浏览器里的网站页面不会停止已允许的本机任务，电脑和桌面客户端必须持续在线。退出小序桌面端会立即停止本机输入，并尝试将任务标记为暂停；网络不可用时云端显示可能延迟，下次启动后需重新选择窗口并允许。云端经营分析或库存同步任务仍按原流程运行。

可在网站或本机点击「暂停」「停止」，也可在本机按 **Ctrl + Alt + X** 停止。切换窗口、手动移动鼠标或按键时，本机先暂停输入，再反馈网站。恢复时点击「继续」，在本机重新选窗口并允许。已发出的单次输入可能已经完成，停止不撤销之前的编辑。

登录、验证码、密码、付款、对外发送、删除、安装和安全设置等步骤交由你处理。弹窗或新窗口不会自动扩大操作范围，需重新选择。没有逐次点击审批；只在任务开始和接手恢复时确认窗口。

任务指令、状态与简短步骤记录保存在本人任务中，截图不落库、不保存在本机文件中。窗口截图和控件文字会交给智能服务处理，请先关闭敏感内容；模型调用产生正常服务费用。

## 限制与故障处理

- 当前支持普通权限的 Windows 应用窗口。不是远程开机服务，不支持锁屏、管理员窗口、终端、脚本执行、密码管理器或系统安全界面，也不会自动启动其他程序。
- 一台电脑同时运行一个任务。每80步或连续操作30分钟进入检查点，先核对结果，再停止旧任务并创建后续任务。不要把“已执行点击”当作业务办理成功，以页面真实结果为准。
- 网络断开时停止本机输入；恢复后需要核对窗口并重新允许。已执行但反馈丢失的步骤不会重复点击或输入；结果不确定时请求接手。
- 窗口遮挡、位置变化、无法截图或应用无响应会暂停。重新选择窗口；截取一直未响应时重启本机助手。截图黑屏或控件无法识别的应用可能不兼容，不能保证完成所有软件的操作。
- 点击网站设备的「断开」会撤销授权并停止其活动任务；本机「断开本机」移除本机保存的连接，网站仍可撤销对应设备。首次安装遇到系统提示时由用户核验来源处理，助手不绕过系统安全拦截。
- 网页不能加载时显示重连入口，也可在系统浏览器中打开工作台。缺少 WebView2 Runtime 时先安装微软官方运行环境。窗口最小化、关机或锁屏时无法继续本机操作；当前不提供托盘常驻或无人值守登录。

## 构建与维护

维护者在 Windows 运行 `pnpm build:desktop`，从固定版本的微软 SDK 构建并执行本机校验。SDK 下载核对 SHA-256，下载包保留微软许可与源代码；生成的发行包和源文件指纹一同提交。网站构建核对发行包完整性和源文件指纹，避免发布与当前源码不一致的桌面版本。网页内容无法调用终端或任意本机方法；连接桥只接受本站主页面的连接、状态与打开控制面板请求。
