# 小序桌面客户端与电脑操作

更新日期为 2026-11-26。工作台按每条文字或语音指令选择执行方式。右栏可在本机打开网页、进入云端独立浏览器或使用「我的电脑」。电脑操作需要个人助理权限，识屏操作还需要对应智能服务就绪。

打开电脑操作面板时从顶部显示连接入口，不沿用聊天的滚动位置。查看下方任务时，后台刷新会保留当前阅读位置。

## 从小序聊天复制本机文件

在「我的工作台 → 我的电脑」选好执行设备，然后在中栏输入指令。复制到已有文件夹时，写明源和目标的路径。可以复制单个普通文件，也可以写「把某个目录里的文件复制到某处」以复制该目录直接包含的普通文件。

| 执行设备 | 聊天指令示例 | 设备上的操作 |
| --- | --- | --- |
| Windows 10/11，桌面端 1.2.12 至 1.2.13 | 把「D:\样品\说明.txt」复制到「D:\已核对」 | 在资源管理器选中源文件，按 Ctrl+C，核对目标后按 Ctrl+V |
| Windows 10/11，桌面端 1.2.14 起 | 把「D:\样品\说明.txt」复制到「D:\已核对」 | 默认后台复制并核验。可以同时使用其他应用、鼠标、键盘和剪贴板。明确要求 Ctrl+C、Ctrl+V 时使用资源管理器 |
| macOS 12 起，小序 Finder 助手 | 把「~/Documents/样品/说明.txt」复制到「~/Documents/已核对」 | 在 Finder 选中源文件，按 ⌘C，核对目标后按 ⌘V |

**在 Windows 桌面新建文件夹并复制进去。** 桌面端 1.2.13 起，可一次发送：

> 在我的电脑桌面新建文件夹“本次样品”，并将路径 D:\样品 下的内容复制进来

小序先检查源目录，再在执行电脑的实际桌面新建「本次样品」，即使桌面迁移到了其他盘也能定位。简写为「在我的电脑新建文件夹……并将……复制进来」也使用桌面。说「内容」会保留普通子文件夹、空文件夹和文件的层级，说「文件」只复制源目录直接包含的普通文件。若源目录为空或含链接、隐藏项等无法完整复制的内容，小序会在建目录前说明原因。桌面已有同名目标时，任务会提示换名。进度和结果显示在同一张任务卡中。若提示客户端版本过低，请打开「我的电脑 → 其他连接方式与客户端更新」下载新版，更新执行设备后再发送原句。

Windows 使用已连接并记住授权的桌面端。1.2.14 接单时，普通复制默认在后台执行。需要保证后台执行时，也可在指令中写明「后台复制」。接单端版本过低时，聊天会提示升级。后台复制支持指定来源和目标，也支持在桌面新建目标文件夹后复制进去。点击或输入其他应用需要前台窗口。任务卡显示复制方式和最终核验结果。暂停或停止会保留已经复制到目标的完整文件。

旧任务若在粘贴时中断，新版会根据同一台电脑上原任务的执行记录核对。处于「等待自动核验」时，可以正常退出旧客户端并更新，重新连接后会接着核对。能证明尚未发出粘贴、原任务创建的目录仍为空且来源清单一致时，可自动续办一次。若曾发出粘贴，则核对目标文件。遇到同名冲突、部分复制或缺少原记录时，在任务卡中查看具体原因。主动暂停会保留核验记录，点「继续当前任务」后重新核验。停止会结束任务。

Mac 首次使用时，在「我的电脑」下载并解压「Mac Finder 助手」，展开「其他连接方式与客户端更新」生成配对码。在 Mac 打开助手，输入配对码，点「开始接单」，选择允许操作的工作文件夹，并按系统提示允许辅助功能及控制 Finder。文件和目标目录都须在所选范围内。保持助手运行，再在工作台将这台 Mac 设为常用电脑。网页端和 Windows 桌面端都可向所选 Mac 下达指令。

Mac 助手 1.0.0 同时支持 Apple 芯片和 Intel。当前下载包使用临时签名，尚无 Apple Developer ID 签名与公证。若系统或公司的软件策略要求公证，安装时可能被拦截，请联系设备管理员。

文件由执行设备本地复制。Windows 单独复制文件时最多处理 512 个普通文件；复制整个目录内容时，文件和子文件夹合计最多 512 项，Mac 的源和目标限于当前用户目录中已授权的位置。核验结果和需要处理的原因显示在原聊天的任务卡。使用快捷键时，窗口或剪贴板发生变化可能需要接手。任务报告同名冲突或核验失败时，按任务卡提示查看目标目录。目标已有同名文件时需要另选目录或先自行处理。复制不覆盖已有文件，不从剪贴板接受上一次任务的内容。（2026-11-26）

## 接着上一条指令操作

### 在 Windows 桌面批量创建编号文件夹

在「我的工作台 → 我的电脑」选择已连接的 Windows 电脑，在桌面端确认「允许并记住」。使用 1.2.16 或更新版本，在中栏发送下面这样的指令。

> 在我的电脑桌面新建文件夹“测试自动化999”，并在文件夹内新建10个文件夹，命名规则按“XUTI-01……XUTI-10”。

每次可创建 1 至 100 个子目录。也可以逐个写名称，例如「在桌面文件夹『样品』里面批量创建子目录：春款、夏款、秋款」。小序一次下发目录清单。客户端在当前用户的实际桌面创建父目录和子目录，核对清单中的每个目录后，在原任务卡显示一条批量操作回执。执行期间可以点击、打字和切换应用。再次执行时会复用已有的普通目录，补齐缺少的目录。如果遇到同名文件或链接，请按任务卡提示核对目标，再继续任务。下载新版的入口在「我的电脑 → 其他连接方式与客户端更新」。（2026-11-26）

### 在资源管理器中创建文件夹或文本文件

已记住设备授权并运行 1.2.11 或更新客户端时，可在工作台发送「在我的电脑桌面新建文件夹，命名为样品资料」。小序会在资源管理器里打开或复用 Windows 为当前用户设置的桌面目录，核对目录后再规划操作。对于包含子文件夹和文本文件的任务，续办时会先检查窗口中已有的内容。

新建文件夹时，小序可在核验后的桌面或其子目录文件列表使用 Windows 的新建文件夹快捷键。常规右键菜单需能核对所属窗口，其他弹窗或无法确认归属的菜单会提示接手。若出现遮挡提示，先在本机移开遮挡、查看文件是否已创建，再点原任务的「继续当前任务」。手动指定窗口时，从本机「电脑任务 → 高级设置」选择实际显示目标文件夹的资源管理器窗口。已重定向到本地其他盘的桌面按 Windows 的实际位置处理。网络目录或无法核对的资源管理器标签需要手动选择。

任务卡的「最近步骤回执」列出动作和结果。已执行的点击或按键只说明该动作已发出；文件是否落盘，请看目标目录和最终核验结果。结果为「未确认」时请先检查现场，再决定是否继续。早期任务无法还原全部回执时，仅显示可核对的信息。（2026-11-26）

### 连续输入与网页指令

在工作台中栏发送「在我的电脑上切换到已打开的记事本窗口」。任务卡显示已完成后，直接输入「输入9999999」。使用 1.2.10 或更新客户端时，输入框可显示原记事本窗口，小序在执行前核对这台设备、当前授权和原窗口。核对成功后，独立的任务卡报告新一条指令的结果。若窗口已关闭或客户端已重启，重新指定窗口后再发指令。

记事本的快捷输入要求正文中有插入光标。选中了文字、切换了文档、文档内容已改变或过长时，任务会提示接手。客户端会在本机核对写入后的正文。若已尝试输入但结果未确认，请先查看原文，避免重复输入。

在同一对话中，刚完成的云端网页任务也可以接续。例如，先让小序访问某个官网并找到帮助中心，任务完成后发「往下滚一点」。小序只在能核对的原会话和页面上继续。桌面端的本地网页使用本机专用浏览器窗口。查看右栏、提出问题和明确下达操作指令都可以在同一工作台完成。「为什么输不进去？」等问题会留在普通对话。

上一步的操作目标保留最多十分钟，限紧邻上一条任务。若输入框显示「待确认操作位置」，可在本条指令补充目标。点目标按钮也可指定本条的去向。清楚的操作指令直接识别；较含蓄的续操作在目标有效时可使用智能服务判断意图，执行时仍会核对目标。

## 网站内操作

在工作台中栏直接输入或说出目标，「＋」用于附件。窄屏时可先收起右栏返回中栏。其他业务页面仍可在助理输入区手动选择「网站内」。发送明确的单条指令，如“打开经营分析”“打开库存明细”“更新罗盘数据”“同步聚水潭库存”，会按当前账号权限直接打开页面或提交相应任务，无需再点确认卡片。文字和智能语音均可使用；查询、否定、复合要求或带附件的消息不会被当作这类快捷指令。

更新数据使用原有后台同步流程，提交不代表同步完成，实际进度和错误在相应页面及小序动态反馈中显示。库存、项目查询仍通过受权限约束的业务工具；日程和记忆保持草稿确认流程。小序提供的其他操作卡片仍需点击后提交。

「返回到我的工作台」「回到工作台」「打开我的工作台」可直接切换至本站工作台，不需要电脑授权或模拟点击。导航也支持「返回库存明细」等已有页面名称；否定、提问和混合指令不自动跳转。

可在文字对话中直接询问明确的公开信息，例如「查一下今天北京的天气」。命中的问题使用公开检索，可在答复下方核对「参考来源」。详见「我的工作台 → 文字对话自动搜索公开网页」。

外部网页也可按名称直接打开：在工作台直接输入，其他业务页可点击「返回网站对话」，然后单独发送「打开腾讯网」「打开百度」或其他明确网站名称。常见名称立即打开；其他名称先打开等待页，查询官网后自动进入，无需再发网址。只有名称不明确或没有可靠来源时才请补充名称。仍支持「打开 https://具体网址」。普通浏览器新建标签页，1.2.0 桌面端新建内置网页窗口，原对话保留，无需重装客户端或跨窗口授权。名称查询只发送该名称，不附带历史或个人资料，按智能服务和公开搜索实际用量计费。弹窗被拦截时会显示打开链接；查询失败或超时可返回原对话查看原因。桌面端回复表示已发出请求，网络失败或达到8个窗口上限时仍需查看本机提示。选择电脑执行位置时仍进入电脑任务流程；此入口不自动登录或操作网页内容，附件、混合任务和连续智能语音不触发此动作。

## 在本机浏览网页

打开「我的工作台」右栏的浏览器，或在其他业务页面从小序面板选择「浏览器」。在地址栏输入 HTTPS 网址并按回车或点击箭头。只填域名时会补全 HTTPS。通过普通浏览器登录时，网页在当前设备的浏览器新标签页打开，使用该浏览器的登录状态。浏览器拦截弹窗时，点「在新标签页打开」。Windows 桌面端 1.2.5 及以上在专用本地窗口打开。手动打开网址由本机直接加载网页，不创建云端任务，也不调用模型。

「本地浏览器」和「云端独立浏览器」的标签栏和地址栏位置一致。本地模式显示「新网页」。点 `+` 清空并聚焦地址栏，点 `×` 清空本地地址，已打开的网页继续保留。在已打开的本机标签页或桌面窗口中前进、后退、刷新或关闭网页。右上角的全屏和收起按钮控制工作台内的浏览器面板。如需在面板查看云端画面，点「云端独立浏览器」。

## 小序独立浏览器

独立浏览器运行在服务器上，不使用你的本机鼠标、键盘或浏览器登录状态。每个账号使用一个独立网页会话，同一账号换电脑登录网站后仍可查看已有页面与任务。管理员需要部署浏览器执行服务并配置会话加密。普通打开网址、点击和输入不调用模型；让小序自动完成目标时，还需要启用并验证对应智能服务。未连接执行服务时明确显示原因，不改用本机或站内操作。

魔方罗盘更新、聚水潭库存同步和竞品云端采集使用各业务模块自己的浏览器会话。工作台的本地和云端选择不影响这些后台任务。

### 在云端直接浏览网页

1. 在工作台右栏或其他业务页的小序浏览器中点击「云端独立浏览器」，输入公开 HTTP/HTTPS 网址，按回车或地址旁箭头打开。仅输入域名时补全 HTTPS。从新标签或历史标签打开网址时，隔离浏览器启动时采用提交时的网页区域尺寸。已有可用页面时复用当前浏览器。首次等待时间受云端启动、目标网站响应和画面回传影响。收到首张画面并确认可操作后开放点击和输入。加载时保留地址栏文字并显示进度。（2026-11-25）
2. 顶部提供真实「后退」「前进」「刷新网页」。前进、后退是否可用以该浏览器的实际历史为准；刷新会重新加载网页。普通浏览不显示 AI 步数和暂停按钮。`+` 打开网址输入页，提交后使用同一个浏览会话，不创建多个同时运行的标签页。
3. 直接点击网页中的按钮或输入框，在画面中用键盘输入，支持中文输入法和纯文本粘贴。Tab、Shift+Tab、Enter、全选、退格、删除、方向键、Home、End、Page Up、Page Down 和 Esc 传给网页，滚轮直接滚动网页。没有第二个输入框或常驻按键条。按 Esc 后再按 Tab 可移出画面。单次输入或粘贴最多2000字符。
4. 人工输入按顺序提交，上一操作得到执行后的新截图确认后才发送下一操作。截图过期或页面跳转时停止尚未发送的输入，核对画面后重新操作；不自动重放旧坐标。等待网页更新时画面点击会禁用并显示忙碌光标，已聚焦的键盘输入仍按顺序处理。截图是定期更新的画面，不是实时视频。主动调整面板、窗口或全屏尺寸时会调整真实浏览器视口，网页区域占满地址栏下方空间，截图保持比例。同一账号在多个窗口查看同一页面时，已有窗口的后台刷新不会反复改回自己的尺寸；新打开的窗口先按比例查看已有画面，需要适配当前窗口时可调整分栏或使用全屏。右上角收起箭头旁的「全屏查看」可将浏览器铺满屏幕，工作台内同样可用；点击「退出全屏」或按 Esc 恢复原分栏。系统不支持全屏接口时使用页面内全屏显示。全屏会同步调整真实网页视口，不会另建会话或发送 AI 目标；收起面板会先退出全屏。
5. 标签上的 `×` 关闭当前网页并释放执行环境；独立的收起箭头只隐藏面板，保留当前网页。工作台右栏收起后，可从场景边缘竖栏重新展开浏览器或选择其他工具。浏览页面连续5分钟无操作会关闭，首次环境准备时间不计入；页面轮询不会延长这个时间。单次会话最长30分钟。重新打开可复用已保存的登录状态，但不保证恢复原页面位置。

### 让小序操作网页

在工作台直接输入或说出明确的网页操作，例如「去品牌官网查退货政策」。已有页面时，可在右栏云端独立浏览器的标签菜单点「让小序操作当前网页」，补全中栏草稿后发送。窄屏可先收起右栏。自动任务只接收本条指令。要交办外站操作，请先移除附件。其他业务页可在对话的「执行位置」选择「小序独立浏览器」。手动浏览云端网页不会改变对话的执行位置。（2026-11-25）

小序自动观察并连续操作时，顶部显示紧凑进度、真实步骤和暂停、继续、停止操作。普通网址输入不触发这条 AI 流程。小序正在操作时，先点「暂停」接管，再点击、输入或修改网址；不会静默抢占正在运行的目标。登录、密码、验证码、付款、对外发送和删除等步骤需要你处理。仅点击、输入或滚动接管后，点「继续」让小序继续原目标；修改网址、前进、后退或刷新会结束原自动目标并转入普通浏览，之后可发出新的目标。「停止」只停止自动目标，网页仍可浏览。AI 目标完成后返回普通浏览，保留当前页面。提交、派发点击和步数都不代表业务办理成功，以目标网页真实结果为准。

网页自动化使用「AI 模型管理 → 小序独立浏览器」的中央配置，不沿用普通聊天选择的型号。自动分流的每个目标采用提交时的型号，已建立的任务保留自身的型号。模型未就绪时仍可直接浏览；自动化目标需对应服务就绪。模型调用按供应商实际回执记录用量，未返回的 Token 或费用显示未知，不当作零；实时语音另按对应通道记录。直接浏览不把网页截图发送给模型，云端浏览器仍消耗执行环境资源。

### 页面、历史与登录状态

点击标签标题打开「浏览器标签与会话菜单」，查看最近网页与任务、管理登录状态。工作台可拖动中右分隔线调整查看面积；其他业务页面从标题菜单选择「展开浏览器／恢复分栏」。手机和窄屏一次显示中栏或右栏，收起右栏返回中栏。切换面板和查看历史不改变对话草稿、不调用模型。

登录会话加密保存在当前账号下，下次打开可复用；目标网站可能要求重新登录。在标签标题菜单选择「清除浏览器登录状态」，核对弹窗后「清除并停止」，会关闭当前浏览器并清除保存的网页登录状态与任务截图。不影响本机浏览器。旧已结束任务的最终遮敏截图可只读查看24小时；地址旁「只读」提示包含保留期限，不能点击或输入。历史画面的刷新仅重新读取保留截图；在地址栏打开网址会进入新的活浏览会话。

普通浏览器刷新工作台后，地址栏重新默认使用本地浏览器。云端登录状态和任务仍按当前账号保留。网络中断、浏览器服务失联或环境回收时显示原因，不会转给你的电脑。执行服务未就绪时显示最近有效检查的安全原因；缺少浏览器程序、运行组件或隔离支持时需管理员检查部署，不会关闭隔离要求继续执行。服务心跳超过30秒未更新后，不把旧原因当作当前结论。

当前只处理公开网络网页，不访问本机文件、内网地址、系统应用或任意脚本。自动化模式会将网页截图和可见内容交给已配置智能服务；普通浏览、等待输入和保留网页期间也占用云端执行资源。登录输入、会话和截图通过当前账号权限约束的接口处理。网站限制自动化、验证码不兼容、文件上传下载或页面无法识别时可能需要接管或无法完成，不能保证所有网站都可自动操作。

## Windows 本地浏览器

1. 解压并登录 1.2.5 或更新版本的 Windows 桌面端。工作台右栏浏览器默认进入「本地浏览器」。在地址栏输入 HTTPS 网址后按回车或点击箭头，网页在单独的桌面窗口打开。只想打开或切回该窗口时，点「打开本地窗口」，也可以在桌面端按 `Ctrl + 2`。
2. 本地浏览使用 WebView2 独立配置。网页由本机加载，登录会话保存在当前 Windows 用户的设备上。本地窗口打开后，右栏显示「已打开本地浏览器窗口」，网页加载进度在桌面窗口查看。点击「云端独立浏览器」可查看云端网页或开始云端浏览。浏览本地网页无需等待云端会话，也不调用模型。
3. 要让小序操作，先在本地窗口打开目标页，并在右栏「我的电脑」连接与选择设备。点击「让小序操作本地网页」填写草稿，或直接输入、说出「在本地浏览器里点击详情」。小序只操作这个窗口里的网页内容，任务按本机逐次允许或已记住的授权执行，进度在「我的电脑」查看。登录、验证和敏感操作仍由本人处理。
4. 小序接手时使用当前前台窗口和本机输入，并沿用暂停、停止机制。网页内容区的画面与可见控件交给现有电脑识屏模型处理。直接浏览时没有这项模型调用。设备离线或网页未打开时会提示检查，任务保持原目标。

## 我的电脑：连接一次，直接使用

在「我的工作台」点场景右侧的电脑图标，打开「我的电脑」查看设备和授权。窄屏上若已打开浏览器等面板，先收起右栏，再点电脑图标。设备列表下方的「操作任务」默认收起。点标题展开，按指令和设备名找到任务卡，即可查看进度或继续需要接手的原任务。再点标题可收起列表。聊天中的任务卡仍可直接操作。（2026-11-26）

**第一次试用**。在已记住本机授权的 Windows 桌面端 1.2.9 或更新版本，保持客户端运行，在中栏底部发「在我的电脑上打开记事本」。客户端优先切到已有记事本，必要时还原最小化的窗口，找不到可用窗口时启动系统记事本。任务卡会在客户端核实记事本已处于前台后显示完成。只想切换已有窗口，可发「在我的电脑上切换到已打开的记事本窗口」。这条指令找不到窗口时会提示接手。两条指令都只操作记事本窗口，无需截图或调用识屏模型。1.2.10 起可在同一对话紧接着下达简单文字输入指令。其他编辑和菜单操作按识屏流程办理。

桌面端在尚未设置常用电脑时可使用当前账号已授权且能接单的本机。已有常用电脑时按设备选择执行，也可以在指令中指定设备名。如需回到输入框，可从「我的电脑」点「下达指令」。在已选定或已识别本机的 XUTI DESKTOP 工作台，明确要求打开或切换微信、企业微信、记事本、计算器时可省略电脑名，例如「打开微信，给好友阿龙发句问候」。适用入口包括文字、听写后发送的文字、分段语音和实时通话。

使用微信前，先在本机登录并打开微信窗口。小序可在已打开的窗口中定位会话、准备问候草稿。联系人重名或收件人无法确认时，在微信中亲自核对并选择目标联系人，再按任务提示继续。最终由你核对收件人和正文并点击「发送」。在右栏「我的电脑」查看实际进度，同一设备已有未结束的任务时，从任务卡查看或继续即可。

### 自动查找并打开企业微信

Windows 桌面端 1.2.15 起，在已安装企业微信、已连接且已记住授权的电脑上，可以直接发「在我的电脑上打开企业微信」。小序会查找并核验腾讯签名的企业微信，必要时从本机安装位置唤起应用。只要求打开或定位时，核实目标窗口位于前台后，结果会显示在原任务卡。

要继续操作，可发「在我的电脑上打开企业微信，搜索联系人陈晨」。小序会先定位企业微信，再根据其窗口中可见的内容操作。搜索和准备问候草稿需要「小序电脑识屏与操作」服务。联系人重名或无法核对时需要你选择，登录和最终发送由本人完成。找不到安装程序、签名无法核验或应用没有可操作窗口时，任务卡会显示原因。旧任务若已显示「需要你接手」，更新接单电脑后可从原任务点「继续当前任务」。（2026-11-26）

在普通浏览器中发送电脑指令、操作其他电脑或使用其他本机应用时，仍需明确指定目标，例如「在我的电脑上打开 Excel」或「在办公室电脑上打开 Excel」。设备离线或同名时先核对设备。其他业务页保留输入区快捷入口。

桌面客户端在右栏电脑面板点击「使用我的电脑」即可连接并请求首次授权。确认后复用授权，取消时保留文字和附件。普通浏览器可从右栏连接 Windows 客户端，再把指定的在线设备设为常用电脑。

当前电脑按账号记住，刷新后核对在线和归属；离线或连接失效时提示恢复或重新选择，不自动改用另一台电脑。旧专用电脑偏好会回到网站内，需主动选择具体电脑。电脑面板只在有设备时显示选择列表；配对码与连接授权管理收起，按需展开，撤销或断开仍可用。正在进行的任务和语音固定原目标；改变模式不会迁移任务。

## Windows 桌面客户端

当前提供 Windows 10/11 x64 免安装版，将工作台、网页窗口和本机电脑操作放在一个客户端中，不需要再启动独立助手。下载包包含已编译程序与依赖，不在用户电脑上编译。

1. 在「我的电脑」点击「下载 Windows 桌面端」，已有设备时可展开「其他连接方式与客户端更新」下载新版，完整解压，双击 `XutiDesktop.exe`，也可双击「启动小序.cmd」。同目录 DLL 文件需要保留。需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime；缺少网页环境时客户端提供微软官网下载入口。不要以管理员身份运行。
2. 首次在桌面端登录网站。桌面端使用独立的本机浏览器配置，不能直接继承 Chrome 登录。网页会话仅保存在当前 Windows 用户目录中，不复制原有浏览器 Cookie；小序设备凭据使用当前 Windows 用户加密保护。
3. 启动后，主窗口标题为 **XUTI DESKTOP**，工作台铺满窗口内容区。查看设备是否在线、任务进度或需要接手的原因时，打开右侧「我的电脑」。点击「使用我的电脑」连接并授权，或点击「打开电脑任务」查看、暂停或停止任务。配对码、手动选择窗口和撤销授权等选项在本机任务页的「高级设置」中。点击任务页的「返回工作台」可回到原网页。
4. 「本地浏览器」打开或返回专用本地窗口，在地址栏输入 HTTPS 地址。支持后退、前进、刷新和用户主动打开的登录弹窗；网页会话在本机保留。文件上传仍由你选择文件，下载弹出保存位置选择。麦克风、摄像头由你在客户端提示中决定是否允许本次使用。
5. 独立网页窗口也可以在「电脑任务」中选作目标，或在跨窗口授权后由小序按任务切换；工作台自身的控制界面不能被电脑任务点击。第三方网页没有本机连接、文件或执行接口。只有已逐次允许或按有效设备授权启动的任务才会抓取画面和执行输入；没有进行中的任务时不会截图。

在客户端主窗口，`Ctrl + 1` 返回工作台，`Ctrl + 2` 打开本地浏览器，`Ctrl + 3` 打开电脑任务，`Ctrl + Shift + L` 打开本机连接与授权。`F5` 或 `Ctrl + R` 刷新工作台，`F1` 打开桌面帮助手册。在独立网页窗口中按 `Ctrl + L` 可聚焦地址栏。

从桌面端 1.2.8 起，主窗口标题栏跟随当前站内页面的主题。可在暗色的「我的工作台」和浅色的「库存明细」之间切换，也可在「经营分析」等支持切换的页面点击顶部太阳／月亮按钮。Windows 11 支持将标题栏背景和文字设为与网站顶栏相同的配色。Windows 10 由系统绘制标题栏，颜色可能随系统版本和个性化设置而异。启用 Windows 高对比度时，标题栏使用系统配色。

### 更新桌面客户端

- 1.2.7 及更新版本在启动和运行期间自动检查官网发布的版本。发现新版时可点「下载新版」，也可点「稍后」继续工作。1.2.5 和 1.2.6 版本加载新版网站后，登录页会显示更新提醒，进入工作台后可在页面右上角点击「下载新版」。主动提醒仅向 Windows 桌面客户端显示。
- 网站页面随线上版本更新。需要手动下载 Windows 程序时，在工作台打开「我的电脑」。已有设备时，展开「其他连接方式与客户端更新」并点击「下载新版桌面端」。
- 下载完成后，先结束本机正在执行的任务，再退出旧程序，将新包完整解压到新目录，启动其中的 `XutiDesktop.exe`。登录配置和设备凭据保存在当前 Windows 用户目录。电脑任务沿用此前选定设备的有效授权。当前下载包尚未配置代码签名，遇到系统拦截时核对来源并自行处理，不关闭安全检查。

## 连接本机并执行任务

1. 登录桌面端后，在工作台右栏电脑面板点击「使用我的电脑」；其他业务页可点输入区「我的电脑」，桌面端也可按 `Ctrl + Shift + L` 连接。系统自动连接并打开本机确认，允许后记住授权，自动选中这台电脑；工作台保留右栏电脑面板，可从中栏下达指令，其他页面回到对话。已有有效授权时直接进入，免去复制配对码、打开任务面板和再次选择设备。取消确认会保留连接与原先的对话模式，可再点「使用我的电脑」重试。1.2.1 客户端也支持输入区快捷入口，1.2.0 仍需在原有电脑任务面板确认。
2. 已在桌面端连接的电脑也会显示在 Chrome 等浏览器的设备列表中，选择即可下达任务。需要连接其他电脑时，展开「其他连接方式与客户端更新」，生成配对码并粘贴到对应桌面端的「电脑任务 → 高级设置」。配对码10分钟有效、仅使用一次，重新生成使先前未使用的码失效。最多连接5台电脑，名称使用本机计算机名。本机已有不同账号的连接时先断开再重新连接，不静默切换账号。
3. 配对绑定当前网站账号及本次登录会话，网站退出登录、登录会话过期、账号失效或权限撤销后需重新配对；设备连接最长30天。电脑凭据及记住的跨窗口授权仅在本机当前 Windows 用户下加密保存，网站不获取浏览器 Cookie、密码或原有登录会话。
4. 连接成功后，在文字或语音中指定目标设备。在 XUTI DESKTOP 工作台明确打开或切换上述四种应用时，可沿用已选定并授权的本机。常用电脑按账号记住，设备离线时提示恢复连接。任务卡显示实际设备与进度。电脑执行器只接收本条指令。要提交电脑任务，请先移除附件。其他业务页的手动语音模式仍在通话开始时绑定设备。
5. 已记住授权时，打开要操作的应用或网页后直接发送任务，小序自动选择起始窗口并逐步观察、点击、输入或滚动。未记住授权时，从「我的电脑 → 打开电脑任务」进入本机任务页，在「高级设置」选择**已经打开的应用窗口**，点击「允许本次任务」。窗口画面及可见控件名称会发送到已配置的智能服务。任务使用默认助理能力；服务或识图失败时，请管理员核对服务连接与支持情况。

## 实时语音识屏点击（2026-11-21）

适用于千问、豆包及原有实时通道，沿用桌面端的截图与执行能力。使用记事本的本机快捷操作、备用停止快捷键及本机接单诊断需 1.2.9 或更新版本。

1. 先连接电脑，在工作台「我的电脑」面板点击「设为常用电脑」，确保默认助理能力支持看图。需要自动开始及跨窗口识别时，在本机记住跨窗口授权；未授权时仍可创建任务，但要在本机选择窗口并允许后才会执行。
2. 开始实时通话。字幕区显示「自动选择」。同一通话内可交替说站内任务、独立浏览器任务和指定电脑的任务。每个任务提交后固定其目标。其他业务页保留通话开始时的手动选择。
3. 明确说出目标，例如「在我的电脑上点击记事本里的编辑菜单」或「在办公室电脑上向下滚动找到库存明细」。小序提交任务，本机执行器根据当前窗口截图和可见控件识别位置，每次执行后重新观察，再决定下一步；目标不明确或无法识别时请求接手，不猜坐标。
4. 普通聊天、能力咨询和任务进度查询不会作为新的电脑任务。说「返回我的工作台」等明确站内导航时，直接切换本站页面。电脑任务的提交回复不代表点击成功；在「我的电脑」查看当前步骤与最终结果，也可询问任务进度。同一台电脑已有未结束任务时，不再创建第二个任务。
5. 开口打断会停止当前语音回复。结束通话后，已提交的电脑任务可在「我的电脑」暂停或停止，也可使用本机「电脑任务」显示的停止快捷键。需要接手的任务保持暂停，登录、付款等步骤仍由本人完成。

电脑离线、连接失效或识图失败时，会给出具体错误。先恢复连接或由管理员核对服务连接与支持情况，再下达新的明确指令。通话中的其他站内指令仍可继续。工作台的分段语音也按识别后的本条文字执行，电脑授权条件相同。

**语音演示面板（2026-11-10）**：桌面客户端打开的是同一网站，实时通话中的半透明演示面板同样显示在客户端窗口内，无需更新客户端。演示只在网站窗口中显示，不会在所选电脑上打开其他窗口或执行点击；使用方法见「我的工作台 → 语音演示面板」。

## 记住设备的跨窗口授权

在工作台「我的电脑」中点击「使用我的电脑」，在本机确认一次后记住授权。取消时保持原先的对话模式。1.2.0 桌面端需要在原有「电脑任务」面板中确认，下载新版后可使用简化流程。授权绑定当前账号、配对设备和 Windows 用户，在客户端重启后保留，直到手动撤销；原登录或设备连接失效、断开、重新配对后需要重新授权，不转移到新账号或其他电脑。1.2.2 在连接前会检查已保存的凭据，确已失效时清理后重新连接；网络异常时保留连接供重试。网站按钮只唤起本机确认，不能自行开启权限。

授权后，发往这台电脑的新任务自动选择一个可操作的起始窗口并开始，不再逐任务确认。小序可在本轮列出的已打开、未最小化的普通应用及网页窗口之间切换，每轮最多40个窗口。每次切换后先观察新窗口再操作；同一窗口的网页标题变化不要求重新授权。关闭不希望被操作的窗口后再发送任务。

跨窗口模式会向已配置的智能服务发送可用窗口的应用名和标题，以及当前操作窗口的截图和可见控件文字。不会同时发送所有窗口截图。只有正在执行任务时才发送画面；授权不授予终端、任意文件读取或管理员权限，敏感步骤仍需本人接手。

可在本机「电脑任务 → 高级设置 → 撤销本机操作授权」或网站「我的电脑 → 选择我的电脑 → 管理连接与授权 → 撤销跨窗口授权」中撤销。设备的实时授权状态与任务进度统一在电脑操作面板查看；工作台的任务卡显示已派发任务的目标，直接发送普通消息即可继续站内对话。其他页面保留输入区的「返回网站对话」。其他电脑的授权需在对应的本机客户端确认。撤销后当前任务暂停，后续回到逐次允许模式，设备连接仍保留。本机撤销立即停止本机输入；网站撤销阻止下一步许可，客户端在线时同步停止。已发出的输入可能已完成。若本机离线撤销提示同步失败，先保持任务停止，联网后确认网站授权标记消失；也可直接从网站撤销。重新开启只能在本机确认，服务器上的授权标记不会自行提升客户端权限。

## 进度、接手与停止

发出指令后，聊天中的任务卡显示目标设备、执行状态、实际步数、窗口和更新时间。看到「已提交」后，可在同一卡片查看电脑何时接单、执行是否完成。设备能否接单、是否已记住授权分别显示。若下发后 30 秒仍未收到客户端接单，查看任务卡上的提示。待客户端恢复后核对原任务，点「继续当前任务」。

升级前已下达的单条记事本指令，若一直未开始、未执行任何操作，升级并恢复接单后可直接在原卡片点「继续当前任务」。客户端会按当前有效的本机授权执行，并把结果更新在原任务中。

关闭对话抽屉或窗口转到后台后，有活动任务的工作台任务卡仍会定期刷新；回到页面或网络恢复时立即重新核对。系统挂起浏览器进程、断网时刷新可能延迟，以更新时间为准。

任务卡可直接「继续当前任务」「暂停任务」「停止任务」，无需重发指令。当前电脑已有等待、运行、暂停或需要接手的任务时，再次发送会先显示已有任务并保留草稿，不创建第二条任务。先继续原任务，或停止后再发送新任务。启动时没有可操作窗口或校验失败，会显示本机上报的具体原因；按提示处理后再继续，不会一直只有“等待执行”。旧任务已被暂停或停止时，迟到的启动错误不会覆盖该状态。

桌面客户端同样支持小序的实时语音通话。在网站「语音设置」启用并验证实时通道后，点击工作台「想聊什么？」或输入栏蓝色声波按钮开始；第一次使用需在客户端允许麦克风。可持续交谈、开口打断、打开业务页面、启动已授权的同步任务，以及向选定的电脑提交识屏操作。实时通话和文字指令使用相同的本机选择及授权规则。退出或最小化导致页面隐藏时停止麦克风，恢复后主动重开。通道配置、计费与故障处理详见「我的工作台 → 智能语音对话」。

「我的电脑」显示设备的「逐次允许 / 已记住跨窗口授权」、任务范围、状态、最近步骤和时间；动态反馈也显示本人电脑任务。关闭外部浏览器里的网站页面不会停止已允许的本机任务，电脑和桌面客户端必须持续在线。退出小序桌面端会立即停止本机输入，并尝试将任务标记为暂停；网络不可用时云端显示可能延迟。重启保留设备授权，但不会自动恢复之前运行中或已暂停的任务，核对后主动继续。云端经营分析或库存同步任务仍按原流程运行。

可在网站或本机点击「暂停」「停止」。本机默认停止快捷键为 **Ctrl + Alt + X**。从 1.2.9 起，如果这组键已被占用，客户端尝试 **Ctrl + Alt + Shift + X**，在「电脑任务」显示实际可用的组合。两组均不可用时会显示原因，恢复收单后可继续。单纯移动鼠标或松开按键、鼠标按钮不会暂停。在 1.2.14 的后台文件复制期间，你可以点击、滚动、打字或切换应用。对于已记住授权的前台识屏任务，小序在观察画面或两步之间遇到手动操作时会让出窗口。回到原窗口并空闲约三秒后，小序重新观察再决定下一步。如果输入已获准发出或正在输入文字，以任务卡的接手提示为准。逐次授权和资源管理器快捷键模式仍需要独占前台操作。已授权的小序自行切换窗口可继续执行。逐次允许模式恢复时需要在本机重新选窗口并允许；记住授权后，核对结果并点击网站「继续」，或点击本机主面板的「继续当前任务」，自动选择起始窗口。需要手动指定窗口时，在高级设置中选择后点击「从此窗口继续」。暂停和需要接手时需主动继续。停止前已发出的单次输入可能已经完成。

登录、验证码、密码、付款、对外发送、删除、安装和安全设置等步骤交由你处理。逐次允许模式的弹窗或新窗口需重新选择；跨窗口模式可切换至符合范围的新窗口，受保护或无法识别的窗口仍需接手。没有逐次点击审批。

任务指令、状态与简短步骤记录保存在本人任务中，截图不落库、不保存在本机文件中。窗口截图和控件文字会交给智能服务处理，请先关闭敏感内容；模型调用产生正常服务费用。

## 限制与故障处理

- 电脑识屏与步骤规划使用「AI 模型管理 → 小序电脑识屏与操作」的 OpenRouter 连接，和千问实时语音的百炼连接独立。语音有余额或验证通过，不表示电脑识屏调用可用。1.2.4 会保留服务器给出的安全失败原因与诊断编号，不再统一改写为“连接或智能服务异常”。按提示核对对应服务；403 表示调用被拒绝，不能仅凭该状态认定余额不足。恢复服务后主动继续原任务，不自动切换模型或重复执行不确定的动作。

- 通用识屏支持已解锁电脑上的普通权限 Windows 应用窗口。Mac Finder 助手支持上文的文件复制。已记住设备授权时，1.2.9 起可按指令启动系统记事本，1.2.15 起可定位或唤起腾讯签名的企业微信。其他应用请先自行打开。远程开机、管理员窗口、终端、脚本执行、密码管理器和系统安全界面均不在支持范围内。
- 一台电脑同时运行一个任务。每80步或连续操作30分钟进入检查点，先核对结果，再停止旧任务并创建后续任务。不要把“已执行点击”当作业务办理成功，以页面真实结果为准。
- 网络断开时停止本机输入；恢复后需要核对窗口并主动继续，逐次允许模式仍需重新允许。已执行但反馈丢失的步骤不会重复点击或输入；结果不确定时请求接手。
- 授权按钮不可用时先连接本机；旧版客户端只支持逐次允许，需要下载新版。授权返回无效时核对网站与桌面端是否已一同更新。已记住授权却未自动开始时，检查客户端是否运行、是否有可操作窗口，以及任务是否已暂停或需要接手。
- 窗口遮挡、位置变化、无法截图或应用无响应会暂停。重新选择窗口；截取一直未响应时重启本机助手。截图黑屏或控件无法识别的应用可能不兼容，不能保证完成所有软件的操作。
- Windows 有时会阻止后台程序把窗口切到前台，特别是从普通浏览器下单时。任务卡若提示记事本未到前台，请按提示切到记事本，再在本机「电脑任务」中继续原任务。
- 点击网站设备的「断开」会撤销授权并停止其活动任务；本机「断开本机」移除本机保存的连接，网站仍可撤销对应设备。首次安装遇到系统提示时由用户核验来源处理，助手不绕过系统安全拦截。
- 网页无法加载时可点「重新连接」或「在浏览器中打开」；需要暂停或停止本机任务时，点击恢复页的「打开电脑任务」。缺少 WebView2 Runtime 时先安装微软官方运行环境。窗口最小化、关机或锁屏时无法继续本机操作；当前不提供托盘常驻或无人值守登录。

## 构建与维护

维护者在 Windows 运行 `pnpm build:desktop`，从固定版本的微软 SDK 构建并执行本机校验。SDK 下载核对 SHA-256，下载包保留微软许可与源代码；生成的发行包和源文件指纹一同提交。网站构建核对发行包完整性和源文件指纹，避免发布与当前源码不一致的桌面版本。网页内容无法调用终端或任意本机方法；连接桥只接受本站主页面的连接、状态、打开本机确认、控制面板与本地浏览器请求。授权请求绑定当前设备，由本机对话框完成确认；重复请求不会切换或撤销已有授权。
