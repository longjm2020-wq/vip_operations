# 小序桌面客户端与电脑操作

更新日期：2026-11-21。桌面客户端版本：1.2.5。工作台按每条文字或语音指令选择执行方式。右栏可打开服务器上的独立浏览器、Windows 本地浏览器和「我的电脑」。自动操作需要个人助理权限和对应智能服务就绪。

打开电脑操作面板时从顶部显示连接入口，不沿用聊天的滚动位置。查看下方任务时，后台刷新会保留当前阅读位置。

## 网站内操作

在工作台中栏直接输入或说出目标，「＋」用于附件。窄屏时可先收起右栏返回中栏。其他业务页面仍可在助理输入区手动选择「网站内」。发送明确的单条指令，如“打开经营分析”“打开库存明细”“更新罗盘数据”“同步聚水潭库存”，会按当前账号权限直接打开页面或提交相应任务，无需再点确认卡片。文字和智能语音均可使用；查询、否定、复合要求或带附件的消息不会被当作这类快捷指令。

更新数据使用原有后台同步流程，提交不代表同步完成，实际进度和错误在相应页面及小序动态反馈中显示。库存、项目查询仍通过受权限约束的业务工具；日程和记忆保持草稿确认流程。小序提供的其他操作卡片仍需点击后提交。

「返回到我的工作台」「回到工作台」「打开我的工作台」可直接切换至本站工作台，不需要电脑授权或模拟点击。导航也支持「返回库存明细」等已有页面名称；否定、提问和混合指令不自动跳转。

外部网页也可按名称直接打开：在工作台直接输入，其他业务页可点击「返回网站对话」，然后单独发送「打开腾讯网」「打开百度」或其他明确网站名称。常见名称立即打开；其他名称先打开等待页，查询官网后自动进入，无需再发网址。只有名称不明确或没有可靠来源时才请补充名称。仍支持「打开 https://具体网址」。普通浏览器新建标签页，1.2.0 桌面端新建内置网页窗口，原对话保留，无需重装客户端、额外开启联网或跨窗口授权。名称查询只发送该名称，不附带历史或个人资料，按智能服务和公开搜索实际用量计费。弹窗被拦截时会显示打开链接；查询失败或超时可返回原对话查看原因。桌面端回复表示已发出请求，网络失败或达到8个窗口上限时仍需查看本机提示。选择电脑执行位置时仍进入电脑任务流程；此入口不自动登录或操作网页内容，附件、混合任务和连续智能语音不触发此动作。

## 小序独立浏览器

独立浏览器运行在服务器上，不使用你的本机鼠标、键盘或浏览器登录状态。每个账号使用一个独立网页会话，同一账号换电脑登录网站后仍可查看已有页面与任务。管理员需要部署浏览器执行服务并配置会话加密。普通打开网址、点击和输入不调用模型；让小序自动完成目标时，还需要启用并验证对应智能服务。未连接执行服务时明确显示原因，不改用本机或站内操作。

### 直接浏览网页

1. 打开右栏「独立浏览器」，在「网页地址」输入公开 HTTP/HTTPS 网址，按回车或地址旁箭头打开。仅输入域名时补全 HTTPS。输入网址会直接导航。从新标签或已结束的历史标签打开新网址时，隔离浏览器启动时就采用提交瞬间的网页区域尺寸。已有可用页面时复用当前浏览器。首次等待时间受云端启动、目标网站响应和画面回传影响。收到当前导航的首张画面后，页面会立即核对会话状态，确认可操作后开放点击和输入。地址输入中的文字会保留，错误以短提示显示。（2026-11-19）
2. 顶部提供真实「后退」「前进」「刷新网页」。前进、后退是否可用以该浏览器的实际历史为准；刷新会重新加载网页。普通浏览不显示 AI 步数和暂停按钮。`+` 打开网址输入页，提交后使用同一个浏览会话，不创建多个同时运行的标签页。
3. 直接点击网页中的按钮或输入框，在画面中用键盘输入，支持中文输入法和纯文本粘贴。Tab、Shift+Tab、Enter、全选、退格、删除、方向键、Home、End、Page Up、Page Down 和 Esc 传给网页，滚轮直接滚动网页。没有第二个输入框或常驻按键条。按 Esc 后再按 Tab 可移出画面。单次输入或粘贴最多2000字符。
4. 人工输入按顺序提交，上一操作得到执行后的新截图确认后才发送下一操作。截图过期或页面跳转时停止尚未发送的输入，核对画面后重新操作；不自动重放旧坐标。等待网页更新时画面点击会禁用并显示忙碌光标，已聚焦的键盘输入仍按顺序处理。截图是定期更新的画面，不是实时视频。主动调整面板、窗口或全屏尺寸时会调整真实浏览器视口，网页区域占满地址栏下方空间，截图保持比例。同一账号在多个窗口查看同一页面时，已有窗口的后台刷新不会反复改回自己的尺寸；新打开的窗口先按比例查看已有画面，需要适配当前窗口时可调整分栏或使用全屏。右上角收起箭头旁的「全屏查看」可将浏览器铺满屏幕，工作台内同样可用；点击「退出全屏」或按 Esc 恢复原分栏。系统不支持全屏接口时使用页面内全屏显示。全屏会同步调整真实网页视口，不会另建会话或发送 AI 目标；收起面板会先退出全屏。
5. 标签上的 `×` 关闭当前网页并释放执行环境；独立的收起箭头只隐藏面板，保留当前网页。工作台右栏收起后，可从场景边缘竖栏重新展开浏览器或选择其他工具。浏览页面连续5分钟无操作会关闭，首次环境准备时间不计入；页面轮询不会延长这个时间。单次会话最长30分钟。重新打开可复用已保存的登录状态，但不保证恢复原页面位置。

### 让小序操作网页

在工作台直接输入或说出明确的网页操作，例如「去品牌官网查退货政策」。已有页面时，可在右栏独立浏览器的标签菜单点「让小序操作当前网页」，补全中栏草稿后发送。窄屏可先收起右栏。自动任务只接收本条指令。要交办外站操作，请先移除附件。其他业务页仍可手动选择独立浏览器。（2026-11-21）

小序自动观察并连续操作时，顶部显示紧凑进度、真实步骤和暂停、继续、停止操作。普通网址输入不触发这条 AI 流程。小序正在操作时，先点「暂停」接管，再点击、输入或修改网址；不会静默抢占正在运行的目标。登录、密码、验证码、付款、对外发送和删除等步骤需要你处理。仅点击、输入或滚动接管后，点「继续」让小序继续原目标；修改网址、前进、后退或刷新会结束原自动目标并转入普通浏览，之后可发出新的目标。「停止」只停止自动目标，网页仍可浏览。AI 目标完成后返回普通浏览，保留当前页面。提交、派发点击和步数都不代表业务办理成功，以目标网页真实结果为准。

网页自动化使用「AI 模型管理 → 小序独立浏览器」的中央配置，不沿用普通聊天选择的型号。自动分流的每个目标采用提交时的型号，已建立的任务保留自身的型号。模型未就绪时仍可直接浏览；自动化目标需对应服务就绪。模型调用按供应商实际回执记录用量，未返回的 Token 或费用显示未知，不当作零；实时语音另按对应通道记录。直接浏览不把网页截图发送给模型，云端浏览器仍消耗执行环境资源。

### 页面、历史与登录状态

点击标签标题打开「浏览器标签与会话菜单」，查看最近网页与任务、管理登录状态。工作台可拖动中右分隔线调整查看面积；其他业务页面从标题菜单选择「展开浏览器／恢复分栏」。手机和窄屏一次显示中栏或右栏，收起右栏返回中栏。切换面板和查看历史不改变对话草稿、不调用模型。

登录会话加密保存在当前账号下，下次打开可复用；目标网站可能要求重新登录。在标签标题菜单选择「清除浏览器登录状态」，核对弹窗后「清除并停止」，会关闭当前浏览器并清除保存的网页登录状态与任务截图。不影响本机浏览器。旧已结束任务的最终遮敏截图可只读查看24小时；地址旁「只读」提示包含保留期限，不能点击或输入。历史画面的刷新仅重新读取保留截图；在地址栏打开网址会进入新的活浏览会话。

浏览器选择按当前账号保存，刷新后恢复，其他账号不会继承。网络中断、浏览器服务失联或环境回收时显示原因，不会转给你的电脑。执行服务未就绪时显示最近有效检查的安全原因；缺少浏览器程序、运行组件或隔离支持时需管理员检查部署，不会关闭隔离要求继续执行。服务心跳超过30秒未更新后，不把旧原因当作当前结论。

当前只处理公开网络网页，不访问本机文件、内网地址、系统应用或任意脚本。自动化模式会将网页截图和可见内容交给已配置智能服务；普通浏览、等待输入和保留网页期间也占用云端执行资源。登录输入、会话和截图通过当前账号权限约束的接口处理。网站限制自动化、验证码不兼容、文件上传下载或页面无法识别时可能需要接管或无法完成，不能保证所有网站都可自动操作。

## Windows 本地浏览器

1. 解压并登录 1.2.5 或更新版本的 Windows 桌面端。从顶部「本地浏览器」或工作台右栏「独立浏览器」中的「本地浏览器」打开单独窗口。输入 HTTPS 网址即可浏览，也可从右栏把当前地址直接交给本地窗口。
2. 本地浏览使用 WebView2 独立配置。网页由本机加载，登录会话保存在当前 Windows 用户的设备上。普通浏览无需连接云端浏览器，也不调用模型。
3. 要让小序操作，先在本地窗口打开目标页，并在右栏「我的电脑」连接与选择设备。点击「让小序操作本地网页」填写草稿，或直接输入、说出「在本地浏览器里点击详情」。小序只操作这个窗口里的网页内容，任务按本机逐次允许或已记住的授权执行，进度在「我的电脑」查看。登录、验证和敏感操作仍由本人处理。
4. 小序接手时使用当前前台窗口和本机输入，并沿用暂停、停止机制。网页内容区的画面与可见控件交给现有电脑识屏模型处理。直接浏览时没有这项模型调用。设备离线或网页未打开时会提示检查，任务保持原目标。

## 我的电脑：连接一次，直接使用

「我的工作台」可从右栏工具标签选择「我的电脑」；浏览器打开时先关闭其标签，再点击竖栏电脑图标，连接、授权管理及任务进度都在右栏显示，中栏保留当前场景、对话与输入。仅查看或收起面板不选择执行电脑、不撤销授权、不停止任务；设为常用电脑后，明确说「在我的电脑上…」才会使用该设备。

在工作台明确说「在我的电脑上打开 Excel」，或写出具体设备名，例如「在办公室电脑上打开 Excel」。设备离线或名称重名时先核对设备。其他业务页保留输入区快捷入口。

桌面客户端在右栏电脑面板点击「使用我的电脑」即可连接并请求首次授权。确认后复用授权，取消时保留文字和附件。普通浏览器可从右栏连接 Windows 客户端，再把指定的在线设备设为常用电脑。

当前电脑按账号记住，刷新后核对在线和归属；离线或连接失效时提示恢复或重新选择，不自动改用另一台电脑。旧专用电脑偏好会回到网站内，需主动选择具体电脑。电脑面板只在有设备时显示选择列表；配对码与连接授权管理收起，按需展开，撤销或断开仍可用。正在进行的任务和语音固定原目标；改变模式不会迁移任务。

## Windows 桌面客户端

当前提供 Windows 10/11 x64 免安装版，将工作台、网页窗口和本机电脑操作放在一个客户端中，不需要再启动独立助手。下载包包含已编译程序与依赖，不在用户电脑上编译。

1. 在「我的电脑」点击「下载 Windows 桌面端」，已有设备时可展开「其他连接方式与客户端更新」下载新版，完整解压，双击 `XutiDesktop.exe`，也可双击「启动小序.cmd」。同目录 DLL 文件需要保留。需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime；缺少网页环境时客户端提供微软官网下载入口。不要以管理员身份运行。
2. 首次在桌面端登录网站。桌面端使用独立的本机浏览器配置，不能直接继承 Chrome 登录。网页会话仅保存在当前 Windows 用户目录中，不复制原有浏览器 Cookie；小序设备凭据使用当前 Windows 用户加密保护。
3. 顶部「工作台」返回已打开的工作台；「操作本机」直接开始连接与授权，完成后回到电脑对话；「电脑任务」查看当前任务、暂停或停止。配对码、手动选择窗口和撤销授权等选项收起在高级设置中。「刷新」刷新工作台，「使用帮助」打开本章。网站仍支持亮暗主题，客户端外框随网站主题变化。
4. 「本地浏览器」打开或返回专用本地窗口，在地址栏输入 HTTPS 地址。支持后退、前进、刷新和用户主动打开的登录弹窗；网页会话在本机保留。文件上传仍由你选择文件，下载弹出保存位置选择。麦克风、摄像头由你在客户端提示中决定是否允许本次使用。
5. 独立网页窗口也可以在「电脑任务」中选作目标，或在跨窗口授权后由小序按任务切换；工作台自身的控制界面不能被电脑任务点击。第三方网页没有本机连接、文件或执行接口。只有已逐次允许或按有效设备授权启动的任务才会抓取画面和执行输入；没有进行中的任务时不会截图。

快捷键：`Ctrl + 1` 返回工作台，`Ctrl + 2` 打开本地浏览器，`Ctrl + 3` 打开电脑任务，`Ctrl + Shift + L` 开始操作本机；独立网页窗口内 `Ctrl + L` 聚焦地址栏。

网站页面随线上版本更新；客户端本体通过「下载新版桌面端」更新，退出旧版后解压到新目录即可。登录配置保存在本机用户目录，不随解压目录变化。当前下载包尚未配置代码签名，遇到系统拦截时核对来源并自行处理，不关闭安全检查。

## 连接本机并执行任务

1. 登录桌面端后，在工作台右栏电脑面板点击「使用我的电脑」；其他业务页可点输入区「我的电脑」，客户端顶部仍可点「操作本机」。系统自动连接并打开本机确认，允许后记住授权，自动选中这台电脑；工作台保留右栏电脑面板，可从中栏下达指令，其他页面回到对话。已有有效授权时直接进入，免去复制配对码、打开任务面板和再次选择设备。取消确认会保留连接与原先的对话模式，再点「操作本机」即可重试。1.2.1 客户端也支持输入区快捷入口，1.2.0 仍需在原有电脑任务面板确认。
2. 已在桌面端连接的电脑也会显示在 Chrome 等浏览器的设备列表中，选择即可下达任务。需要连接其他电脑时，展开「其他连接方式与客户端更新」，生成配对码并粘贴到对应桌面端的「电脑任务 → 高级设置」。配对码10分钟有效、仅使用一次，重新生成使先前未使用的码失效。最多连接5台电脑，名称使用本机计算机名。本机已有不同账号的连接时先断开再重新连接，不静默切换账号。
3. 配对绑定当前网站账号及本次登录会话，网站退出登录、登录会话过期、账号失效或权限撤销后需重新配对；设备连接最长30天。电脑凭据及记住的跨窗口授权仅在本机当前 Windows 用户下加密保存，网站不获取浏览器 Cookie、密码或原有登录会话。
4. 连接成功后，在文字或语音中明确指定本机或已连接的设备名。常用电脑按账号记住，设备离线时提示恢复连接。任务卡显示实际设备与进度。电脑执行器只接收本条指令。要提交电脑任务，请先移除附件。其他业务页的手动语音模式仍在通话开始时绑定设备。
5. 已记住授权时，打开要操作的应用或网页后直接发送任务，小序自动选择起始窗口并逐步观察、点击、输入或滚动。未记住授权时，可在顶部「电脑任务」选择**已经打开的应用窗口**，点击「允许本次任务」。窗口画面及可见控件名称会发送到已配置的智能服务。任务使用默认助理能力；服务或识图失败时，请管理员核对服务连接与支持情况。

## 实时语音识屏点击（2026-11-21）

适用于千问、豆包及原有实时通道，沿用 1.2.0 桌面端的截图与执行能力，无需为此重装客户端；网站 API、前端和数据库迁移需一起更新。

1. 先连接电脑，在工作台「我的电脑」面板点击「设为常用电脑」，确保默认助理能力支持看图。需要自动开始及跨窗口识别时，在本机记住跨窗口授权；未授权时仍可创建任务，但要在本机选择窗口并允许后才会执行。
2. 开始实时通话。字幕区显示「自动选择」。同一通话内可交替说站内任务、独立浏览器任务和指定电脑的任务。每个任务提交后固定其目标。其他业务页保留通话开始时的手动选择。
3. 明确说出目标，例如「在我的电脑上点击记事本里的编辑菜单」或「在办公室电脑上向下滚动找到库存明细」。小序提交任务，本机执行器根据当前窗口截图和可见控件识别位置，每次执行后重新观察，再决定下一步；目标不明确或无法识别时请求接手，不猜坐标。
4. 普通聊天、能力咨询和任务进度查询不会作为新的电脑任务。说「返回我的工作台」等明确站内导航时，直接切换本站页面。电脑任务的提交回复不代表点击成功；在「我的电脑」查看当前步骤与最终结果，也可询问任务进度。同一台电脑已有未结束任务时，不再创建第二个任务。
5. 开口打断只停止当前语音回复；结束通话也不撤销已经提交的电脑任务。停止电脑执行请使用「我的电脑 → 暂停／停止」或本机 **Ctrl + Alt + X**。需要接手的任务保持暂停，登录、付款等步骤仍由本人完成。

电脑离线、连接失效或识图失败时，会给出具体错误。先恢复连接或由管理员核对服务连接与支持情况，再下达新的明确指令。通话中的其他站内指令仍可继续。工作台的分段语音也按识别后的本条文字执行，电脑授权条件相同。

**语音演示面板（2026-11-10）**：桌面客户端打开的是同一网站，实时通话中的半透明演示面板同样显示在客户端窗口内，无需更新客户端。演示只在网站窗口中显示，不会在所选电脑上打开其他窗口或执行点击；使用方法见「我的工作台 → 语音演示面板」。

## 记住设备的跨窗口授权

点击「操作本机」，在本机确认一次后记住授权。取消时保持原先的对话模式。1.2.0 桌面端需要在原有「电脑任务」面板中确认，下载新版后可使用简化流程。授权绑定当前账号、配对设备和 Windows 用户，在客户端重启后保留，直到手动撤销；原登录或设备连接失效、断开、重新配对后需要重新授权，不转移到新账号或其他电脑。1.2.2 在连接前会检查已保存的凭据，确已失效时清理后重新连接；网络异常时保留连接供重试。网站按钮只唤起本机确认，不能自行开启权限。

授权后，发往这台电脑的新任务自动选择一个可操作的起始窗口并开始，不再逐任务确认。小序可在本轮列出的已打开、未最小化的普通应用及网页窗口之间切换，每轮最多40个窗口。每次切换后先观察新窗口再操作；同一窗口的网页标题变化不要求重新授权。关闭不希望被操作的窗口后再发送任务。

跨窗口模式会向已配置的智能服务发送可用窗口的应用名和标题，以及当前操作窗口的截图和可见控件文字。不会同时发送所有窗口截图。只有正在执行任务时才发送画面；授权不授予终端、任意文件读取或管理员权限，敏感步骤仍需本人接手。

可在本机「电脑任务 → 高级设置 → 撤销本机操作授权」或网站「我的电脑 → 选择我的电脑 → 管理连接与授权 → 撤销跨窗口授权」中撤销。设备的实时授权状态与任务进度统一在电脑操作面板查看；工作台的任务卡显示已派发任务的目标，直接发送普通消息即可继续站内对话。其他页面保留输入区的「返回网站对话」。其他电脑的授权需在对应的本机客户端确认。撤销后当前任务暂停，后续回到逐次允许模式，设备连接仍保留。本机撤销立即停止本机输入；网站撤销阻止下一步许可，客户端在线时同步停止。已发出的输入可能已完成。若本机离线撤销提示同步失败，先保持任务停止，联网后确认网站授权标记消失；也可直接从网站撤销。重新开启只能在本机确认，服务器上的授权标记不会自行提升客户端权限。

## 进度、接手与停止

提交电脑任务后会留在聊天中，回复下方和当前电脑输入区显示实时任务卡，包含等待、运行、暂停、需要接手或完成状态，以及具体原因、实际执行步数、窗口和更新时间。「已提交」只表示收到指令，不表示已点击或完成。任务尚未选定窗口时，不能根据空窗口判断设备授权丢失。

关闭对话抽屉或窗口转到后台后，有活动任务的工作台任务卡仍会定期刷新；回到页面或网络恢复时立即重新核对。系统挂起浏览器进程、断网时刷新可能延迟，以更新时间为准。

任务卡可直接「继续当前任务」「暂停任务」「停止任务」，无需重发指令。当前电脑已有等待、运行、暂停或需要接手的任务时，再次发送会先显示已有任务并保留草稿，不创建第二条任务。先继续原任务，或停止后再发送新任务。启动时没有可操作窗口或校验失败，会显示本机上报的具体原因；按提示处理后再继续，不会一直只有“等待执行”。旧任务已被暂停或停止时，迟到的启动错误不会覆盖该状态。

桌面客户端同样支持小序的实时语音通话。在网站「语音设置」启用并验证实时通道后，点击工作台「想聊什么？」或输入栏蓝色声波按钮开始；第一次使用需在客户端允许麦克风。可持续交谈、开口打断、打开业务页面、启动已授权的同步任务，以及向本条指令明确指定的电脑提交识屏操作。实时通话不会跳过电脑任务的窗口选择与允许；退出或最小化导致页面隐藏时停止麦克风，恢复后主动重开。通道配置、计费与故障处理详见「我的工作台 → 智能语音对话」。

「我的电脑」显示设备的「逐次允许 / 已记住跨窗口授权」、任务范围、状态、最近步骤和时间；动态反馈也显示本人电脑任务。关闭外部浏览器里的网站页面不会停止已允许的本机任务，电脑和桌面客户端必须持续在线。退出小序桌面端会立即停止本机输入，并尝试将任务标记为暂停；网络不可用时云端显示可能延迟。重启保留设备授权，但不会自动恢复之前运行中或已暂停的任务，核对后主动继续。云端经营分析或库存同步任务仍按原流程运行。

可在网站或本机点击「暂停」「停止」，也可在本机按 **Ctrl + Alt + X** 停止。1.2.3 不会因为单纯移动鼠标，或松开发送指令时的按键、鼠标按钮而暂停；新按下鼠标按钮、滚动滚轮、按下键盘按键或主动切换窗口时仍会暂停并反馈原因。已授权的小序自行切换窗口可继续执行。逐次允许模式恢复时需要在本机重新选窗口并允许；记住授权后，核对结果并点击网站「继续」，或点击本机主面板的「继续当前任务」，自动选择起始窗口。需要手动指定窗口时，在高级设置中选择后点击「从此窗口继续」。暂停和需要接手不会因授权保留而自行恢复。已发出的单次输入可能已经完成，停止不撤销之前的编辑。

登录、验证码、密码、付款、对外发送、删除、安装和安全设置等步骤交由你处理。逐次允许模式的弹窗或新窗口需重新选择；跨窗口模式可切换至符合范围的新窗口，受保护或无法识别的窗口仍需接手。没有逐次点击审批。

任务指令、状态与简短步骤记录保存在本人任务中，截图不落库、不保存在本机文件中。窗口截图和控件文字会交给智能服务处理，请先关闭敏感内容；模型调用产生正常服务费用。

## 限制与故障处理

- 电脑识屏与步骤规划使用「AI 模型管理 → 小序电脑识屏与操作」的 OpenRouter 连接，和千问实时语音的百炼连接独立。语音有余额或验证通过，不表示电脑识屏调用可用。1.2.4 会保留服务器给出的安全失败原因与诊断编号，不再统一改写为“连接或智能服务异常”。按提示核对对应服务；403 表示调用被拒绝，不能仅凭该状态认定余额不足。恢复服务后主动继续原任务，不自动切换模型或重复执行不确定的动作。

- 当前支持普通权限的 Windows 应用窗口。不是远程开机服务，不支持锁屏、管理员窗口、终端、脚本执行、密码管理器或系统安全界面，也不会自动启动其他程序。
- 一台电脑同时运行一个任务。每80步或连续操作30分钟进入检查点，先核对结果，再停止旧任务并创建后续任务。不要把“已执行点击”当作业务办理成功，以页面真实结果为准。
- 网络断开时停止本机输入；恢复后需要核对窗口并主动继续，逐次允许模式仍需重新允许。已执行但反馈丢失的步骤不会重复点击或输入；结果不确定时请求接手。
- 授权按钮不可用时先连接本机；旧版客户端只支持逐次允许，需要下载新版。授权返回无效时核对网站与桌面端是否已一同更新。已记住授权却未自动开始时，检查客户端是否运行、是否有可操作窗口，以及任务是否已暂停或需要接手。
- 窗口遮挡、位置变化、无法截图或应用无响应会暂停。重新选择窗口；截取一直未响应时重启本机助手。截图黑屏或控件无法识别的应用可能不兼容，不能保证完成所有软件的操作。
- 点击网站设备的「断开」会撤销授权并停止其活动任务；本机「断开本机」移除本机保存的连接，网站仍可撤销对应设备。首次安装遇到系统提示时由用户核验来源处理，助手不绕过系统安全拦截。
- 网页不能加载时显示重连入口，也可在系统浏览器中打开工作台。缺少 WebView2 Runtime 时先安装微软官方运行环境。窗口最小化、关机或锁屏时无法继续本机操作；当前不提供托盘常驻或无人值守登录。

## 构建与维护

维护者在 Windows 运行 `pnpm build:desktop`，从固定版本的微软 SDK 构建并执行本机校验。SDK 下载核对 SHA-256，下载包保留微软许可与源代码；生成的发行包和源文件指纹一同提交。网站构建核对发行包完整性和源文件指纹，避免发布与当前源码不一致的桌面版本。网页内容无法调用终端或任意本机方法；连接桥只接受本站主页面的连接、状态、打开本机确认、控制面板与本地浏览器请求。授权请求绑定当前设备，由本机对话框完成确认；重复请求不会切换或撤销已有授权。
