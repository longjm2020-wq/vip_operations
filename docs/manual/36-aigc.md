# AIGC 创作空间

更新日期：2026-11-08。

## 入口与权限

左侧菜单「AIGC」集中提供短视频制作、电商详情页制作、数字人、作品库、站长精选和任务进度。页面沿用本站账号，作为一级入口固定使用暗色主题，不显示亮暗切换按钮；不会覆盖账号在其他业务页面保存的主题偏好。默认仅超级管理员有权限；可通过角色权限分配「使用 AIGC 创作」。配置服务和发布精选需要「管理 AIGC 服务」。没有积分账户、充值、会员或收费管理。

所有项目、上传素材和任务按当前账号隔离，不能直接访问其他账号的素材。站长主动发布的精选模板可供有 AIGC 使用权限的账号制作同款。接入不会导入来源站点的账号、历史项目、素材或凭据，也不修改商品档案和库存。

## 准备模型服务

点击右上角「服务设置」。短视频拆解复用「系统设置 → AI 模型管理」中已启用且验证通过的智能服务。视频通过阿里云百炼北京业务空间调用 `MiniMax/MiniMax-H3`；图片使用独立服务。填写北京业务空间 ID 和有 H3 权限的 API Key，也可勾选「使用已保存的百炼语音连接」在服务器复制现有连接，复制后两处独立配置。Key 加密保存在服务器，不回显，留空保留原值。第三方 API 可能产生供应商费用，本站不增加平台收费。

H3 须已在百炼开通，业务空间与密钥权限均须包含 `MiniMax/MiniMax-H3`。H3 无免费额度：当前刊例 768P 为 0.50 元/秒，2K 为 0.80 元/秒；输入参考视频按同档秒价计费，前 5 张图片免费，超出部分 0.20 元/张，参考音频免费。报价是预估，实际以供应商账单为准。

保存连接后，点击「验证 H3 视频连接」可确认创建一条 4 秒 768P 测试视频，刊例约 2 元，不使用业务素材。验证只创建一个持久任务，页面每 15 秒查询结果；重新打开设置可继续查询。供应商确认成功后显示「H3 视频生成已验证」。提交结果不确定时会保留待核实状态并阻止重复测试，请先在百炼检查原请求。

数字人需要独立部署的 OpenTalking 推理服务。在模型连接中保存 HTTPS 地址及网关 Key，然后到「数字人配置」检测真实模型，选择可用形象模板，再启用服务、文字口播或实时互动。未配置的服务不会以演示结果代替真实生成。运行中的任务未结束前不可更换服务配置。

已有数字人形象或远端任务时保持原推理服务地址，以免旧编号被发送到另一服务；普通文字长度、模板选择和启用开关仍可调整。没有配置当前图像或视频模型的 Key 时，生成按钮不可用。

创作页面使用“视频服务”“视频创作”“图像创作”等能力名称；具体型号仅在有管理权限的服务设置中维护。小序也提供独立的轻量文档、图像及视频剪辑任务，见“我的工作台”，不改变已有 AIGC 项目。

## 短视频

1. 点击「短视频制作」创建草稿，填写名称与创作说明。
2. 上传参考视频、人物原图、商品原图，选择相对或完整复刻、场景、视频模型、比例与画质。
3. 点击「保存项目」持久保存素材关联与设置。「拆解参考视频」将任务加入队列，脚本结果可在项目进度下载；完成拆解后点击「生成成片」。
4. 需要首帧的模型会生成或接受上传的首帧，关键帧面板可选择图像模型、刷新结果，经过视觉扫描后继续。结果不确定时需核实原请求，不能强制重复提交。生成中可查看日志及暂停任务。
5. 「更多素材与实测资料」支持已有模板、衣长和补充实测资料；支持视频/音频参考的模型会显示对应上传入口。

当前新生成仅提供百炼 H3，多模态参考流程要求人物和商品图片共 2～9 张，可选最多 3 段视频和 3 段音频；视频与音频各自单段 2～15 秒、总时长不超过 15 秒。支持 768P / 2K，单次生成 4～15 秒。参考图片与视频须符合 H3 尺寸和比例要求；素材校验后通过与任务绑定的临时链接提供给供应商，完成后清理临时图片副本。模型原生还有其他生成模式，当前创作编辑器使用上述多模态参考流程。

旧模型已移出新选项。旧项目显示提示时，先点击「改用当前视频服务」并保存；已提交旧任务仍用原路由和任务编号查询，不自动换线路或重复生成。

不要填写未经确认的实测信息。上游短视频流程在全部完成后会清理项目原始上传副本，保留脚本和成片，请保留本机原始素材；再次制作可使用可复用模板并重新上传人物与商品。

## 电商详情页和主图

填写商品名称、品类、主色、面料和已确认卖点，上传商品、人物、品牌或场景素材。选择详情页/主图、框架、图像模型和比例。「策划内容模块」根据资料与框架建立内容；逐项修改标题、正文并启用所需模块。「检查生成内容」提示缺失资料；检查通过后生成全部所选图片或单个模块。参考图片模式可分析上传图片的结构。

右侧显示真实任务状态、图片与下载入口。可保存历史版本并恢复；恢复结构不会抹除已生成的历史图片。缺少面料、尺寸等资料时不会自动编造。完成图片自动归档作品库。

## 数字人

选择可用形象，也可以使用已配置模板上传照片或视频创建自己的形象。填写口播文案或上传音频，保存后生成视频。数字人素材最多 10 MB，音频最多 180 秒；文字合成须先启用。

启用实时互动后，可创建会话，等待形象准备好，再连接音视频。输入文字让形象说话，支持打断和结束会话。离开实时互动面板会结束连接；异常断线和服务状态会明确提示。此入口是数字人语音呈现，不会自动调用小序个人助理或读取业务数据。

## 作品、精选与项目管理

作品库可分类查看、预览、下载、收藏和移入回收站；短视频支持制作同款。站长精选内置服装详情页和主图框架，也展示站长主动推荐的短视频模板；尚无模板时显示空状态。管理者可以将自己的可复用模板加入或移出精选。项目可移入回收站并恢复；仍有活动任务时需先等待结束或暂停核实。

## 保存与常见问题

项目状态保存在 PostgreSQL，媒体优先保存在对象存储；没有配置对象存储时使用数据库存储，单个文件最多 20 MB，已配置对象存储时最多 180 MB。上传控件按对应素材的实际限制提示。服务发布会交接队列；交接期间显示稍后重试，不影响其他业务模块。

草稿须点击保存；关闭或刷新浏览器前注意未保存提示。生成任务在服务器执行，关闭页面不取消已提交任务。任务保存供应商请求编号；如果重启发生在提交后、回包前，会保留「结果待核实」而不自动重复生成。错误时先查看任务日志或服务配置，不要连续重复提交。

## 统一模型与用量管理

「系统设置 → AI 模型管理」登记脚本与视觉分析、图片、视频、视频增强、RunningHub 深度工作流和数字人。可切换已配置的编译和图片默认模型；视频仅提供百炼 H3，约 10 秒内应用到创作服务。新视频项目采用 H3，旧项目需重新选择后提交新任务，已提交任务保留原型号。管理页可打开服务配置抽屉。

编译、图片、百炼视频及视频增强保持独立连接。数字人由检测后的模板和项目选择决定，语音参数在数字人配置维护；固定网关或工作流不伪装成任意文字模型下拉框。

新推理请求通过统一计量记录；媒体任务只在提交时增加请求记录，最终回执更新消耗，不把轮询次数当作新的生成。RunningHub 返回的积分、明确的 USD 实际费用、OpenRouter credits 等分别保留来源与单位。没有供应商回执的历史、未返回字段以及数字人网关未提供的费用显示未知，不用价格估算冒充实际消耗。

H3 按供应商任务编号归并回执，记录输入视频秒数、输出视频秒数和计费参考图片数。未提供的 Token 和实际金额保持未知；成功任务回执可验证该次生成，保存密钥或取得任务编号不代表成功。

H3 连接测试失败时显示供应商错误代码和分类说明（参数、权限、余额、费用保护、内容检查或临时服务故障）。仅不含业务素材的固定连接测试可附带经过密钥与链接脱敏、截断后的参数诊断；业务生成任务不展示原始错误全文。失败任务仍保留原编号；查询旧失败任务的原因不会创建新视频，修正原因后再次测试需重新确认。
