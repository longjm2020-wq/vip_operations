# AIGC 创作空间

更新日期：2026-11-28。

## 入口与权限

左侧菜单「AIGC」集中提供短视频制作、电商详情页制作、数字人、作品库、站长精选和任务进度。页面沿用本站账号，作为一级入口固定使用暗色主题，不显示亮暗切换按钮；不会覆盖账号在其他业务页面保存的主题偏好。默认仅超级管理员有权限；可通过角色权限分配「使用 AIGC 创作」。配置服务和发布精选需要「管理 AIGC 服务」。没有积分账户、充值、会员或收费管理。

所有项目、上传素材和任务按当前账号隔离，不能直接访问其他账号的素材。站长主动发布的精选模板可供有 AIGC 使用权限的账号制作同款。接入不会导入来源站点的账号、历史项目、素材或凭据，也不修改商品档案和库存。

「创作工作台」提供 AI智能成片、电商详情页制作和数字人入口。「我的项目」支持搜索名称、按类型筛选和从回收站恢复。上方可切换到作品库、站长精选和任务进度。进入任意创作子页面（AI智能成片、电商详情页制作、数字人）后，顶部导航栏统一显示「返回创作空间」返回入口与当前子页面名称。

## 准备模型服务

点击右上角「服务设置」。短视频拆解复用「系统设置 → AI 模型管理」中已启用且验证通过的智能服务。视频通过阿里云百炼北京业务空间调用 `MiniMax/MiniMax-H3`；图片使用独立服务。填写北京业务空间 ID 和有 H3 权限的 API Key，也可勾选「使用已保存的百炼语音连接」在服务器复制现有连接，复制后两处独立配置。Key 加密保存在服务器，不回显，留空保留原值。第三方 API 可能产生供应商费用，本站不增加平台收费。

「模型连接」按百炼视频、百炼音色、AgentAI 图片、RunningHub 深度参考、脚本与视觉分析、原声对口型、数字人和历史 xAI 视频分组，默认展开百炼 H3。展开所需分组后填写，底部保存。分组中的「已配置」表示已保存密钥，模型管理的成功状态来自实际调用回执。

图片生成在「AI 模型管理 → AgentAI 连接」配置。脚本和视觉分析复用已验证的共享 OpenRouter。历史 xAI 视频的凭据用于其已提交任务。已下线的线路保留原任务号和已归档作品。H3 的测试任务编号在「测试详情」查看，价格在「规格与费用」中查看，创建测试需要确认费用。

H3 须已在百炼开通，业务空间与密钥权限均须包含 `MiniMax/MiniMax-H3`。开通入口在百炼「模型广场」：搜索 MiniMax，在「MiniMax视频模型」卡片点击「立即开通」并确认；商品开通可能有分钟级延迟。仅查看模型详情或添加密钥权限不会开通产品。供应商可能将未开通错误标为 `InvalidParameter`，本站会按具体原因提示开通服务。

H3 无免费额度：当前刊例 768P 为 0.50 元/秒，2K 为 0.80 元/秒；输入参考视频按同档秒价计费，前 5 张图片免费，超出部分 0.20 元/张，参考音频免费。报价是预估，实际以供应商账单为准。

保存连接后，点击「验证 H3 视频连接」可确认创建一条 4 秒 768P 测试视频，刊例约 2 元，不使用业务素材。验证只创建一个持久任务，页面每 15 秒查询结果；重新打开设置可继续查询。供应商确认成功后显示「H3 视频生成已验证」。提交结果不确定时会保留待核实状态并阻止重复测试，请先在百炼检查原请求。

数字人需要独立部署的 OpenTalking 推理服务。在模型连接中保存 HTTPS 地址及网关 Key，然后到「数字人配置」检测真实模型，选择可用形象模板，再启用服务、文字口播或实时互动。未配置的服务不会以演示结果代替真实生成。运行中的任务未结束前不可更换服务配置。

已有数字人形象或远端任务时保持原推理服务地址，以免旧编号被发送到另一服务；普通文字长度、模板选择和启用开关仍可调整。没有配置当前图像或视频模型的 Key 时，生成按钮不可用。

创作页面使用“视频服务”“视频创作”“图像创作”等能力名称；具体型号仅在有管理权限的服务设置中维护。小序也提供独立的轻量文档、图像及视频剪辑任务，见“我的工作台”，不改变已有 AIGC 项目。

## 短视频

服装商品可通过「服装口播」四区集成工作台完成一站式制作（顶部项目栏与模式切换、左上单排横向能力栏：`导入 / 拆解 / 参演配置 / 分镜 / 剪辑 / 预演 / 模型`、中上实时播放器与滤镜字幕预览、右上草稿与分镜参数检查器、底部画面/配音/字幕多轨时间轴；各面板之间支持拖动分割线自由调整宽高，双击恢复默认尺寸）：
- **参演配置（左二级分类侧栏 + 右内容区）**：统一收拢 **总览绑定（含产品主体）**、**角色库**、**服饰库**、**道具库** 与 **场景库**：
  - **角色库**：专注新建角色与角色管理，支持上传面部特写与正面/背面/侧面三视图并绑定百炼音频克隆音色，勾选加入脚本后数字人可按分镜视角（正面近景、正面中景、侧面轮廓、背面回眸、全身走位、过肩/对镜）自由多角度出镜；
  - **服饰库**：支持绑定商品档案款号、上传自定义服装图/输入自定义服饰，并支持按剧情题材智能推荐服装（如武侠剧自动匹配铠甲/布衣等）；
  - **道具库**：支持上传自定义道具图/输入自定义道具，并支持按剧情题材智能推荐道具（如武侠剧自动匹配兵器刀/剑/棍/棒/斧等）；
  - **场景库**：支持上传自定义场景图/输入自定义场景，以及按分类筛选选用 40 种精选风格关键词场景；
- **流水线参演配置**：底部时间轴流水线按 `① 拆解 → ② 参演配置 → ③ 脚本 → ④ 分镜图 → ⑤ 预演 → ⑥ 生成分镜 → ⑦ 合成成片` 推进，点击「② 参演配置」可直接切入参演配置总览一站式绑定角色、产品主体、服饰、道具与拍摄场景后生成脚本；
- **AI 代码自动化智能剪辑**：支持自动编排镜头转场、调色滤镜、画面特效、关键帧运镜动画、动态字幕与卖点花字，云端直出成片或一键导出 Adobe After Effects `.jsx` 自动化脚本。详见「服装口播视频」章节。

1. 点击「短视频制作」创建草稿，填写名称与创作说明。
2. 本机上传参考视频，或在「参考视频 → 导入分享链接」粘贴抖音、小红书的完整分享文案或公开视频链接，点击「导入参考片」。取得可播放视频后，文件会显示在当前项目的「参考视频」。再上传人物和商品原图，选择复刻方式、场景、画幅与视频模型。
3. 点击「保存项目」持久保存素材关联与设置。「拆解参考视频」将任务加入队列，脚本结果可在项目进度下载；完成拆解后点击「生成成片」。
4. 需要首帧的模型会生成或接受上传的首帧，关键帧面板可选择图像模型、刷新结果，经过视觉扫描后继续。结果不确定时需核实原请求，不能强制重复提交。生成中可查看日志及暂停任务。
5. 「更多素材与实测资料」支持已有模板、衣长和补充实测资料；支持视频/音频参考的模型会显示对应上传入口。

分享链接导入适用于服务器可公开读取的 MP4、MOV 和 WebM，单片最长 30 分钟，体积上限和本项目的上传空间一致。遇到登录页、播放限制或已失效的链接时，可上传有权使用的本机原片继续。若当前项目已有参考片，导入失败会保留现有素材。导入只保存素材，点击「拆解参考视频」才调用现有脚本与视觉分析服务。

百炼 H3 的多模态参考流程要求人物和商品图片共 2～9 张，可选最多 3 段视频和 3 段音频；视频与音频各自单段 2～15 秒、总时长不超过 15 秒。支持 768P / 2K，单次生成 4～15 秒。参考图片与视频须符合 H3 尺寸和比例要求；素材校验后通过与任务绑定的临时链接提供给供应商，完成后清理临时图片副本。另可选择已连接的 AgentAI 图片参考视频型号，范围见下节；这条线路不接收参考视频或参考音频。

旧项目显示提示时，先点击「改用当前视频服务」并保存。仍受支持的线路使用原任务编号继续查询。已下线线路保留原任务编号供核对，完成作品可在作品库查看。

不要填写未经确认的实测信息。上游短视频流程在全部完成后会清理项目原始上传副本，保留脚本和成片，请保留本机原始素材；再次制作可使用可复用模板并重新上传人物与商品。

### 浏览本机素材

在支持素材索引的 Windows 小序客户端，点「参考视频 → 浏览本机素材」，选择素材文件夹。客户端在本机扫描相对路径、类型和大小，支持按文件名或子目录查找。单次最多索引 20,000 个文件。首次扫描读取目录与文件属性。确认「上传原片」或「上传此处短片」后，只上传所选视频文件或本机截取的短片。视频预览与截取需要桌面端可用的 FFmpeg。

### 用 CozyClay 预演指定片段

选百炼 MiniMax H3，上传人物和商品原图。在「角色与镜头预演」按角色分配人物和商品图，保存并完成参考拆解。上传 CozyClay 工程和灰模参考片，选择工程中的镜头与已拆解的片段。可填写每句的时间、台词与发言人，并上传一条已按同一时间轴排好的授权整轨对白。灰模和整轨对白与目标片段的时长差均须在 0.75 秒内。可添加首尾参考图留作审片，也可下载工程回到 CozyClay 修改。

保存绑定后，点「生成绑定片段」。H3 接收人物、商品图、灰模视频，以及上传的整轨对白。实际用量记录到「AIGC 视频生成」。作品库单独归档片段，生成后核对角色、商品归属、道具交接和逐句口型。

## AgentAI 图片与视频（2026-11-18）

管理员先在「系统设置 → AI 模型管理 → AgentAI 连接」保存独立密钥、启用并同步目录。目录连接就绪后可选择兼容型号。任务需要 AIGC 权限，素材及成品按账号隔离。

当前适配范围如下，名称沿用 AgentAI 平台目录，不代表原厂直连认证：

| 用途 | 已适配型号 | 当前工作流 |
| --- | --- | --- |
| 图片 | GT Image 2.6 Sunb 高端版、GT Image 2.6 Flare 快速版、GM NB 2.1 Image | 多参考图片融合，每次 1 张 2K；数量、画幅及单图大小按型号校验 |
| 视频 | Seedance 2.5 · 特价按次／特价按秒／官方直连、Seedance 2.0 · 特价按次／特价按秒／官方直连、GK Imagine 1.5 Pro、MiniMax H3、MU Video | 图片参考生视频；时长、分辨率、比例按所选型号和最新目录校验 |

当前媒体工作流至少需要 2 张参考图；不会将超出数量的图片静默丢弃。Seedance 2.5 特价按次固定 30 秒，Seedance 2.0 特价按次固定 15 秒。MU Video 当前参考图工作流开放 10 秒，以兼容多图与各画幅限制。各档位的参数组合以最新目录校验为准。

这条 AIGC 线路不接收参考视频、参考音频、首尾帧或编辑请求。两个指定音频型号在「AI 模型管理 → AgentAI 连接 → 语音制作」单独使用，详见语音制作手册。新任务的 AgentAI 型号只接受指定清单；旧型号的已提交任务仍按原编号查询与归档。

生成前会按同一参数获取估价，并采用智能调度综合价格、成功率与耗时选择可用渠道，由平台自动避开故障渠道。新任务不锁定单条渠道；参数发生不兼容调整或报价缺少有效金额时停止提交。报价、备用渠道价格上界和冻结额不是实际账单。参考图通过 AgentAI 上传接口换取素材地址后提交，异步任务按原任务号查询；提交结果不确定、参数被调整或等待较久时不自动重新收费生成。任务完成后核对结果并归档，供应商实际费用进入「AI 模型管理」相应图片或视频条目，未返回的消耗显示未知。

## 电商详情页和主图

填写商品名称、品类、主色、面料和已确认卖点，上传商品、人物、品牌或场景素材。选择详情页/主图、框架、图像模型和比例。「策划内容模块」根据资料与框架建立内容；逐项修改标题、正文并启用所需模块。「检查生成内容」提示缺失资料；检查通过后生成全部所选图片或单个模块。参考图片模式可分析上传图片的结构。

右侧显示真实任务状态、图片与下载入口。可保存历史版本并恢复；恢复结构不会抹除已生成的历史图片。缺少面料、尺寸等资料时不会自动编造。完成图片自动归档作品库。

## 原声对口型

拥有「使用 AIGC 创作」权限即可使用。管理员先在「AIGC → 服务设置 → 模型连接 → 原声对口型」保存具备推理权限和可用额度的 fal API Key。网站须有可访问的 HTTPS 地址，以便供应商读取任务素材。密钥在服务器加密保存，留空保留旧值。保存连接不会创建生成任务。[fal 密钥管理](https://fal.ai/dashboard/keys)

1. 从 AIGC 打开口播页，进入「原声对口型」。添加一张已授权的 JPG、PNG 或 WebP 单人照，以及一段 5～15 秒的已授权 MP3、WAV、M4A 或 OGG 录音。照片最大 20 MiB，录音最大 10 MiB。清晰正面照和无背景音乐的清晰录音便于核对口型。
2. 勾选素材使用授权并查看费用预估，再提交生成。照片和录音通过任务专用的临时链接交给 fal。MiniMax H3 Max Lip Sync 使用原录音生成 768P 口播，fal 刊例为每成片秒 0.08 美元，实际以 fal 账单为准。
3. 在最近任务查看进度，完成后播放或下载 MP4，也可在作品库的数字人分类中找到。页面关闭后服务器继续处理。每个账号可同时处理一条原声口播任务。提交结果待核对时，请先检查原请求和供应商记录，避免重复计费。

模型管理中的「数字人口播 · 原声对口型」显示此固定模型、连接状态和实际回执。供应商返回的成片秒数单独记录，未提供的 Token 或账单金额显示未知。声音与画面在试播时一起核对。

## OpenTalking 数字人

选择可用形象，也可以使用已配置模板上传照片或视频创建自己的形象。填写口播文案或上传音频，保存后生成视频。数字人素材最多 10 MB，音频最多 180 秒；文字合成须先启用。

启用实时互动后，可创建会话，等待形象准备好，再连接音视频。输入文字让形象说话，支持打断和结束会话。离开实时互动面板会结束连接；异常断线和服务状态会明确提示。此入口是数字人语音呈现，不会自动调用小序个人助理或读取业务数据。

## 作品、精选与项目管理

作品库可分类查看、预览、下载、收藏和移入回收站；短视频支持制作同款。站长精选内置服装详情页和主图框架，也展示站长主动推荐的短视频模板；尚无模板时显示空状态。管理者可以将自己的可复用模板加入或移出精选。项目可移入回收站并恢复；仍有活动任务时需先等待结束或暂停核实。

## 保存与常见问题

项目状态保存在 PostgreSQL，媒体优先保存在对象存储；没有配置对象存储时使用数据库存储，单个文件最多 20 MB，已配置对象存储时最多 180 MB。上传控件按对应素材的实际限制提示。服务发布会交接队列；交接期间显示稍后重试，不影响其他业务模块。

草稿须点击保存；关闭或刷新浏览器前注意未保存提示。生成任务在服务器执行，关闭页面不取消已提交任务。任务保存供应商请求编号；如果重启发生在提交后、回包前，会保留「结果待核实」而不自动重复生成。错误时先查看任务日志或服务配置，不要连续重复提交。

## 统一模型与用量管理

「系统设置 → AI 模型管理」登记脚本与视觉分析、图片、视频、RunningHub 深度工作流和数字人。可切换已配置的编译和图片默认模型。视频提供百炼 H3 与已适配的 AgentAI 型号，约 10 秒内应用到创作服务。旧项目需选择当前可用线路后提交新任务，已提交任务保留原型号记录。管理页可打开服务配置抽屉。

编译、图片、百炼视频及 RunningHub 保持独立连接。数字人由检测后的模板和项目选择决定，语音参数在数字人配置维护。

新推理请求通过统一计量记录；媒体任务只在提交时增加请求记录，最终回执更新消耗，不把轮询次数当作新的生成。RunningHub 返回的积分、明确的 USD 实际费用、OpenRouter credits 等分别保留来源与单位。没有供应商回执的历史、未返回字段以及数字人网关未提供的费用显示未知，不用价格估算冒充实际消耗。

H3 按供应商任务编号归并回执，记录输入视频秒数、输出视频秒数和计费参考图片数。未提供的 Token 和实际金额保持未知；成功任务回执可验证该次生成，保存密钥或取得任务编号不代表成功。
