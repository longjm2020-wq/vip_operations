# 图片批量命名

更新日期：2026-10-26。

## 入口与准备

在商品档案、选款登记或项目协作表格中，打开「工具箱 → 图片批量命名」。账号需具有商品查看、选款查看或项目查看权限之一。该工具处理本人选择的本地图片，不读取选中商品行、不修改商品资料、不上传图片到服务器，无须 AI 模型或 API 费用。

使用支持目录读写的桌面版 Chrome 或 Edge，并通过 HTTPS 打开系统。点击「选择本地目录」，在系统窗口中选择文件夹，也可粘贴电脑上的目录路径定位，然后授权读写。网页不能只凭输入的路径直接访问电脑文件。刷新或关闭工具后，需要重新选择目录。

## 操作步骤

1. 选择一个款号目录，或包含多个款号目录的上级目录。目录结构默认自动识别：所选目录直接有图片，或目录名看起来是款号时，作为一款；否则将下一级目录作为款号。识别不符可选择「所选目录就是一款」或「下一级目录分别是款号」。切换目录结构会重新生成预览，清除本次人工分组调整。
2. 自动扫描 JPG、JPEG、PNG、WebP 图片，显示原图、尺寸、体积、款号目录、颜色组、用途、顺序和输出路径。使用已有编号、文件名提示和尺寸判断用途；已有颜色子目录以及文件名中的常见颜色或“颜色1 / color1”标记用于分组。不会根据画面自动识别颜色。没有颜色标记的文件需人工核对，单色款可留空，多色款可勾选多张后批量设置颜色组。
3. 核对分类，必要时修改「款号目录」「颜色组」「用途」和「顺序」。图片按原文件名自然排序，例如 2 排在 10 前面；可手动调整顺序数字。单击缩略图可在新窗口查看原图。「仅看待确认」便于处理无法解码、用途不明、数量超限或重名的项目；不处理的图片明确选择「跳过」。有待确认项目时不能开始。
4. 多色目录可选择「沿用颜色组名称」，保留参考成品中的款号加颜色码等文件夹名；或选择「颜色分组文件夹（1）（2）…」，按颜色组名称自然顺序编号。预览显示实际输出路径。
5. 点击「开始处理」，允许目录写入后，系统逐张转换、压缩并保存。进度显示当前文件和已处理张数。处理时保持页面打开，可点击「停止处理」停止后续文件。
6. 完成后，在所选目录内打开新建的「图片命名结果-时间-随机码」文件夹。结果包含款号目录和「处理清单.json」，清单记录原路径、目标路径、成功或失败、前后体积与输出尺寸。原文件保留，重复运行生成另一个结果目录，不覆盖之前的结果。再次扫描会忽略已有结果目录。

## 文件结构与规则

单色款的全部图片直接放入款号目录。多色款的轮播、30 号、50 号图分别放到颜色子目录，每色独立编号；详情及 826 号图放在款号目录。

| 用途 | 命名 | 数量与体积 |
| --- | --- | --- |
| 方形轮播图 | 1、2、3、4、15、16、17、18、19、20、21、22.jpg | 每色最多 12 张；每张不超过 1024 KB |
| 详情图 | 601.jpg～650.jpg | 按详情自身张数连续编号，每款最多 50 张；没有额外的输出体积上限 |
| 透明方形平铺图 | 30.png | 每色 1 张，不超过 600 KB；必须有透明像素 |
| 商品列表图 | 50.jpg | 每色 1 张，不超过 1024 KB |
| 吊牌合格证图 | 826.jpg | 每款 1 张，不超过 1024 KB |

KB 按 1024 字节计算。轮播和平铺图必须为正方形；其他用途要求竖向矩形。常用列表图为 950×1200，吊牌合格证图为 640×840。详情兼容 3:4 附近的图片以及长详情图，如 900×1230、900×2600，不强制裁成固定尺寸。640×840 等尺寸可能与其他用途重合，自动识别结果仍可人工修改。

原图格式和体积均满足要求时直接复制，保留原文件字节。需要转换或压缩时，JPEG 优先降低编码质量，再按需等比缩小；PNG 必要时等比缩小，始终保留透明背景。不会裁切、拉伸或自动抠图。透明矩形图转换为 JPEG 时透明部分使用白底。输出尺寸和体积可在清单核对。

## 限制与常见问题

- 每批最多 3000 张图片、20000 个目录项目、10 层子目录。单张原图不超过 50 MB、4000 万像素且最长边不超过 16000 像素。大量原图建议按款分批。
- 原目录中的其他格式文件、隐藏文件以及之前的结果目录不会处理。没有写入商品或库存，也不会替换表格图片。
- 只有一个颜色组名时按单色款输出；若原图实际有多色但全部混在一起、无任何颜色标记，须在预览指定不同颜色组。工具无法仅凭文件数量判断颜色。
- 同一色组超过一张 30 或 50 号图、同款超过一张 826 号图，以及轮播或详情超出编号范围，会阻止开始；请改用途、颜色组或跳过多余项，不会覆盖同名文件。
- 无法读取的文件需要换原图重新扫描，或明确跳过。30 号图不透明时，请提供已经抠图的透明原图。
- 浏览器提示不支持目录读写：换桌面版 Chrome / Edge，确认 HTTPS。取消选择或拒绝授权不会处理图片；权限失效时重新授权或重新选择目录。
- 磁盘空间不足、目录被移走或写入失败会逐张记录为失败，其他图片继续处理。停止、关闭页面或浏览器退出可能留下部分结果；原图保留，重新运行会生成新结果目录。未成功写完的文件不可作为交付成品。
- 处理结果和预览不进入表格撤销历史。可直接从文件管理器删除不需要的结果目录。
