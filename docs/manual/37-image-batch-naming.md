# 图片批量命名

更新日期：2026-10-26。

## 入口与准备

在商品档案、选款登记或项目协作表格中，打开「工具箱 → 图片批量命名」。账号需具有商品查看、选款查看或项目查看权限之一。工具处理本人选择的本地图片，不读取选中商品行、不修改商品资料、不上传图片到服务器，无须 AI 模型或 API 费用。

使用支持目录读写的桌面版 Chrome 或 Edge，通过 HTTPS 打开系统。选择目录时可在系统窗口粘贴本地路径并授权读写；网页不能只凭输入路径访问电脑文件。刷新或关闭工具后需要重新选择目录。

## 自动处理整个目录

1. 选择目录前设置「目录结构」及「多色目录命名」。默认自动识别：所选目录直接有图片，或目录名看起来是款号时作为一款，否则将下一级目录作为款号。也可明确指定「所选目录就是一款」或「下一级目录分别是款号」。
2. 默认勾选「识别后自动处理整个目录」。点击「选择本地目录」，选择款号目录或包含多个款号的上级目录并授权后，系统递归扫描全部子目录中的 JPG、JPEG、PNG、WebP 图片。
3. 识别尺寸、透明度、用途和颜色分组后，立即按命名规则转换、压缩、保存，无须逐张勾选或再次点击开始。所有分页都会处理；表格勾选仅用于批量修改，勾选当前页或打开「仅看待确认」不会缩小处理范围。
4. 个别异常不阻断整批。可以确定规则的图片正常生成；用途或颜色不明、30 号图不透明、超出编号数量等图片原样另存到结果中的「_待确认/原相对路径」，并记录原因。这些原图尚未达到交付规则，核对后可重新处理。
5. 进度显示当前文件及整个目录的处理张数。处理时保持页面打开，可点击「停止处理」。结束后显示成功命名、原图另存待确认、失败及停止时未处理的数量。
6. 在所选目录内打开新建的「图片命名结果-时间-随机码」文件夹。结果包含款号目录、「_待确认」（有异常时）及「处理清单.json」。清单逐项记录原路径、目标路径、状态、体积、尺寸、分组依据及待确认原因。原文件保留，重复运行生成新结果目录；再次扫描自动忽略旧结果目录。

如需先核对，选择目录前取消「识别后自动处理整个目录」。扫描后可修改款号、颜色组、用途和顺序，勾选多张可批量设置用途或颜色。点击「处理整个目录 N 张」处理所有未明确跳过的图片。修改后重新处理会另建结果目录，之前的结果保留。切换目录结构会重建识别结果，清除人工分组调整。

## 用途和颜色识别

- 已有编号、文件名提示、尺寸及透明度用于判断用途。按原文件名自然排序，例如 2 在 10 前；详情按自身张数从 601 开始，可人工调整顺序。
- 颜色优先沿用原颜色子目录或文件名中的颜色标记。单色款可不填颜色组；只有一个颜色组时按单色输出。
- 同款混放多组轮播、平铺或列表图时，使用本款的列表图或平铺图作为颜色参考，读取图片中央区域的颜色特征，在本机自动匹配轮播、30、50 号图。自动生成「颜色分组文件夹（1）（2）…」，不猜测颜色名称。已有明确的颜色标记不被替换。
- 颜色相近、混色画面、参考图不足或不同构图可能无法可靠匹配；此时相关原图另存待确认。相似颜色也可能误分，完成后应核对预览及输出目录，可修改颜色组重新处理。不会只按轮播图片数量硬拆颜色，也不会调用外部视觉模型。
- 「多色目录命名」可沿用原颜色组名称，或按组名自然排序生成「颜色分组文件夹（1）（2）…」。多色款的轮播、30、50 号图进入颜色目录；详情及 826 号图位于款号目录。

## 命名与压缩规则

| 用途 | 命名 | 数量与体积 |
| --- | --- | --- |
| 方形轮播图 | 1、2、3、4、15、16、17、18、19、20、21、22.jpg | 每色最多 12 张；每张不超过 1024 KB |
| 详情图 | 601.jpg～650.jpg | 按详情自身张数连续编号，每款最多 50 张；没有额外输出体积上限 |
| 透明方形平铺图 | 30.png | 每色 1 张，不超过 600 KB；必须有透明像素 |
| 商品列表图 | 50.jpg | 每色 1 张，不超过 1024 KB |
| 吊牌合格证图 | 826.jpg | 每款 1 张，不超过 1024 KB |

KB 按 1024 字节计算。轮播和平铺必须为正方形，其余用途要求竖向矩形。列表通常为 950×1200，吊牌合格证通常为 640×840。详情兼容 3:4 附近及长图，如 900×1230、900×2600。尺寸可能与其他用途重合，可人工改用途。

原格式和体积合规时直接复制，保留原字节。需要转换或压缩时，JPEG 先降低编码质量，再按需等比缩小；PNG 必要时等比缩小并保留透明背景。不会裁切、拉伸或自动抠图。透明矩形图转 JPEG 时使用白底。输出尺寸和体积在清单中可核对。

## 限制与常见问题

- 每批最多 3000 张图片、20000 个目录项目、10 层子目录；单张不超过 50 MB、4000 万像素且最长边不超过 16000 像素。超出整批限制会停止扫描，请分批选择。
- 非图片文件（如 Thumbs.db）、隐藏文件及旧结果目录不参加命名。没有上传、替换商品图片或写入库存，也不进入表格撤销历史。
- 同色超过 12 张轮播、超过一张 30 或 50 号图，同款超过 50 张详情或一张 826 号图时，按排序保留编号范围内的图片，多余原图另存待确认。不会覆盖同名文件。
- 名为 30.png 或 30.jpg 但没有透明像素的图片会另存待确认，不会伪装成透明平铺图；需提供已抠图原图。无法解码但能读取的文件同样保留原字节；完全无法读取的文件记录为失败。
- 浏览器不支持时换桌面版 Chrome / Edge 并确认 HTTPS。取消选择或拒绝授权不会开始自动处理；权限失效时重新授权或重新选择目录。
- 磁盘不足、目录被移走或写入失败会逐张记录，后续文件继续处理。停止、关页或退出浏览器可能留下部分结果；未写完的文件不可作为交付成品。重新运行另建结果目录。
- 结果目录可从文件管理器打开、检查或删除。若清单写入失败，界面会显示原因，已完成图片仍保留。
