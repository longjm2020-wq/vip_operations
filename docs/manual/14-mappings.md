# 颜色尺码映射

更新日期：2026-10-20。入口：商品档案、选款登记或项目协作表格 → 顶部工具栏「工具箱」图标 → 颜色尺码映射。工具箱位于手机拍图之后、查找/替换之前；鼠标悬停显示「工具箱」。原 ERP 菜单入口已移除，旧收藏网址仍可访问。

查看工具箱内的映射需要商品查看权限，新增、编辑、删除和表格批量导入需要商品编辑权限；表格自身的编辑权限不会自动授予映射维护权限。没有商品查看权限时不显示工具箱入口。

映射在侧边面板内打开。当前页签的「搜索编码或名称」也在面板内，输入后按回车或点击搜索图标查询当前颜色或尺码资料；切换页签后搜索对应页签，不混合两类资料。表格顶部搜索、选区及查看位置保留，关闭工具箱可继续操作表格。

## 操作步骤

1. 点击工具箱图标，在面板内切换「颜色映射」或「尺码映射」页签。
2. 颜色填写 3 位色码及参考颜色名称；尺码填写 3 位尺码代码及尺码名称。
3. 核对状态后保存。多条可用表格批量导入。
4. 建立 SKU 时选取对应代码并核对名称。

代码按文本处理，例如 001 不应变成 1。颜色与尺码分别维护，不要把两个编码混入同一页签。映射资料不直接改变库存或触发平台商品同步。

点击「保存」后更新系统共用的映射资料，不会自动替换当前选区的颜色、尺码或生成 SKU，也不进入表格的撤销历史。已有 SKU 使用的编码不能删除或改码，可按原规则停用；编码重复、格式不正确或已被引用时按提示修正。读取失败可在面板内重试；仅关闭工具箱不会提交未保存的编辑，已保存的资料不会撤销。
