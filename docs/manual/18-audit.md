# 操作日志

更新日期：2026-10-09。入口：系统设置 → 操作日志。

## 操作步骤

1. 打开操作日志，查找业务变化记录。
2. 核对操作者、操作时间、业务对象及前后值。
3. 按需要导出当前页，用于内部核对；更多记录需翻页查看。

日志只读，不可修改。排查问题时记录时间、单据号及错误信息，不要将密码或平台令牌附在反馈中。库存数量的逐笔变化请同时查看「库存流水」。

## 选款协作与私有字段保护（2026-10-09）

选款登记、产品信息收集表、收集表单款和保护区域的记录仍限管理员、超级管理员查看。普通管理员看到的前后值按当前查看权限过滤：其他用户未公开的字段、字段名称与选项、对应格式、图片及保护区域信息不会显示；公开字段和有权查看的标准内容保留。字段取消公开后，历史日志也随当前权限隐藏。涉及隐藏内容的补充说明不显示，避免从说明读出原内容。

SOP、项目和自建表格的日志还检查当前内容访问权；无权访问、已移至回收站或已清理的内容仅显示操作者、时间、动作等操作元信息，不提供名称、成员设置及前后内容。有审计查看权限不代表可以查看这些内容。超级管理员可查看完整原始日志。过滤不修改服务器保存的原记录，日志仍只读。其他模块的审计查看仍按审计查看权限执行。
