# 聚水潭库存接入

更新日期：2026-10-29。入口：运营中心 → 唯品会 → 库存明细 →「聚水潭同步」。

## 接入准备

本功能使用聚水潭新版开放平台的**商家自研应用**。ERP 网页登录与开放平台授权是两回事；当前版本不支持服务商应用、旧版 partnerid 授权或浏览器 Cookie。

在[聚水潭开放平台](https://openweb.jushuitan.com/management/apps)检查应用审核和「商品库存查询」`/open/inventory/query`、「仓库查询」`/open/wms/partner/query` 的权限；未开通时由商家管理员按[官方接入说明](https://openweb.jushuitan.com/doc?docId=2)申请。若应用配置了 IP 白名单，需允许服务器出口地址，不能填写个人电脑的地址代替服务器。

有库存查看权限即可查看来源、同步记录及结果；保存应用凭据、验证、选择仓库、开启定时任务和立即同步要求超级管理员身份及库存调整权限。服务器需要已配置凭据加密密钥。App Key 与 App Secret 仅在此设置页填写，保存后不回显，不写入日志或手册。

## 首次配置与同步

1. 打开「聚水潭同步」，填入已获批自研应用的 App Key、App Secret，保持定时同步关闭，点击「保存设置」。留空保留原凭据，更换时两项须同时填写。
2. 点击「验证授权并读取仓库」。服务器从已批准的自研应用获取访问令牌，读取生效仓库，并显示验证时间及授权有效期。此步骤验证授权与仓库权限，商品库存权限在同步时进一步核验。
3. 从实际返回的仓库列表选择**杭州总仓**，核对公司编号和仓库编号，再保存。不能使用编号 0 或不传编号代替杭州总仓，这两种方式在聚水潭接口中代表所有仓库合计；列表没有目标仓库时需由聚水潭管理员确认分仓编号及授权账号，系统不会自行改为全部仓库。
4. 可选：在聚水潭核对可用数业务设置，再勾选「已核对聚水潭的可用数业务设置」及是否计入采购在途、进货仓、销退仓。未核对时可同步其他库存字段，可用数显示「待核对口径」。修改计算口径需保存并重新同步。
5. 点击「立即同步」。后台按网站中已有的完整商品编码每批最多 100 个查询，记录展示匹配数、已查询数和总数。只有所有批次完成后才发布新快照；可关闭面板继续工作，稍后查看结果。
6. 完成后点击「查看聚水潭库存」，或在库存明细的「库存数据来源」下拉框选择「聚水潭库存」。页面显示仓库、完整同步时间和匹配数量。当前来源选择仅在本次页面访问保留，重新打开默认查看网站库存。
7. 核对成功后可开启定时同步，选择每 15、30 或 60 分钟。云端 worker 执行任务，无需本机浏览器在线；待执行任务约每 10 秒检查一次。手动和定时任务不会并行重复运行。授权续期在同步前按官方自研应用流程处理；接口不可达或授权不可续期时显示失败原因，不声称数据已更新。

## 字段和数据口径

| 网站字段             | 聚水潭来源                                                                  |
| -------------------- | --------------------------------------------------------------------------- |
| 实际库存数           | `qty`                                                                       |
| 订单占有数           | `order_lock`                                                                |
| 销退仓库存           | `return_qty`                                                                |
| 进货仓库存           | `in_qty`                                                                    |
| 采购在途数           | `purchase_qty`，已生效采购单尚未入库的数量                                  |
| 调拨在途数           | `allocate_qty`                                                              |
| 虚拟库存             | `virtual_qty`，可能为负                                                     |
| 可用数（按配置计算） | 实际库存 − 订单占有 + 虚拟库存 + 已核对设置中选中的采购在途／进货仓／销退仓 |

可用数是依据[官方库存口径](https://openweb.jushuitan.com/dev-doc?docType=3&docId=15)及管理员核对的开关计算，接口不直接返回这个页面字段。不同聚水潭账号的业务设置可能不同，不能把未核对的计算值当作聚水潭原值。

商品编码严格按文本精确匹配，保留前导零和完整长度，不按款号合并猜测颜色或尺码。只查询网站已有的 SKU，不自动创建聚水潭独有商品，也不修改商品档案、图片、内部库存余额或流水。图片和罗盘经营参考继续沿用原有匹配来源。

未返回的商品或数量显示「暂无数据」，不补零，不回退为网站库存。货号／款号汇总含缺失数量时该项也显示「暂无数据」，总计含缺失数量时显示「不完整」，不会把部分合计当作完整库存。未匹配编码可在同步记录展开查看，最多列出 50 个。所有编码都未匹配时本次失败，保留上次完整快照。

两个库存来源独立，不能相加。网站库存仍沿用内部采购发货、质检和入库口径；聚水潭可用数可能已含虚拟和在途库存，因此选择聚水潭来源时暂不估算可售天数、补货建议，也不展示内部补货计算设置。经营参考周期只影响罗盘销售指标，不把当前库存转换为历史库存。「导入网站库存」仍用于内部库存导入，不会更改聚水潭快照。

## 保存效果与失败处理

同步使用只读查询，不向聚水潭生成盘点、采购、调拨或出入库业务单据。失败、断网、重复编码、非法数量或分页不完整都不发布部分库存；上次快照和时间继续显示。超过两个同步间隔仍无更新时页面用提示色标记，应核对时间和任务记录。

更换应用、清除凭据、切换仓库（包括授权公司变化）或更改可用数口径会撤下当前快照入口，重新同步后再展示；设置变更会阻止旧任务覆盖新设置。关闭定时同步保留上次快照，已经开始的手动或定时任务可能因设置版本改变而结束失败，需再次手动同步。超过十分钟的同步结果不会发布。

授权失败：核对自研应用审批状态、App Key／Secret、接口权限和服务器 IP 白名单。接口明确拒绝请求（返回错误码或 HTTP 401／403）时自动关闭定时同步，避免持续刷新无效授权；处理后重新验证并开启。网络异常则保留已启用的定时设置，在下个周期重试。仓库缺失：确认授权公司的生效仓库列表及杭州总仓编号。库存权限不足：申请商品库存查询权限后再同步。一直等待同步：确认云端 worker 正常运行。授权有效期或续期异常：在开放平台检查应用授权，处理后重新验证。

导出附带库存来源、仓库与同步时间；空白库存表示未返回。总计仍覆盖全部筛选结果，明细导出当前页。聚水潭快照保留最近五次完整数据，同步记录保留；内部库存台账不受缓存清理影响。
