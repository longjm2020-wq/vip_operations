# 聚水潭库存表格同步

更新日期：2026-10-30。入口：运营中心 → 唯品会 → 库存明细 →「聚水潭同步」。

## 登录与同步

本功能复用云端浏览器中加密保存的聚水潭登录会话，操作「商品库存」网页查询和导出原始 Excel，再匹配网站商品。无需开放平台应用、App Key、App Secret 或接口申请。旧开放平台同步任务已停用。

有库存查看权限的用户可查看结果及合并明细。登录、移除会话、配置定时任务和立即同步要求超级管理员及库存调整权限。云端同步进程必须在线，服务器凭据加密必须已就绪。

1. 点击「登录聚水潭」。下方是独立的云端浏览器，不会读取本机 Chrome 的 Cookie。
2. 在画面中选择登录方式。可使用聚水潭页面嵌入的微信或钉钉官方扫码页；扫码平台的登录状态不会保存到本站。画面默认适应窗口，可点击「放大登录画面」。需输入时先点击画面中的输入框，再在窗口下方输入账号、密码或验证码并点击「发送输入」。输入内容只临时加密传递，处理后删除；画面遮盖所有输入框。滑块等交互由用户在画面中手动完成，不能保证所有验证方式均可用。
3. 登录已授权的公司，打开「商品 → 商品库存」，确认仓库为**序缇杭州总仓**。点击「核验杭州总仓并保存会话」。系统会再用一个新浏览器窗口验证会话可以恢复，成功后才加密保存。
4. 关闭登录窗口，点击「立即同步」。后台读取网站当前已有的商品编码和条码，最多每批 200 个，分别通过「商品编码」精确匹配和「其它属性5」筛选查询。只查询这些编码匹配到的库存，不执行全仓导出。若尚未显示「选择其它属性」，自动在聚水潭的筛选设置中显示该查询项。
5. 每批核验公司、仓库、查询条件、页面条数与原始文件条数。所有批次成功后一次性发布新快照。可关闭面板继续工作；记录显示当前批次进度、导出原始商品数、匹配的网站商品数和本次查询的网站商品总数。
6. 完成后点击「查看聚水潭库存」。点击「查看合并明细」可核对网站条码、各聚水潭原始编码、其它属性5、颜色尺码及各原始商品的库存贡献。
7. 可按需开启每 15、30、60 分钟定时同步，点击「保存设置」生效。云端完成任务，无需本机浏览器在线；不会并行重复同步。会话不能保证永久有效，平台要求重新登录或验证时提示处理并停止定时同步。

登录窗口最长保留 20 分钟，只有发起登录的管理员能操作或读取画面。关闭登录窗口不等于移除已保存的会话；「移除会话」会删除服务器保存的登录状态并停用定时任务，保留上次库存供参考。登录窗口一律使用新会话，不向其他管理员展示已有账号的登录状态。

## 匹配和同款合并

优先使用完整商品编码精确匹配网站商品编码或条码；聚水潭「其它属性5」也可明确映射到网站条码。前导零和长编码保留，不把款号中的 X、连字符或其他字符自行替换。

例如聚水潭存在标准编码商品以及「款号-粉色-L」商品，后者的其它属性5明确填写标准商品编码，且颜色尺码与网站一致时，两条原始库存会汇总到网站的同一个粉色 L 条码。粉色 M、米白色 L 等分别汇总。没有映射编码的样衣不合并，也不导入无关商品。

每个聚水潭原始商品编码只计一次；在两种查询中重复返回的相同记录会去重。商品编码和其它属性5指向不同网站商品、一个网站条码对应多个商品、颜色尺码冲突、不同批次中同一原始库存发生变化时均停止发布，提示核对，避免重复累计。

## 字段口径

| 网站字段   | 导出表字段             |
| ---------- | ---------------------- |
| 实际库存数 | 实际库存数             |
| 订单占有数 | 订单占有数             |
| 销退仓库存 | 销退仓库存             |
| 进货仓库存 | 进货仓库存             |
| 采购在途数 | 采购在途数             |
| 调拨在途数 | 调拨在途数             |
| 虚拟库存   | 虚拟库存数             |
| 可用数     | 可用数，直接采用原始值 |

同一网站条码对应的不同原始商品，以上数量分别相加。可用数允许为负数，不重新套用公式，也不把虚拟库存再加一次。未导出的残次数字段保持未知。库存来自本次网页导出时的快照；不同批次有时间差，经营参考周期不会将它转成历史库存。

聚水潭库存与网站内部库存是独立来源，不能相加。同步不修改商品档案、图片、内部库存余额、库存流水，也不创建采购、调拨或盘点单据。网站未匹配商品显示「暂无数据」，不补零；汇总含未知数量时显示不完整。所有编码均未匹配时不覆盖旧快照。本来源暂不估算补货建议和可售天数。图片及罗盘参考继续使用已有来源。「导入网站库存」仍是内部库存导入，与此同步分开。

## 失败处理与留存

会话失效：重新登录并核验保存，再同步。公司或仓库不符：在登录画面切换到已授权公司和杭州总仓。页面无法加载或导出权限不足：检查聚水潭页面及账号权限。网页结构变化、下载失败、表格被加密、文件数量不完整、缺少必需列、编码精度丢失、重复编码或非法数量：本次不发布，保留上次完整库存及其时间。记录没有完成，不代表库存已更新。

单份原始表最大 20MB，展开后最大 100MB；仅处理可读取的 Excel，不修改源文件。当前同步最长三十分钟；超时或设置变更会阻止旧任务发布，修复后重新同步。同步期间网站商品编码、颜色尺码变化也会阻止本次发布。

保留最近五次完整快照、对应原始 Excel、文件哈希和原始商品贡献记录，同步历史继续保留。日志、接口响应和手册不会包含登录 Cookie、密码或验证码。两个同步间隔仍无更新时库存页会提示检查时间；手动同步模式下请根据自己的业务需要刷新。
