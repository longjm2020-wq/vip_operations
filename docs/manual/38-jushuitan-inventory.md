# 聚水潭库存表格同步

更新日期：2026-10-31。入口：运营中心 → 唯品会 → 库存明细 →「聚水潭同步」。

## 登录与同步

本功能复用云端浏览器中加密保存的聚水潭登录会话，操作「商品库存」网页查询和导出原始 Excel，再匹配网站商品。无需开放平台应用、App Key、App Secret 或接口申请。旧开放平台同步任务已停用。

有库存查看权限的用户可查看结果及合并明细。登录、移除会话、配置定时任务和立即同步要求超级管理员及库存调整权限。云端同步进程必须在线，服务器凭据加密必须已就绪。

1. 点击「登录聚水潭」。下方是独立的云端浏览器，不会读取本机 Chrome 的 Cookie。
2. 在画面中选择登录方式。可使用聚水潭页面嵌入的微信或钉钉官方扫码页；扫码平台的登录状态不会保存到本站。画面默认适应窗口，可点击「放大登录画面」。账号密码登录时，点击画面里的账号、密码或验证码框，等待蓝色输入控件出现后直接输入，按回车或点击底部「发送输入」填写。底部输入栏始终可见，也可在那里输入。收到「已填入聚水潭」反馈后选择下一项，最后点击画面里的登录按钮。发送失败保留尚未送达的内容；切换到另一字段会清空本地草稿，避免误填。灰色区域表示隐藏云端输入内容，并非禁用；字段已填写时会显示状态，不回传内容。输入仅临时加密传递，处理后删除。协议复选框仍可直接操作。滑块等交互由用户在画面中手动完成，不能保证所有验证方式均可用。
3. 登录已授权的公司，点击「核验杭州总仓并保存会话」。系统识别当前可见的「商品库存」页面；若尚未打开，尝试点击首页的商品库存入口。若仍处于公司范围，通过左侧货主仓储入口选择**序缇杭州总仓**。仅在候选列表出现该仓库不算核验通过，必须确认当前仓库。库存查询条件会正常显示，账号、密码及验证码继续隐藏。自动打开或选择失败时，请在画面中打开「商品 → 商品库存」，点击左侧竖排的公司或仓库名称手动切换后重试。核验显示当前步骤，并再用一个新浏览器窗口验证登录和仓库可以恢复，成功后才加密保存。隐藏的旧库存页不会干扰识别；多个同时可见的库存页须先关闭重复窗口。新窗口加载、登录、库存页和仓库核验失败会分别提示，失败不保存会话。
4. 关闭登录窗口，点击「立即同步」。后台按网站商品所属款号生成两组查询：如 `XFA16X31196L` 和 `XFA16-31196L`，分别在「款式编码」中批量**精确匹配**后导出 Excel。保留 `XFA`、`XFW` 开头的 X；款号中间的 X 与连字符相互转换，例如 `H49XJMX16579` 对应 `H49-JM-16579`。正常两组各导出一份；查询框容量或明示数量上限较小时自动拆批，每批最多 2000 款、查询文本最多 60000 字符。页面无匹配结果的一组不生成文件。开始时仅重置一次，后续替换款号，避免反复加载整仓列表。单次查询最多等待 90 秒，超时不发布库存。
5. 每批核验公司、仓库、精确查询条件、页面条数与原始文件条数，并检查导出表中的「款式编码」全部属于当前批次。再按完整商品编码与其它属性5匹配、去重汇总，检查编码映射及跨批次记录冲突。所有批次成功后一次性发布新快照。可关闭面板继续工作；进度显示标准款号、连字符款号及当前批次。完成后显示导出原始商品数、匹配的网站商品数和本次查询的网站商品总数。
6. 完成后点击「查看聚水潭库存」。点击「查看合并明细」可核对网站条码、各聚水潭原始编码、其它属性5、颜色尺码及各原始商品的库存贡献。
7. 可按需开启每 15、30、60 分钟定时同步，点击「保存设置」生效。云端完成任务，无需本机浏览器在线；不会并行重复同步。会话不能保证永久有效，平台要求重新登录或验证时提示处理并停止定时同步。

登录窗口最长保留 20 分钟，只有发起登录的管理员能操作或读取画面。关闭登录窗口不等于移除已保存的会话；「移除会话」会删除服务器保存的登录状态并停用定时任务，保留上次库存供参考。登录窗口一律使用新会话，不向其他管理员展示已有账号的登录状态。

## 匹配和同款合并

款号的两种格式仅用于查询原始库存，不作为库存合并依据。优先使用完整商品编码精确匹配网站商品编码或条码；聚水潭「其它属性5」也可明确映射到网站条码。匹配成功即汇总，不再核对颜色或尺码名称；这些描述仅保留在合并明细中供参考。前导零和长商品编码保留，不改写商品编码或其它属性5。

同款导出的表格可能含网站尚未建立的颜色尺码。无法通过上述编码明确对应网站商品的原始行不会纳入库存汇总，原始 Excel 仍完整保留。若聚水潭使用与这两种格式完全无关的款式编码，需要先维护正确款号；系统不会按图片或近似名称猜测。网站缺少关联款号的旧数据暂沿用按商品编码每批200个、其它属性5每批50个的查询方式。

例如聚水潭存在标准编码商品以及「款号-浅绿色-L」商品，后者的其它属性5明确填写网站绿色 L 的完整商品编码，即使两边分别称为「浅绿色」和「绿色」，两条原始库存仍汇总到同一网站条码。其它条码分别汇总。没有映射编码的样衣不合并，也不导入无关商品。请维护好聚水潭的商品编码与其它属性5；系统以这些明确对应关系为准，不根据图片或颜色名称重新判断。

每个聚水潭原始商品编码只计一次；在两种查询中重复返回的相同记录会去重。商品编码和其它属性5指向不同网站商品、一个网站条码对应多个商品、不同批次中同一原始库存发生变化时均停止发布，提示核对，避免重复累计。

## 字段口径

| 网站字段   | 导出表字段             |
| ---------- | ---------------------- |
| 实际库存数 | 实际库存数             |
| 订单占有数 | 订单占有数             |
| 销退仓库存 | 销退仓库存             |
| 进货仓库存 | 进货仓库存             |
| 采购在途数 | 采购在途数             |
| 调拨在途数 | 调拨在途数             |
| 虚拟库存   | 虚拟库存数             |
| 可用数     | 可用数，直接采用原始值 |

同一网站条码对应的不同原始商品，以上数量分别相加。可用数允许为负数，不重新套用公式，也不把虚拟库存再加一次。未导出的残次数字段保持未知。库存来自本次网页导出时的快照；不同批次有时间差，经营参考周期不会将它转成历史库存。

数量支持数值单元格及等值的整数文本，例如 `1,234.0000` 按 1234 读取；不会四舍五入。原始表中某个商品的全部八个库存数量字段均为空白时，保留为未知，页面显示「暂无数据」，不补成 0。若参与同条码合并的任一原始商品数量未知，合并数量也保持未知，避免只累计一部分。仅部分数量字段为空、公式、Excel 错误、非整数或超出安全范围的数量会中止导入，并提示行号和字段。

聚水潭库存与网站内部库存是独立来源，不能相加。同步不修改商品档案、图片、内部库存余额、库存流水，也不创建采购、调拨或盘点单据。网站未匹配商品显示「暂无数据」，不补零；汇总含未知数量时显示不完整。所有编码均未匹配时不覆盖旧快照。本来源暂不估算补货建议和可售天数。图片及罗盘参考继续使用已有来源。「导入网站库存」仍是内部库存导入，与此同步分开。

## 失败处理与留存

登录核验会依次显示公司、库存页、仓库、会话读取、新窗口恢复、加密和保存步骤。若提示「读取当前登录会话未完成」或「保存已核验的登录会话未完成」，不表示已保存，也不能启动同步；保留窗口重试并提供提示的步骤供排查。

同步记录会区分标准款号、连字符款号的精确查询、导出和文件校验。旧数据回退查询会显示商品编码或其它属性5批次。页面控件超时会指出失败步骤，已保存的登录会话仍保留；可点击「立即同步」重试，无需因一次查询控件超时重新登录。

旧数据回退查询条数异常偏多时，在确认输入条件未变化后自动重新搜索，最多重试两次；仍异常则不导出。款号查询输入被截断、无法确认精确匹配、缺少款式编码或返回范围外款号时不发布库存。颜色名称差异不再导致同步失败。

发起新的同步后，面板顶部清除上次错误提示，历史失败记录仍保留；请以最新一条记录的状态判断本次是否完成。

系统会关闭已识别的 Logo 搜索菜单及库存视角新手引导，避免遮挡查询按钮；协议确认、账号验证和其它业务弹窗仍须本人处理。

登录跳转期间，画面或输入框读取短暂失败会自动重试，保留当前云端登录。恢复前临时停用画面点击和输入，避免操作旧画面；恢复后可继续。画面恢复期间仍可点击「刷新画面页面」，已完成登录也可直接点击「核验杭州总仓并保存会话」；核验读取当前页面，仍须通过公司、仓库及新窗口恢复检查才保存。每次只执行一个操作，核验或刷新正在执行时需等待完成。只有浏览器中断、窗口关闭或到期才需要重新打开登录窗口。

会话按整体大小校验，允许聚水潭单项页面状态超过128KB，完整会话最多8MB。超限会明确提示且不截断保存；可在聚水潭清理不必要的页面缓存后重新核验。

会话失效：重新登录并核验保存，再同步。公司或仓库不符：在登录画面切换到已授权公司和杭州总仓。页面无法加载或导出权限不足：检查聚水潭页面及账号权限。网页结构变化、下载失败、表格被加密、文件数量不完整、缺少必需列、编码精度丢失、重复编码或非法数量：本次不发布，保留上次完整库存及其时间。记录没有完成，不代表库存已更新。

单份原始表最大 20MB，展开后最大 100MB；仅处理可读取的 Excel，不修改源文件。当前同步最长三十分钟；超时或设置变更会阻止旧任务发布，修复后重新同步。同步期间网站商品编码或条码变化也会阻止本次发布；仅修改颜色尺码名称不影响编码匹配。

保留最近五次完整快照、对应原始 Excel、文件哈希和原始商品贡献记录，同步历史继续保留。日志、接口响应和手册不会包含登录 Cookie、密码或验证码。两个同步间隔仍无更新时库存页会提示检查时间；手动同步模式下请根据自己的业务需要刷新。
