# 商品档案

更新日期：2026-09-19。入口：ERP系统 → 商品档案。

## 建档前准备

先在系统设置建立品类；需要关联品牌或默认供应商时，先建立对应资料。商品以款号组织，一款的不同颜色、尺码通过 SKU 管理。

## 单款新建与修改

1. 点击新建入口，填写必填的款号、商品名称和品类。
2. 按需要填写品牌、默认供应商、年份、季节、吊牌价、主图网址、备注及状态。
3. 保存后搜索款号或名称确认记录。点击该行「编辑」直接在当前表格修改，点击「保存」统一保存该行，或点击「取消」放弃本行修改。正在编辑时不能翻页、筛选或更改列配置，先保存或取消。
4. 打开商品详情查看基本资料、SKU，以及权限允许的库存、采购和操作日志。

## 批量建档

点击「表格导入」，下载模板并匹配品类、品牌、供应商等字段，检查数据后保存。导入用于新增；要改已有商品，编辑表格中载入的记录。具体限制见「表格编辑与 Excel 导入」。

## 表格布局、列与筛选

商品档案采用紧凑网格，支持勾选、行号、图片预览和横向滚动，右侧保留操作列。右上角齿轮菜单可切换行高、打开列设置、筛选设置及自定义字段。

- 列设置按基础资料、唯品会、合格证、质检与护理、自定义字段分组，勾选显示、取消隐藏；款号保留。列偏好保存在当前浏览器、当前账号下，可恢复默认。隐藏不会删除数据。
- 筛选支持末级品类、品牌、供应商、年份、适穿季节、状态和已启用的扩展字段。条件同时满足；扩展文本按包含匹配，数字、日期、单选按精确匹配。筛选作用于完整商品库，支持清空条件。
- 导出当前页或当前页勾选的商品，按当前显示列导出，包括扩展字段。列很多时先选择需要的列。尚未保存的编辑不参与导出。
- 修改需要商品编辑权限；只有查看权限的账号仍可筛选、设置显示列和导出。其他人修改同一商品后，保存旧版本会提示冲突，取消并刷新后重新编辑。

## 参考表字段

| 分组 | 字段 |
| --- | --- |
| 基础资料 | 款号、供应商款式编码、图片网址及预览、三级分类、单品价、自定义颜色、标准颜色、尺码范围、适穿季节，以及商品名称、品牌、默认供应商、年份、吊牌价、状态、备注 |
| 唯品会 | 上线状态、最低售卖折扣、选款批次、主标题、标题字数、吊牌限价、合格证吊牌价、吊牌价限价是否达标、吊牌价白名单申请 |
| 合格证 | 品名、成分含量、安全类别、执行标准 |
| 质检与护理 | 洗涤标志核对、面料材质核对、是否豁免、衣服整改描述、检测报告编号 |

标题字数自动按字符统计；两项价格都填写时，合格证吊牌价不超过吊牌限价显示「达标」，超过显示「不达标」，缺失显示「待补充」。这两个计算列不可直接填写。白名单字段仅记录人工维护状态，不自动豁免限价提示，也不提交平台申请。

本页唯品会字段为内部资料，不会自动上架、申请白名单或改变平台商品。最低折扣、核对状态等由业务人员维护；颜色、尺码范围作为资料保存，不自动创建SKU或修改库存。新增字段不会把截图样例或推断结果写入已有商品。

## 自定义字段

具备商品编辑权限的账号可新增文本、数字、日期或单选字段。字段名称在商品档案中唯一，定义在所有商品间共享；文本最多1000字符，单选须先配置选项。包括预置扩展字段在内最多50个。可改名、停用和重新启用；停用保留原值，不能继续编辑该字段。已有字段的类型和选项不可更换，需另建字段。扩展字段均选填，原有款号、名称、品类仍必填。

扩展字段可在行内、新增表单和表格导入中维护，也可筛选及导出。批量模板含启用的扩展字段；日期填写 YYYY-MM-DD，数字填写数值，单选按配置选项填写。

## 常见问题

建档不等于创建所有 SKU，也不增加库存。吊牌价不是实际销售成交价。平台自动同步保存在「唯品会接入」的独立商品库，不自动覆盖此处资料。商品详情中的旧接入提示不能代替唯品会接入页的同步状态判断。
