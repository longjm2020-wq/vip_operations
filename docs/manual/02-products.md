# 商品档案

更新日期：2026-10-05。入口：ERP系统 → 商品档案。查看需要商品查看权限，修改需要商品编辑权限，新建实际商品另需商品创建权限。

商品档案使用与「新建表格」「选款登记」相同的在线表格。已有商品载入表格，保留原商品ID、SKU、库存和采购关联，不清空原档案或复制为另一批商品。顶部搜索随输入过滤款号、名称及字段内容。

## 查看和编辑

1. 直接修改单元格，离开单元格后自动保存；保存失败保留待保存内容，修正后重试。其他人修改同一条资料时会提示冲突，刷新后重新编辑。
2. 名称、末级品类、品牌、默认供应商、年份、季节、状态和备注对应原商品基本资料。品类、品牌和供应商通过列表选择，不能填写任意名称代替ID；停用选项不能新选。
3. 供应商款式编码、供货价、颜色、尺码范围和材质对应原商品扩展字段，吊牌价及第一张商品图片对应吊牌价和主图。其余已启用的原商品扩展字段继续载入。多张商品图和洗唛图在表格中保存，旧详情页只使用第一张商品图作为主图。
4. 行号「#」区域的「↗」打开原商品详情，继续查看基本资料、SKU，以及权限允许的库存、采购和操作日志。详情修改已对应资料后，表格同步更新。

实际商品沿用款号唯一校验、有效末级品类及原业务校验。表格字段改名、隐藏或调序不改变其对应资料标识。原商品扩展数字字段保存为数字；文本、日期和选项仍受原字段限制。

## 新增与批量传送

「添加一行」和底部批量添加先创建空白草稿。填写有效款号后创建实际商品；名称未填写时先使用款号，品类未填写时先归入「导入待分类」，后续补齐资料。没有商品创建权限的账号只能编辑已有商品。

也可使用表格「导入」，或在选款登记、其他表格中勾选行，通过「跨表传送」选择商品档案并配置字段对应。传送至商品档案必须对应并填写款号；目标已有相同款号时更新所选字段，其他资料保留。确认前预览新增和更新数量，每次最多100条已保存、未锁定且有完整编辑权的行；任一行失败时整批回滚。

表格内新增的普通单选、多选及标签字段，与同类源字段对应时会补齐源候选选项；预览列出新增选项，确认时与记录一起保存。目标已有选项、顺序、颜色、类型及其他设置保留，新选项带入源字段已设置的颜色，按本人账号及商品档案保存；普通字段合并后最多100项，源内容及目标限制仍须校验。

「洗涤标志核对」「面料材质核对」等原商品共享单选字段，传送时也可追加源已配置候选项，合并后最多50项。预览标注「商品共享」，明确新增项对所有用户生效；点击「确认传送」后追加，保留原选项及字段类型，仍只能保存一个选项。修改共享候选项沿用商品编辑权限，新增项的颜色保存在操作者个人布局。刷新或重新进入商品档案会读取最新共享候选项，个人显示名称、类型、列宽与配色继续保留。预览不修改目标记录或字段，校验失败、并发冲突时共享选项、记录和个人布局都不写入；源字段选项未配置时须先修正，文本值不会自动扩展单选候选项。（2026-10-05）

传送成功后原行仍保留，填充透明黑色并禁止修改。原表行号的小铅笔释放原行编辑，目标档案仍保留；释放后再次传送会更新关联目标行。两张表不会持续自动同步。

已有实际商品行不能直接删除，以免影响SKU、库存和采购关联；请设置「停用」或「归档」。尚未关联实际商品的空白草稿可以删除。

## 表格功能和个人设置

支持字段管理、拖动调整字段顺序、固定列、字段分组、行分组、筛选排序、复制粘贴、图片上传与放大、手机拍图、产品收集表、保护区域、导入导出；具体操作与「选款登记」「新建表格」一致。商品权限和表内保护规则同时生效，项目权限不能代替商品权限。

字段定义、顺序、宽度、固定列、字段分组及当前分组、显示格式、筛选排序、行高分页和跨表传送配置，按账号及商品档案保存到服务器，跨电脑、浏览器恢复。原商品扩展字段属于商品资料；在表格内另加的普通字段属于本表，不会自动变成商品详情字段、SKU、库存或订单资料。

## 常见问题

建档、修改颜色或尺码资料不等于创建SKU，不增加库存，也不会在唯品会自动上架。平台同步保存在「唯品会接入」的独立商品库，不会覆盖此处资料。吊牌价和供货价不是实际成交价。商品创建、编辑或字段校验失败时，按提示修正；其他人在预览后更改记录时，刷新并重新预览传送。
