# 商品档案

更新日期：2026-09-16。入口：ERP系统 → 商品档案。

## 建档前准备

先在系统设置建立品类；需要关联品牌或默认供应商时，先建立对应资料。商品以款号组织，一款的不同颜色、尺码通过 SKU 管理。

## 单款新建与修改

1. 点击新建入口，填写必填的款号、商品名称和品类。
2. 按需要填写品牌、默认供应商、年份、季节、吊牌价、主图网址、备注及状态。
3. 保存后搜索款号或名称确认记录。需要改某款时，使用该行编辑入口，修改后保存。
4. 打开商品详情查看基本资料、SKU，以及权限允许的库存、采购和操作日志。

## 批量建档

点击「表格编辑 / Excel 导入」，下载模板并匹配品类、品牌、供应商等字段，检查数据后保存。导入用于新增；要改已有商品，编辑表格中载入的记录。具体限制见「表格编辑与 Excel 导入」。

## 常见问题

建档不等于创建所有 SKU，也不增加库存。吊牌价不是实际销售成交价。平台自动同步保存在「唯品会接入」的独立商品库，不自动覆盖此处资料。商品详情中的旧接入提示不能代替唯品会接入页的同步状态判断。
