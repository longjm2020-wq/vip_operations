# 库存明细

更新日期：2026-11-02。入口：运营中心 → 唯品会 → 库存明细。本页统一查看聚水潭序缇杭州总仓的库存快照、经营参考及平台状态，并支持导出。SKU 资料在商品档案详情维护，历史内部库存记录保留。

库存明细仅使用聚水潭库存，已移除「网站库存」来源选择与「导入网站库存」入口。点击「聚水潭同步」配置、核验登录会话并发起同步；完整成功后显示杭州总仓快照及同步时间。虚拟库存、可用数已从查看、汇总、导出及后续同步中移除，暂不估算补货建议及可售天数。未同步成功时显示缺少完整数据提示，不回退到网站内部余额；未匹配不补零。详见[聚水潭库存接入](./38-jushuitan-inventory.md)。原聚水潭字段分组设置继续保留。

库存明细的「商品编码 / 货号 / 款号 / 条码」搜索移到顶部导航栏，输入或粘贴后停止输入约500毫秒自动查询；按回车或点击搜索图标可立即查询，清空搜索立即恢复当前筛选下的全部结果。中文输入法选字期间不查询，选字完成后再计时；每次新查询回到第1页，汇总维度、经营参考周期与罗盘匹配筛选继续在表格上方设置。

点击搜索框右侧「批量查询」图标可粘贴最多200个款号、货号、商品编码或条码，每个最多100字符；支持换行、空格、逗号与分号分隔。在搜索框直接粘贴多个编码也会打开批量面板。去重后点击「查询」，按完整编码精确匹配（字母不区分大小写），任一编码匹配即纳入结果；不按相似名称或编码片段匹配。前导零、连字符和长编码不转换成数字，重复编码不重复累计库存。结果仍叠加当前维度、状态与报表匹配筛选，分页、总计、状态卡片及导出沿用同一范围。搜索框旁显示批量编码数，点击清空图标恢复全部；输入普通关键词则切回单项模糊搜索。

唯品会工作区的库存明细卡片沿用库存查看权限；页面顶部「唯品会工作区」可返回平台卡片页。我的工作台中原有库存快捷工具也打开新的库存明细页面，无需重新保存个人工具。

店铺运营和商品运营均具有库存查看权限，可从上述入口查询库存明细、在途数量及经营参考，并按当前筛选导出明细。此次查看权限补齐保留角色原有权限，不授予库存导入、调整、质检或入库过账权限。新增卡片需刷新页面后显示；修改库存仍由相应操作权限单独控制。

库存明细及相关业务列表中的款号、货号、商品编码、条码和供应商款式编码均提供复制图标；商品编码与附加条码分别复制，未维护货号时可复制其下方的商品编码。复制完整文本并保留前导零，不改变维度、统计日期或库存记录。（2026-10-21）

聚水潭完整同步提示仅保留一行仓库、同步时间和匹配数量，显示30秒后自动收起，同一批次刷新或切换筛选不反复弹出；新批次完成后重新提示。最新同步失败的具体错误持续显示在同一行；窄屏文字省略时悬停可读完整提示。同步时间、来源和记录可随时通过左侧「聚水潭同步」查看，提示收起不影响数据与同步任务。状态卡片置顶，两个同步按钮位于其下方工具栏左侧；上线与部分上线使用品牌蓝色，状态文字区分具体含义。

## 查询口径

按商品编码、货号、款号、商品名称或条码搜索。通过表格左上方「库存汇总维度」下拉框选择「条码（商品编码）」「货号」「款号」，选择后立即切换对应字段和数据，默认条码（商品编码）。库存明细暂不提供仓库筛选，三个维度统一使用聚水潭序缇杭州总仓的库存与在途数量，页面总计和 Excel 导出使用相同范围。切换维度保留搜索条件并回到第一页；经营参考周期和罗盘匹配设置在切回条码视图时继续使用，各维度的字段分组和固定列分别恢复。

页面直接显示查询工具栏与表格，不再单独显示「库存明细／查询库存与在途数量」标题行，当前位置仍可在顶部导航查看。悬停或点击筛选旁的「统计与补货说明」信息图标，展开库存汇总范围、罗盘匹配数量、实际统计日期、报表覆盖天数、日销与退货率方法及聚水潭库存暂不估算补货的说明；键盘聚焦图标后按回车也可展开，Esc 收起。切换周期后说明同步更新，货号和款号视图仅显示库存汇总范围。查询失败的错误提示仍直接显示在工具栏下方。

条码视图默认保留全部商品并优先排列已匹配当前罗盘报表的商品，避免第一页全部是报表未覆盖的历史款。可通过「全部商品 · 已匹配优先」「仅看罗盘已匹配」「仅看未匹配报表」筛选；匹配数按当前搜索范围内的全部 SKU 统计，不是本页条数，也不因同条码的多个仓库重复增加。选择匹配筛选后，置顶总计与导出总计同步使用所选范围。未匹配不代表销量为零，缺少记录时不补零或借用其他条码的经营数值。

- 条码（商品编码）：每行对应一个内部 SKU，保留完整商品编码、条码、颜色和尺码；不同 SKU 即使条码相同也不会合并。商品编码列不再重复显示商品名称或款号。
- 货号：同一款号下相同货号的各尺码合并，保留款号、货号与颜色；包含多种颜色时显示「多颜色」。未维护货号的 SKU 分别显示「未维护货号」与完整商品编码，避免合并不同商品。
- 款号：同款的所有颜色与尺码合并，隐藏货号、商品编码、颜色和尺码列。

表头下方第二行固定显示「总计」，使用浅灰色填充与加粗文字，随当前搜索和罗盘匹配条件更新；总计覆盖筛选结果的所有分页，不是当前页明细之和。三个维度对同一范围的库存总计一致，只改变分组方式。实际库存、采购在途、调拨在途与进货仓分别统计，不能把这些数量直接相加当作可售库存。期间销量、退货率、可售天数、日销参考及补货建议不在总计行相加，显示「—」，避免把分页数据或重复条码误作总销量。货号和款号视图隐藏 SKU 经营参考列。

表格右下方分页沿用商品档案样式，显示「共 N 条」、上一页、页码、下一页和每页条数选择。默认20条／页，可选择20、50、100、200、500、1000、5000条／页；修改每页条数回到第1页。搜索、状态筛选、经营参考周期或汇总维度切换也回到第1页，并保留本次页面选择的每页条数。总条数按当前筛选和汇总维度计算，没有结果时显示「共 0 条」；首次查询显示「加载中…」，不会将尚未返回的数据当作0条。Excel仍导出当前页明细与全部筛选库存总计。

同步数量包含实际库存数、采购在途数、调拨在途数、进货仓库存、订单占有数及销退仓库存，分别沿用聚水潭导出表口径。新增计算字段位于实际库存数前，按各自保存的公式计算。仓库固定为当前核验的杭州总仓，不与历史内部库存相加。

款号、供应商款式编码来自内部商品档案；SKU、条码、颜色、尺码来自内部 SKU 资料。货号按 SKU 资料维护；未设置时显示空缺或上述货号维度的提示。原始表明确为零才显示零；未匹配或原始数量未知显示「暂无数据」，总计包含未知值时显示「不完整」。经营参考列区分「未匹配报表」「未导入报表」「记录有歧义」「待补退货率」「历史覆盖不足」「有效数据不足」，悬停可查看具体原因及匹配条码。

库存图片按当前行对应的颜色商品匹配。条码视图按款号和完整条码匹配「唯品会接入 → 平台商品库」已同步的商品图片，未维护条码才使用商品编码；货号视图通过该货号包含的内部 SKU 条码匹配，不截取编码、不猜色码。平台商品图片与整款 SPU 通用图分开保存，条码和货号视图只采用商品图片，避免不同颜色套用同一张通用图；汇总含多种颜色时不采用某一个颜色图片。款号视图仍可使用同款平台图片或内部档案主图，作为整款代表图。匹配有跨连接或款号歧义时不任取图片。

平台暂无有效商品图片时，条码与货号视图使用当前完整罗盘货号报表的同款号、同完整货号图片，其次使用完整条码报表的同款同货号图片（同条码优先）；未维护货号只用同款完整条码。旧平台缓存尚未区分商品图与 SPU 通用图时，不会覆盖已精确匹配的罗盘图片，后续商品详情同步会补齐图片来源。仍未匹配到对应图片或货号汇总含多种颜色时显示「—」，不借用其他颜色的图片或未标颜色的档案主图。平台商品详情同步后，重新查询或点击「刷新」即可采用新图，无需重新导入库存。小图悬停显示120像素预览，点击放大；Excel 导出的图片链接与页面来源一致。图片仅用于库存页面展示与导出，不改写内部档案图片、颜色或库存数量。

聚水潭的实际库存、订单占有、销退仓、进货仓和在途分别展示，不套用网站内部可售公式。原始文件中即使有虚拟库存、可用数，也不再解析、写入快照或参与计算；既有历史原始文件不改写。

## 计算字段配置

点击工具栏「计算字段配置」，管理多个自定义计算字段。已保存的旧「在仓总库存」公式自动保留为当前账号的私有字段，可继续编辑、删除、隐藏或公开；从未保存公式时不会创建空白计算列。

1. 点击「新增字段」，填写名称和公式。也可点击「新增在仓可用库存」，预填 `[实际库存数] + [销退仓库存] + [进货仓库存] - [订单占有数]`，核对后保存。字段名称最多40字，同一创建者不能重名，也不能使用原始字段名称。每个账号最多创建20项计算字段，全站最多40项公开计算字段。
2. 在公式框定位光标，点击库存字段或 `+、-、×、÷、(、)` 按钮插入，也可直接输入数字及完整字段名。仅支持页面列出的六项原始库存字段，不引用其他计算字段；支持小数常量和一元负号，数字常量不超过1000000，公式最多512字符和63个记号。运算遵循先乘除后加减、括号优先；相同优先级从左向右。
3. 条码视图提供当前页前三个商品的结果预览。示例按钮只填入草稿，点击「保存并重算」才写入服务器，跨浏览器恢复；语法、括号、名称或字段错误时无法保存。返回列表或关闭不保存草稿。公式不能为空；临时停用请隐藏，不再需要可删除。
4. 列表中的「编辑」可修改名称、公式与公开范围。新字段默认「不公开」，仅创建者本人可见和管理；包括超级管理员在内的其他账号也不会收到其私有字段。设为「公开」后，有库存查看权限的账号可查看、计算与导出，创建者和超级管理员可管理；其他查看者只能调整自己的显示状态。取消公开后，其他账号在下次查询或刷新时移除该字段。
5. 「显示／隐藏」只影响当前账号，保存到服务器，刷新及跨浏览器恢复；隐藏的字段从当前账号的明细、总计和导出中移除，公式保留，其他账号不受影响。「删除」需确认，删除公开字段会让所有账号在下次查询时移除该列，不删除原始库存。其他页面已更新字段或显示设置时提示版本冲突，请重新读取后编辑。
6. 显示的计算字段按创建顺序位于「实际库存数」前，可参与字段分组、固定列与列宽设置；「库存」默认分组自动纳入新增计算字段。不同创建者的公开字段重名时，表头和导出附带创建者及字段编号以便区分。其他账号的变更通过「刷新」或下次查询读取。
7. 先逐商品计算并四舍五入保留4位小数，再汇总到货号、款号及全部筛选结果，避免把乘除公式直接套到汇总数量。缺失的引用字段、除数为0或结果超出可展示范围时，该商品显示「无法计算」，含未知值的汇总显示「不完整」，不补零。导出附带所有显示计算字段的公式与汇总口径；计算列不是额外库存，不应再次与原始字段相加。所有字段操作均不改写聚水潭或网站原始库存。

## 平台上下架状态

库存明细显示「条码状态」「款号状态」「状态核验时间」「最后上下架时间」「最后上下架操作」。有库存查看权限即可查看这些只读字段。工具栏左侧的「聚水潭同步」旁提供「同步唯品会状态」：具有唯品会接入管理权限者点击后，在同步面板点击「立即同步」，向已配置且在线的连接提交官方状态核验任务。手动任务重新查询任务开始时已采集的全部不同条码，保留完整编号及前导零，不受当前分页、搜索或库存筛选限制。

面板按本轮任务显示已处理／总数、成功、异常、待处理、进度、开始／结束时间及用时；最近两小时有效状态单独显示，包含之前的成功记录，不能当成本轮完成数。「最近全量成功」仅在本轮开始范围的全部条码重新核验成功后更新；后台空闲检查、局部补查或存在异常不会推进该时间。升级前无法验证的旧完整核验时间不沿用，下一次全量成功后重新建立。最后一批保存后立即判定结果；部分异常及中途失败不会显示全量成功。同步期间新增的采集条码由后续任务处理，不改变本轮已确定的范围。

状态同步独立于商品采集和详情补齐，每批最多50个条码，批次保持请求间隔；同批结果一次保存，中断后从本轮未处理条码继续。实际耗时取决于条码数量和唯品会响应，几千个条码不能保证瞬间完成。任务完成后自动刷新库存明细与状态卡片；可关闭面板继续查看，页面仍跟踪本次任务。正在同步时不能重复提交，手动请求至少间隔一分钟。只读账号的按钮不可用；未配置连接、后台服务离线及读取失败均明确提示。普通「刷新」只重读已有结果，不提交任务。

顶部导航下方、查询工具栏之前提供两张状态数据卡片：「条码状态」显示上线、下线、未发布数量；「款号状态」显示上线、下线、部分上线、未发布数量。条码按同款的完整条码去重（没有条码时使用商品编码），款号按款号去重，不重复计算多个仓库、重复平台资料或同条码的多个内部 SKU。数字表示条码数／款号数，不是库存件数，覆盖当前搜索及罗盘匹配条件下的全部分页。货号、款号维度不使用罗盘匹配条件，卡片也随之按该维度的查询范围统计。

点击卡片中的一个状态立即筛选明细并回到第一页，选中项以蓝色边框显示；再次点击取消。每张卡片可选一个状态，两张卡片组合时取交集，例如「条码上线＋款号部分上线」只看部分上线款号中的上线条码。切换汇总维度保留状态选择，搜索、经营参考周期及罗盘匹配筛选可继续叠加。卡片数量保留当前搜索／罗盘匹配范围的分布，不随状态点击缩减，方便改选；查询期间显示加载状态，不将未返回的数量当作0。没有符合条件的明细时显示空表与0库存总计，仍可再次点击已选状态取消筛选。

状态筛选在货号／款号合并、分页及库存总计之前执行，因此货号、款号视图只汇总符合所选条码状态的 SKU，不能将此时的库存当作整款全部库存。款号状态本身仍按平台完整款号范围判定，不因只显示上线条码而从「部分上线」改成「上线」。导出沿用状态筛选后的当前页和全部筛选库存总计，并在「平台状态口径」注明所选状态。卡片不提交上下架操作、不修改库存，也无需额外保存。

悬停或聚焦卡片标题旁的信息图标可查看统计范围与其他状态数量。「待更新」「未匹配平台」「查询失败」「匹配待确认」「款号不一致」「不存在」等不并入上线、下线或未发布，所以卡片列出的状态数之和可能小于全部条码／款号数。若数量暂不可用显示「—」，请刷新重试或核对平台同步与状态核验情况。

- **条码维度**：按内部款号和完整条码匹配平台商品；未维护条码时使用完整商品编码，保留前导零，条码英文字母不区分大小写。未找到显示「未匹配平台」；条码对应其他款号显示「款号不一致」；同一条码存在多个连接或款号归属时显示「匹配待确认」，不任取一条状态或时间。未匹配不是下线。
- **款号状态**：三个库存维度均显示，汇总对应平台连接中该款号全部已采集的不同条码，不仅限于当前页、货号或罗盘匹配范围。同款跨多个平台连接时显示「匹配待确认」。上线、下线、部分上线、未发布、不存在或待确认的判定与「唯品会接入」一致；悬停可查看数量及范围，不代表唯品会尚未采集商品的状态。
- **状态时效**：条码查询失败显示「查询失败」，超过两小时未核验显示「待更新」；悬停可查看上次记录。相应款号显示「待确认」，不能将旧状态作为当前上线或下线判断。
- **时间与操作**：条码维度显示该条码最后成功核验时间、平台返回的最后上下架时间和操作。货号与款号维度隐藏条码状态，时间针对整个平台款号：核验时间取所有已采集条码中最早的一次，有未核验条码时显示「—」；上下架时间取最近已知值，对应操作无法唯一判断时显示「—」。缺失时间不推算；平台时间单位无法核对时显示「平台时间待核对」。可悬停时间字段查看范围。

Excel 导出包含当前维度的状态中文名称、时间、操作及「平台状态口径」。库存总计不合计这些字段。匹配、分组和导出不会修改库存或操作平台上下架。

## 字段分组

库存工具栏提供「字段分组」，表格上方提供「全部字段」「库存」「经营参考」「平台状态」快捷标签；货号与款号维度没有经营参考分组。点击「平台状态」可快速定位状态字段。

1. 点击「字段分组」→「添加分组」，填写名称并选择至少一个字段。同一字段可以加入多个分组，名称不能重复或使用「全部字段」。
2. 可以改名、增减字段、删除分组，拖动左侧手柄或点击上移／下移调整标签顺序；手柄聚焦后也支持方向键。点击「保存分组」才生效，取消不保存草稿。
3. 点击标签：有固定列时，将分组字段放到固定列右侧，其余字段继续显示；没有固定列时，横向定位到分组首列。蓝色表头上边线标记当前组字段。点击「全部字段」恢复原字段顺序和左侧位置，保留固定列。

分组及当前标签按账号和「条码（商品编码）／货号／款号」维度分别保存在当前浏览器，刷新后恢复；不会同步给其他账号或设备。搜索和翻页不改变分组，不影响库存数量、筛选范围或 Excel 导出列顺序。浏览器禁止存储时，保存分组会显示错误并保留草稿；清除本地数据会重置分组。删除分组只移除标签，不删除字段或数据。

## 列宽与单元格显示

三个维度的所有字段初始宽度均为120px。将鼠标移到表头右侧边缘，指针变为左右拖动形状后拖动调整，允许72–600px；表头、明细和总计同步调整。松开鼠标后自动保存，拖动中按Esc或窗口失去焦点取消本次调整。双击边缘恢复该列120px；键盘聚焦边缘后，左右方向键每次调整10px，Home恢复120px。

列宽按账号和汇总维度分别保存在当前浏览器，搜索、翻页、切换字段分组及刷新后保留；清除浏览器本地数据后恢复默认。浏览器无法保存时会提示，本次调整仍生效。调整仅影响页面，不修改数据或Excel导出。加宽固定列后若窗口已无法容纳，暂时停用固定，缩窄列宽或放大窗口后自动恢复。

明细行高固定84px，单元格文字在列内自动换行，图片和长内容均不会撑开列宽或行高。图片单元格不显示内部滚动条，缩窄图片列时缩略图适配可用宽度，仍可悬停预览、点击放大。超过单元格可显示高度的文字可在该单元格内滚动查看；复制仍取得完整编号，Excel导出保留完整字段内容。

## 选列与右键固定

具有库存查看权限即可使用。此功能只通过表头选列和右键菜单提供，不增加工具栏按钮或勾选面板。

1. 选列：单击表头选中该列，选中列的表头和数据以浅蓝色高亮；再次单击唯一选中的表头可取消。在表头上按住鼠标横向拖过相邻表头，松开即选中拖过的连续列，拖动中实时高亮；按住 Ctrl（Mac 为 ⌘）拖动则把拖过的列追加到已有选择。按住 Shift 单击另一个表头，选中两者之间按当前显示顺序连续的全部列；按住 Ctrl（Mac 为 ⌘）单击表头可逐列加选或取消，用于选择不连续的列。Ctrl／⌘ 与 Shift 同时按住单击，会把连续范围追加到已有选择。
2. 固定：在任一选中列的表头或数据单元格上点击右键，选择「固定所选 N 列」（只选一列时为「固定此列」）。在未选中的列上右键只对该列操作，并改为选中该列。
3. 取消：右键已固定的列选择「取消固定此列」，或选中多列后选择「取消固定所选 N 列」；选区同时含已固定和未固定列时两项均显示，固定时保留其他已有固定列。「取消所有固定列」立即清除当前视图的全部固定。
4. 清除选择：按 Esc，或单击表头以外的任意位置（含数据行）。固定或取消固定后自动清除选择。

固定列按原来的列顺序集中到左侧，与选择先后无关；横向滚动时表头、明细和总计同步固定。最后一个固定列右侧显示一条较深的竖向分隔线（与选款登记一致），贯穿表头、总计和明细，横向滚动时保持显示；滚动到一半时，被固定列遮住左侧的列会显示在分隔线右边。表头文字区域单击或拖动用于选列，表头右侧边缘拖动用于调整列宽；不提供点击排序或拖动换列，不会选中表头文字。拖选只在当前可见的表头之间进行，不会自动横向滚动。

设置按当前账号和「条码（商品编码）／货号／款号」视图分别保存在当前浏览器，刷新后恢复，搜索或翻页保留设置；不会同步给其他账号或浏览器。固定仅调整页面显示，不修改库存、查询口径或 Excel 导出列顺序。

固定列总宽不能占满可视区域并遮住其他列；出现宽度提示时请减少选中列。窗口缩窄后若容纳不下已固定的列，将暂时停用固定以保留完整横向浏览，放大窗口后自动恢复原设置。浏览器禁止保存设置时，本次固定仍生效，刷新后需重新设置。清除浏览器本地数据也会清除固定设置。

## 供应链库存关联

供应链订单继续在「供应链端 → 订单中心 → 订单详情」处理 SKU 关联、配送、质检及正式入库，具体步骤见供应链订单章节。这些历史内部业务记录保留，与本页聚水潭快照独立，不相加，也不通过本页的同步反向修改。旧 ERP 业务页面已下线。

## 渠道经营参考

条码维度的「期间销量」「渠道日销参考」「退货率」「预估销退数」使用同一个「经营参考周期」，可选择近3天、近7天、近15天、近30天、近3个月、近半年或近1年。首次默认近30天；此前保存过个人参考配置的账号沿用其默认周期。上方下拉框可临时切换，页面会重新查询并回到第一页；搜索和罗盘匹配筛选继续生效。货号及款号维度隐藏该选择和这些列，切回条码维度保留本次已选周期。

窗口以当前最新完整条码来源的截止日为终点，不随电脑当天日期或经营分析页面的日期筛选变化。天数周期包含起止两日；近3个月、近半年和近1年按日历月或年滚动，不固定等于90、180或365天。页面列出实际起止日期、已覆盖天数／应覆盖天数，以及日销、退货率各自的取值方法。只有窗口中全部日期均有完整导入的条码历史时才使用该期间的自动参考；日期覆盖完整不代表每个 SKU 的每项指标都有值。

先按内部 SKU 条码完整匹配；未维护条码时按完整商品编码匹配，保留前导零，不截断或猜测编码。渠道日销使用所选期间每日「销售量」，退货率使用原始列「退货率(退货件数/销售量)」中的每日百分比；两者沿用当前账号已保存的中位数、众数（并列取均值）或平均值配置，初始均为中位数；聚水潭视图不提供内部库存计算配置入口。中位数将有效值排序，奇数取中间值，偶数取中间两值平均，例如1、3、5、100得到4。众数统计频次，例如1、3、5各出现3次且均为最高频次，结果为（1+3+5）÷3=3。平均值为有效每日数值合计÷有效样本天数。明确记录的0参与；缺失日期或单元格不补0。退货率参考允许报表值超过100%，不改成期间退货件数÷期间销量，也不将其宣称为订单批次退货概率。数值展示最多4位小数。

「期间销量」显示此条码在所选期间已提供的每日销售件数合计，并在提示中列出起止日期及已记录天数；导出同步保留该列。日期覆盖完整但某条码没有每天记录时，此合计仅代表已记录的销量，不推算缺失日期；销量单元格缺失、条码存在歧义或整体历史覆盖不足时显示相应原因，不补零。中位数与合计是两种不同指标：期间已有成交，每日销量的中位数仍可能为0；日销提示会同时说明期间销量。

### 每日销量与库存趋势

点击条码行的「期间销量」（包括0或缺失提示）打开趋势窗口，沿用点击时的经营参考周期和截止日，仅查询本行商品，不跨颜色、尺码或不同报表维度汇总。每日销量与在仓可用库存分别绘图，并提供逐日数量、较前日库存变化、库存同步时间及销量来源文件。悬停或键盘聚焦图表数据点查看日期和数量。

库存默认选择当前可见的「在仓可用库存」计算字段，也可从下拉框切换其他有权查看的计算字段。没有该字段时先选择已有字段，或在「计算字段配置」新增；不会擅自采用原聚水潭可用数。历史库存使用保存的六项原始数量，按所选字段的**当前公式**重新计算，窗口展示公式及版本；修改公式后历史曲线也按新口径重算。私有及取消公开的字段继续遵循账号权限。

每次聚水潭完整同步成功后，按北京时间保留当日最后一次成功同步的完整快照，独立于最近五次原始文件的清理；一天内多次同步会替换当日快照，不累计库存。库存同步失败不发布历史。上线时仅恢复仍有真实快照的历史日期，已清理日期无法恢复；没有同步的日期、未匹配商品、未知数量、除零或无权查看的公式不补零，也不使用当前值或前一天的库存补填。仅相邻两日均有有效库存时计算变化量。同步时间不一定在午夜，快照不代表精确日终盘点。所选销量截止日前没有库存记录时图表留空，即使明细已有更新的当前库存。

库存趋势按每次同步自动积累，打开趋势窗口本身不会发起聚水潭同步、修改商品档案或原始库存。要增加某日库存记录，需在当天完成一次聚水潭同步。

预估销退数 = 同条码所选期间的报表销售件数合计 × 按已选方法计算的每日退货率参考，保留最多4位小数，不强制取整。按窗口内已提供的销量记录求和，有效记录天数在提示中列明，不补齐缺失日期；存在缺失销量单元格或没有有效参考退货率时不生成估算。同条码同日出现多个平台记录时，无法确定此 SKU 的参考口径，不自动合并使用。

悬停或键盘聚焦这三项数值可查看所选周期、实际起止日期、历史覆盖天数、匹配条码、有效样本天数和实际计算方法：中位数列出中间值，众数列出最高频次及并列数值，平均值列出有效样本天数。预估销退同时显示期间销量合计及计算公式。历史不足、条码未匹配、存在歧义或某项数据不足时，保留该项已维护的人工参考，并在提示中明确标注；未维护则直接显示缺失原因。近半年或近1年缺少历史时显示「历史覆盖不足」，不会拿局部30天值冒充整个期间。匹配数量表示条码在来源窗口中存在记录，不保证每项字段都有有效值；出现同日多平台记录时仍会标注歧义。

较长周期需先在经营分析「导入报表」积累对应日期的原始条码日报；每张报表统计区间最多90天，可分段导入并补齐缺口。完整导入后，重叠日期以较新完成的该日完整数据整体替换，不叠加旧记录或把新来源中已不存在的商品保留下来。较早截止日，或与当前相同截止日但起始日较晚、覆盖更短的条码导入，只补日历史，不替换当前经营分析来源；相同或更完整的区间，以及更新的截止日，可正常替换。未完成的导入不能计入覆盖。旧解析版本未保存原始每日退货率时，可重新导入同一原始条码文件补齐，不重复累计销量。经营分析手动「更新数据」下载近30天，报表定时更新已移除，不会自动追溯半年或一年历史。

历史人工参考只在相应报表参考不可用时使用，并明确标注。库存明细已移除网站库存导入和逐行编辑入口。自动参考在查询时计算，不覆盖人工参考记录，不修改商品档案或实物库存。刷新读取当前已完整导入的罗盘来源。

## 补货参考限制

「补货日均」仍可作为渠道需求参考；聚水潭视图的「可售天数」「补货建议」统一显示「暂不估算」，不会把聚水潭快照或自定义在仓总库存套入历史内部库存的回仓和补货公式。

## 权限

查看、导出、新增计算字段及调整个人显示设置需要库存查看权限；字段的编辑、删除与公开范围遵循上述创建者及超级管理员规则。聚水潭登录配置和发起同步仍需超级管理员及库存调整权限；唯品会平台状态同步需要唯品会接入管理权限。这两类同步独立。供应链业务继续使用各自权限，历史 ERP 权限不会恢复旧入口。

## 导出

点击「导出」下载当前维度、当前筛选下本页数据的 Excel。第二行是全部筛选结果的总计，后续行是当前页完整明细，包含尚未滚动到的行。例如选择5000条／页时，本页返回的5000条都会导出。款号、货号、商品编码和条码保留文本格式与前导零；库存缺失值保留为空，总计含缺失值不能当作完整库存。

导出包含聚水潭来源、同步时间、平台状态口径；条码维度附经营参考周期、起止日期、覆盖天数、实际计算方法及「暂不估算」限制。总计不合计经营参考或平台状态。查询正在更新或失败时不能导出，请等加载完成。库存明细不再提供网站库存 Excel 导入。

## 常见问题

提示没有完整聚水潭数据：打开「聚水潭同步」核验杭州总仓并完成一次同步。失败时保留上一次完整快照及提示，不以内部余额充当结果。无匹配或原始数量未知显示「暂无数据」，不是库存为零。

平台状态尚未更新：打开「同步平台状态」查看任务、连接和后台服务提示；失败会保留具体错误，不宣称同步完成。有效状态超过两小时会标记待更新，需要重新核验；未匹配不是下线。

大分页首次读取仍取决于网络及服务器响应。超过100条／页启用虚拟滚动，仅渲染视窗附近的行，滚动时按需显示后续行；图片继续懒加载。总计覆盖全部筛选结果，分页总数及导出不受可见行数量影响。切换页码、每页条数、搜索或筛选会回到表格顶部并取消过时请求；列宽调整、分组定位及固定列继续可用。

表格按工具栏、提示信息和分页的实际高度自动占满页面剩余空间，分页下方仅保留8px操作边距。缩放窗口、收起侧栏或提示信息换行时自动调整；短窗口仍保留可阅读的明细高度，必要时可滚动页面到达分页。
