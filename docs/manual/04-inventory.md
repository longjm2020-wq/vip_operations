# SKU 库存

更新日期：2026-09-16。入口：SKU 库存。

## 查询口径

按 SKU、款号、商品名称或仓库筛选。实际库存、锁定数量、次品和采购在途分别显示。可售数量 = 实际 − 锁定 − 次品。在途来自已确认的采购单，不是已入库数量。

## 单笔或批量调整

1. 点击库存调整，选择 SKU 和仓库。
2. 填写变化数量：正数增加，负数减少。选择期初建账、盘点差异或人工调整，并填写说明。
3. 核对后提交，再到库存流水查看结果。多条调整可使用批量库存调整表格。

例：系统实际库存 100 件，盘点为 96 件，应填变化数量 -4，而不是 96。日常采购到货请使用入库过账，避免同一批货重复调整。

## 常见问题

保存到货单但库存未变：检查是否已经「核对并过账」。表格调整可能部分成功，应只重试失败行。唯品会平台库存当前未同步到此处，不能将内部库存等同于平台库存。
