# 表格编辑与 Excel 导入

更新日期：2026-09-19。

## 适用范围

商品、SKU、供应商、仓库、品类、品牌、颜色尺码映射支持批量建档和修改。采购、入库、库存调整、采购建议和项目任务使用各自的业务表格。单条新建、编辑方式保留，适合修改某一款商品。

## 操作步骤

1. 进入模块，点击「表格编辑 / Excel 导入」或该模块的表格入口。
2. 先下载模板；整理数据后导入 .xlsx 或 UTF-8 .csv。旧 .xls 请另存为 .xlsx。文件最多 5 MB，每批最多 500 行；多工作表可选择工作表。
3. 在导入预览中核对列匹配。也可从 Excel、WPS、飞书复制多行多列后粘贴到目标单元格。
4. 点击单元格编辑，使用 Tab 横向移动、Enter 纵向移动；支持添加行、复制行、撤销和重做。
5. 点击「检查数据」，修正错误，再保存。核对成功和失败数量，修正失败行后重试。

## 关键规则

主数据编辑载入当前列表页，不是整个数据库。导入追加新记录，不会自动按编码覆盖现有资料；修改已有记录请编辑载入的行。重复编码会报错。「移出选中行」仅移出本次编辑，不删除已保存资料。

编码应在 Excel 中设为文本，保留前导零。关联字段先建立对应资料，再使用编码或完整下拉选项；重名时用编码区分。品类表使用「上级品类编码」建立一级、二级、三级关系，父级行须排在子级行之前。公式请先粘贴为值。

表格不是完整办公电子表格，不支持任意公式、合并单元格或多人实时协作光标。导出列表通常仅包含当前页。

商品档案的「表格导入」包含已启用的扩展字段，超过26列时列号继续显示 AA、AB 等。标题字数、限价是否达标等计算列不作为填写列；保存资料后在商品列表查看计算结果。

## 不同模块保存的区别

主数据保存会逐行写入，成功行不会随其他行失败而回滚。库存表格填写的是增减量，保存会改变库存。采购建议表格保存会确认待处理行。采购和入库表格仅编辑当前单据，仍需后续确认或过账。

网络异常且结果不确定时，按页面提示重试原行确认结果，避免修改原请求后重复提交。已有成功记录不要再次整批导入。
