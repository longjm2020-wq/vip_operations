# 供应链产品管理

更新日期：2026-09-17。入口：供应链端 → 供应链产品库。需要“查看供应链产品与维护序缇款号”权限。

先选择已入驻供应商，再查看其产品、颜色图、报价和库存。序缇款号旁点击编辑，保存后供应商可见；供应商不能自行修改此字段。产品资料和上下架由供应商维护。

列表点击“产品详情”，右侧展开完整资料卡片，包含颜色图、价格、库存明细和产品卖点。卖点不单独占列表列，为非必填，最多1000字，由供应商在编辑产品时维护。

支持以分号分隔多个完整款号搜索，按上架/下架筛选。导出可以选择筛选结果、已勾选或全部产品；库存按款、颜色、尺码或颜色尺码明细汇总。图片链接需要登录并具备供应链产品权限。

此产品库与ERP内部商品、SKU及库存分开维护，供应商上架表示可售，不会直接创建ERP商品、采购单或修改内部库存。拥有供应链采买权限的内部人员可点击单款「采买」，或勾选多款后「采买已选产品」，按颜色尺码生成采买清单推送对应供应商；订单在「订单中心」跟进。仅已上架且库存、颜色图已维护的产品可采购，数量不得超过扣除未发货订单占用量后的可采购库存。统一收货信息由采购订单的「收货设置」维护。此供应链订单不自动创建ERP采购或入库单。

产品详情与编辑卡片按接近全屏宽度展开，移动端自适应屏幕。

「翻单周期（天）」列位于「颜色」前，产品详情及产品资料导出中同步显示。该字段由供应商填写，为必填非负整数；旧资料未填写时显示「待补充」，内部人员不代填默认值。供应商编辑保存或重新上架前需补齐。
