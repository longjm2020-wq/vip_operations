# 唯品会接入

更新日期：2026-10-03。入口：ERP系统 → 唯品会接入，需要接入管理权限。

## 查看与同步

1. 查看供应商连接卡片中的同步状态、平台商品数、待处理数、上次完成时间及授权到期时间。
2. 在平台商品库核对款号、条码、名称、合作编码、仓库和更新时间。
3. 需要更新时点击「立即同步 / 重试」。这会提交任务，不代表所有商品立即完成；观察后续状态。

当前每小时检查更新，每日重新核对全量。商品详情渐进补齐，颜色、尺码、品牌、品类、图片以及平台返回的价格可能在后续批次出现；缺失不等于数值为零。

## 数据范围

范围是唯品会档期商品，默认不包含 OXO。可补充颜色、尺码、品牌、品类、图片及市场价、售价、供货价等返回字段；资料售价不是实时成交价。原始平台资料独立保存，不会覆盖内部商品、SKU、采购或库存。

本页的订单、销售和库存官方接口同步尚未启用，因此商品接入卡片不能提供已验证的近 7 天销量或平台库存。不要把平台商品数当作库存件数。另可在「经营分析」导入魔方罗盘的款号、货号和条码每日报表，按实际报表分析销售、退货与平台库存；这种报表采集不代表官方罗盘 API 已开通，也不会覆盖内部库存。

## 罗盘官方取数验证

「罗盘官方取数接入」卡片提供配置检查与一次只读取数验证。首次接入需要唯品会对接商务开通罗盘取数，在罗盘登记 RSA 公钥，并提供具体指标 API code、查询参数及字段口径。开放平台应用获批或浏览器已经登录不代表罗盘取数已经开通。

管理员在 Worker 部署环境配置罗盘账号、公钥对应的 RSA 私钥文件、API code 和字符串格式的查询参数 JSON，重启 Worker 后观察四项配置状态。页面仅显示配置是否存在，不显示账号、私钥、签名或查询参数值。配置格式、私钥读取失败会给出提示；处理原因后重启 Worker。不要把私钥或登录凭据填入商品表、聊天消息或浏览器调试工具。

配置有效且 Worker 在线时，点击「验证官方取数」。这会提交一次任务，Worker 查询一页数据；一分钟内不能再次发起。页面显示最近验证时间、业务状态码、本页行数、最多100个字段名、是否返回下一页游标以及平台更新时间。请求中的签名、返回的数据值和平台原始错误消息不会保存到验证记录。

「已收到响应，待核对口径」只表示返回了符合接口结构的响应，不代表业务状态码已确认为成功、查询范围完整或指标口径已核验。验证不自动翻页、导入或替换经营分析来源，不改动内部商品、库存、采购，也不会启用或发送每日邮件。当前经营分析继续使用已完整导入的 Excel 报表。

平台返回403时，可能是权限、白名单或并发上限，需要核对具体开通状态；405表示查询参数被拒绝，400表示查询失败。未知返回格式或 Worker 中断会提示重新检查。配置改变会清除上一次验证的结果，避免把旧配置的响应当作新配置已通过。

## 状态与问题处理

同步中、继续下一批：等待后续批次，不必反复点击。部分记录待处理：已有数据不等于全部成功，请管理员核对异常。需要处理或失败：记录安全错误提示，联系管理员检查授权、白名单或 Worker。

超过 70 分钟未报告状态会告警。授权恢复和生产密钥配置由管理员在部署环境处理，不要将密钥填入普通商品表或聊天消息。修复原因后再手动重试。
