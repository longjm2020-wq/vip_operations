# XUTI 服装口播 · 抖音 / 小红书爆款一键拆解插件

兼容 Chrome / Microsoft Edge（Manifest V3）。

## 安装步骤
1. 打开 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录 `apps/browser-extension`。
4. 点击扩展图标，填写你的 XUTI 系统地址（例如 `https://your-xuti-domain.com` 或本地 `http://localhost:5173`）并保存。

## 使用方式
1. 确保当前浏览器已登录 XUTI 系统（插件自动复用登录态，无需配置 API Token）。
2. 在抖音（`douyin.com`）或小红书（`xiaohongshu.com` / `rednote.com`）浏览同行爆款视频时，在页面或视频上点击右键：
   - **一键拆解复刻到 XUTI（人工介入修改）**：自动导入并拆解，每个阶段暂停供人工修改。
   - **一键拆解复刻到 XUTI（全自动模式）**：自动导入并全流程自动推进。
3. 浏览器将自动打开 XUTI「服装口播 → 爆款复刻工作流」并开始逆向拆解。
