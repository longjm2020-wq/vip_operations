小序桌面端 1.3.3 · Windows 10/11 x64

AI 导演台支持从已配对的 Windows 客户端导入本地素材、在后台按分镜生成 H.264/AAC MP4、分镜稿、SRT 和 edit-plan.json。安装独立 FFmpeg Windows 构建（https://ffmpeg.org/download.html），将 ffmpeg.exe 放入 %LOCALAPPDATA%\XutiDesktop\tools，或设置 XUTI_DIRECTOR_FFMPEG 为 ffmpeg.exe 的完整路径。也支持 PATH 中的 FFmpeg。请选择包含 libx264、AAC 的构建。本客户端不附带 FFmpeg 二进制。可选的本地模型和动效模板安装说明位于 director-media\README.md。
在「AI 导演台」的「导入素材」中选择本机文件或文件夹，将打开 Windows 选择窗口。一次可多选文件或选择整个素材包。确认选择后，客户端核验项目权限并在本机登记素材。每个项目最多 500 份素材，可引用几十 GB 的素材包。请保留原文件的位置和内容，外接硬盘需在预览和导出时保持连接。客户端在本地应用数据目录保存素材索引、镜头缓存和各次导出。打开作品后，可用「打开文件夹」取出四份交付物。暂停后可继续，关闭客户端会暂停后台工作。改片时未改变的镜头可复用。

选取包含「商品素材」「授权肖像」「授权音色」「正式配音」「参考片」「文字资料」子目录的素材包时，文件按最近的用途目录归类。用途不符的文件会跳过。肖像与音色的项目授权需在页面单独确认。本机支持登记 TXT、MD、SRT、PDF、DOCX、PPTX 和 XLSX 文档，编排时需使用的文案可填写在项目的创作要求中。

将压缩包完整解压到一个文件夹，双击 XutiDesktop.exe（或“启动小序.cmd”）。
无需安装第二个电脑助手，无需管理员权限，无需开发工具。
请保留同目录的 DLL 文件；不要只移动 EXE。

1. 登录工作台。此客户端有独立的本机网页会话，首次使用需要重新登录。
2. 首次使用时，从工作台右侧“我的电脑”连接本机，在本机确认“允许并记住”。也可按 Ctrl + Shift + L 连接。
   此后保持客户端运行，在工作台中栏底部直接发指令。右栏显示设备能否接收任务和已有授权。
3. 在工作台直接说或输入。网站内任务直接处理；电脑任务请明确说「在我的电脑上…」或指定已连接的设备。
4. 可先发送“在我的电脑上打开记事本”。已记住授权时，小序会切到记事本；需要时启动系统记事本，并在核实前台窗口后报告完成。
   如果只想切换已有窗口，请发送“在我的电脑上切换到已打开的记事本窗口”。找不到窗口时，任务卡会提示你如何继续。
   已记住授权后，发“在我的电脑上打开企业微信”。小序会查找腾讯签名的企业微信，必要时从本机安装位置启动或唤起，并核验前台窗口。发“打开企业微信，搜索联系人陈晨”可继续在企业微信内查找。登录和最终发送由本人完成。
   复制文件可发“把「D:\样品\说明.txt」复制到「D:\已核对」”。请先创建目标文件夹，保持客户端在线并记住授权。小序在后台复制并核对结果，此时可以使用其他应用和剪贴板。明确要求用 Ctrl+C、Ctrl+V 时，才使用资源管理器快捷键。
   批量建目录可发“在我的电脑桌面新建文件夹「测试自动化999」，并在文件夹内新建10个文件夹，命名规则按「XUTI-01……XUTI-10」”。小序会在后台创建并核验这些目录，期间可以切换窗口、移动鼠标或打字。
   建目录时也可在同一条指令后加“然后在每个子文件夹内新建一个记事本，命名按子文件夹名命名”。小序先把整句拆成建目录、补同名 .txt 和核验三个步骤，再由客户端的隐藏命令行进程执行这份任务脚本。在任务卡展开“后台执行计划”可以查看顺序。已有普通文本保留原内容。
   批量建目录完成后，可在同一对话说“在每个子文件夹内新建一个记事本，命名按文件夹名命名”。小序会在刚才核验的每个子目录里后台创建同名 .txt 文件，并核对结果。已有的同名普通文件保留原内容。
   分发聊天附件时，随消息附上一份文件，例如“把这张图复制到桌面『样品』下的 10 个子文件夹（XUTI-01 至 XUTI-10），每个文件夹一份，保留原名”。先在“我的电脑”选择已授权的 Windows 电脑。客户端后台将附件按原名复制到指定的 1 至 100 个现有子目录，逐个核验 SHA-256。同名且内容相同的文件计为已完成，同名但内容不同、目录缺失或包含链接时会提示核对。暂停后在任务卡继续，可补齐剩余副本。
   同一条消息可附 1 至 6 个不同名称的文件，总计最多 80 MiB。要一边建目录一边分发，可说“在我的电脑桌面新建文件夹「样品」，在里面新建 10 个子文件夹，命名为 XUTI-01 至 XUTI-10，然后把这些附件全部复制到每个子文件夹，保留原名”。已建好的目录可直接指定父目录和子目录名称或编号范围。客户端先核对整批附件和已有目标，再将每份附件复制到每个指定的子目录。完成时，各目录里的每份副本都已经核验。
   想用新的桌面文件夹装入整份资料，可发“在我的电脑桌面新建文件夹「本次样品」，并将路径 D:\样品 下的内容复制进来”。小序核对源目录后在当前用户的桌面建文件夹，连同普通子文件夹一起复制。桌面已有同名项目时会提示换名。
   等任务卡显示已完成，可紧接着说“输入9999999”。小序会核对上一条任务的授权和记事本窗口。输入框会显示本条消息的去向，普通提问仍在对话中回答。
   取消确认后可再点“使用我的电脑”重试。在客户端按 Ctrl + 3 打开“电脑任务”，查看、暂停或停止任务。
   已允许本机的暂停任务，可在主面板点击“继续当前任务”，无需再找高级设置或重新授权。
   手动配对、选择窗口、逐次允许及撤销操作均在“电脑任务 → 高级设置”，需要时再展开。
   本机或网站可随时撤销允许。已记住允许后重复连接不会再弹确认。
5. 工作台右侧点“独立浏览器”，在“本地浏览器”中输入 HTTPS 网址，或点“打开本地窗口”。在客户端也可按 Ctrl + 2 打开本地浏览器。
   登录会话保存在这台电脑。让小序接手时先打开目标网页，再说「在本地浏览器里点击…」。
   小序只操作专用窗口的网页内容，沿用已记住的本机授权或逐次允许。登录、验证步骤由你完成。

6. 在已记住设备授权的电脑上发送需要操作资源管理器的建文件任务时，小序会先找到或打开资源管理器中的桌面目录，核对窗口后操作。任务暂停后，可先查看目标目录里已有的文件，再点原任务的“继续当前任务”。要自己选窗口，可到“电脑任务 → 高级设置”选择实际文件夹窗口。任务卡的“最近步骤回执”可区分已执行、未执行和未确认。

在“电脑任务”查看实际可用的停止快捷键。默认 Ctrl + Alt + X，被占用时改用 Ctrl + Alt + Shift + X。两组都不可用时，客户端会提示原因，恢复接单后再发任务。
后台文件复制期间可以正常使用电脑。已记住授权的前台任务在观察或两步之间遇到手动操作时会等待，原窗口回到前台并空闲三秒后重新观察。
在小序已获准向窗口输入时接手，任务卡会提示核对该步。已经输入的文字不会重复输入。主动暂停、停止和撤销授权仍然生效。
启动前没有可操作窗口等失败会显示“需要你接手”和具体原因，打开窗口后可继续。
网站或智能服务出错时保留具体原因及安全诊断编号；任务已经暂停时不覆盖原来的失败说明。
主窗口标题为 XUTI DESKTOP，工作台占满窗口内容区。在右侧“我的电脑”查看连接和任务状态，点“打开电脑任务”可查看暂停或需要接手的完整原因。
打开不同主题的站内页面，或在支持切换的页面点击太阳／月亮按钮，主窗口标题栏会随网页主题更新。Windows 11 支持设置标题栏背景和文字颜色。Windows 10 的显示效果取决于系统版本和个性化设置。启用 Windows 高对比度时，标题栏使用系统配色。
诊断不保存截图、控件、供应商原始响应或连接密钥，不需要导出本机登录文件。
退出客户端后停止本机执行。
运行中的云端数据任务仍由服务器继续处理，以网站实际结果为准。
暂停或需要接手时仍需主动继续；断开、登录失效或重新配对后需重新授权。
连接时会核验本机凭据；失效后可在同一流程重新连接，网络故障不会清除已保存的允许。
批量文件任务由客户端按任务卡中的授权计划执行。其他窗口任务继续使用前台观察和输入。

运行环境：.NET Framework 4.8、Microsoft Edge WebView2 Runtime。
若提示缺少网页运行环境，请通过客户端提供的微软官网链接安装后重试。

Windows 客户端会在启动和运行期间检查官网版本。有新版时可选“下载新版”，也可选“稍后”继续工作。需要手动下载时，在工作台打开“我的电脑”。已连接设备的用户可展开“其他连接方式与客户端更新”，点击“下载新版桌面端”。
下载完成后，请先结束本机正在执行的任务，退出旧程序，将新包完整解压到新目录，再双击其中的 XutiDesktop.exe。网站页面随线上版本更新。

登录信息保存在本机当前用户的 WebView2 配置目录，设备凭据使用 Windows 加密保护。
窗口截图仅在允许的任务执行中发送到网站的智能服务，不保存截图文件。
