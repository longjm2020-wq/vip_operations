小序桌面端 1.2.7 · Windows 10/11 x64

将压缩包完整解压到一个文件夹，双击 XutiDesktop.exe（或“启动小序.cmd”）。
无需安装第二个电脑助手，无需管理员权限，无需开发工具。
请保留同目录的 DLL 文件；不要只移动 EXE。

1. 登录工作台。此客户端有独立的本机网页会话，首次使用需要重新登录。
2. 在工作台右侧点击“我的电脑”，再点“使用我的电脑”。首次连接时，在本机确认“允许并记住”。
   已有有效授权时会直接选中这台电脑。也可在客户端按 Ctrl + Shift + L 打开本机连接与授权。
3. 在工作台直接说或输入。网站内任务直接处理；电脑任务请明确说「在我的电脑上…」或指定已连接的设备。
4. 授权后新任务自动开始，可在已打开的普通应用和网页之间切换，重启后仍记住授权。
   取消确认后可再点“使用我的电脑”重试。在客户端按 Ctrl + 3 打开“电脑任务”，查看、暂停或停止任务。
   已允许本机的暂停任务，可在主面板点击“继续当前任务”，无需再找高级设置或重新授权。
   手动配对、选择窗口、逐次允许及撤销操作均在“电脑任务 → 高级设置”，需要时再展开。
   本机或网站可随时撤销允许。已记住允许后重复连接不会再弹确认。
5. 工作台右侧点“独立浏览器”，在“本地浏览器”中输入 HTTPS 网址，或点“打开本地窗口”。在客户端也可按 Ctrl + 2 打开本地浏览器。
   登录会话保存在这台电脑。让小序接手时先打开目标网页，再说「在本地浏览器里点击…」。
   小序只操作专用窗口的网页内容，沿用已记住的本机授权或逐次允许。登录、验证步骤由你完成。

Ctrl + Alt + X 随时停止；真实点击、滚轮或按键按下会暂停，移动鼠标及松开按键不会误停。
手动切换窗口仍会暂停。文字输入被接手时会提示核对已输入部分，不自动重放。
启动前没有可操作窗口等失败会显示“需要你接手”和具体原因，打开窗口后可继续。
网站或智能服务出错时保留具体原因及安全诊断编号；任务已经暂停时不覆盖原来的失败说明。
主窗口标题为 XUTI DESKTOP，工作台占满窗口内容区。在右侧“我的电脑”查看连接和任务状态，点“打开电脑任务”可查看暂停或需要接手的完整原因。
诊断不保存截图、控件、供应商原始响应或连接密钥，不需要导出本机登录文件。
退出客户端后停止本机执行。
运行中的云端数据任务仍由服务器继续处理，以网站实际结果为准。
暂停或需要接手时仍需主动继续；断开、登录失效或重新配对后需重新授权。
连接时会核验本机凭据；失效后可在同一流程重新连接，网络故障不会清除已保存的允许。
电脑操作尚不代替文件系统工具，不会直接运行终端或脚本。

运行环境：.NET Framework 4.8、Microsoft Edge WebView2 Runtime。
若提示缺少网页运行环境，请通过客户端提供的微软官网链接安装后重试。
https://developer.microsoft.com/microsoft-edge/webview2/

Windows 客户端会在启动和运行期间检查官网版本。有新版时可选“下载新版”，也可选“稍后”继续工作。需要手动下载时，在工作台打开“我的电脑”。已连接设备的用户可展开“其他连接方式与客户端更新”，点击“下载新版桌面端”。
下载完成后，请先结束本机正在执行的任务，退出旧程序，将新包完整解压到新目录，再双击其中的 XutiDesktop.exe。网站页面随线上版本更新。
客户端未配置代码签名；请通过本网站获得此包，不关闭或绕过系统安全检查。
登录信息保存在本机当前用户的 WebView2 配置目录，设备凭据使用 Windows 加密保护。
窗口截图仅在允许的任务执行中发送到网站的智能服务，不保存截图文件。
跨窗口模式还会发送可操作窗口的标题及应用名；最多列出40个普通窗口。
来源代码在 source 目录，第三方组件许可在 licenses 目录。
