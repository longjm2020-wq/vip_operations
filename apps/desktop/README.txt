小序桌面端 1.1.0 · Windows 10/11 x64

将压缩包完整解压到一个文件夹，双击 XutiDesktop.exe（或“启动小序.cmd”）。
无需安装第二个电脑助手，无需管理员权限，无需开发工具。
请保留同目录的 DLL 文件；不要只移动 EXE。

1. 登录工作台。此客户端有独立的本机网页会话，首次使用需要重新登录。
2. 点击顶部“连接本机”，在小序的“电脑操作”面板点击“连接本机”。
3. 网站内任务可直接在小序对话中发送。电脑任务先选择本机，再发送任务。
4. 顶部“电脑任务”选择一个已打开的窗口，点击“允许本次任务”。
5. “打开网页”提供独立网页窗口，可打开罗盘、聚水潭等 HTTPS 网站；
   在电脑任务中也可选择这些网页窗口。登录、验证步骤由你完成。

Ctrl + Alt + X 随时停止；手动输入、切换窗口会暂停。退出客户端后停止本机执行。
运行中的云端数据任务仍由服务器继续处理，以网站实际结果为准。
本版本不能跨多个窗口连续操作；更换目标窗口需要重新选择并允许。
电脑操作尚不代替文件系统工具，不会直接运行终端或脚本。

运行环境：.NET Framework 4.8、Microsoft Edge WebView2 Runtime。
若提示缺少网页运行环境，请通过客户端提供的微软官网链接安装后重试。
https://developer.microsoft.com/microsoft-edge/webview2/

网站功能随线上版本更新；桌面程序更新请在“电脑操作”下载新版，退出后解压到新目录。
客户端未配置代码签名；请通过本网站获得此包，不关闭或绕过系统安全检查。
登录信息保存在本机当前用户的 WebView2 配置目录，设备凭据使用 Windows 加密保护。
窗口截图仅在用户允许任务后发送到网站的智能服务，不保存截图文件。
来源代码在 source 目录，第三方组件许可在 licenses 目录。
